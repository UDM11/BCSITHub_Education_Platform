Unit 4: Micro Operations [3 Hours] - Detailed Study Guide

4.1 Register Transfer Language (RTL)

A digital system is composed of registers, and the data operations performed on contents of registers are called micro-operations. To specify the symbolic transfer sequences and execution constraints, we use a symbolic language called Register Transfer Language (RTL).

Basic RTL Notation Rules:

  • Registers: Represented by capital letters (e.g., AR, PC, R1). Individual bits can be specified inside parentheses (e.g., R1(0-7) for the low-order byte of R1).
  • Replacement/Transfer: Denoted by an arrow <-. The source is on the right, and the destination is on the left.
    Example: R2 <- R1 (Copies contents of R1 into R2).
  • Control Function: A conditional statement prefixing the transfer, separated by a colon :.
    Example: P: R2 <- R1 (If control variable P = 1, transfer contents of R1 to R2).
  • Comma Separator: Denotes micro-operations executed in parallel during the same clock cycle.
    Example: T: R2 <- R1, AR <- PC.

4.2 Arithmetic Micro Operations and Hardware Design

Arithmetic micro-operations operate on numeric data stored in registers. The fundamental arithmetic operations are: Addition, Subtraction, Increment, and Decrement.

Detailed Arithmetic Hardware Circuit:

A complete 4-bit Arithmetic Unit can be implemented using 4 Full Adders, 4 multiplexers, and XOR gates. The mode is selected using inputs S1 and S0 along with the carry input Cin:

S1 S0 Cin Input Y to Adder Output (D = A + Y + Cin) Arithmetic Operation
0 0 0 B D = A + B Add A and B
0 0 1 B D = A + B + 1 Add A and B with carry
0 1 0 B' D = A + B' Subtract B from A with borrow
0 1 1 B' D = A + B' + 1 Subtract B from A (2's complement)
1 0 0 0 D = A Transfer A
1 0 1 0 D = A + 1 Increment A by 1
1 1 0 -1 (all 1s) D = A - 1 Decrement A by 1
1 1 1 -1 (all 1s) D = A Transfer A

ASCII stages of Binary Adder-Subtractor:

[Mode Control M] | v Bi --------+ | | | v v +-------+ | XOR | +---+---+ | (Y bit input) Ai ----------+ | +--------- (Carry In Cin) | | | v v v +-----------------+ | Full Adder | +---+---------+---+ | | v v [Sum Si] [Carry Out Cout]

4.3 Logic Micro Operations and Practical Applications

Logic micro-operations treat each bit in a register independently (no carry is generated). They are used for bit-level manipulation.

Hardware Stage of Logic Unit:

A single stage of a logic unit is designed using a 4-to-1 multiplexer that selects between logical combinations of bits Ai and Bi:

Ai, Bi ----> [ AND gate ] ----> Input 0 (S1=0, S0=0) Ai, Bi ----> [ OR gate ] ----> Input 1 (S1=0, S0=1) +---------+ Ai, Bi ----> [ XOR gate ] ----> Input 2 (S1=1, S0=0) -| 4-to-1 |----> Output [Ei] Ai --------> [ NOT gate ] ----> Input 3 (S1=1, S0=1) | MUX | +----+----+ | Select lines (S1, S0)

Logic Applications with 8-Bit Examples:

Let Register A = 1010 1100 (Original Data).

  • 1. Selective Set: Force selected bits to 1. Uses the OR operation with a mask.
    Let Mask B = 1111 0000.
    A OR B = 1010 1100 OR 1111 0000 = 1111 1100 (first 4 bits set to 1, others unchanged).
  • 2. Selective Complement: Toggle/invert selected bits. Uses the XOR operation with a mask.
    Let Mask B = 1111 0000.
    A XOR B = 1010 1100 XOR 1111 0000 = 0101 1100 (first 4 bits inverted).
  • 3. Selective Clear: Force selected bits to 0. Uses the AND operation with a complemented mask.
    Let Mask B = 1111 0000.
    A AND B' = 1010 1100 AND 0000 1111 = 0000 1100 (first 4 bits cleared).
  • 4. Masking: Preserves selected bits while clearing others. Uses the AND operation.
    Let Mask B = 0000 1111.
    A AND B = 1010 1100 AND 0000 1111 = 0000 1100 (cleared first 4 bits, preserved last 4).
  • 5. Insert: Writes a new bit configuration into a register field.
    Step 1: Mask off current bits: A = A AND 0000 1111 = 0000 1100.
    Step 2: OR with new value (e.g., 0101): A = A OR 0101 0000 = 0101 1100.

4.4 Shift Micro Operations and Overflow Detection

Shift operations shift the bits of a register left or right. They are used for serial transfer and fast multiplication/division.

1. Logical Shifts:

Insert 0 into the serial input position.
Logical Shift Right (shr R1): 0 -> MSB...LSB -> Out
Logical Shift Left (shl R1): Out <- MSB...LSB <- 0

2. Circular Shifts (Rotate):

Bits shifted out are circulated back into the opposite end.
Circular Shift Right (cir R1): LSB is moved to MSB.
Circular Shift Left (cil R1): MSB is moved to LSB.

3. Arithmetic Shifts:

Shift signed numeric data.
Arithmetic Shift Right (ashr): Shifts data right but preserves the sign bit (MSB). This is equivalent to dividing the signed number by 2.
Arithmetic Shift Left (ashl): Shifts data left and inserts 0 into LSB. The sign bit (MSB) is replaced by bit D6.
Overflow Hazard: If the sign bit changes during an arithmetic left shift, an Arithmetic Overflow occurs.
Overflow Detector Logic: An overflow flip-flop V is set if the sign bit changes: V = Rn-1 XOR Rn-2 (where Rn-1 is the sign bit, and Rn-2 is the bit shifting into it).

4.5 Arithmetic Logic Shift Unit (ALSU) Stage

An ALSU combines arithmetic, logic, and shift stages into a single unit. Below is the selection logic table for a typical stage:

S3 S2 S1 S0 Cin Output Operation Selected
0 0 0 0 0 F = A + B (Addition)
0 0 0 1 1 F = A - B (Subtraction)
0 0 1 0 1 F = A + 1 (Increment)
0 1 0 0 X F = A AND B (Bitwise AND)
0 1 0 1 X F = A OR B (Bitwise OR)
0 1 1 0 X F = A XOR B (Bitwise XOR)
1 0 X X X F = shr A (Shift Right A)
1 1 X X X F = shl A (Shift Left A)
