Unit 2: Intel 8085 Microprocessor [8 Hours] - Comprehensive Guide

2.1 Functional Block Diagram and System Architecture

The Intel 8085 is a general-purpose, 8-bit microprocessor manufactured using NMOS technology. It is a 40-pin IC that operates on a single +5V DC power supply, has an internal clock frequency of 3 MHz, and addresses up to 64KB of memory.

1. Internal Registers:

  • Accumulator (A Register): An 8-bit register that acts as the primary destination for arithmetic, logical, and input/output data operations.
  • General-Purpose Registers (B, C, D, E, H, L): Six 8-bit registers. They can be operated as single registers or in 16-bit register pairs: BC, DE, and HL. The HL pair is also used as a memory pointer (M) that stores the 16-bit memory address.
  • Program Counter (PC): A 16-bit register that holds the memory address of the next instruction to be fetched.
  • Stack Pointer (SP): A 16-bit register that points to the top of the stack area in RAM memory.
  • Temporary Register and W/Z Registers: Used internally by the CPU for micro-operations; not accessible to programmers.

2. Flag Register (Flag Flip-Flops):

An 8-bit register containing five 1-bit status flags that are set (1) or reset (0) after arithmetic and logical operations:

Flag Byte Layout: +----+----+----+----+----+----+----+----+ | S | Z | X | AC | X | P | X | CY | +----+----+----+----+----+----+----+----+ D7 D6 D5 D4 D3 D2 D1 D0 Where: S=Sign, Z=Zero, AC=Auxiliary Carry, P=Parity, CY=Carry, X=Undefined

Mathematical Flag Example:

Let's add 0x9C (156) and 0x76 (118) in the Accumulator:


   0x9C =  1001 1100
 + 0x76 =  0111 0110
 -------------------
   Result= 0001 0010 (Hex 0x12, Dec 18) with Carry = 1
   
Flags set after this operation:
 - Sign Flag (S): 0 (Since the result bit D7 is 0, indicating positive).
 - Zero Flag (Z): 0 (Since the result is 0x12, not zero).
 - Carry Flag (CY): 1 (Since there was a carry out from D7).
 - Parity Flag (P): 0 (Result 00010010 has two 1s, which is even, so P = 1).
 - Auxiliary Carry (AC): 1 (Carry generated from bit D3 to D4: 1100 + 0110 yields carry out of bit D3).

3. Timing and Control Unit:

Generates control and synchronization signals for execution. It includes status indicators S0, S1, IO/M' to identify machine cycle types:

IO/M' S1 S0 Machine Cycle Type Active Control Signal
0 1 1 Opcode Fetch RD' = 0
0 1 0 Memory Read RD' = 0
0 0 1 Memory Write WR' = 0
1 1 0 I/O Port Read RD' = 0
1 0 1 I/O Port Write WR' = 0

4. Interrupt Control Block:

Provides hardware interrupt lines sorted in priority order:

  • TRAP: Non-maskable, vectored (0024H), highest priority. Triggered by edge-and-level.
  • RST 7.5: Maskable, vectored (003CH), priority 2. Edge-triggered.
  • RST 6.5: Maskable, vectored (0034H), priority 3. Level-triggered.
  • RST 5.5: Maskable, vectored (002CH), priority 4. Level-triggered.
  • INTR: Maskable, non-vectored, priority 5. Level-triggered. Requires externally supplied restart opcode.

5. Serial I/O Control (SIM & RIM):

Uses SID (Serial Input Data) and SOD (Serial Output Data) pins. They are controlled by the SIM (Set Interrupt Mask) and RIM (Read Interrupt Mask) instructions.

2.2 Pin Configuration and Multiplexed Bus Demultiplexing

The 8085 IC has 40 pins. To reduce pin counts, the lower-order address bus (A0-A7) is multiplexed with the data bus (D0-D7) into AD0-AD7.

40-Pin Classification:

  1. Address Bus (A8-A15): Pins 21-28. High-order 8 bits of the memory address.
  2. Address/Data Bus (AD0-AD7): Pins 12-19. Multiplexed lower address/data.
  3. Control & Status: ALE (Pin 30), RD' (Pin 32), WR' (Pin 31), IO/M' (Pin 34), S0 (Pin 29), S1 (Pin 33).
  4. Interrupts: TRAP (Pin 6), RST 7.5 (Pin 7), RST 6.5 (Pin 8), RST 5.5 (Pin 9), INTR (Pin 10), INTA' (Pin 11).
  5. DMA: HOLD (Pin 39), HLDA (Pin 38).
  6. Serial I/O: SID (Pin 5), SOD (Pin 4).
  7. Clock & Power: X1, X2 (Pins 1, 2 - crystal input), CLK OUT (Pin 37), RESET IN' (Pin 36), RESET OUT (Pin 3), Vcc (Pin 40, +5V), Vss (Pin 20, Ground).

Demultiplexing the Bus (ALE & Latch Logic):

During the first T-state (T1) of a machine cycle, the CPU outputs the lower 8 bits of address on AD0-AD7 and sets the ALE (Address Latch Enable) pin to 1. This pulse triggers a 74LS373 Octal Latch to store the address bits. For the remaining T-states (T2-T4), the ALE drops to 0, allowing AD0-AD7 to be used for bidirectional data transfer while the latch maintains the lower address lines.

+---------------+ | |---- A8-A15 -----------------------> High Address Bus (A8-A15) | | | 8085 CPU |---- AD0-AD7 ----+ | | | | | v [D-Inputs] | | +---------+ | | | 74LS373 |------------> Low Address Bus (A0-A7) | ALE |------------| Latch | [Q-Outputs] +---------------+ +---------+ | (ALE Latch Enable) v [Data lines split from AD0-AD7 bypass latch to data bus directly]

2.3 Instruction Classification and Addressing Modes

The 8085 instruction set includes 74 instructions with 246 different opcodes. They are classified into 5 categories:

Instruction Categories:

  • Data Transfer: Copies data from a source to a destination.
    Examples: MOV A, B, MVI A, 32H, LDA 2050H, STA 3000H, LXI H, 4000H.
  • Arithmetic: Performs mathematical operations.
    Examples: ADD B, ADI 05H, SUB C, INR A, INX H, DAD B.
  • Logical: Performs bitwise logical operations.
    Examples: ANA B, ANI F0H, ORA C, XRA A, CMA, RLC.
  • Branching: Alters program flow conditionally or unconditionally.
    Examples: JMP 2000H, JZ 2500H, CALL 3000H, RET.
  • Machine Control: Controls execution state.
    Examples: NOP, HLT, EI, DI.

Addressing Modes:

  1. Immediate Addressing: Data operand is specified directly in instruction. (e.g., MVI A, 45H).
  2. Register Addressing: Operands are general-purpose registers. (e.g., ADD B).
  3. Direct Addressing: The 16-bit address of data is directly stated. (e.g., LDA 2500H).
  4. Register Indirect Addressing: The HL register pair points to the memory location of data. (e.g., MOV A, M).
  5. Implied Addressing: The operand is implicit in the instruction opcode. (e.g., CMA).

2.4 Assembly Language Programming Examples

Here are detailed, structured assembly programs for the Intel 8085 processor.

Example 1: Bubble Sort Algorithm (Ascending Order)

Sorts an array starting at memory address 3000H. The first byte contains the array count.


START:  LDA 3000H     ; Load array count into Accumulator
        MOV C, A      ; Outer loop counter = array count
        DCR C         ; Decrement outer loop count (N - 1 passes)
PASS:   LXI H, 3001H  ; Initialize memory pointer to first element
        MOV B, C      ; Inner loop counter = Outer loop counter
LOOP:   MOV A, M      ; Get current element
        INX H         ; Move pointer to next element
        CMP M         ; Compare current element with next element
        JC SKIP       ; If current < next, skip swapping
        JZ SKIP       ; If equal, skip swapping
        ; SWAP DATA IN MEMORY
        MOV D, M      ; Load next element to D
        MOV M, A      ; Write current element to next position
        DCX H         ; Point back to current position
        MOV M, D      ; Write next element (D) to current position
        INX H         ; Restore pointer to next position
SKIP:   DCR B         ; Decrement inner loop counter
        JNZ LOOP      ; If inner loop != 0, repeat comparison
        DCR C         ; Decrement outer loop counter
        JNZ PASS      ; If outer loop != 0, perform next pass
        HLT           ; Terminate program

Bubble Sort Execution Trace Table:

Assume array stored at 3001H-3003H is [09H, 02H, 05H] (Count at 3000H = 03H):

Pass Outer Counter (C) Inner Counter (B) Pointer (HL) Compare values Action Array State
Pass 1 02 02 3001H [3001H]=09H vs [3002H]=02H Swap (09 > 02) [02H, 09H, 05H]
Pass 1 02 01 3002H [3002H]=09H vs [3003H]=05H Swap (09 > 05) [02H, 05H, 09H]
Pass 2 01 01 3001H [3001H]=02H vs [3002H]=05H Skip (02 < 05) [02H, 05H, 09H]

Example 2: 16-Bit Division

Divide 16-bit dividend at 2500H-2501H by 8-bit divisor at 2502H. Store quotient at 2503H and remainder at 2504H.


LHLD 2500H    ; Load 16-bit dividend into HL register pair
LDA 2502H     ; Load 8-bit divisor into register A
MOV C, A      ; Move divisor to register C
MVI B, 00H    ; Initialize quotient register B to 00H
MOV A, H      ; Get high-byte of dividend

DIV_HIGH:
        CMP C         ; Compare High byte with divisor
        JC DIV_LOW    ; If High byte < divisor, check low-byte
        SUB C         ; Subtract divisor from High byte
        INR B         ; Increment quotient count
        JMP DIV_HIGH  ; Loop high subtraction

DIV_LOW:
        MOV H, A      ; Restore remainder to High byte position
        MOV A, L      ; Get Low byte of dividend
        LXI D, 0008H  ; Load bit counter (8 bits)

LOOP_DIV:
        DAD H         ; Shift HL left by 1 bit (Rotate dividend)
        RAL           ; Shift accumulator left
        SUB C         ; Subtract divisor
        JNC SET_Q     ; If no borrow, quotient bit is 1
        ADD C         ; Else, restore divisor
        JMP DEC_COUNT
SET_Q:  INR L         ; Set quotient LSB to 1
DEC_COUNT:
        DCX D
        MOV A, D
        ORA E
        JNZ LOOP_DIV
        SHLD 2503H    ; Save quotient in 2503H (L) and remainder in 2504H (H)
        HLT
