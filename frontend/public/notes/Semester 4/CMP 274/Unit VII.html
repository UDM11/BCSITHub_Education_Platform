7.1 Classification of Second-Order Linear PDEs

A partial differential equation (PDE) relates multi-variable functions to their partial derivatives. A linear second-order PDE in two independent variables is written as:


A*(∂^2u/∂x^2) + B*(∂^2u/∂x∂y) + C*(∂^2u/∂y^2) + D*(∂u/∂x) + E*(∂u/∂y) + F*u = G

Using the discriminant B^2 - 4*A*C, we classify these equations into three categories:

  • Elliptic (B^2 - 4*A*C < 0): Steady-state physical equilibria. Examples: Laplace and Poisson equations.
  • Parabolic (B^2 - 4*A*C == 0): Diffusion processes. Example: Heat equation.
  • Hyperbolic (B^2 - 4*A*C > 0): Vibrational systems. Example: Wave equation.

7.2 Derivation of Finite Difference Approximations

Using Taylor expansions around the grid node (x_i, y_j) with step sizes h = Δx and k = Δy, we approximate the partial derivatives:


1) u(x+h, y) = u(x,y) + h*(∂u/∂x) + (h^2/2)*(∂^2u/∂x^2) + (h^3/6)*(∂^3u/∂x^3) + ...
2) u(x-h, y) = u(x,y) - h*(∂u/∂x) + (h^2/2)*(∂^2u/∂x^2) - (h^3/6)*(∂^3u/∂x^3) + ...

Adding equation 1 and equation 2:
u(x+h, y) + u(x-h, y) = 2*u(x,y) + h^2*(∂^2u/∂x^2) + O(h^4)

Rearranging for the second-order partial derivative yields the central difference formula:
∂^2u/∂x^2 ≈ [ u_i+1,j - 2*u_i,j + u_i-1,j ] / h^2

Similarly for the y-direction:
∂^2u/∂y^2 ≈ [ u_i,j+1 - 2*u_i,j + u_i,j-1 ] / k^2

7.3 Laplace's Equation & Liebmann's Iteration

Laplace's equation in 2D is: ∂^2u/∂x^2 + ∂^2u/∂y^2 = 0.
Assuming a square grid (h = k), substituting the central difference approximations yields the **Standard Five-Point Formula (SFPF)**:
u_i,j = (1/4) * [ u_i+1,j + u_i-1,j + u_i,j+1 + u_i,j-1 ]

Liebmann's Iteration C Implementation:

The following C program solves Laplace's equation on a 4x4 grid with specified boundary conditions using Liebmann's method:


#include <stdio.h>
#include <math.h>

#define SIZE 4 // 4x4 Grid (2x2 interior nodes, 12 boundary nodes)

void liebmann_laplace(double grid[SIZE][SIZE], double tol) {
    int max_iter = 100;
    int converged = 0;
    
    printf("\nLiebmann Iterations for Laplace Equation:\n");
    for (int step = 1; step <= max_iter; step++) {
        double max_diff = 0.0;
        
        // Update interior nodes only (rows 1 to SIZE-2, cols 1 to SIZE-2)
        for (int i = 1; i < SIZE - 1; i++) {
            for (int j = 1; j < SIZE - 1; j++) {
                double old_val = grid[i][j];
                // SFPF: average of 4 orthogonal neighbors
                grid[i][j] = 0.25 * (grid[i+1][j] + grid[i-1][j] + grid[i][j+1] + grid[i][j-1]);
                
                double diff = fabs(grid[i][j] - old_val);
                if (diff > max_diff) {
                    max_diff = diff;
                }
            }
        }
        
        printf("Iteration %2d: Max change = %lf\n", step, max_diff);
        if (max_diff < tol) {
            printf("\nLiebmann converged in %d iterations.\n", step);
            converged = 1;
            break;
        }
    }
    
    if (!converged) {
        printf("\nLiebmann reached max iterations without full convergence.\n");
    }
    
    // Print final grid values
    printf("\nFinal Grid Values:\n");
    for (int i = 0; i < SIZE; i++) {
        for (int j = 0; j < SIZE; j++) {
            printf("%7.2f ", grid[i][j]);
        }
        printf("\n");
    }
}

int main() {
    // Initialize 4x4 grid with boundary conditions
    // Interior nodes are initialized to 0.0
    double grid[SIZE][SIZE] = {
        {100.0, 100.0, 100.0, 100.0}, // Top boundary
        { 75.0,   0.0,   0.0,  50.0}, // Left / Right boundary
        { 75.0,   0.0,   0.0,  50.0}, // Left / Right boundary
        {  0.0,   0.0,   0.0,   0.0}  // Bottom boundary
    };
    liebmann_laplace(grid, 0.001);
    return 0;
}

7.4 Poisson's Equation

Poisson's equation is: ∂^2u/∂x^2 + ∂^2u/∂y^2 = f(x, y).
For a square grid (h = k), substituting the central difference approximations yields the finite difference equation:
u_i+1,j + u_i-1,j + u_i,j+1 + u_i,j-1 - 4*u_i,j = h^2 * f(x_i, y_j)

Poisson Equation Solver C Implementation:


#include <stdio.h>
#include <math.h>

#define SIZE 4

// Define function f(x, y) = -10 * (x^2 + y^2 + 10)
double f_source(double x, double y) {
    return -10.0 * (x*x + y*y + 10.0);
}

void solve_poisson(double grid[SIZE][SIZE], double h, double tol) {
    int max_iter = 100;
    double x_vals[SIZE] = {0.0, 0.5, 1.0, 1.5};
    double y_vals[SIZE] = {0.0, 0.5, 1.0, 1.5};
    
    printf("\nIterative Solver for Poisson Equation:\n");
    for (int step = 1; step <= max_iter; step++) {
        double max_diff = 0.0;
        
        for (int i = 1; i < SIZE - 1; i++) {
            for (int j = 1; j < SIZE - 1; j++) {
                double old_val = grid[i][j];
                
                // Poisson finite difference:
                // u_i,j = 0.25 * (u_i+1,j + u_i-1,j + u_i,j+1 + u_i,j-1 - h^2 * f(x_i, y_j))
                double source_term = h * h * f_source(x_vals[i], y_vals[j]);
                grid[i][j] = 0.25 * (grid[i+1][j] + grid[i-1][j] + grid[i][j+1] + grid[i][j-1] - source_term);
                
                double diff = fabs(grid[i][j] - old_val);
                if (diff > max_diff) {
                    max_diff = diff;
                }
            }
        }
        
        if (max_diff < tol) {
            printf("Converged in %d iterations.\n", step);
            break;
        }
    }
    
    // Print final grid values
    printf("\nFinal Poisson Grid:\n");
    for (int i = 0; i < SIZE; i++) {
        for (int j = 0; j < SIZE; j++) {
            printf("%7.2f ", grid[i][j]);
        }
        printf("\n");
    }
}

int main() {
    double grid[SIZE][SIZE] = {0.0}; // Boundary conditions set to 0.0
    double h = 0.5; // Step size
    solve_poisson(grid, h, 0.001);
    return 0;
}

7.5 Parabolic equations (1D Heat Equation)

The 1D Heat Equation represents diffusion systems: ∂u/∂t = c^2 * ∂^2u/∂x^2.
We solve this equation over a grid where x_i = i*h (space step) and t_j = j*k (time step).

1. Schmidt Explicit Method:

Using forward difference for time derivative and central difference for space derivative:
[ u_i,j+1 - u_i,j ] / k = c^2 * [ u_i+1,j - 2*u_i,j + u_i-1,j ] / h^2

Let r = c^2 * k / h^2. The explicit relation is:
u_i,j+1 = r*u_i-1,j + (1 - 2*r)*u_i,j + r*u_i+1,j

Stability Condition: The explicit scheme converges stable only if r <= 0.5.
If we choose r = 0.5 (Schmidt Simplification):
u_i,j+1 = 0.5 * ( u_i-1,j + u_i+1,j )

1D Heat Equation Explicit Solver C Implementation:


#include <stdio.h>

#define NX 5 // Number of space steps
#define NT 5 // Number of time steps

void solve_heat_explicit() {
    double u[NX][NT] = {0.0};
    double h = 0.2;
    double k = 0.02;
    double c2 = 1.0;
    double r = c2 * k / (h * h); // r = 0.5
    
    // Boundary conditions:
    // u(0, t) = 0.0, u(1, t) = 0.0
    // Initial condition: u(x, 0) = sin(pi * x)
    double pi = 3.14159265;
    for (int i = 0; i < NX; i++) {
        u[i][0] = sin(pi * i * h);
    }
    
    // Perform explicit time step updates
    for (int j = 0; j < NT - 1; j++) {
        for (int i = 1; i < NX - 1; i++) {
            u[i][j+1] = r * u[i-1][j] + (1.0 - 2.0 * r) * u[i][j] + r * u[i+1][j];
        }
    }
    
    printf("\nExplicit 1D Heat Equation Solution Matrix [u(x,t)]:\n");
    printf("   x=0.0    x=0.2    x=0.4    x=0.6    x=0.8    x=1.0\n");
    for (int j = 0; j < NT; j++) {
        printf("t=%4.2f: ", j * k);
        for (int i = 0; i < NX; i++) {
            printf("%7.4f  ", u[i][j]);
        }
        printf("\n");
    }
}

int main() {
    solve_heat_explicit();
    return 0;
}

7.6 Hyperbolic equations (1D Wave Equation)

The 1D Wave Equation represents vibrating string systems: ∂^2u/∂t^2 = c^2 * ∂^2u/∂x^2.
Using central differences for both time and space derivatives:
[ u_i,j+1 - 2*u_i,j + u_i,j-1 ] / k^2 = c^2 * [ u_i+1,j - 2*u_i,j + u_i-1,j ] / h^2

Letting r = c * k / h. The explicit relation is:
u_i,j+1 = 2*(1 - r^2)*u_i,j + r^2*( u_i+1,j + u_i-1,j ) - u_i,j-1

If we choose r = 1 (simplification):
u_i,j+1 = u_i+1,j + u_i-1,j - u_i,j-1

1D Wave Equation Explicit Solver C Implementation:


#include <stdio.h>

#define NX 6
#define NT 4

void solve_wave_explicit() {
    double u[NX][NT] = {0.0};
    double h = 0.2;
    double k = 0.2;
    double c = 1.0;
    double r = c * k / h; // r = 1.0
    
    // Boundary conditions:
    // u(0, t) = 0.0, u(1, t) = 0.0
    // Initial displacement: u(x, 0) = x * (1 - x)
    for (int i = 0; i < NX; i++) {
        double x = i * h;
        u[i][0] = x * (1.0 - x);
    }
    
    // Initial velocity condition: du/dt = 0 at t = 0
    // Yields: u_i,1 = 0.5 * r^2 * (u_i-1,0 + u_i+1,0) + (1 - r^2)*u_i,0
    for (int i = 1; i < NX - 1; i++) {
        u[i][1] = 0.5 * (u[i-1][0] + u[i+1][0]);
    }
    
    // Explicit calculations for remaining time levels
    for (int j = 1; j < NT - 1; j++) {
        for (int i = 1; i < NX - 1; i++) {
            u[i][j+1] = u[i+1][j] + u[i-1][j] - u[i][j-1];
        }
    }
    
    printf("\nExplicit 1D Wave Equation Solution Matrix [u(x,t)]:\n");
    for (int j = 0; j < NT; j++) {
        printf("t=%4.2f: ", j * k);
        for (int i = 0; i < NX; i++) {
            printf("%7.4f  ", u[i][j]);
        }
        printf("\n");
    }
}

int main() {
    solve_wave_explicit();
    return 0;
}
