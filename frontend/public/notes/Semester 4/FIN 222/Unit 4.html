Unit 4: Fundamentals of Risk and Return [7 Hrs.]

4.1 Concept of Risk and Return (Individual Assets)

Basic Definitions

  • Return: The financial gain or loss on an investment over a specific period. It is usually expressed as a percentage of the initial investment.
  • Risk: The variability or uncertainty of the actual returns relative to the expected return. An investment is considered riskier if it has a wider range of possible returns.

Expected Rate of Return ($\hat{r}$)

The weighted average of all possible returns, where the weights are the probabilities of occurrence:

$$\hat{r} = \sum_{i=1}^n P_i \times r_i$$ Where $P_i$ is the probability of state $i$ and $r_i$ is the return in state $i$.

Variance ($\sigma^2$) and Standard Deviation ($\sigma$)

Measure the absolute dispersion of returns around the expected value. Standard deviation is the square root of variance:

$$\text{Variance } (\sigma^2) = \sum_{i=1}^n P_i \times (r_i - \hat{r})^2$$ $$\text{Standard Deviation } (\sigma) = \sqrt{\sigma^2}$$

Coefficient of Variation (CV)

Measures relative risk per unit of return. Useful when comparing assets with different expected returns:

$$CV = \frac{\sigma}{\hat{r}}$$ Rule: Prefer the asset with the lower CV (less risk per unit of return).

4.2 Systematic vs. Unsystematic Risk and Portfolio Diversification

Types of Risk

  • Unsystematic (Diversifiable / Unique) Risk: Company-specific risk (e.g., strikes, lawsuits, bad management, product recalls). This risk can be completely eliminated by holding a well-diversified portfolio.
  • Systematic (Non-Diversifiable / Market) Risk: Economy-wide risk affecting all companies (e.g., inflation, GDP contraction, changes in interest rates, wars). This risk cannot be eliminated through diversification.

The Portfolio Diversification Effect

  Total Portfolio Risk (Standard Deviation)
    ▲
    │ \
    │  \   Unsystematic Risk (Diversifiable)
    │   \
    │────└───► Systematic Risk (Non-diversifiable)
    │
    └───────────────────────────────────────► Number of Stocks
      0         10        20        30

As the number of stocks in a portfolio increases, the unsystematic risk drops rapidly, leaving only systematic market risk (usually achieved with 30-40 stocks).

Measuring Systematic Risk: Beta ($\beta$)

Beta ($\beta$) measures the sensitivity of a stock's return relative to the overall market return:

  • $\beta = 1.0$: Stock has average risk (moves exactly with the market).
  • $\beta > 1.0$: Stock is more volatile than the market (aggressive stock, e.g., tech start-up).
  • $\beta < 1.0$: Stock is less volatile than the market (defensive stock, e.g., utility company).
  • $\beta = 0.0$: Risk-free asset (e.g., government treasury bill).

4.3 Portfolio Risk and Return

Portfolio Expected Return ($r_p$)

The weighted average of the expected returns of the individual assets in the portfolio:

$$r_p = \sum_{j=1}^k w_j \times \hat{r}_j$$ Where $w_j$ is the weight of asset $j$ in the portfolio.

Portfolio Beta ($\beta_p$)

The weighted average of individual asset betas:

$$\beta_p = \sum_{j=1}^k w_j \times \beta_j$$

Portfolio Risk (Standard Deviation $\sigma_p$)

For a 2-asset portfolio, risk depends on the correlation ($\rho_{AB}$) between the two assets:

$$\sigma_p = \sqrt{w_A^2 \sigma_A^2 + w_B^2 \sigma_B^2 + 2 w_A w_B \sigma_A \sigma_B \rho_{AB}}$$ Where $\rho_{AB}$ is the correlation coefficient between asset A and asset B.

Role of Correlation Coefficient ($\rho$) in Diversification

  • Perfect Positive Correlation ($\rho = +1.0$): No risk reduction is achieved. Risk is a simple weighted average.
  • No Correlation ($\rho = 0.0$): Significant risk reduction is achieved.
  • Perfect Negative Correlation ($\rho = -1.0$): Risk can be completely eliminated to zero.

4.4 Capital Asset Pricing Model (CAPM) and SML

The CAPM Equation

The **Capital Asset Pricing Model (CAPM)** defines the required rate of return for an individual asset based on its systematic risk ($\beta$):

$$r_i = r_{RF} + (r_M - r_{RF}) \times \beta_i$$ Where:
- $r_i$ = Required rate of return on stock $i$.
- $r_{RF}$ = Risk-free rate of return (e.g., T-bills).
- $r_M$ = Expected return on the market portfolio.
- $(r_M - r_{RF})$ = **Market Risk Premium (MRP)**.
- $(r_M - r_{RF}) \times \beta_i$ = **Stock Risk Premium**.

The Security Market Line (SML)

The SML is the graphical representation of the CAPM, plotting required returns against beta: 

  Required Return (%)
    ▲
    │               / SML (Security Market Line)
    │              /
 rM │─────────────o  (Market Portfolio: Beta = 1.0)
    │            /
rRF │───────────/
    │          /
    └──────────┴─────────────────────────► Risk (Beta)
    0         1.0

4.5 Worked Numerical Example

Risk and Return Calculations

Problem: You are analyzing two stocks, Stock A and Stock B, with the following probability distributions:
- State 1 (Recession, P=0.2): Return A = -5%, Return B = 5%
- State 2 (Normal, P=0.6): Return A = 12%, Return B = 10%
- State 3 (Boom, P=0.2): Return A = 25%, Return B = 15%
1. Calculate the expected return ($\hat{r}$), standard deviation ($\sigma$), and CV for both stocks.
2. Find the expected return of a portfolio consisting of 60% Stock A and 40% Stock B.
3. If the risk-free rate is 5% and the market return is 11%, calculate the required return for a stock with Beta = 1.5 using CAPM.

Solution:

1. Stock A expected return ($\hat{r}_A$):
$\hat{r}_A = 0.2 \times (-5\%) + 0.6 \times (12\%) + 0.2 \times (25\%) = -1\% + 7.2\% + 5\% = 11.2\%$.

Stock A variance ($\sigma_A^2$):
$\sigma_A^2 = 0.2 \times (-5 - 11.2)^2 + 0.6 \times (12 - 11.2)^2 + 0.2 \times (25 - 11.2)^2$
$\sigma_A^2 = 0.2 \times (262.44) + 0.6 \times (0.64) + 0.2 \times (190.44)$
$\sigma_A^2 = 52.488 + 0.384 + 38.088 = 90.96$.
$\text{Standard Deviation } \sigma_A = \sqrt{90.96} \approx 9.54\%$.
$\text{Coefficient of Variation } CV_A = 9.54 / 11.2 \approx 0.85$.

2. Stock B expected return ($\hat{r}_B$):
$\hat{r}_B = 0.2 \times (5\%) + 0.6 \times (10\%) + 0.2 \times (15\%) = 1\% + 6\% + 3\% = 10\%$.

Stock B variance ($\sigma_B^2$):
$\sigma_B^2 = 0.2 \times (5 - 10)^2 + 0.6 \times (10 - 10)^2 + 0.2 \times (15 - 10)^2$
$\sigma_B^2 = 0.2 \times (25) + 0.6 \times (0) + 0.2 \times (25) = 5 + 0 + 5 = 10$.
$\text{Standard Deviation } \sigma_B = \sqrt{10} \approx 3.16\%$.
$\text{Coefficient of Variation } CV_B = 3.16 / 10 \approx 0.32$.

3. Portfolio Return ($r_p$):
$r_p = w_A \hat{r}_A + w_B \hat{r}_B = 0.6 \times (11.2\%) + 0.4 \times (10\%) = 6.72\% + 4.0\% = 10.72\%$.

4. CAPM Required Return ($r_i$):
$r_i = r_{RF} + (r_M - r_{RF}) \times \beta = 5\% + (11\% - 5\%) \times 1.5 = 5\% + 6\% \times 1.5 = 5\% + 9\% = 14\%$.

4.6 Behavioral Finance Overview

While classical finance assumes that investors are rational wealth maximizers, **Behavioral Finance** argues that psychology affects investment decisions. Common investor biases include:

  • Loss Aversion: The tendency for individuals to strongly prefer avoiding losses over acquiring gains. Studies show that the pain of losing $100 is twice as intense as the pleasure of gaining $100.
  • Overconfidence: Investors overestimate their ability to predict market shifts, leading to excessive trading.
  • Herding Behavior: Following the crowd or copying other investors' actions (explains market bubbles and crashes).
  • Anchoring: Relying too heavily on initial pieces of information (like a purchase price) when making decisions.

4.7 Detailed Portfolio Risk Analysis (Covariance & Correlation)

To find the standard deviation of a multi-asset portfolio, we must account for the interaction between asset returns. This interaction is measured using Covariance and the Correlation Coefficient:

Worked Example: Covariance and Portfolio Risk Calculation

Problem: Using the probability distribution from Section 4.5:
- State 1 (Recession, P=0.2): Return A = -5%, Return B = 5%
- State 2 (Normal, P=0.6): Return A = 12%, Return B = 10%
- State 3 (Boom, P=0.2): Return A = 25%, Return B = 15%
Expected Returns: $\hat{r}_A = 11.2\%$, $\hat{r}_B = 10.0\%$.
Standard Deviations: $\sigma_A = 9.54\%$, $\sigma_B = 3.16\%$.
1. Calculate Covariance between Stock A and Stock B.
2. Calculate the Correlation Coefficient ($\rho_{AB}$).
3. Compute the portfolio standard deviation ($\sigma_p$) for a 60% Stock A and 40% Stock B portfolio.

Solution:

1. Compute Covariance ($Cov_{AB}$):
$$Cov_{AB} = \sum P_i \times (r_{Ai} - \hat{r}_A) \times (r_{Bi} - \hat{r}_B)$$
- State 1: $0.2 \times (-5 - 11.2) \times (5 - 10) = 0.2 \times (-16.2) \times (-5) = 0.2 \times (81) = 16.2$
- State 2: $0.6 \times (12 - 11.2) \times (10 - 10) = 0.6 \times (0.8) \times (0) = 0$
- State 3: $0.2 \times (25 - 11.2) \times (15 - 10) = 0.2 \times (13.8) \times (5) = 0.2 \times (69) = 13.8$
$Cov_{AB} = 16.2 + 0 + 13.8 = 30.0$.

2. Compute Correlation Coefficient ($\rho_{AB}$):
$$\rho_{AB} = \frac{Cov_{AB}}{\sigma_A \times \sigma_B} = \frac{30.0}{9.54 \times 3.16} = \frac{30.0}{30.1464} \approx 0.995$$
This indicates that the two stocks are very highly positively correlated (virtually move together), meaning diversification benefits will be minimal.

3. Compute Portfolio Risk ($\sigma_p$):
$$\sigma_p = \sqrt{w_A^2 \sigma_A^2 + w_B^2 \sigma_B^2 + 2 w_A w_B Cov_{AB}}$$
$\sigma_p = \sqrt{(0.6)^2(90.96) + (0.4)^2(10) + 2(0.6)(0.4)(30.0)}$
$\sigma_p = \sqrt{0.36(90.96) + 0.16(10) + 0.48(30.0)}$
$\sigma_p = \sqrt{32.7456 + 1.6 + 14.4} = \sqrt{48.7456} \approx 6.98\%$.
The portfolio standard deviation is 6.98%.

4.9 Stock Evaluation and Security Alpha

Investors use CAPM to evaluate whether a stock is a good buy. They compare the stock's Estimated Return ($\hat{r}$) (from financial analysts) with its **Required Return ($r$)** (from CAPM):

  • Alpha ($\alpha$): The difference between estimated return and required return:
    $$\alpha = \text{Estimated Return} - \text{Required Return}$$
  • Underpriced Stock (Buy Signal): If $\alpha > 0$. The stock is expected to return more than its risk warrants. The stock plots **above the SML**.
  • Overpriced Stock (Sell/Short Signal): If $\alpha < 0$. The stock is expected to return less than its risk warrants. The stock plots **below the SML**.
  • Fairly Priced Stock: If $\alpha = 0$. The stock plots **on the SML**.

4.10 Historical Returns and Sample Risk Calculations

When analyzing historical asset data rather than forward-looking probability states, we use sample average and sample standard deviation:

  • Sample Mean Return ($\bar{r}$):
    $$\bar{r} = \frac{\sum_{t=1}^n r_t}{n}$$
  • Sample Standard Deviation ($S$): Uses $n-1$ in the denominator to ensure an unbiased estimator:
    $$S = \sqrt{\frac{\sum_{t=1}^n (r_t - \bar{r})^2}{n - 1}}$$

Worked Example: Historical Data analysis

Problem: Stock X recorded the following annual returns over the last 4 years: Year 1: 10%, Year 2: 15%, Year 3: -5%, Year 4: 20%. Calculate the sample mean and sample standard deviation.

Solution:
1. Calculate Mean ($\bar{r}$):
$$\bar{r} = \frac{10 + 15 - 5 + 20}{4} = \frac{40}{4} = 10.0\%$$
2. Calculate Variance Numerator:
- $(r_1 - \bar{r})^2 = (10 - 10)^2 = 0$
- $(r_2 - \bar{r})^2 = (15 - 10)^2 = 25$
- $(r_3 - \bar{r})^2 = (-5 - 10)^2 = 225$
- $(r_4 - \bar{r})^2 = (20 - 10)^2 = 100$
Sum of Squared Deviations = $0 + 25 + 225 + 100 = 350$.

3. Compute Sample Standard Deviation ($S$):
$$S = \sqrt{\frac{350}{4 - 1}} = \sqrt{\frac{350}{3}} = \sqrt{116.67} \approx 10.80\%$$

4.11 Mathematical Derivation of Beta ($\beta$)

A stock's Beta represents its systematic covariance with the market, scaled by the market's own variance:
$$\beta_i = \frac{Cov(i, M)}{\sigma_M^2} = \rho_{iM} \times \frac{\sigma_i}{\sigma_M}$$ Where $Cov(i, M)$ is the covariance of stock $i$ with the market, $\sigma_M^2$ is market variance, and $\rho_{iM}$ is the correlation between the stock and the market.

Worked Example: Beta Calculation

Problem: Stock Y has a standard deviation of 15%. The market portfolio has a standard deviation of 10%. The correlation between Stock Y and the market is 0.80. Calculate the stock's Beta.

Solution:
$$\beta_Y = \rho_{YM} \times \frac{\sigma_Y}{\sigma_M} = 0.80 \times \frac{15\%}{10\%} = 0.80 \times 1.5 = 1.20$$
Stock Y is 20% more volatile than the market.

4.12 Beyond CAPM: The Fama-French Three-Factor Model

Although CAPM is widely used, empirical studies show that a single factor (Beta) does not fully explain stock returns. To address this, Eugene Fama and Kenneth French introduced the **Three-Factor Model**, which adds size and book-to-market factors:

$$r_i = r_{RF} + b_i(r_M - r_{RF}) + s_i(\text{SMB}) + h_i(\text{HML})$$ Where:
- **SMB (Small Minus Big):** Represents the historical return premium of small-cap stocks over large-cap stocks.
- **HML (High Minus Low):** Represents the historical return premium of high book-to-market (value) stocks over low book-to-market (growth) stocks.
- $b_i, s_i, h_i$ are the factor loadings (sensitivities) of the asset.

4.13 The Efficient Frontier and Sharpe Ratio

Markowitz Modern Portfolio Theory (MPT) outlines how rational investors construct optimal portfolios:

  • Portfolio Opportunity Set: The collection of all possible risk-return combinations that can be created by combining risky assets in various weights.
  • Efficient Frontier: The upper boundary of the opportunity set. It contains the portfolios that provide the highest possible expected return for a given level of standard deviation (risk).
  • The Sharpe Ratio: Measures the excess return per unit of total risk in a portfolio:
    $$\text{Sharpe Ratio} = \frac{r_p - r_{RF}}{\sigma_p}$$ Investors seek to select the portfolio on the efficient frontier that maximizes the Sharpe Ratio (the **Tangency Portfolio**).

4.14 Capital Market Line (CML) Calculations

When we introduce a risk-free asset, the efficient frontier becomes a straight line starting from $r_{RF}$ and passing through the tangency market portfolio. This is the **CML**:
$$r_p = r_{RF} + \left[ \frac{r_M - r_{RF}}{\sigma_M} \right] \times \sigma_p$$ Where the term in brackets is the market price of risk (Sharpe Ratio of the market).

Worked Example: CML Calculation

Problem: You are constructing an efficient portfolio. The risk-free rate is 4%, and the market portfolio has an expected return of 10% with a standard deviation of 12%. If you want your efficient portfolio to have a standard deviation of 8%, calculate its expected return using the CML.

Solution:
$$r_p = r_{RF} + \left[ \frac{r_M - r_{RF}}{\sigma_M} \right] \times \sigma_p$$
$$r_p = 4\% + \left[ \frac{10\% - 4\%}{12\%} \right] \times 8\%$$
$$r_p = 4\% + \left[ \frac{6\%}{12\%} \right] \times 8\% = 4\% + 0.5 \times 8\% = 4\% + 4\% = 8.0\%$$
The expected return of the efficient portfolio is 8.0%.

4.15 CAPM Assumptions and Real-World Limitations

The Capital Asset Pricing Model is built upon several strict theoretical assumptions:

  • Theoretical Assumptions:
    1. *Homogeneous Expectations:* All investors have access to the same information and agree on the expected returns, standard deviations, and covariances of all assets.
    2. *Risk-Free Borrowing/Lending:* All investors can borrow and lend unlimited sums at the risk-free rate.
    3. *No Market Friction:* There are no taxes, no transaction costs, and no restrictions on short-selling.
    4. *Price Takers:* No single investor is large enough to influence stock prices.
  • Real-World Limitations:
    1. Retail investors cannot borrow at the same rate as the government (risk-free rate is too low).
    2. Transaction costs and taxes exist, which drag down investment returns.
    3. Expectations differ widely among analysts, creating pricing anomalies.

4.16 Advanced Portfolio Performance Evaluation Metrics

To measure the quality of portfolio management, analysts use metrics that adjust returns for risk:

  1. Treynor Ratio: Measures excess return per unit of systematic risk (Beta):
    $$\text{Treynor Ratio} = \frac{r_p - r_{RF}}{\beta_p}$$ Best for evaluating portfolios that are sub-components of a larger, well-diversified fund.
  2. Jensen's Alpha ($\alpha_p$): Measures the absolute abnormal return generated by the portfolio manager relative to the CAPM required return:
    $$\alpha_p = r_p - \left[ r_{RF} + (r_M - r_{RF}) \cdot \beta_p \right]$$ A positive Jensen's Alpha ($\alpha_p > 0$) indicates that the manager beat the market on a risk-adjusted basis.

4.17 Arbitrage Pricing Theory (APT)

An alternative to CAPM is the **Arbitrage Pricing Theory (APT)** developed by Stephen Ross. Unlike CAPM, which assumes only market return is relevant, APT assumes that an asset's return is driven by multiple macroeconomic factors:
$$r_i = r_{RF} + \beta_{i1}(F_1) + \beta_{i2}(F_2) + \dots + \beta_{ik}(F_k)$$ Where:
- $F_1, F_2, \dots, F_k$ represent macroeconomic factors (such as inflation rate changes, GDP growth, interest rate shifts).
- $\beta_{ij}$ represents the sensitivity of asset $i$ to factor $j$.

Comparison to CAPM:
1. *No market portfolio required:* APT does not require identifying the hard-to-measure "market portfolio."
2. *Multivariate:* It reflects real-world complexities where different economic forces affect assets differently.
