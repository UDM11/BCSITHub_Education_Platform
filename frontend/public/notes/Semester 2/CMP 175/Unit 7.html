7.1 Introduction to Graphical User Interface (GUI) Programming in Java

Graphical User Interface (GUI) programming in Java allows developers to create interactive, user-friendly applications with visual components like buttons, text fields, and windows. Java provides the Swing library in the javax.swing package for building platform-independent GUIs.

🖥️ What is Swing?
A lightweight, platform-independent toolkit for creating GUIs, built on top of the older AWT (Abstract Window Toolkit). Provides a rich set of components.
🎨 Key Features
Rich set of components, customizable look and feel, support for event-driven programming, and platform-independent.

Key Swing Classes

  • JFrame — Top-level container (main window).
  • JPanel — Container for grouping components.
  • JButton — Clickable button.
  • JLabel — Display text or images.
  • JTextField — Single-line text input.
  • JTextArea — Multi-line text input/display.
  • JCheckBox — Checkbox for options.
  • JRadioButton — Radio button for mutually exclusive options.
// Basic JFrame Example
import javax.swing.*;

public class SimpleFrame {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Simple GUI");
        frame.setSize(300, 200);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);
    }
}

Swing provides a variety of components for building GUIs, including buttons, labels, text fields, and text areas. These are part of the javax.swing package and typically start with a "J" prefix.

// Swing Components Example
import javax.swing.*;
import java.awt.*;

public class SwingComponents {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Swing Components");
        frame.setSize(400, 300);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setLayout(new FlowLayout());

        JLabel label = new JLabel("Name:");
        JTextField textField = new JTextField(15);
        JButton button = new JButton("Submit");
        JCheckBox checkBox = new JCheckBox("Agree");

        frame.add(label);
        frame.add(textField);
        frame.add(checkBox);
        frame.add(button);

        frame.setVisible(true);
    }
}

Layout Managers

  • FlowLayout — Arranges components left to right.
  • BorderLayout — North, South, East, West, Center.
  • GridLayout — Components in a grid.
  • BoxLayout — Vertical or horizontal stacking.
  • GridBagLayout — Flexible grid with complex constraints.

7.3 Event-Driven Programming and Event Handling: Mouse Event and Key Event

Event-driven programming is a paradigm where the flow of the program is determined by events such as user actions (e.g., clicks, key presses). In Swing, events are handled using listeners that respond to specific actions.

Event Handling Mechanism

  • Event Source: The component that generates the event (e.g., button).
  • Event Listener: The interface that defines methods to handle events.
  • Event Object: Contains information about the event (e.g., MouseEvent).

// Mouse and Key Events Example
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class EventHandling {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Event Handling");
        frame.setSize(400, 300);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setLayout(new FlowLayout());

        JButton button = new JButton("Click Me");
        JTextField textField = new JTextField(20);

        // ActionListener for button
        button.addActionListener(e ->
            textField.setText("Button Clicked!")
        );

        // MouseListener for frame
        frame.addMouseListener(new MouseAdapter() {
            @Override
            public void mouseClicked(MouseEvent e) {
                textField.setText("Mouse Clicked at: " + e.getX() + ", " + e.getY());
            }
        });

        // KeyListener for text field
        textField.addKeyListener(new KeyAdapter() {
            @Override
            public void keyTyped(KeyEvent e) {
                textField.setText("Key Typed: " + e.getKeyChar());
            }
        });

        frame.add(button);
        frame.add(textField);
        frame.setVisible(true);
    }
}
🔄 Key insight: Event-driven programming is the foundation of GUI applications. Understanding listeners and event objects is essential for creating interactive Swing applications.

7.4 Building Simple Interactive Applications

Swing enables the creation of interactive applications by combining components, layouts, and event handling. A simple interactive application typically includes a user interface with input/output components and responds to user actions.

Simple Calculator Application

// Simple Calculator Example
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class SimpleCalculator {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Simple Calculator");
        frame.setSize(350, 200);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setLayout(new FlowLayout());

        JTextField num1 = new JTextField(8);
        JTextField num2 = new JTextField(8);
        JLabel resultLabel = new JLabel("Result: ");
        JButton addButton = new JButton("+");
        JButton subButton = new JButton("-");
        JButton mulButton = new JButton("×");
        JButton divButton = new JButton("÷");

        // Action listener for all buttons
        ActionListener calcListener = e -> {
            try {
                double n1 = Double.parseDouble(num1.getText());
                double n2 = Double.parseDouble(num2.getText());
                double result = 0;
                String op = ((JButton)e.getSource()).getText();
                switch(op) {
                    case "+": result = n1 + n2; break;
                    case "-": result = n1 - n2; break;
                    case "×": result = n1 * n2; break;
                    case "÷":
                        if (n2 == 0) throw new ArithmeticException("Divide by zero");
                        result = n1 / n2; break;
                }
                resultLabel.setText("Result: " + result);
            } catch (NumberFormatException ex) {
                resultLabel.setText("Invalid input");
            } catch (ArithmeticException ex) {
                resultLabel.setText("Cannot divide by zero");
            }
        };

        addButton.addActionListener(calcListener);
        subButton.addActionListener(calcListener);
        mulButton.addActionListener(calcListener);
        divButton.addActionListener(calcListener);

        frame.add(new JLabel("Num 1:"));
        frame.add(num1);
        frame.add(new JLabel("Num 2:"));
        frame.add(num2);
        frame.add(addButton);
        frame.add(subButton);
        frame.add(mulButton);
        frame.add(divButton);
        frame.add(resultLabel);

        frame.setVisible(true);
    }
}

Key Concepts in Building Interactive Apps

  • Components: Use Swing components for input/output.
  • Layout: Choose appropriate layout manager.
  • Events: Add listeners for user interactions.
  • Validation: Handle invalid input gracefully.
  • Feedback: Provide visual feedback to users.
🚀 Key insight: Building interactive applications requires combining components, layouts, and event handling. Start with simple applications and gradually add complexity as you become comfortable with Swing.
