6.1 Introduction to Stream, Byte Stream, and Character Stream

A stream in Java is a sequence of data elements made available over time, used for input/output (I/O) operations such as reading from or writing to files, networks, or other sources. Java provides a robust I/O framework through the java.io package.

📥 What is a Stream?
A stream is a sequence of data that flows between a program and an external source (file, network, etc.). It abstracts the details of the underlying data source.
📤 Two Types of Streams
Byte Streams (raw binary data) and Character Streams (text data with Unicode support).

Byte Streams

  • Purpose: Handle raw binary data (bytes).
  • Use Case: Reading/writing images, audio, video, or any binary file.
  • Base Classes: InputStream (read), OutputStream (write).
  • Examples: FileInputStream, FileOutputStream, BufferedInputStream.

Character Streams

  • Purpose: Handle text data (Unicode characters).
  • Use Case: Reading/writing text files, strings, and other character-based data.
  • Base Classes: Reader (read), Writer (write).
  • Examples: FileReader, FileWriter, BufferedReader, PrintWriter.
// Byte Stream Example
import java.io.*;

public class ByteStreamDemo {
    public static void main(String[] args) throws IOException {
        FileInputStream fis = new FileInputStream("image.jpg");
        FileOutputStream fos = new FileOutputStream("image_copy.jpg");
        int data;
        while ((data = fis.read()) != -1) {
            fos.write(data);
        }
        fis.close();
        fos.close();
    }
}

// Character Stream Example
FileReader fr = new FileReader("text.txt");
FileWriter fw = new FileWriter("text_copy.txt");
int ch;
while ((ch = fr.read()) != -1) {
    fw.write(ch);
}
fr.close();
fw.close();

6.2 I/O Class Hierarchy

The java.io package provides a hierarchy of classes for handling I/O operations. The main base classes are:

Byte Stream Hierarchy

InputStream (abstract)
    ├── FileInputStream
    ├── BufferedInputStream
    ├── DataInputStream
    ├── ObjectInputStream
    └── ByteArrayInputStream

OutputStream (abstract)
    ├── FileOutputStream
    ├── BufferedOutputStream
    ├── DataOutputStream
    ├── ObjectOutputStream
    └── ByteArrayOutputStream

Character Stream Hierarchy

Reader (abstract)
    ├── FileReader
    ├── BufferedReader
    ├── InputStreamReader
    ├── StringReader
    └── CharArrayReader

Writer (abstract)
    ├── FileWriter
    ├── BufferedWriter
    ├── OutputStreamWriter
    ├── StringWriter
    └── CharArrayWriter

Key Differences

FeatureByte StreamsCharacter Streams
Data TypeRaw bytes (8-bit)Unicode characters (16-bit)
Base ClassesInputStream, OutputStreamReader, Writer
Use CaseBinary data (images, audio)Text data (files, strings)
EncodingNo encodingCharacter encoding support
Buffered ClassesBufferedInputStream, BufferedOutputStreamBufferedReader, BufferedWriter
📚 Key insight: Character streams handle text with proper character encoding, while byte streams handle raw binary data. Choose the appropriate stream type based on the data you're processing.

6.3 Manipulating File

Java provides several classes for file manipulation under the java.io package. Below are key classes for handling file I/O.

FileInputStream

  • Purpose: Reads raw bytes from a file.
  • Use Case: Binary data or non-text files.
// FileInputStream Example
FileInputStream fis = new FileInputStream("input.txt");
int data;
while ((data = fis.read()) != -1) {
    System.out.print((char) data);
}
fis.close();

FileOutputStream

  • Purpose: Writes raw bytes to a file.
  • Use Case: Binary data or non-text files.
// FileOutputStream Example
FileOutputStream fos = new FileOutputStream("output.txt");
String text = "Hello, Java!";
fos.write(text.getBytes());
fos.close();

FileReader

  • Purpose: Reads characters from a file.
  • Use Case: Text files.
// FileReader Example
FileReader fr = new FileReader("text.txt");
int ch;
while ((ch = fr.read()) != -1) {
    System.out.print((char) ch);
}
fr.close();

FileWriter

  • Purpose: Writes characters to a file.
  • Use Case: Text files.
// FileWriter Example
FileWriter fw = new FileWriter("text_output.txt");
fw.write("Hello, Java!");
fw.close();

DataInputStream & DataOutputStream

  • Purpose: Read/write primitive data types (int, double, etc.) in a machine-independent way.
// DataInputStream & DataOutputStream Example
// Write
FileOutputStream fos = new FileOutputStream("data.bin");
DataOutputStream dos = new DataOutputStream(fos);
dos.writeInt(100);
dos.writeDouble(3.14);
dos.close();

// Read
FileInputStream fis = new FileInputStream("data.bin");
DataInputStream dis = new DataInputStream(fis);
int num = dis.readInt();
double dbl = dis.readDouble();
System.out.println("Number: " + num + ", Double: " + dbl);
dis.close();

ObjectInputStream & ObjectOutputStream (Serialization)

  • Purpose: Serialize/deserialize Java objects.
  • Requirement: Objects must implement Serializable interface.
// ObjectOutputStream Example
class Person implements Serializable {
    String name;
    int age;
    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

// Serialize
Person p = new Person("Alice", 25);
FileOutputStream fos = new FileOutputStream("person.ser");
ObjectOutputStream oos = new ObjectOutputStream(fos);
oos.writeObject(p);
oos.close();

// Deserialize
FileInputStream fis = new FileInputStream("person.ser");
ObjectInputStream ois = new ObjectInputStream(fis);
Person person = (Person) ois.readObject();
System.out.println(person.name + " - " + person.age);
ois.close();

Buffered Streams

  • Purpose: Improve performance by reducing direct access to underlying resources.
  • Examples: BufferedReader, BufferedWriter, BufferedInputStream, BufferedOutputStream.
// BufferedReader & BufferedWriter Example
// Reading
BufferedReader br = new BufferedReader(new FileReader("file.txt"));
String line;
while ((line = br.readLine()) != null) {
    System.out.println(line);
}
br.close();

// Writing
BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"));
bw.write("Hello, World!");
bw.newLine();
bw.write("Line 2");
bw.close();
📁 Key insight: Use the appropriate stream type for your data. Buffered streams improve performance significantly. For text files, use Readers/Writers; for binary files, use Streams.
📘 Unit 6 summary
Java streams provide a framework for I/O operations. Byte streams handle binary data, character streams handle text data. Various classes support file, data, and object I/O.
🔑 Key takeaways
• Stream: sequence of data for I/O.
• Byte streams: InputStream/OutputStream (binary).
• Character streams: Reader/Writer (text).
• File streams: FileInputStream, FileOutputStream, FileReader, FileWriter.
• Data streams: DataInputStream, DataOutputStream (primitives).
• Object streams: ObjectInputStream, ObjectOutputStream (serialization).
• Buffered streams: improve performance.
• Always close streams after use.
