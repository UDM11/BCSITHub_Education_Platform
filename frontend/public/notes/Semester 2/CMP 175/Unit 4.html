4.1 Inheritance and Reuse

Inheritance is a mechanism in Java where a class (subclass) inherits properties and methods from another class (superclass). It promotes code reuse and establishes a hierarchical relationship between classes.

🧬 Inheritance
A subclass (child) inherits fields and methods from a superclass (parent). Uses the extends keyword.
♻️ Reuse
By inheriting from a superclass, a subclass can use existing code without rewriting it, reducing redundancy and improving maintainability.

Key Concepts

  • Superclass (Parent): The class being inherited from.
  • Subclass (Child): The class that inherits from the superclass.
  • Keyword: extends is used to implement inheritance.
  • Benefits:
    • Code reusability
    • Method overriding (polymorphism)
    • Establishing hierarchical relationships
// Inheritance Example
public class Animal {
    void eat() {
        System.out.println("This animal eats food.");
    }
}

public class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks.");
    }

    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat(); // Inherited from Animal
        dog.bark(); // Defined in Dog
    }
}
💡 Key insight: Inheritance establishes an "is-a" relationship. A Dog is-a Animal. This allows subclasses to be used wherever superclasses are expected (polymorphism).

4.2 Types of Inheritance and its Implementation

Java supports the following types of inheritance:

Single Inheritance

  • A class inherits from one superclass.
  • Example: A → B

Multilevel Inheritance

  • A class inherits from a superclass, which itself inherits from another class.
  • Example: A → B → C

Hierarchical Inheritance

  • Multiple classes inherit from a single superclass.
  • Example: A → B, A → C
Inheritance Types:
Single:    A → B

Multilevel: A → B → C

Hierarchical:  A
              / \
             B   C
// Hierarchical Inheritance Example
public class Vehicle {
    void move() {
        System.out.println("Vehicle is moving.");
    }
}

public class Car extends Vehicle {
    void honk() {
        System.out.println("Car honks.");
    }
}

public class Bike extends Vehicle {
    void ringBell() {
        System.out.println("Bike rings bell.");
    }
}
📌 Key insight: Java does not support multiple inheritance (a class inheriting from multiple superclasses) directly to avoid the "diamond problem." However, multiple inheritance can be achieved using interfaces.

4.3 Polymorphism: Method Overriding, Method Overloading, Dynamic Method Invocation, and Run-time Polymorphism

Polymorphism allows objects to be treated as instances of their superclass, enabling flexibility in method calls.

Method Overloading (Compile-time Polymorphism)

  • Multiple methods with the same name but different parameter lists.
  • Resolved at compile time.

Method Overriding (Run-time Polymorphism)

  • A subclass provides a specific implementation of a method already defined in its superclass.
  • Uses @Override annotation (optional but recommended).
  • Resolved at runtime.

Dynamic Method Invocation

  • The JVM determines the method to execute at runtime based on the object's actual type, not the reference type.
// Method Overloading Example
public class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

// Method Overriding Example
public class Shape {
    void draw() {
        System.out.println("Drawing a shape.");
    }
}

public class Circle extends Shape {
    @Override
    void draw() {
        System.out.println("Drawing a circle.");
    }
}

// Run-time Polymorphism
Shape shape = new Circle();
shape.draw(); // Output: Drawing a circle.

4.4 Abstract Classes: Abstract Method and Abstract Class

An abstract class is a class declared with the abstract keyword that cannot be instantiated. It is used to define common behavior for subclasses.

An abstract method is a method declared without an implementation, forcing subclasses to provide their own implementation.

Key Points

  • Abstract classes can contain both abstract and concrete methods.
  • Abstract methods must be implemented by the first concrete subclass.
  • Abstract classes provide a template for subclasses.
// Abstract Class Example
public abstract class Animal {
    abstract void makeSound(); // Abstract method

    void sleep() { // Concrete method
        System.out.println("Animal is sleeping.");
    }
}

public class Cat extends Animal {
    @Override
    void makeSound() {
        System.out.println("Cat meows.");
    }
}

public class Dog extends Animal {
    @Override
    void makeSound() {
        System.out.println("Dog barks.");
    }
}

4.5 Packages and Interfaces

Packages

  • Definition: Organize related classes and interfaces into a namespace to avoid naming conflicts and improve maintainability.
  • Keyword: package
  • Import: import keyword to use classes from other packages.
// File: mypackage/MyClass.java
package mypackage;

public class MyClass {
    public void display() {
        System.out.println("Inside MyClass.");
    }
}

// File: Main.java
import mypackage.MyClass;

public class Main {
    public static void main(String[] args) {
        MyClass obj = new MyClass();
        obj.display(); // Output: Inside MyClass.
    }
}

Interfaces

  • Definition: Define a contract of methods that implementing classes must provide.
  • Keyword: interface
  • Implementation: implements keyword
  • Features:
    • All methods are implicitly public abstract (before Java 8).
    • Can contain default and static methods (Java 8+).
    • Multiple interfaces can be implemented by a single class.
// Interface Example
public interface Drawable {
    void draw(); // Abstract method
}

public interface Resizable {
    void resize(double factor);
}

public class Rectangle implements Drawable, Resizable {
    @Override
    public void draw() {
        System.out.println("Drawing a rectangle.");
    }

    @Override
    public void resize(double factor) {
        System.out.println("Resizing by factor: " + factor);
    }
}

4.6 Lambda Function

Lambda expressions (introduced in Java 8) provide a concise way to implement functional interfaces (interfaces with a single abstract method). They enable functional programming in Java.

Syntax

  • (parameters) -> expression
  • (parameters) -> { statements; }

Functional Interface

  • An interface with exactly one abstract method.
  • Can be annotated with @FunctionalInterface (optional but recommended).
// Lambda Expression Example
@FunctionalInterface
interface Operation {
    int operate(int a, int b);
}

public class Main {
    public static void main(String[] args) {
        // Lambda with expression
        Operation add = (a, b) -> a + b;
        System.out.println("Sum: " + add.operate(5, 3));

        // Lambda with block
        Operation multiply = (a, b) -> {
            return a * b;
        };
        System.out.println("Product: " + multiply.operate(5, 3));
    }
}

List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// Using lambda with forEach
numbers.forEach(n -> System.out.print(n + " "));

// Using lambda with filter
List<Integer> evens = numbers.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());
⚡ Key insight: Lambda expressions enable functional programming in Java, making code more concise and readable. They are particularly useful with Java's Stream API for collection processing.
