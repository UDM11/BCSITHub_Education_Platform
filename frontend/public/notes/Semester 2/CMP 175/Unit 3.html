3.1 Classes and Objects: Object Creation, Initializing the Instance Variables

A class in Java is a blueprint for creating objects, defining their properties (instance variables) and behaviors (methods). An object is an instance of a class, representing a specific entity with its own state and behavior.

📦 Class
A blueprint or template that defines the structure and behavior of objects. Contains fields (variables) and methods (functions).
🎯 Object
An instance of a class, created using the new keyword. Each object has its own copy of instance variables.

Object Creation

  • Objects are created using the new keyword, which allocates memory and invokes a constructor.
  • Syntax: ClassName objectName = new ClassName();
  • Example: Student s1 = new Student();

Initializing Instance Variables

  • Direct Initialization: Assign values at the time of declaration.
  • Constructor Initialization: Use constructors to initialize fields.
  • Setter Methods: Use public setter methods to set values.
// Class and Object Example
public class Student {
    String name; // Instance variable
    int age; // Instance variable

    // Constructor for initialization
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void display() {
        System.out.println("Name: " + name + ", Age: " + age);
    }

    public static void main(String[] args) {
        // Object creation
        Student s1 = new Student("Alice", 20);
        s1.display(); // Output: Name: Alice, Age: 20
    }
}

Encapsulation

  • Definition: The process of bundling data (instance variables) and methods that operate on the data into a single unit (class), while restricting direct access to some components.
  • Implementation: Make fields private and provide public getter/setter methods.
  • Benefits:
    • Data hiding and protection
    • Controlled access to fields
    • Flexibility to change internal implementation
// Encapsulation Example
public class BankAccount {
    private double balance; // Private field

    // Public getter
    public double getBalance() {
        return balance;
    }

    // Public setter with validation
    public void setBalance(double balance) {
        if (balance >= 0) {
            this.balance = balance;
        }
    }
}
🔒 Key insight: Encapsulation is a fundamental principle of OOP that protects data integrity and promotes modular design. It allows implementation details to change without affecting other parts of the code.

3.3 Constructors and Garbage Collection

Constructors

  • Definition: Special methods used to initialize objects. They have the same name as the class and no return type.
  • Default Constructor: Provided automatically if no constructors are defined, initializes fields to default values (e.g., 0, null).
  • Parameterized Constructor: Accepts parameters to initialize fields.
  • Constructor Overloading: Multiple constructors with different parameter lists.
// Constructor Example
public class Car {
    String model;
    int year;

    // Default constructor
    public Car() {
        model = "Unknown";
        year = 0;
    }

    // Parameterized constructor
    public Car(String model, int year) {
        this.model = model;
        this.year = year;
    }

    // Constructor overloading
    public Car(String model) {
        this.model = model;
        this.year = 2024;
    }
}

Garbage Collection

  • Definition: Java's automatic memory management system that deallocates memory for objects no longer referenced.
  • Process: The JVM's garbage collector identifies and frees unused objects, preventing memory leaks.
  • Eligibility: Objects are eligible for garbage collection when they are no longer reachable (no references point to them).
  • Method: System.gc() can be used to request garbage collection (but not guaranteed).
// Garbage Collection Example
public class GarbageDemo {
    public static void main(String[] args) {
        Car c1 = new Car("Toyota", 2020);
        Car c2 = new Car("Honda", 2021);

        c1 = null; // c1 eligible for garbage collection
        c2 = null; // c2 eligible for garbage collection

        System.gc(); // Request garbage collection
    }
}

3.4 "this" Pointer

The this keyword refers to the current object in a method or constructor. It is used to:

  • Distinguish instance variables from local variables or parameters with the same name.
  • Invoke another constructor of the same class (this()).
  • Pass the current object as a parameter to methods.
  • Return the current object from a method.
// "this" Keyword Example
public class Employee {
    String name;
    int id;

    // Constructor using 'this' to distinguish parameters
    public Employee(String name, int id) {
        this.name = name; // this.name refers to instance variable
        this.id = id; // this.id refers to instance variable
    }

    // Calling another constructor
    public Employee() {
        this("Unknown", 0); // Calls parameterized constructor
    }

    public void display() {
        System.out.println("Name: " + this.name + ", ID: " + this.id);
    }

    public Employee getInstance() {
        return this; // Returning current object
    }
}

3.5 Static Members

Static members belong to the class rather than any specific object. They are declared with the static keyword and are shared across all instances of the class.

Static Variables

  • Single copy shared by all objects.
  • Used for constants, counters, or shared state.
  • Accessed using the class name (e.g., ClassName.staticVar).

Static Methods

  • Can be called without creating an object.
  • Often used for utility functions.
  • Cannot directly access instance variables (non-static).

Static Blocks

  • Used to initialize static variables.
  • Executed when the class is loaded.
// Static Members Example
public class Counter {
    static int count = 0; // Static variable
    int instanceId; // Instance variable

    // Static block
    static {
        System.out.println("Static block executed once");
        count = 100; // Initialize static variable
    }

    // Constructor
    public Counter() {
        count++;
        instanceId = count;
    }

    // Static method
    public static int getCount() {
        return count; // Can access static variables only
    }

    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        System.out.println("Total objects: " + Counter.getCount());
        System.out.println("c1 ID: " + c1.instanceId);
        System.out.println("c2 ID: " + c2.instanceId);
    }
}
