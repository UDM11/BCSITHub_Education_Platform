5.1 Types of Sequential Logic Circuit

Sequential logic circuits have outputs that depend on both current inputs and previous states (memory), unlike combinational circuits, which depend only on current inputs.

⏱️ Definition
Sequential circuits incorporate memory elements, enabling them to store and process information over time. Examples: Counters, registers, flip-flops.
📋 Types
Synchronous (clock-driven) and Asynchronous (input-driven). Components include flip-flops, latches, and combinational logic.

Synchronous vs Asynchronous

FeatureSynchronousAsynchronous
Clock SignalYes (all operations synchronized)No (operations depend on input changes)
StabilityMore reliable, predictable timingLess reliable, race conditions possible
ExampleEdge-triggered flip-flopsUnclocked latches
ApplicationsCPUs, counters, shift registersSimple control circuits

Applications

  • Memory units (RAM, registers)
  • Counters and timers
  • Shift registers
  • Finite state machines in processors and controllers

5.2 Triggering of Flip-Flops

Triggering determines how and when a flip-flop changes its state based on input signals and clock events.

Level Triggering

  • Definition: Flip-flop responds to input levels (high or low).
  • Example: Latches change state as long as the enable signal is active.
  • Drawback: Sensitive to noise during the active level.

Edge Triggering

  • Definition: Flip-flop responds to the rising (positive) or falling (negative) edge of a clock signal.
  • Types:
    • Positive Edge (Rising Edge): State changes when clock transitions from 0 to 1.
    • Negative Edge (Falling Edge): State changes when clock transitions from 1 to 0.
  • Advantage: More stable, predictable timing.
Clock Signal:
   ┌─┐ ┌─┐ ┌─┐
───┘ └─┘ └─┘ └─
   ↑   ↑   ↑   ↑
Positive Edge (Rising)
   └───┘
Negative Edge (Falling)
// Edge Detection Logic
// Positive edge: clock goes from 0 to 1
if (clk && !clk_prev) {
    Q = D; // Update state
}
clk_prev = clk;
⏰ Key insight: Edge triggering is preferred in synchronous digital systems because it ensures that flip-flops update at precise clock edges, avoiding race conditions and timing hazards.

5.3 Flip-Flops (RS, JK, T, D, Master-Slave)

Flip-flops are basic memory elements in sequential circuits, storing one bit of information.

RS (Set-Reset) Flip-Flop

  • Inputs: S (Set), R (Reset)
  • Operation:
    • S=1, R=0 → Q=1 (Set)
    • S=0, R=1 → Q=0 (Reset)
    • S=0, R=0 → Hold state
    • S=1, R=1 → Invalid (race condition)

JK Flip-Flop

  • Inputs: J, K, Clock
  • Operation:
    • J=0, K=0 → Hold
    • J=0, K=1 → Reset (Q=0)
    • J=1, K=0 → Set (Q=1)
    • J=1, K=1 → Toggle (Q = Q')
  • Advantage: Resolves RS invalid state.
JKQ(next)
00Q (Hold)
010 (Reset)
101 (Set)
11Q' (Toggle)

T (Toggle) Flip-Flop

  • Input: T, Clock
  • Operation:
    • T=0 → Hold
    • T=1 → Toggle (Q = Q')
  • Derived from JK: J = K = T
TQ(next)
0Q (Hold)
1Q' (Toggle)

D (Data) Flip-Flop

  • Input: D, Clock
  • Operation: Q follows D at the clock edge.
  • Advantage: Prevents invalid states.
DQ(next)
00
11

Master-Slave Flip-Flop

  • Structure: Two flip-flops in series (Master and Slave).
  • Operation:
    • Master updates on clock active edge.
    • Slave copies master on opposite clock edge.
  • Advantage: Prevents race conditions, ensures stable output.
Master-Slave Flip-Flop:
Input → [Master] → [Slave] → Output
         ↑          ↑
         Clock     Clock
         (active)  (opposite)

5.4 State Diagrams and State Tables

State diagrams and state tables describe the behavior of sequential circuits, showing how states transition based on inputs.

State Diagram

  • Definition: A graphical representation where nodes represent states, and directed edges show transitions based on inputs.
  • Labels: Edges are labeled with input/output conditions.
  • Example: 2-bit up-counter (00 → 01 → 10 → 11 → 00).
State Diagram: 2-bit Up-Counter

State Table

  • Definition: A tabular representation of state transitions.
  • Columns: Current State, Input, Next State, Output.
  • Example: 2-bit up-counter state table.
