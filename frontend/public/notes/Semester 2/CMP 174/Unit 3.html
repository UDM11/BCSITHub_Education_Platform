3.1 Minterms and Maxterms

Minterms and maxterms are standard forms of Boolean expressions used to represent any Boolean function in a canonical form.

📘 Minterms
A product (AND) of all variables, each appearing once (complemented or uncomplemented). For n variables, there are 2ⁿ minterms. Denoted as mᵢ.
📗 Maxterms
A sum (OR) of all variables, each appearing once (complemented or uncomplemented). For n variables, there are 2ⁿ maxterms. Denoted as Mᵢ.

Minterms (Product Terms)

  • Definition: A minterm is a product term that evaluates to 1 for exactly one combination of input variables.
  • For 2 variables (A, B):
    • m₀ = A'B' (00)
    • m₁ = A'B (01)
    • m₂ = AB' (10)
    • m₃ = AB (11)
  • Notation: A function expressed as sum of minterms: F = Σm(i₁, i₂, ...)

Maxterms (Sum Terms)

  • Definition: A maxterm is a sum term that evaluates to 0 for exactly one combination of input variables.
  • For 2 variables (A, B):
    • M₀ = A + B (00)
    • M₁ = A + B' (01)
    • M₂ = A' + B (10)
    • M₃ = A' + B' (11)
  • Notation: A function expressed as product of maxterms: F = ΠM(i₁, i₂, ...)

3.2 Sum of Products and Product of Sums

Sum of Products (SOP) and Product of Sums (POS) are two standard forms for representing Boolean functions.

Sum of Products (SOP)

  • Definition: A Boolean function expressed as a sum (OR) of minterms.
  • Form: F = Σm(i₁, i₂, ...)
  • Implementation: AND-OR (first level AND, second level OR).
  • Example: F(A,B,C) = A'BC + AB'C + ABC = Σm(3, 5, 7)

Product of Sums (POS)

  • Definition: A Boolean function expressed as a product (AND) of maxterms.
  • Form: F = ΠM(i₁, i₂, ...)
  • Implementation: OR-AND (first level OR, second level AND).
  • Example: F(A,B,C) = (A+B+C)·(A+B'+C)·(A'+B+C') = ΠM(0, 2, 6)

3.3 Dual and Complement of Boolean Function

The dual and complement operations transform Boolean expressions while preserving or altering their logic.

Dual of a Boolean Function

  • Definition: Replace AND (·) with OR (+), OR with AND, 0 with 1, and 1 with 0. Variables remain unchanged.
  • Notation: Fᵈ
  • Example: If F = A · B + C, then Fᵈ = (A + B) · C
  • Property: The dual of a function is not necessarily equal to the original.

Complement of a Boolean Function

  • Definition: The complement of F (denoted F') gives the opposite output for all inputs.
  • Methods:
    • Use De Morgan's theorems.
    • Use the dual and then complement variables.
    • Use a truth table.
  • Example: If F = A · B, then F' = (A · B)' = A' + B'

📐 Key insight: The dual of a function is useful for converting between SOP and POS forms. The complement is essential for implementing functions in negative logic or using NAND/NOR gates.

3.4 K-map & Don't Care Conditions

Karnaugh maps (K-maps) are graphical tools for simplifying Boolean expressions, and don't care conditions help further optimize circuits.

Karnaugh Map (K-map)

  • Definition: A grid where each cell represents a minterm. Adjacent cells differ by one variable.
  • Grid Sizes:
    • 2 variables: 2×2
    • 3 variables: 4×2
    • 4 variables: 4×4
  • Grouping Rules:
    • Group adjacent 1s (or 0s) in powers of 2 (1, 2, 4, 8, ...).
    • Groups can wrap around edges.
    • Each group gives a simplified product term (SOP) or sum term (POS).
3-Variable K-map (A, B, C):
         BC
         00  01  11  10
A  0 | m0 | m1 | m3 | m2 |
   1 | m4 | m5 | m7 | m6 |

Don't Care Conditions

  • Definition: Input combinations where the output is unspecified (denoted X).
  • Usage: Treat don't cares as 0 or 1 to create larger groups and simplify expressions.
  • Example: F(A,B,C) = Σm(0, 1) + d(4, 5) → grouping with don't cares gives F = A'

3.5 Two-Level and Multilevel Gate Implementations

Boolean functions can be implemented using two-level or multilevel gate circuits, balancing speed, complexity, and cost.

Two-Level Gate Implementation

  • SOP (AND-OR):
    • Level 1: AND gates for each product term.
    • Level 2: OR gate to sum them.
    • Example: F = A'B + AB' → 2 AND gates + 1 OR gate.
    • Advantage: Fast (only 2 gate delays).
    • Disadvantage: May require many gates.
  • POS (OR-AND):
    • Level 1: OR gates for each sum term.
    • Level 2: AND gate to combine them.
    • Example: F = (A+B)·(A'+B) → 2 OR gates + 1 AND gate.

Multilevel Gate Implementation

  • Definition: Uses more than two levels of gates (AND, OR, NOT, etc.).
  • Goal: Reduce gate count by factoring expressions.
  • Example: F = A'B + AB'C = A'(B + BC) = A'(B + C)
  • Advantage: Fewer gates, lower cost.
  • Disadvantage: Slower (more gate delays).
// Two-Level vs Multilevel Example
// F = A'B'C + A'BC + AB'C + ABC

// Two-Level SOP (4 AND, 1 OR):
F = A'B'C + A'BC + AB'C + ABC

// Multilevel (factorization):
F = C(A'B' + A'B + AB' + AB)
F = C(A' + B')

🔑 Key insight: Two-level implementations are faster but may require more gates. Multilevel implementations use fewer gates but introduce more propagation delays. The choice depends on speed requirements and cost constraints.
📘 Unit 3 summary
Boolean function simplification techniques include minterms/maxterms, SOP/POS forms, dual/complement, K-maps, and gate implementations.
🔑 Key takeaways
• Minterms: Σm(i), Maxterms: ΠM(i).
• SOP: sum of products (AND-OR).
• POS: product of sums (OR-AND).
• Dual: swap AND/OR, 0/1.
• Complement: invert the function.
• K-maps: graphical simplification.
• Don't cares: X for unspecified outputs.
• Two-level: fast, more gates.
• Multilevel: slower, fewer gates.
