1.1 Introduction to Digital System

A digital system is an electronic system that processes and stores data using discrete values, typically represented as binary digits (0s and 1s). These systems form the backbone of modern computing and communication technologies.

💡 Definition
Digital systems manipulate discrete signals to perform computations, store information, or control processes. Examples: Computers, smartphones, and digital watches.
⚡ Characteristics
Operate using binary logic, are noise-resistant, and allow precise data representation. Digital signals (0/1) are less prone to distortion than analog signals.
🧩 Components
Include logic gates, memory units, and processors that handle binary data. These components work together to execute instructions.
📱 Applications
Used in computing, telecommunications, digital signal processing, and embedded systems across all modern industries.

1.2 Binary Number System, Hexadecimal and Octal Number Systems

Number systems represent numerical values using different bases, with binary, hexadecimal, and octal being critical in digital systems.

Binary Number System (Base-2)

  • Digits: 0 and 1
  • Positional Value: Each position represents a power of 2
  • Example: 1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8 + 0 + 2 + 1 = 11₁₀
  • Applications: Fundamental to all computer hardware and digital logic.

Hexadecimal Number System (Base-16)

  • Digits: 0–9 and A–F (A=10, B=11, C=12, D=13, E=14, F=15)
  • Positional Value: Each position represents a power of 16
  • Example: 2A₁₆ = 2·16¹ + 10·16⁰ = 32 + 10 = 42₁₀
  • Applications: Simplifies binary representation (memory addresses, color codes).

Octal Number System (Base-8)

  • Digits: 0–7
  • Positional Value: Each position represents a power of 8
  • Example: 23₈ = 2·8¹ + 3·8⁰ = 16 + 3 = 19₁₀
  • Applications: Used in legacy systems and Unix file permissions.

1.3 Number System Conversion

Converting between number systems is essential for data representation and processing in digital systems.

Decimal to Binary

  • Method: Divide by 2 repeatedly, record remainders in reverse order.
  • Example: Convert 19₁₀ to binary:
    19 ÷ 2 = 9 rem 1
    9 ÷ 2 = 4 rem 1
    4 ÷ 2 = 2 rem 0
    2 ÷ 2 = 1 rem 0
    1 ÷ 2 = 0 rem 1
    Result: 10011₂

Binary to Decimal

  • Method: Sum the powers of 2 for each 1 bit.
  • Example: 1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8 + 0 + 2 + 1 = 11₁₀

Binary to Hexadecimal

  • Method: Group binary digits into sets of 4 (from right), convert each to hex digit.
  • Example: 10110110₂ = 1011 0110 = B6₁₆ (1011 = B, 0110 = 6)

Hexadecimal to Binary

  • Method: Convert each hex digit to its 4-bit binary equivalent.
  • Example: 2A₁₆ = 0010 1010₂

Decimal to Octal

  • Method: Divide by 8 repeatedly, record remainders in reverse order.
  • Example: 19₁₀: 19 ÷ 8 = 2 rem 3, 2 ÷ 8 = 0 rem 2 → 23₈

Octal to Decimal

  • Method: Sum the powers of 8 for each digit.
  • Example: 23₈ = 2·8¹ + 3·8⁰ = 16 + 3 = 19₁₀
📐 Key insight: Practice conversions regularly. Verify by converting back to the original base. Use grouping for binary-hex/oct conversions.

1.4 Binary Codes: Weighted and Non-Weighted Codes

Binary codes represent data in binary form, with weighted and non-weighted codes serving different purposes.

Weighted Codes

  • Definition: Each digit position has a specific weight; value is the sum of weights for non-zero digits.
  • BCD (Binary-Coded Decimal):
    • Each decimal digit represented by 4-bit binary (0000 to 1001).
    • Example: 45₁₀ = 0100 0101_BCD
    • Use: Simplifies decimal arithmetic in digital systems.
  • 2421 Code:
    • Weights: 2, 4, 2, 1
    • Example: 5₁₀ = 0101_2421 (0·2 + 1·4 + 0·2 + 1·1 = 5)

Non-Weighted Codes

  • Definition: No fixed weights; designed for error detection or specific properties.
  • Gray Code:
    • Adjacent numbers differ by one bit.
    • Example: 3₁₀ = 010_Gray, 4₁₀ = 110_Gray
    • Use: Rotary encoders to reduce errors during transitions.
  • Excess-3 Code:
    • BCD value plus 3.
    • Example: 5₁₀ = 0101_BCD = 1000_Excess-3 (0101 + 0011)
    • Use: BCD addition and subtraction.

1.5 Alphanumeric Codes (ASCII, EBCDIC)

Alphanumeric codes represent letters, digits, and special characters in binary for computer processing.

ASCII (American Standard Code for Information Interchange)

  • Bits: 7 or 8 bits (128 or 256 characters)
  • Examples:
    • A = 65₁₀ = 1000001₂
    • a = 97₁₀ = 1100001₂
    • 0 = 48₁₀ = 0110000₂
  • Includes: Letters, digits, punctuation, control characters (newline, carriage return).
  • Use: Standard in modern computing, internet protocols, text files.

EBCDIC (Extended Binary Coded Decimal Interchange Code)

  • Bits: 8 bits (256 characters)
  • Developed by: IBM
  • Example: A = 11000001₂ in EBCDIC
  • Use: IBM mainframes and legacy enterprise systems.

1.6 Representation of Negative Numbers

Negative numbers in digital systems are represented using specific formats to facilitate arithmetic operations.

Sign-Magnitude

  • Format: Most significant bit = sign (0 for positive, 1 for negative)
  • Example (8 bits):
    • +5 = 00000101₂
    • -5 = 10000101₂
  • Drawback: Two zeros (+0 and -0), complex arithmetic.

One's Complement

  • Format: Invert all bits of the positive number.
  • Example (8 bits):
    • +5 = 00000101₂
    • -5 = 11111010₂
  • Drawback: Two zeros (00000000₂ and 11111111₂).

Two's Complement

  • Format: Invert bits of positive number and add 1.
  • Example (8 bits):
    • +5 = 00000101₂
    • -5 = 11111010₂ + 1 = 11111011₂
  • Advantage: Only one zero, simple arithmetic (addition and subtraction).

1.7 Subtraction Using Complements

Complements simplify subtraction in digital systems by converting it to addition.

One's Complement Subtraction

  • Method: a - b = a + (one's complement of b)
  • End-Around Carry: If there's a carry-out, add 1 to the result.
  • Example: 7 - 4 in 4 bits:
    7 = 0111₂
    4 = 0100₂
    One's complement of 4 = 1011₂
    0111 + 1011 = 10010₂
    Discard carry → 0010₂ + 1 = 0011₂ = 3₁₀

Two's Complement Subtraction

  • Method: a - b = a + (two's complement of b)
  • Example: 7 - 4 in 4 bits:
    7 = 0111₂
    4 = 0100₂
    Two's complement of 4 = 1100₂
    0111 + 1100 = 10011₂
    Discard carry → 0011₂ = 3₁₀

Comparison

  • One's Complement: Requires end-around carry, more circuitry.
  • Two's Complement: No end-around carry, simpler hardware.
