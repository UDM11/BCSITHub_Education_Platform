4.1 Introduction to Combinational Logic Circuit

Combinational logic circuits produce outputs that depend solely on the current inputs, with no memory or feedback. They are fundamental building blocks in digital systems.

📐 Definition
A combinational circuit's output is a function of its inputs at any given time. Examples: Adders, multiplexers, decoders.
⚡ Characteristics
No memory elements; outputs are determined by Boolean functions of inputs. Example: F = A·B + C'.

Design Process

  • Step 1: Define inputs and outputs.
  • Step 2: Create the truth table.
  • Step 3: Derive Boolean expressions from the truth table.
  • Step 4: Simplify using Boolean algebra or K-maps.
  • Step 5: Implement with logic gates.

Applications

  • Arithmetic operations (adders, subtractors)
  • Data routing (multiplexers, demultiplexers)
  • Code conversion (BCD to 7-segment, etc.)
  • Control logic in processors and communication systems

4.2 Adders and Subtractors

Adders and subtractors are combinational circuits used for binary arithmetic operations.

Half Adder

  • Inputs: A, B (2 single-bit inputs)
  • Outputs: Sum (S), Carry (C)
  • Formulas:
    • S = A ⊕ B
    • C = A · B

Full Adder

  • Inputs: A, B, Carry-in (Cin)
  • Outputs: Sum (S), Carry-out (Cout)
  • Formulas:
    • S = A ⊕ B ⊕ Cin
    • Cout = (A·B) + (B·Cin) + (A·Cin)

Ripple Carry Adder

  • Chains full adders to add multi-bit numbers.
  • Example: 4-bit adder for A = A₃A₂A₁A₀ and B = B₃B₂B₁B₀.
  • Drawback: Delay due to carry propagation.

Subtractors

  • Half Subtractor:
    • D = A ⊕ B (Difference)
    • Bout = A' · B (Borrow)
  • Full Subtractor:
    • D = A ⊕ B ⊕ Bin
    • Bout = A'·B + A'·Bin + B·Bin
  • Two's Complement Subtraction: A - B = A + (two's complement of B)

4.3 Decoder and Encoder

Decoders and encoders are combinational circuits used for data selection and conversion.

Decoder

  • Function: Converts binary input to activate one of many outputs.
  • Example: 2-to-4 Decoder
    • Inputs: A₁, A₀ (2 bits)
    • Outputs: D₀, D₁, D₂, D₃ (4 outputs)

Encoder

  • Function: Converts one active input to a binary output code.
  • Example: 4-to-2 Encoder
    • Inputs: D₀, D₁, D₂, D₃
    • Outputs: A₁, A₀
  • Priority Encoder: Handles multiple active inputs by prioritizing the highest-indexed input.

4.4 Multiplexer and Demultiplexer

Multiplexers and demultiplexers route data by selecting inputs or distributing outputs.

Multiplexer (MUX)

  • Function: Selects one of many inputs to a single output based on select lines.
  • Example: 4-to-1 MUX
    • Inputs: D₀, D₁, D₂, D₃
    • Select Lines: S₁, S₀
    • Output: Y = S₁'S₀'D₀ + S₁'S₀D₁ + S₁S₀'D₂ + S₁S₀D₃

Demultiplexer (DEMUX)

  • Function: Routes one input to one of many outputs based on select lines.
  • Example: 1-to-4 DEMUX
    • Input: D
    • Select Lines: S₁, S₀
    • Outputs: Y₀ = S₁'S₀'D, Y₁ = S₁'S₀D, Y₂ = S₁S₀'D, Y₃ = S₁S₀D

Code conversion transforms numbers between different binary coding schemes used in digital systems.

Binary to Gray Code Conversion

  • Formula: Gₙ = Bₙ, Gᵢ = Bᵢ ⊕ Bᵢ₊₁
  • Example: Binary 0101 (5₁₀)
    • G₃ = B₃ = 0
    • G₂ = B₂ ⊕ B₃ = 1 ⊕ 0 = 1
    • G₁ = B₁ ⊕ B₂ = 0 ⊕ 1 = 1
    • G₀ = B₀ ⊕ B₁ = 1 ⊕ 0 = 1
    • Result: 0111_Gray

Gray to Binary Code Conversion

  • Formula: Bₙ = Gₙ, Bᵢ = Bᵢ₊₁ ⊕ Gᵢ
  • Example: Gray 0111 → Binary 0101

4.6 Programmable Logic Device (PROM)

Programmable Read-Only Memory (PROM) is a combinational logic device used to implement complex Boolean functions.

Structure

  • AND Array: Fixed — generates all possible minterms for input combinations.
  • OR Array: Programmable — fuses connect minterms to outputs.
  • Example: For F(A,B) = A'B + AB, PROM stores 1s for minterms m₁, m₃ at the output.

PROM Programming

  • Fuses are blown to configure the OR array.
  • One-time programmable (OTP).
  • Stores truth tables for Boolean functions.

Applications

  • Microcontrollers
  • Lookup tables
  • Implementing combinational logic in embedded systems
  • Boot code storage in embedded devices
PROM Structure:
Inputs → [AND Array (Fixed)] → Minterms → [OR Array (Programmable)] → Outputs
                                          ↑
                                      Fuses (blown to configure)
🔑 Key insight: PROMs are useful for implementing functions that may change during development. PALs and PLAs offer more flexibility with programmable AND and OR arrays.
📘 Unit 4 summary
Combinational logic circuits produce outputs based on current inputs. Key components include adders, subtractors, decoders, encoders, multiplexers, demultiplexers, code converters, and PROMs.
🔑 Key takeaways
• Combinational circuits: no memory, output = f(input).
• Adders: half, full, ripple carry.
• Subtractors: half, full, two's complement.
• Decoder: n inputs → 2ⁿ outputs.
• Encoder: 2ⁿ inputs → n outputs.
• MUX: selects one of many inputs.
• DEMUX: routes one input to many outputs.
• Code conversion: BCD, Gray, Excess-3, 2421.
• PROM: fixed AND, programmable OR.
