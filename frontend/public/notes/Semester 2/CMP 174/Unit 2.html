2.1 Basic Laws of Boolean Algebra

Boolean algebra is a mathematical framework used to analyze and design digital circuits, manipulating binary variables (0 and 1) with operations like AND, OR, and NOT.

🧮 Purpose
Simplify logic expressions, optimize digital circuits, and provide a mathematical foundation for computer hardware design.
🔑 Key Operations
AND (·), OR (+), NOT (') — the fundamental operations of Boolean algebra.

Fundamental Laws

IdempotentA + A = AA · A = A

A·A' = 0
💡 Key insight: Boolean algebra laws are essential for simplifying logic circuits, reducing the number of gates, and minimizing power consumption and cost.

2.2 De Morgan's Theorems

De Morgan's theorems provide rules to transform logical expressions involving complements, useful for circuit design and simplification.

The Theorems

  • First Theorem: (A + B)' = A' · B' — The complement of an OR is the AND of the complements.
  • Second Theorem: (A · B)' = A' + B' — The complement of an AND is the OR of the complements.

Generalization

  • For n variables:
    • (A₁ + A₂ + ... + Aₙ)' = A₁' · A₂' · ... · Aₙ'
    • (A₁ · A₂ · ... · Aₙ)' = A₁' + A₂' + ... + Aₙ'
// De Morgan's Theorem Examples

// Example 1: 3 variables
(A + B + C)' = A' · B' · C'
(A · B · C)' = A' + B' + C'

// Example 2: Simplification
F = (A + B)' · C
F = (A' · B') · C
F = A' · B' · C
📐 Key insight: De Morgan's theorems allow conversion between AND/OR gates and are essential for implementing circuits using only NAND or NOR gates.

2.5 Universal Gates

Universal gates can implement any Boolean function, reducing the need for multiple gate types in circuit design.

NAND Gate as Universal Gate

  • NOT using NAND: A NAND A = (A · A)' = A'
  • AND using NAND: (A NAND B)' = ((A · B)')' = A · B
  • OR using NAND: (A' NAND B') = (A' · B')' = A + B
// NAND Gate Implementations

// NOT gate using NAND
NOT A = A NAND A

// AND gate using NAND
A · B = (A NAND B) NAND (A NAND B)

// OR gate using NAND
A + B = (A NAND A) NAND (B NAND B)

NOR Gate as Universal Gate

  • NOT using NOR: A NOR A = (A + A)' = A'
  • OR using NOR: (A NOR B)' = ((A + B)')' = A + B
  • AND using NOR: (A' NOR B') = (A' + B')' = A · B
// NOR Gate Implementations

// NOT gate using NOR
NOT A = A NOR A

// OR gate using NOR
A + B = (A NOR B) NOR (A NOR B)

// AND gate using NOR
A · B = (A NOR A) NOR (B NOR B)

🔑 Key insight: NAND and NOR gates are called "universal" because they can implement any logic function. This simplifies manufacturing and reduces the variety of gate types needed in integrated circuits.
