7.1 Arithmetic Logic Unit (Design of 4-bit ALU)

The Arithmetic Logic Unit (ALU) is a core component of a processor that performs arithmetic and logical operations on binary data.

🔢 Definition
A 4-bit ALU processes 4-bit operands, performing operations like addition, subtraction, AND, OR, and NOT based on control signals.
📐 Design
Uses four 1-bit ALUs in parallel, each with logic unit, arithmetic unit (full adder), and multiplexer to select output based on control signals.

ALU Inputs and Outputs

  • Inputs:
    • Operand A (4-bit): A₃A₂A₁A₀
    • Operand B (4-bit): B₃B₂B₁B₀
    • Control Signals: S₁, S₀ (select operation)
    • Carry-in: C_in
  • Outputs:
    • Result F (4-bit): F₃F₂F₁F₀
    • Carry-out: C_out
    • Status Flags: Zero (Z), Overflow (V), Sign (S)

ALU Operation Table

S₁S₀OperationDescription
00F = A AND BBitwise AND
01F = A OR BBitwise OR
10F = A + BArithmetic Addition
11F = A - BArithmetic Subtraction (two's complement)

1-Bit ALU Design

  • Logic Unit: AND, OR gates for logical operations.
  • Arithmetic Unit: Full adder for addition; subtraction via two's complement.
  • Multiplexer: Selects output based on S₁, S₀.
1-Bit ALU:
┌─────────────────────────────────────┐
│  A ───┐         ┌─────────┐        │
│       ├──[AND]──┤         │        │
│  B ───┼──[OR]───┤  MUX    ├── F    │
│       ├──[ADD]──┤         │        │
│  C_in ┤         └─────────┘        │
│       └─────────────────────────────┘
│  S₁, S₀ ─────────────────────► Select
└─────────────────────────────────────┘
// 4-bit ALU Example
// A = 1010 (10), B = 0011 (3), S₁=1, S₀=0 (ADD)
// Result: F = 1010 + 0011 = 1101 (13)
// Flags: Z=0, C=0, V=0
💡 Key insight: The ALU is the computational engine of the CPU. Its design balances speed, functionality, and complexity. A 4-bit ALU is a fundamental building block for larger processors.

7.2 Accumulator

An accumulator is a register that stores intermediate results during processing, typically used in arithmetic and logic operations.

Definition and Operation

  • Definition: A special-purpose register that holds one operand and the result of an ALU operation.
  • Operation:
    • Receives data from memory or input.
    • Feeds data to the ALU.
    • Stores the ALU's output after each operation.

Structure

  • Typically a 4-bit or 8-bit register using D flip-flops.
  • Example: A 4-bit accumulator uses four D flip-flops, updated on clock pulses.
// Accumulator Example
// Acc = 0011 (3), ADD 0100 (4)
// ALU computes 0011 + 0100 = 0111 (7)
// Result stored back in accumulator
// New Acc = 0111 (7)

Applications

  • Iterative computations (e.g., summing values)
  • Arithmetic operations in CPUs
  • Temporary storage in microprocessors
  • Data accumulation in signal processing

7.3 Status Register and Flags

The status register (or flag register) stores condition flags that indicate the outcome of ALU operations.

Common Flags

FlagSymbolConditionExample
ZeroZResult = 05 - 5 = 0 → Z=1
CarryCCarry-out in addition, borrow in subtraction15 + 1 = 16 (4-bit) → C=1
SignSResult is negative (MSB=1 in two's complement)-3 (1101₂) → S=1
OverflowVArithmetic overflow occurred7 + 7 = 14 (4-bit) → V=1

Flag Examples

// 7 - 4 = 3
// 0111 - 0100 = 0011
// Flags: Z=0, C=0, S=0, V=0

// 7 + 7 = 14 (4-bit overflow)
// 0111 + 0111 = 1110
// Flags: Z=0, C=0, S=1, V=1

Implementation

  • A 4-bit status register stores Z, C, S, V as individual flip-flops.
  • Updated after each ALU operation.
  • Used for conditional jumps and decision-making in CPUs.
🚩 Key insight: Flags enable conditional execution in programs. The status register allows the processor to make decisions based on previous operation results.

7.4 Processor Unit

The processor unit (Central Processing Unit or CPU) is the core of a digital system, executing instructions by processing data through its components.

CPU Components

  • ALU: Performs arithmetic and logical operations.
  • Registers:
    • Accumulator (Acc) — stores ALU results
    • Program Counter (PC) — points to next instruction
    • Instruction Register (IR) — holds current instruction
    • General-purpose registers
  • Control Unit: Generates control signals for fetch-decode-execute cycles.
  • Status Register: Stores flags for conditional execution.

CPU Operation Cycle

  • Fetch:
    • PC sends address to memory.
    • Instruction loaded into IR.
    • PC incremented.
  • Decode:
    • Control unit interprets instruction in IR.
    • Generates control signals.
  • Execute:
    • ALU processes data based on control signals.
    • Results stored in accumulator or memory.
    • Flags updated in status register.
