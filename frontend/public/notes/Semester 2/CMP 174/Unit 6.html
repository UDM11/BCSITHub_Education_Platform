6.1 Shift Register

A shift register is a sequential logic circuit composed of flip-flops connected in series, used to store and shift data in a digital system.

📦 Definition
A cascade of flip-flops where the output of one flip-flop is connected to the input of the next, allowing data to shift left or right with each clock pulse.
⚡ Operation
Data bits are shifted by one position per clock cycle, either left (toward higher-order bits) or right (toward lower-order bits).

Components and Operation

  • Flip-flops: Typically D or JK flip-flops.
  • Clock Signal: Synchronizes the shifting process.
  • Example: 4-bit shift register shifting right: 1011 → 0101 (with 0 input).
4-Bit Shift Register:
┌─────┐   ┌─────┐   ┌─────┐   ┌─────┐
│ D0  │──▶│ D1  │──▶│ D2  │──▶│ D3  │
│ Q0  │   │ Q1  │   │ Q2  │   │ Q3  │
└─────┘   └─────┘   └─────┘   └─────┘
   ↑         ↑         ↑         ↑
  Clock     Clock     Clock     Clock

Applications

  • Data storage and transfer
  • Serial-to-parallel conversion
  • Delay lines
  • Communication systems
  • Digital signal processing

6.2 Modes of Shift Register (SISO, SIPO, PISO, PIPO)

Shift registers operate in different modes based on how data is input and output.

SISO (Serial-In, Serial-Out)

  • Input: Serial (one bit at a time)
  • Output: Serial (one bit at a time)
  • Example: 4-bit SISO with input 1010 → after 4 cycles, output is 1010.
  • Use: Data delay, temporary storage in serial communication.

SIPO (Serial-In, Parallel-Out)

  • Input: Serial
  • Output: Parallel (all bits simultaneously)
  • Example: 4-bit SIPO: shift in 1010, then output Q₃Q₂Q₁Q₀ = 1010.
  • Use: Serial-to-parallel conversion (e.g., receiving serial data).

PISO (Parallel-In, Serial-Out)

  • Input: Parallel (all bits simultaneously)
  • Output: Serial
  • Example: 4-bit PISO: load 1010 in parallel, then shift out one bit per cycle.
  • Use: Parallel-to-serial conversion (e.g., transmitting parallel data).

PIPO (Parallel-In, Parallel-Out)

  • Input: Parallel
  • Output: Parallel
  • Example: 4-bit PIPO: load 1010 and output 1010 after one clock cycle.
  • Use: Data storage and transfer (e.g., CPU registers).

6.3 Asynchronous Counter (Binary Ripple, BCD Counter)

Asynchronous counters are sequential circuits where flip-flops are not synchronized by a common clock, leading to ripple effects in state changes.

Binary Ripple Counter

  • Circuit: Uses T or JK flip-flops, where each flip-flop's output clocks the next.
  • Operation: First flip-flop toggles on clock pulse; its output toggles the next, causing a ripple effect.
  • Example: 3-bit counter sequence: 000, 001, 010, 011, 100, 101, 110, 111.
  • Drawback: Propagation delay due to rippling, limiting speed.
// 3-bit Ripple Counter Sequence
Clock 0: 000
Clock 1: 001
Clock 2: 010
Clock 3: 011
Clock 4: 100
Clock 5: 101
Clock 6: 110
Clock 7: 111
Clock 8: 000 (rollover)

BCD Counter (Binary-Coded Decimal)

  • Counts: 0 to 9 (0000 to 1001 in BCD).
  • Operation: Resets to 0000 after 1001 using additional logic.
  • Example: After 1001 (9), next state is 0000 instead of 1010.
  • Use: Decimal displays in digital clocks and calculators.

⏱️ Key insight: Asynchronous counters are simple but slow due to ripple propagation delay. They are suitable for low-speed applications where timing precision is not critical.

6.4 Synchronous Counter (Up/Down Counter)

Synchronous counters use a common clock to synchronize all flip-flops, eliminating ripple delays.

Operation

  • All flip-flops toggle based on a single clock signal and control logic.
  • Example: 3-bit synchronous counter uses T flip-flops with:
    • T₀ = 1 (always toggles)
    • T₁ = Q₀ (toggles when Q₀ = 1)
    • T₂ = Q₀ · Q₁ (toggles when Q₀ = 1 and Q₁ = 1)

Up Counter

  • Counts upward: 000, 001, 010, ..., 111.
  • Logic: T₀ = 1, T₁ = Q₀, T₂ = Q₀ · Q₁.

Down Counter

  • Counts downward: 111, 110, 101, ..., 000.
  • Logic: T₀ = 1, T₁ = Q₀', T₂ = Q₀' · Q₁'.

Up/Down Counter

  • Switches between up and down counting based on a control input.
  • Mode: Mode = 1 for up, Mode = 0 for down.
  • Implementation: Use multiplexers to select between up and down logic.
// 3-bit Synchronous Up Counter Logic
T₀ = 1
T₁ = Q₀
T₂ = Q₀ · Q₁

// 3-bit Synchronous Down Counter Logic
T₀ = 1
T₁ = Q₀'
T₂ = Q₀' · Q₁'

// Up/Down Counter
T₀ = 1
T₁ = Mode ? Q₀ : Q₀'
T₂ = Mode ? (Q₀ · Q₁) : (Q₀' · Q₁')

Advantages

  • Faster: No ripple delay, all flip-flops update simultaneously.
  • More predictable: Synchronous timing ensures reliable operation.
  • Use: High-speed circuits, frequency dividers, and timers in microprocessors.
🚀 Key insight: Synchronous counters are preferred in high-speed applications because they eliminate propagation delays. The design is more complex but offers better performance and reliability.
📘 Unit 6 summary
Registers store and shift data; counters count sequences. Shift registers have SISO, SIPO, PISO, PIPO modes. Counters can be asynchronous (ripple) or synchronous.
🔑 Key takeaways
• Shift registers: store and shift data.
• Modes: SISO, SIPO, PISO, PIPO.
• Asynchronous counters: ripple effect, simpler but slower.
• Binary ripple counter: counts in binary.
• BCD counter: counts 0-9, resets to 0.
• Synchronous counters: common clock, no ripple.
• Up/Down counters: count in either direction.
