3.1 Introduction

A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle, where the last element added is the first to be removed. It can be visualized as a stack of plates, where you can only add or remove plates from the top.

📚 LIFO Principle
Last In, First Out — the most recently added element is the first to be removed. Like a stack of books or plates.
🎯 Key Operations
Push (add to top) and Pop (remove from top). Additional operations: Peek, isEmpty, isFull.

Real-World Analogy

  • Stack of Plates: Add plates on top, remove from top.
  • Browser Back Button: Stores visited pages; pressing back goes to the most recent page.
  • Undo Operation: Reverses the most recent action first.

3.2 Operation Stack

Stacks support two primary operations:

Primary Operations

  • Push: Adds an element to the top of the stack.
    // Push Operation
    void push(int value) {
        if (isFull()) {
            printf("Stack Overflow\n");
            return;
        }
        stack[++top] = value;
    }
  • Pop: Removes and returns the top element from the stack.
    // Pop Operation
    int pop() {
        if (isEmpty()) {
            printf("Stack Underflow\n");
            return -1;
        }
        return stack[top--];
    }

Additional Operations

  • Peek/Top: Returns the top element without removing it.
  • isEmpty: Checks if the stack is empty.
  • isFull: Checks if the stack is full (for fixed-size stacks).

3.3 Stack Terminology

Key terms associated with stacks:

TermDescription
TopThe index or pointer indicating the topmost element of the stack.
CapacityThe maximum number of elements a stack can hold (for array-based stacks).
SizeThe current number of elements in the stack.
Stack OverflowOccurs when trying to push an element onto a full stack.
Stack UnderflowOccurs when trying to pop an element from an empty stack.
// Stack Terminology in Code
#define MAX 100
int stack[MAX];
int top = -1; // top = -1 indicates empty stack
// top = MAX-1 indicates full stack

3.4 Algorithm for POP and PUSH

Push Algorithm

// Algorithm: Push
Algorithm Push(stack, element, maxSize)
1. If size(stack) >= maxSize
    Print "Stack Overflow"
    Return
2. top = top + 1
3. stack[top] = element

Pop Algorithm

// Algorithm: Pop
Algorithm Pop(stack)
1. If isEmpty(stack)
    Print "Stack Underflow"
    Return null
2. element = stack[top]
3. top = top - 1
4. Return element
// Complete Stack Implementation in C
#include <stdio.h>
#define MAX 100

int stack[MAX];
int top = -1;

void push(int value) {
    if (top >= MAX - 1) {
        printf("Stack Overflow\n");
        return;
    }
    stack[++top] = value;
}

int pop() {
    if (top < 0) {
        printf("Stack Underflow\n");
        return -1;
    }
    return stack[top--];
}

int peek() {
    if (top < 0) {
        printf("Stack is empty\n");
        return -1;
    }
    return stack[top];
}

int isEmpty() {
    return top == -1;
}

int isFull() {
    return top == MAX - 1;
}

3.5 Stack Applications

1. Function Call Management (Call Stack)

  • Used to manage function calls and recursion.
  • Each function call creates a stack frame with local variables and return address.

2. Reverse a String

// Reverse String using Stack
#include <stdio.h>
#include <string.h>
#define MAX 100

char stack[MAX];
int top = -1;

void push(char c) { stack[++top] = c; }
char pop() { return stack[top--]; }

void reverse(char *str) {
    for (int i = 0; i < strlen(str); i++) {
        push(str[i]);
    }
    for (int i = 0; i < strlen(str); i++) {
        str[i] = pop();
    }
}

int main() {
    char str[MAX] = "hello";
    reverse(str);
    printf("Reversed: %s\n", str); // "olleh"
    return 0;
}

3. Postfix Expression Evaluation

// Postfix Evaluation using Stack
#include <stdio.h>
#include <ctype.h>

int stack[100];
int top = -1;

void push(int x) { stack[++top] = x; }
int pop() { return stack[top--]; }

int evaluate(char* exp) {
    for (int i = 0; exp[i]; i++) {
        if (isdigit(exp[i])) {
            push(exp[i] - '0');
        } else {
            int b = pop();
            int a = pop();
            switch (exp[i]) {
                case '+': push(a + b); break;
                case '-': push(a - b); break;
                case '*': push(a * b); break;
                case '/': push(a / b); break;
            }
        }
    }
    return pop();
}

int main() {
    char exp[] = "34+";
    printf("Result: %d\n", evaluate(exp)); // 7
    return 0;
}

4. Undo/Redo Operations

  • Two stacks: one for undo history, one for redo history.
  • Push operations onto undo stack; pop and push to redo when undoing.

3.6 Algorithm for Converting Infix Expression to Postfix Form

An infix expression (e.g., A + B * C) is converted to postfix form (e.g., A B C * +) using a stack.

Algorithm

  • Scan the infix expression from left to right.
  • If operand: add to postfix expression.
  • If '(': push onto stack.
  • If ')': pop and output until '(' is encountered.
  • If operator: pop operators with higher or equal precedence and output them, then push the current operator.
  • At the end, pop all remaining operators.
// Infix to Postfix Conversion in C
#include <stdio.h>
#include <ctype.h>
#include <string.h>

#define MAX 100
char stack[MAX];
int top = -1;

void push(char c) { stack[++top] = c; }
char pop() { return stack[top--]; }

int precedence(char op) {
    switch(op) {
        case '+':
        case '-': return 1;
        case '*':
        case '/': return 2;
        case '^': return 3;
        default: return 0;
    }
}

void infixToPostfix(char* infix, char* postfix) {
    int i, j = 0;
    char c;
    for (i = 0; infix[i]; i++) {
        c = infix[i];
        if (isalnum(c)) {
            postfix[j++] = c;
        } else if (c == '(') {
            push(c);
        } else if (c == ')') {
            while (top != -1 && stack[top] != '(') {
                postfix[j++] = pop();
            }
            pop(); // remove '('
        } else {
            while (top != -1 && precedence(stack[top]) >= precedence(c)) {
                postfix[j++] = pop();
            }
            push(c);
        }
    }
    while (top != -1) {
        postfix[j++] = pop();
    }
    postfix[j] = '\0';
}

int main() {
    char infix[MAX] = "A+B*C";
    char postfix[MAX];
    infixToPostfix(infix, postfix);
    printf("Postfix: %s\n", postfix); // "ABC*+"
    return 0;
}
