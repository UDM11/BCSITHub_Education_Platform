7.1 Introduction

Sorting is the process of arranging elements in a specific order, typically ascending or descending. It is a fundamental operation in computer science, used in databases, searching, and data processing. Efficient sorting improves the performance of algorithms that rely on ordered data.

📊 What is Sorting?
Arranging data in a specific order (ascending or descending) to enable efficient searching, indexing, and data processing.
🎯 Why Sort?
Improves search efficiency (binary search), enables data analysis, and is a building block for many algorithms.

Real-World Applications

  • Database indexing and query optimization.
  • E-commerce product listings (price, rating, popularity).
  • Data analysis and statistics (sorting for percentiles, medians).
  • Operating system process scheduling.

7.2 Internal & External Sort

Internal Sort

  • Definition: Sorting performed entirely within the main memory (RAM).
  • Suitable For: Small to medium datasets that fit in memory.
  • Examples: Bubble Sort, Quick Sort, Merge Sort, Insertion Sort.
  • Characteristics: Fast access, no disk I/O overhead.

External Sort

  • Definition: Sorting used for large datasets that cannot fit in main memory, requiring disk storage.
  • Approach: Divide data into smaller chunks, sort each chunk in memory, then merge the sorted chunks.
  • Example: External Merge Sort.
  • Characteristics: Uses disk I/O, more complex, handles large datasets.

7.3 Common Sorting Algorithms

Bubble Sort

  • Approach: Repeatedly compares adjacent elements and swaps them if they are in the wrong order.
  • Time Complexity: O(n²)
  • Space Complexity: O(1)
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j+1]);
            }
        }
    }
}

Insertion Sort

  • Approach: Builds sorted array one element at a time by inserting each element into its correct position.
  • Time Complexity: O(n²)
  • Space Complexity: O(1)
  • Best For: Small datasets or partially sorted arrays.
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

Selection Sort

  • Approach: Repeatedly selects the smallest element from the unsorted portion and places it at the beginning.
  • Time Complexity: O(n²)
  • Space Complexity: O(1)
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        swap(&arr[i], &arr[minIdx]);
    }
}

Quick Sort

  • Approach: Divide-and-conquer. Selects a pivot and partitions the array around it.
  • Time Complexity: O(n log n) average, O(n²) worst case.
  • Space Complexity: O(log n) (recursive stack).
  • Best For: Large datasets, general-purpose sorting.
int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i+1], &arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

Merge Sort

  • Approach: Divide-and-conquer. Divides array into halves, recursively sorts, and merges.
  • Time Complexity: O(n log n)
  • Space Complexity: O(n)
  • Best For: Large datasets where stability is required.
void merge(int arr[], int l, int m, int r) {
    int n1 = m - l + 1, n2 = r - m;
    int L[n1], R[n2];
    for (int i = 0; i < n1; i++) L[i] = arr[l+i];
    for (int i = 0; i < n2; i++) R[i] = arr[m+1+i];
    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) {
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    }
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void mergeSort(int arr[], int l, int r) {
    if (l < r) {
        int m = l + (r - l) / 2;
        mergeSort(arr, l, m);
        mergeSort(arr, m + 1, r);
        merge(arr, l, m, r);
    }
}

Shell Sort

  • Approach: Optimization of insertion sort using a gap sequence.
  • Time Complexity: O(n^(4/3)) to O(n²) depending on gap sequence.
  • Space Complexity: O(1)
void shellSort(int arr[], int n) {
    for (int gap = n/2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = arr[i], j;
            for (j = i; j >= gap && arr[j - gap] > temp; j -= gap)
                arr[j] = arr[j - gap];
            arr[j] = temp;
        }
    }
}

Binary Insertion Sort

  • Approach: Insertion sort that uses binary search to find the insertion point.
  • Time Complexity: O(n²) for insertions, O(n log n) for searches.
  • Space Complexity: O(1)
int binarySearch(int arr[], int key, int low, int high) {
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] <= key) low = mid + 1;
        else high = mid;
    }
    return low;
}

void binaryInsertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int loc = binarySearch(arr, key, 0, i);
        for (int j = i - 1; j >= loc; j--)
            arr[j + 1] = arr[j];
        arr[loc] = key;
    }
}

Big O Notation Summary

  • O(1): Constant time — independent of input size.
  • O(n): Linear time — grows proportionally with input size.
  • O(n²): Quadratic time — grows with the square of input size (inefficient for large n).
  • O(n log n): Log-linear time — efficient for large datasets.

Choosing the Right Algorithm

  • Small datasets: Insertion Sort or Selection Sort.
  • Large datasets: Quick Sort or Merge Sort.
  • Data nearly sorted: Insertion Sort (O(n) best case).
  • Stability required: Merge Sort or Insertion Sort.
  • Memory constraints: Quick Sort (in-place) or Heap Sort.
📊 Key insight: No single sorting algorithm is best for all cases. The choice depends on dataset size, memory constraints, stability requirements, and whether the data is partially sorted.
