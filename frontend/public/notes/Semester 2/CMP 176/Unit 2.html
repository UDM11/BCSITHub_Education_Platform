2.1 Introduction to Recursion

Recursion is a programming technique where a function calls itself to solve a smaller instance of the same problem. It breaks a complex problem into simpler subproblems, each solved in the same manner, until a base case is reached that stops the recursion.

🔄 What is Recursion?
A function that calls itself to solve smaller subproblems. It's a powerful technique for problems that can be defined in terms of themselves.
📐 Key Components
Base Case (termination condition) and Recursive Case (self-call with smaller input).

Why Use Recursion?

  • Simplifies Complex Problems: Breaks problems into smaller, manageable pieces.
  • Natural Fit: Some problems are inherently recursive (tree traversal, divide-and-conquer).
  • Readability: Recursive solutions can be more elegant and easier to understand.
// Basic Recursion Structure
void recursiveFunction(parameters) {
    if (baseCondition) {
        // Base case: stop recursion
        return;
    }
    // Recursive case: call itself with smaller input
    recursiveFunction(modifiedParameters);
}

2.2 Principle of Recursion

The principle of recursion relies on two key components:

Components of Recursion

  • Base Case: The condition that terminates the recursion, preventing infinite calls. Provides a direct solution for the smallest subproblem.
  • Recursive Case: The part where the function calls itself with a modified input, reducing the problem size toward the base case.

How Recursion Works

  • Call Stack: Each recursive call is pushed onto the stack until the base case is reached.
  • Unwinding: After the base case, the stack unwinds, returning results back up the chain.
Recursion Flow:
factorial(4)
    ├── 4 * factorial(3)
    │   ├── 3 * factorial(2)
    │   │   ├── 2 * factorial(1)
    │   │   │   ├── 1 * factorial(0)
    │   │   │   │   └── 1 (base case)
    │   │   │   └── 1 * 1 = 1
    │   │   └── 2 * 1 = 2
    │   └── 3 * 2 = 6
    └── 4 * 6 = 24
// Factorial Example
int factorial(int n) {
    if (n == 0 || n == 1) { // Base case
        return 1;
    }
    return n * factorial(n - 1); // Recursive case
}

2.3 Types of Recursions

Recursion can be categorized based on how the recursive calls are structured.

Direct Recursion

  • A function calls itself directly within its body.
  • Example: Factorial, Fibonacci.
int sum(int n) {
    if (n <= 0) return 0;
    return n + sum(n - 1);
}

Indirect Recursion

  • A function calls another function, which eventually calls the original function.
  • Forms a cycle of calls.
void funcB(int n); // Forward declaration

void funcA(int n) {
    if (n > 0) {
        printf("%d\n", n);
        funcB(n - 1);
    }
}

void funcB(int n) {
    if (n > 0) {
        printf("%d\n", n);
        funcA(n - 1);
    }
}

Linear Recursion

  • Makes a single recursive call in each invocation.
  • Example: Factorial, sum of numbers.

Tree Recursion

  • Makes multiple recursive calls in each invocation.
  • Example: Fibonacci (calls itself twice).

Tail Recursion

  • The recursive call is the last operation in the function.
  • Allows compilers to optimize by reusing the same stack frame.
// Tail Recursive Factorial
int factorialTail(int n, int acc) {
    if (n == 0 || n == 1) return acc;
    return factorialTail(n - 1, acc * n);
}
// Call with factorialTail(n, 1)

2.4 Recursion Examples

Tower of Hanoi (TOH)

  • A classic puzzle where n disks are moved from one peg to another using an auxiliary peg.
  • Rules: Only one disk at a time, larger disk cannot be placed on a smaller one.
void towerOfHanoi(int n, char source, char auxiliary, char destination) {
    if (n == 1) {
        printf("Move disk 1 from %c to %c\n", source, destination);
        return;
    }
    towerOfHanoi(n - 1, source, destination, auxiliary);
    printf("Move disk %d from %c to %c\n", n, source, destination);
    towerOfHanoi(n - 1, auxiliary, source, destination);
}

// For n=2: prints steps to move 2 disks

Fibonacci Series

  • Sequence where each number is the sum of the two preceding ones: 0, 1, 1, 2, 3, 5, 8, ...
int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

// Time Complexity: O(2^n) - exponential
// Space Complexity: O(n) - call stack depth

2.5 Application of Recursion

Recursion is applied in various domains due to its ability to simplify complex problems.

Common Applications

  • Tree and Graph Traversal:
    • Depth-First Search (DFS)
    • Tree traversals: preorder, inorder, postorder
    • Binary search trees operations
  • Divide-and-Conquer Algorithms:
    • Merge Sort
    • Quick Sort
    • Binary Search
  • Mathematical Computations:
    • Factorial, Fibonacci
    • GCD (Greatest Common Divisor)
    • Power/exponentiation
  • Backtracking:
    • N-Queens problem
    • Sudoku solver
    • Maze solving
  • Dynamic Programming:
    • Knapsack problem (with memoization)
    • Longest Common Subsequence
// Binary Search using Recursion
int binarySearch(int arr[], int left, int right, int x) {
    if (right >= left) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == x) return mid;
        if (arr[mid] > x)
            return binarySearch(arr, left, mid - 1, x);
        return binarySearch(arr, mid + 1, right, x);
    }
    return -1;
}
// Time: O(log n), Space: O(log n) for call stack
// Preorder Tree Traversal using Recursion
void preorder(Node* root) {
    if (root == NULL) return;
    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}
🔄 Key insight: Recursion is a powerful tool for problems that have a recursive structure. Understanding when to use recursion and when to use iteration is crucial for writing efficient code.
