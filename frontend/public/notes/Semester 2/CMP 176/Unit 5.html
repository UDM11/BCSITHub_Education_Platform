Unit 5: Linked List

Introduction · advantages & disadvantages · operations · types · insertion · deletion · polynomial addition

5.1 Introduction

A linked list is a linear data structure where elements, called nodes, are linked using pointers. Unlike arrays, linked lists do not store elements in contiguous memory locations, allowing dynamic memory allocation and flexible size management.

🔗 What is a Linked List?
A sequence of nodes where each node contains data and a pointer to the next node. The last node points to NULL.
📊 Key Features
Dynamic size, efficient insertions/deletions, non-contiguous memory allocation.
Singly Linked List Structure:
┌─────────┐    ┌─────────┐    ┌─────────┐
│ Data │Next│───▶│ Data │Next│───▶│ Data │NULL│
└─────────┘    └─────────┘    └─────────┘
    Head                                      Tail

5.2 Linked List: Advantages and Disadvantages

Advantages

  • Dynamic Size: Grows or shrinks during runtime, unlike arrays with fixed sizes.
  • Efficient Insertions/Deletions: O(1) if the position is known, compared to O(n) for arrays (which require shifting).
  • Memory Efficiency: Allocates memory only as needed, avoiding wasted space.

Disadvantages

  • No Random Access: Accessing an element requires traversal (O(n) time).
  • Extra Memory: Requires additional memory for storing pointers to link nodes.
  • Poor Cache Performance: Non-contiguous memory allocation leads to slower access compared to arrays.

5.3 Key Terms

  • Data Field: The part of a node that stores the actual data (e.g., integer, string, or object).
  • Link Field (Next): The part of a node that stores a reference (pointer) to the next node.
  • Head: The first node of the linked list.
  • Tail: The last node of the linked list (points to NULL).
  • Node: The basic unit of a linked list containing data and link fields.
// Node Structure in C
struct Node {
    int data; // Data field
    struct Node* next; // Link field (pointer to next node)
};

5.4 Representation of Linear Linked List

A linear linked list is a sequence of nodes where each node contains a data field and a link field pointing to the next node. The last node's link field points to NULL.

[Data | Next] -> [Data | Next] -> [Data | NULL]
    Head                               Tail
// C Representation of Linked List
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} LinkedList;

Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}

5.5 Operations of Linked List

  • Creation: Initialize an empty list or create nodes with data.
  • Insertion: Add a node at the beginning, end, or a specific position.
  • Deletion: Remove a node from the beginning, end, or a specific position.
  • Traversing: Visit each node to process or display data.
  • Searching: Find a node with a specific value.
  • Concatenation: Merge two linked lists into one.
  • Display: Print the elements of the list.
// Basic Operations Implementation
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} LinkedList;

Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}

void insertAtBeginning(LinkedList* list, int data) {
    Node* newNode = createNode(data);
    newNode->next = list->head;
    list->head = newNode;
}

void deleteAtBeginning(LinkedList* list) {
    if (list->head != NULL) {
        Node* temp = list->head;
        list->head = list->head->next;
        free(temp);
    }
}

void display(LinkedList* list) {
    Node* current = list->head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}

5.6 Types of Linked List

Singly Linked List

  • Each node has data and a pointer to the next node.
  • Last node points to NULL.

Doubly Linked List

  • Each node has data, next pointer, and previous pointer.
  • Allows bidirectional traversal.

Circular Linked List

  • The last node points to the first node, forming a loop.
  • Can be singly or doubly linked.

Circular Doubly Linked List

  • A doubly linked list where the last node's next points to the first, and the first's prev points to the last.
Types of Linked Lists:
Singly:     [A]→[B]→[C]→NULL
Doubly:     NULL←[A]⇄[B]⇄[C]→NULL
Circular:   [A]→[B]→[C]→[A] (loop)
Circular Doubly: [A]⇄[B]⇄[C]⇄[A]

5.7 Create Single Linked List

Creating a singly linked list involves defining a node structure and initializing a list with nodes.

// Create Linked List from Array
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} LinkedList;

Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}

void createList(LinkedList* list, int values[], int size) {
    list->head = NULL;
    for (int i = 0; i < size; i++) {
        Node* newNode = createNode(values[i]);
        if (list->head == NULL) {
            list->head = newNode;
        } else {
            Node* current = list->head;
            while (current->next != NULL) {
                current = current->next;
            }
            current->next = newNode;
        }
    }
}

void display(LinkedList* list) {
    Node* current = list->head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}

5.8 Insertion of Single Linked List at Specific Position

// Insert at Position Algorithm
Algorithm InsertAtPosition(list, data, position)
1. Create new node with data
2. If position == 1
    a. newNode.next = head
    b. head = newNode
    c. Return
3. current = head, count = 1
4. While count < position - 1 and current != null
    a. current = current.next
    b. count++
5. If current == null
    Print "Invalid position"
    Return
6. newNode.next = current.next
7. current.next = newNode
// Insert at Position Implementation
void insertAtPosition(LinkedList* list, int data, int position) {
    Node* newNode = createNode(data);
    if (position == 1) {
        newNode->next = list->head;
        list->head = newNode;
        return;
    }
    Node* current = list->head;
    int count = 1;
    while (count < position - 1 && current != NULL) {
        current = current->next;
        count++;
    }
    if (current == NULL) {
        printf("Invalid position\n");
        free(newNode);
        return;
    }
    newNode->next = current->next;
    current->next = newNode;
}

5.9 Deletion of Single Linked List at Specific Position

// Delete at Position Algorithm
Algorithm DeleteAtPosition(list, position)
1. If head == null
    Print "List is empty"
    Return
2. If position == 1
    a. head = head.next
    b. Return
3. current = head, count = 1
4. While count < position - 1 and current != null
    a. current = current.next
    b. count++
5. If current == null or current.next == null
    Print "Invalid position"
    Return
6. current.next = current.next.next
// Delete at Position Implementation
void deleteAtPosition(LinkedList* list, int position) {
    if (list->head == NULL) {
        printf("List is empty\n");
        return;
    }
    if (position == 1) {
        Node* temp = list->head;
        list->head = list->head->next;
        free(temp);
        return;
    }
    Node* current = list->head;
    int count = 1;
    while (count < position - 1 && current != NULL) {
        current = current->next;
        count++;
    }
    if (current == NULL || current->next == NULL) {
        printf("Invalid position\n");
        return;
    }
    Node* temp = current->next;
    current->next = current->next->next;
    free(temp);
}

5.10 Application: Addition of Two Polynomials

Linked lists are ideal for representing and adding polynomials, where each node stores a coefficient and an exponent.

// Polynomial Addition Algorithm
Algorithm AddPolynomials(poly1, poly2)
1. Initialize result list as empty
2. While poly1 != null and poly2 != null
    a. If poly1.exponent == poly2.exponent
        i. Add coefficients, create new node with sum
        ii. Move both to next
    b. Else if poly1.exponent > poly2.exponent
        i. Add poly1 term to result
        ii. Move poly1 to next
    c. Else
        i. Add poly2 term to result
        ii. Move poly2 to next
3. Append remaining nodes of poly1 or poly2
4. Return result
// Polynomial Addition Implementation
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int coefficient, exponent;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} Polynomial;

Node* createPolyNode(int coeff, int exp) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->coefficient = coeff;
    newNode->exponent = exp;
    newNode->next = NULL;
    return newNode;
}

void addPolynomials(Polynomial* p1, Polynomial* p2, Polynomial* result) {
    Node* a = p1->head;
    Node* b = p2->head;
    Node* temp = NULL;
    result->head = NULL;

    while (a != NULL && b != NULL) {
        Node* newNode = createPolyNode(0, 0);
        if (a->exponent == b->exponent) {
            newNode->coefficient = a->coefficient + b->coefficient;
            newNode->exponent = a->exponent;
            a = a->next; b = b->next;
        } else if (a->exponent > b->exponent) {
            newNode->coefficient = a->coefficient;
            newNode->exponent = a->exponent;
            a = a->next;
        } else {
            newNode->coefficient = b->coefficient;
            newNode->exponent = b->exponent;
            b = b->next;
        }
        if (result->head == NULL) {
            result->head = newNode;
            temp = newNode;
        } else {
            temp->next = newNode;
            temp = newNode;
        }
    }
    while (a != NULL) {
        temp->next = createPolyNode(a->coefficient, a->exponent);
        temp = temp->next;
        a = a->next;
    }
    while (b != NULL) {
        temp->next = createPolyNode(b->coefficient, b->exponent);
        temp = temp->next;
        b = b->next;
    }
}

void displayPolynomial(Polynomial* p) {
    Node* current = p->head;
    while (current != NULL) {
        printf("%dx^%d ", current->coefficient, current->exponent);
        current = current->next;
    }
    printf("\n");
}

int main() {
    Polynomial p1, p2, result;
    p1.head = createPolyNode(5, 2);
    p1.head->next = createPolyNode(4, 1);

    p2.head = createPolyNode(3, 2);
    p2.head->next = createPolyNode(2, 1);

    addPolynomials(&p1, &p2, &result);
    displayPolynomial(&result); // 8x^2 6x^1
    return 0;
}
🔗 Key insight: Linked lists provide dynamic memory management and efficient insertions/deletions. They are ideal for applications requiring frequent modifications, such as polynomial arithmetic, stacks, and queues.
