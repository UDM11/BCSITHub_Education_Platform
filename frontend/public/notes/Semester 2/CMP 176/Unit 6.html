6.1 Introduction

A tree is a non-linear data structure consisting of nodes connected by edges, forming a hierarchical structure. Unlike linear structures like arrays or linked lists, trees represent relationships in a parent-child hierarchy, with a single root node and no cycles.

🌳 What is a Tree?
A hierarchical data structure with a root node and child nodes. Used to represent hierarchical relationships like file systems or organizational charts.
📊 Key Features
Non-linear, hierarchical, each node has zero or more children, no cycles.

6.3 Binary Tree

A binary tree is a tree where each node has at most two children, referred to as the left child and the right child.

Types of Binary Trees

  • Strictly Binary Tree: Every node has either zero or two children.
  • Complete Binary Tree: All levels except possibly the last are fully filled, and all nodes in the last level are as far left as possible.
  • Full Binary Tree: Every node has exactly 0 or 2 children.
  • Perfect Binary Tree: All internal nodes have two children and all leaves are at the same level.

6.4 Binary Tree Representation

Array Representation

  • Nodes are stored in an array.
  • For node at index i:
    • Left child: 2i + 1
    • Right child: 2i + 2
    • Parent: (i - 1) / 2
  • Suitable for complete binary trees.
// Array Representation
int tree[] = {1, 2, 3, 4, 5, 6, 7};
// Root: tree[0] = 1
// Left child of 1: tree[1] = 2
// Right child of 1: tree[2] = 3

Linked List Representation

  • Each node contains data and pointers to left and right children.
  • Dynamic and flexible.
// Linked List Representation
typedef struct Node {
    int data;
    struct Node* left;
    struct Node* right;
} Node;

Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->left = NULL;
    newNode->right = NULL;
    return newNode;
}

6.6 Traversal of Binary Tree

Preorder Traversal (Root, Left, Right)

  • Visit root, then recursively traverse left and right subtrees.
  • Order: Root → Left → Right

Inorder Traversal (Left, Root, Right)

  • Recursively traverse left subtree, visit root, then right subtree.
  • Order: Left → Root → Right
  • For BST: gives sorted order.

Postorder Traversal (Left, Right, Root)

  • Recursively traverse left and right subtrees, then visit root.
  • Order: Left → Right → Root
// Tree Traversals
void preorder(Node* node) {
    if (node == NULL) return;
    printf("%d ", node->data);
    preorder(node->left);
    preorder(node->right);
}

void inorder(Node* node) {
    if (node == NULL) return;
    inorder(node->left);
    printf("%d ", node->data);
    inorder(node->right);
}

void postorder(Node* node) {
    if (node == NULL) return;
    postorder(node->left);
    postorder(node->right);
    printf("%d ", node->data);
}
📊 Key insight: Inorder traversal of a BST produces sorted order. Preorder is useful for creating a copy of the tree. Postorder is used for deleting the tree.

6.7 Binary Search Tree

A Binary Search Tree (BST) is a binary tree where each node's left subtree contains values less than the node, and the right subtree contains values greater than the node.

Properties

  • Left subtree values < node value < Right subtree values
  • No duplicate values (typically).
  • Inorder traversal gives sorted order.

Operations

  • Insert: O(log n) average, O(n) worst case.
  • Search: O(log n) average, O(n) worst case.
  • Delete: O(log n) average, O(n) worst case.
// BST Operations
Node* insert(Node* node, int data) {
    if (node == NULL) return createNode(data);
    if (data < node->data)
        node->left = insert(node->left, data);
    else if (data > node->data)
        node->right = insert(node->right, data);
    return node;
}

Node* search(Node* node, int data) {
    if (node == NULL || node->data == data) return node;
    if (data < node->data)
        return search(node->left, data);
    return search(node->right, data);
}

Node* minValueNode(Node* node) {
    Node* current = node;
    while (current && current->left != NULL)
        current = current->left;
    return current;
}

Node* deleteNode(Node* node, int data) {
    if (node == NULL) return node;
    if (data < node->data)
        node->left = deleteNode(node->left, data);
    else if (data > node->data)
        node->right = deleteNode(node->right, data);
    else {
        if (node->left == NULL) {
            Node* temp = node->right;
            free(node);
            return temp;
        }
        if (node->right == NULL) {
            Node* temp = node->left;
            free(node);
            return temp;
        }
        Node* temp = minValueNode(node->right);
        node->data = temp->data;
        node->right = deleteNode(node->right, temp->data);
    }
    return node;
}

6.8 Tree Height, Level, and Depth

  • Height: Length of the longest path from the root to a leaf (measured in edges). Height of leaf = 0, height of empty tree = -1.
  • Level: Number of edges from the root to a node (root level = 0).
  • Depth: Number of edges from the root to a node (same as level).
// Calculate Height of Tree
int height(Node* node) {
    if (node == NULL) return 0;
    int leftHeight = height(node->left);
    int rightHeight = height(node->right);
    return 1 + (leftHeight > rightHeight ? leftHeight : rightHeight);
}

// Calculate Depth of a Node
int depth(Node* root, Node* node, int d) {
    if (root == NULL) return -1;
    if (root == node) return d;
    int left = depth(root->left, node, d + 1);
    if (left != -1) return left;
    return depth(root->right, node, d + 1);
}

6.9 Balanced Tree: AVL Balanced Trees

An AVL tree is a self-balancing binary search tree where the height difference (balance factor) between the left and right subtrees of any node is at most 1.

Balance Factor

  • Balance Factor = height(left) - height(right)
  • Valid values: -1, 0, 1

Rotations

  • Right Rotation: For left-left case.
  • Left Rotation: For right-right case.
  • Left-Right Rotation: For left-right case.
  • Right-Left Rotation: For right-left case.
// AVL Tree Insertion
typedef struct AVLNode {
    int data, height;
    struct AVLNode* left;
    struct AVLNode* right;
} AVLNode;

int height(AVLNode* node) {
    return node ? node->height : 0;
}

int balanceFactor(AVLNode* node) {
    return node ? height(node->left) - height(node->right) : 0;
}

AVLNode* rightRotate(AVLNode* y) {
    AVLNode* x = y->left;
    AVLNode* T2 = x->right;
    x->right = y;
    y->left = T2;
    y->height = max(height(y->left), height(y->right)) + 1;
    x->height = max(height(x->left), height(x->right)) + 1;
    return x;
}

AVLNode* insert(AVLNode* node, int data) {
    if (node == NULL) return createAVLNode(data);
    if (data < node->data) node->left = insert(node->left, data);
    else if (data > node->data) node->right = insert(node->right, data);
    else return node;

    node->height = max(height(node->left), height(node->right)) + 1;
    int balance = balanceFactor(node);

    if (balance > 1 && data < node->left->data) return rightRotate(node);
    if (balance < -1 && data > node->right->data) return leftRotate(node);
    if (balance > 1 && data > node->left->data) {
        node->left = leftRotate(node->left);
        return rightRotate(node);
    }
    if (balance < -1 && data < node->right->data) {
        node->right = rightRotate(node->right);
        return leftRotate(node);
    }
    return node;
}

6.10 The Huffman Algorithm

The Huffman Algorithm is used for lossless data compression, creating a binary tree (Huffman tree) to assign variable-length codes to characters based on their frequencies.

Algorithm Steps

  1. Create a min-heap of nodes, each storing a character and its frequency.
  2. While heap has more than one node:
    • Extract two nodes with the lowest frequencies.
    • Create a new internal node with frequency = sum of the two nodes.
    • Make the two nodes as left and right children.
    • Insert the new node into the heap.
  3. The remaining node is the root of the Huffman tree.
  4. Traverse the tree to generate codes (left = 0, right = 1).
// Huffman Coding Implementation
typedef struct HuffmanNode {
    int frequency;
    char data;
    struct HuffmanNode* left;
    struct HuffmanNode* right;
} HuffmanNode;

void printCodes(HuffmanNode* root, char* code, int top) {
    if (root == NULL) return;
    if (root->data != '\0') {
        code[top] = '\0';
        printf("%c: %s\n", root->data, code);
    }
    if (root->left) { code[top] = '0'; printCodes(root->left, code, top+1); }
    if (root->right) { code[top] = '1'; printCodes(root->right, code, top+1); }
}

6.11 B-Tree

A B-Tree is a self-balancing tree data structure that maintains sorted data and allows efficient insertion, deletion, and search operations. It is widely used in databases and file systems.

Properties

  • Each node can have multiple keys and children.
  • All leaves are at the same level.
  • Number of children = number of keys + 1.
  • Minimum degree t:
    • Each node (except root) has at least t-1 keys.
    • Each node has at most 2t-1 keys.
  • Operations: O(log n) time.

Applications

  • Database indexing (MySQL, MongoDB).
  • File systems (NTFS, ext4).
  • File systems indexing.
// B-Tree Node Structure
typedef struct BTreeNode {
    int* keys;
    struct BTreeNode** children;
    int numKeys;
    int isLeaf;
} BTreeNode;

BTreeNode* createBTreeNode(int degree, int isLeaf) {
    BTreeNode* newNode = (BTreeNode*)malloc(sizeof(BTreeNode));
    newNode->isLeaf = isLeaf;
    newNode->keys = (int*)malloc((2*degree - 1) * sizeof(int));
    newNode->children = (BTreeNode**)malloc(2*degree * sizeof(BTreeNode*));
    newNode->numKeys = 0;
    for (int i = 0; i < 2*degree; i++)
        newNode->children[i] = NULL;
    return newNode;
}
📊 Key insight: Trees are fundamental for hierarchical data and efficient searching. Different tree types (BST, AVL, B-Tree) offer trade-offs between simplicity, balance, and performance.
📘 Unit 6 summary
Trees are hierarchical data structures. Binary trees, BSTs, AVL trees, Huffman trees, and B-Trees are key variants with specific applications.
🔑 Key takeaways
• Tree: hierarchical, root, parent, child, leaf.
• Binary tree: max 2 children per node.
• BST: left < node < right.
• Traversals: preorder, inorder, postorder.
• AVL: self-balancing (balance factor ±1).
• Huffman: lossless compression with variable-length codes.
• B-Tree: balanced, multiple keys, database indexing.
