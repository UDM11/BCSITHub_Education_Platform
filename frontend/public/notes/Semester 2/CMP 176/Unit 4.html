Unit 4: Queue

Introduction · terminology · enqueue · dequeue · limitations · variations · applications

4.1 Introduction

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle, where elements are added at the rear and removed from the front. It resembles a line of people waiting, where the first person in line is served first.

📋 FIFO Principle
First In, First Out — the element that has been in the queue the longest is removed first. Like a line at a ticket counter.
🎯 Key Operations
Enqueue (add to rear) and Dequeue (remove from front). Additional operations: Peek, isEmpty, isFull.
Queue Visualization:

Enqueue: Add to rear
Dequeue: Remove from front

4.2 Queue Terminology

Key terms associated with queues:

TermDescription
FrontIndex or pointer to the first element (removed from here).
RearIndex or pointer to the last element (added here).
EnqueueOperation to add an element to the rear.
DequeueOperation to remove and return the front element.
CapacityMaximum number of elements (for array-based queues).
SizeCurrent number of elements in the queue.
Queue OverflowOccurs when trying to enqueue into a full queue.
Queue UnderflowOccurs when trying to dequeue from an empty queue.

#define MAX 100
int queue[MAX];
int front = -1; // -1 indicates empty
int rear = -1; // -1 indicates empty

4.3 Algorithm for Insertion in Queue (Enqueue)

// Algorithm: Enqueue
Algorithm Enqueue(queue, element, maxSize)
1. If size(queue) >= maxSize
    Print "Queue Overflow"
    Return
2. rear = rear + 1
3. queue[rear] = element
4. If front == -1
    front = 0
// Enqueue Implementation in C
#include <stdio.h>
#define MAX 100

int queue[MAX];
int front = -1;
int rear = -1;

void enqueue(int value) {
    if (rear >= MAX - 1) {
        printf("Queue Overflow\n");
        return;
    }
    if (front == -1) {
        front = 0;
    }
    queue[++rear] = value;
}

4.4 Algorithm for Deletion in Queue (Dequeue)

// Algorithm: Dequeue
Algorithm Dequeue(queue)
1. If front == -1
    Print "Queue Underflow"
    Return null
2. element = queue[front]
3. If front == rear
    front = rear = -1
4. Else
    front = front + 1
5. Return element
// Dequeue Implementation in C
int dequeue() {
    if (front == -1) {
        printf("Queue Underflow\n");
        return -1;
    }
    int element = queue[front];
    if (front == rear) {
        front = rear = -1;
    } else {
        front++;
    }
    return element;
}

4.5 Limitation of Simple Queue

A simple queue implemented using an array has the following limitations:

  • Wasted Space: After dequeuing elements, the space at the front cannot be reused, even if the queue is not full.
  • Fixed Size: The queue's size is fixed at creation, leading to overflow if more elements are added than capacity.
  • Inefficient Memory Usage: As elements are dequeued, the rear pointer moves forward, reducing available space until the queue is considered full, even with free slots at the front.
Simple Queue Limitation:
    ┌─────┬─────┬─────┬─────┬─────┐
    │  X  │  X  │  3  │  4  │  5  │
    └─────┴─────┴─────┴─────┴─────┘
      ↑front        ↑rear
      (space wasted, cannot be reused)
⚠️ Key insight: Simple queues waste memory because dequeued spaces cannot be reused. This is addressed by circular queues and linked-list based queues.

4.6 Variations in Queue

Circular Queue

  • Concept: Front and rear pointers wrap around to the beginning when they reach the end, forming a circular structure.
  • Advantage: Reuses space freed by dequeued elements.
// Circular Queue Enqueue Algorithm
Algorithm CircularEnqueue(queue, element, maxSize)
1. If (rear + 1) % maxSize == front
    Print "Queue Overflow"
    Return
2. If front == -1
    front = 0
3. rear = (rear + 1) % maxSize
4. queue[rear] = element
// Circular Queue Implementation in C
#define MAX 5
int queue[MAX];
int front = -1, rear = -1;

void enqueue(int value) {
    if ((rear + 1) % MAX == front) {
        printf("Queue Overflow\n");
        return;
    }
    if (front == -1) front = 0;
    rear = (rear + 1) % MAX;
    queue[rear] = value;
}

int dequeue() {
    if (front == -1) {
        printf("Queue Underflow\n");
        return -1;
    }
    int element = queue[front];
    if (front == rear) {
        front = rear = -1;
    } else {
        front = (front + 1) % MAX;
    }
    return element;
}

Priority Queue

  • Concept: Elements are dequeued based on priority rather than FIFO.
  • Example: Hospital emergency room (critical patients first).
// Priority Queue using Array (Simple Min-Heap)
#include <stdio.h>
#define MAX 100

int pq[MAX];
int size = 0;

void add(int element) {
    if (size >= MAX) {
        printf("Queue Overflow\n");
        return;
    }
    pq[size++] = element;
}

int poll() {
    if (size == 0) {
        printf("Queue Underflow\n");
        return -1;
    }
    int min = pq[0], minIdx = 0;
    for (int i = 1; i < size; i++) {
        if (pq[i] < min) {
            min = pq[i];
            minIdx = i;
        }
    }
    for (int i = minIdx; i < size - 1; i++) {
        pq[i] = pq[i + 1];
    }
    size--;
    return min;
}

Deque (Double-Ended Queue)

  • Concept: Insertion and deletion can occur at both ends.
  • Operations: addFirst, addLast, removeFirst, removeLast.
  • Use: Sliding window algorithms, palindrome checking.

4.7 Application of Queue

Queues are widely used in computing and real-world scenarios due to their FIFO nature.

Applications

  • Process Scheduling: Operating systems use ready queues for CPU scheduling.
  • Task Management: Print job queues in printers, task queues in multitasking systems.
  • Buffering: Keyboard input buffers, network packet processing.
  • Breadth-First Search (BFS): Queue-based traversal in graphs.
  • Simulation Systems: Modeling customer lines in banks or supermarkets.
  • Message Queues: Asynchronous communication between system components.
  • Request Queues: Web server requests handling.
// BFS using Queue (Graph Traversal)
void bfs(int start, int** adj, int V) {
    int visited[V] = {0};
    int queue[MAX];
    int front = 0, rear = 0;

    visited[start] = 1;
    queue[rear++] = start;

    while (front < rear) {
        int node = queue[front++];
        printf("%d ", node);

        for (int i = 0; i < V; i++) {
            if (adj[node][i] && !visited[i]) {
                visited[i] = 1;
                queue[rear++] = i;
            }
        }
    }
}
📊 Key insight: Queues are essential for managing data in a FIFO manner. They are fundamental to operating systems, networking, and many algorithms like BFS.
