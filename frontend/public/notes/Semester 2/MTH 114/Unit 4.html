Unit 4: Optimization: Functions of Several Variables

Introduction · partial derivatives · rules · maxima & minima · second derivative test

4.1 Introduction

Optimization for functions of several variables involves finding the maximum or minimum values of a function with multiple independent variables, often subject to constraints. This is a key concept in multivariable calculus, used to solve problems in economics, engineering, physics, and data science.

📐 Definition
A function f(x₁, x₂, ..., xₙ) maps multiple variables to a single output. Optimization seeks points where f achieves its highest (maxima) or lowest (minima) values.
📊 Applications
Cost minimization, profit maximization, machine learning (error minimization), and design optimization.

Types of Extrema

  • Local Maxima/Minima: Points where f is higher/lower than nearby points.
  • Global Maxima/Minima: The absolute highest/lowest value of f over its domain.
  • Saddle Points: Points that are neither maxima nor minima (e.g., f(x,y) = x² - y² at (0,0)).
Types of Extrema:
Local Maximum:  hilltop
Local Minimum:  valley
Saddle Point:   horse saddle (up in one direction, down in another)

4.2 Partial Derivative

The partial derivative measures the rate of change of a function with respect to one variable, while holding other variables constant.

Definition

  • For f(x, y), ∂f/∂x = limh→0 [f(x+h, y) - f(x, y)]/h (treating y as constant)
  • Similarly, ∂f/∂y = limh→0 [f(x, y+h) - f(x, y)]/h (treating x as constant)
// Partial Derivatives Example
f(x, y) = x² + xy + y²
∂f/∂x = 2x + y
∂f/∂y = x + 2y

Higher-Order Partial Derivatives

  • Second derivatives: ∂²f/∂x², ∂²f/∂y², ∂²f/∂x∂y, ∂²f/∂y∂x
  • If f is sufficiently smooth, mixed partials are equal: ∂²f/∂x∂y = ∂²f/∂y∂x
// Higher-Order Partial Derivatives
f(x, y) = x² + xy
∂²f/∂x² = 2
∂²f/∂y² = 0
∂²f/∂x∂y = 1
∂²f/∂y∂x = 1

4.4 Maxima and Minima for the Function of Two Variables

Critical Points

  • Points where ∂f/∂x = 0 and ∂f/∂y = 0 (or gradient is undefined).

Second Derivative Test (Hessian)

  • Let A = ∂²f/∂x², B = ∂²f/∂x∂y, C = ∂²f/∂y²
  • D = A·C - B²
  • If D > 0 and A > 0 → local minimum
  • If D > 0 and A < 0 → local maximum
  • If D < 0 → saddle point
  • If D = 0 → inconclusive
// Example: f(x, y) = x² + y²
∂f/∂x = 2x = 0 → x = 0
∂f/∂y = 2y = 0 → y = 0
Critical point: (0, 0)

A = 2, B = 0, C = 2
D = 2·2 - 0 = 4 > 0, A > 0
→ Local minimum at (0, 0)
// Example: f(x, y) = x² - y²
∂f/∂x = 2x = 0 → x = 0
∂f/∂y = -2y = 0 → y = 0
Critical point: (0, 0)

A = 2, B = 0, C = -2
D = 2·(-2) - 0 = -4 < 0
→ Saddle point at (0, 0)

Global Extrema on Closed Domains

  • Check critical points inside the domain.
  • Check the boundary of the domain.
  • Compare values to find global max/min.
// Global Extrema on Closed Domain
f(x, y) = x² + y² on x² + y² ≤ 1
Critical point: (0, 0) → f = 0
Boundary: x² + y² = 1 → f = 1
Global min = 0 at (0, 0), Global max = 1 on boundary

Applications

  • Profit Maximization: Maximize revenue minus cost.
  • Cost Minimization: Minimize production costs subject to constraints.
  • Machine Learning: Minimize error/loss functions.
  • Resource Allocation: Optimize distribution of resources.
📊 Key insight: The second derivative test for functions of two variables uses the Hessian determinant to classify critical points. For optimization with constraints, Lagrange multipliers are often used.
📘 Unit 4 summary
Optimization of functions of several variables involves finding extrema using partial derivatives, critical points, and the second derivative test.
🔑 Key takeaways
• Partial derivatives: rate of change w.r.t. one variable.
• Rules: constant, power, sum, product, chain, quotient.
• Critical points: ∂f/∂x = 0, ∂f/∂y = 0.
• Second derivative test: D = A·C - B².
• D > 0 and A > 0 → local min; D > 0 and A < 0 → local max; D < 0 → saddle point.
• Global extrema: check critical points and boundaries.
