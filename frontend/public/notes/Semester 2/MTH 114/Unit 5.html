5.1 Introduction

An ordinary differential equation (ODE) is an equation involving a function of one independent variable and its derivatives. ODEs describe relationships between a function and its rates of change, widely used to model phenomena in physics, engineering, biology, and economics.

📐 Definition
F(x, y, y', y'', ..., yⁿ) = 0, where y = f(x) is the unknown function. Example: y' + 2y = x.
📊 Applications
Population growth (dy/dt = ky), motion (Newton's second law), electrical circuits (L di/dt + Ri = V).

Key Concepts

  • Order: Highest derivative in the equation.
  • Degree: Power of the highest-order derivative (if polynomial in derivatives).
  • Linearity: Linear if y and its derivatives appear to the first power and are not multiplied together.

5.2 Order and Degree of Differential Equation

Order

  • Highest derivative in the equation.
  • Example: y'' + 3y' + 2y = 0 → order 2.
  • Example: y' = x² → order 1.

Degree

  • Power of the highest-order derivative when the equation is polynomial in derivatives.
  • Example: (y'')² + y' + y = 0 → degree 2.
  • Example: y'' + y = 0 → degree 1.
// Order and Degree Examples
y'' + 2y' = 0 → Order 2, Degree 1
(y')³ + y = x → Order 1, Degree 3
√(y') + y = x → Order 1, Degree 1/2 (after squaring)
📌 Key insight: The order determines the number of arbitrary constants in the general solution. The degree affects the solution techniques.

5.3 Solution of the First Order and First Degree Differential Equation

First-order, first-degree ODEs have the form dy/dx = f(x, y).

General and Particular Solutions

  • General Solution: Includes an arbitrary constant (e.g., y = x²/2 + C).
  • Particular Solution: Satisfies an initial condition (e.g., y(0) = 1 → y = x²/2 + 1).
// Direct Integration
dy/dx = 2x → y = ∫ 2x dx = x² + C
y(0) = 1 → 1 = 0 + C → C = 1 → y = x² + 1

5.4 Variable Separation, Homogeneous, Linear Differential Equation

Variable Separation

  • Form: dy/dx = f(x)g(y)
  • Rewrite: dy/g(y) = f(x) dx
  • Integrate both sides.
// Variable Separation Example
dy/dx = xy
dy/y = x dx
ln|y| = x²/2 + C → y = A e^(x²/2)

Homogeneous Equations

  • Form: dy/dx = f(x,y) where f(tx,ty) = f(x,y)
  • Substitution: y = vx → dy/dx = v + x dv/dx
// Homogeneous Equation Example
dy/dx = (x + y)/x = 1 + y/x
Let y = vx → v + x dv/dx = 1 + v
x dv/dx = 1 → dv = dx/x → v = ln|x| + C
y = x ln|x| + Cx

Linear Differential Equations

  • Form: dy/dx + P(x)y = Q(x)
  • Integrating factor: e^(∫ P(x) dx)
// Linear Equation Example
dy/dx + 2y/x = x
IF = e^(∫ 2/x dx) = x²
d/dx (x²y) = x³ → x²y = x⁴/4 + C
y = x²/4 + C/x²

5.5 Second-Order Linear Differential Equation with Constant Coefficients

Form: ay'' + by' + cy = f(x), where a, b, c are constants.

Homogeneous Case (f(x) = 0)

  • Characteristic equation: ar² + br + c = 0
  • Real Distinct Roots: y = C₁e^(r₁x) + C₂e^(r₂x)
  • Repeated Roots: y = (C₁ + C₂x)e^(rx)
  • Complex Roots: y = e^(αx)(C₁ cos βx + C₂ sin βx)

Non-Homogeneous Case

  • Solution: y = y_h + y_p
  • Undetermined Coefficients: Guess y_p based on f(x).
// Homogeneous Examples
y'' - 3y' + 2y = 0 → r² - 3r + 2 = 0 → r = 1, 2
y = C₁e^x + C₂e^(2x)

y'' + y = 0 → r² + 1 = 0 → r = ±i
y = C₁ cos x + C₂ sin x
// Non-Homogeneous Example
y'' + y = x
y_h = C₁ cos x + C₂ sin x
Guess y_p = ax + b → y_p = x
y = C₁ cos x + C₂ sin x + x

5.6 Initial and Boundary Value Problems

Initial Value Problems (IVP)

  • Conditions given at a single point (x₀).
  • Example: y(0) = 1, y'(0) = 0.
// IVP Example
y'' + y = 0, y(0) = 1, y'(0) = 0
y = C₁ cos x + C₂ sin x
y(0) = C₁ = 1, y'(0) = C₂ = 0 → y = cos x

Boundary Value Problems (BVP)

  • Conditions given at different points.
  • Example: y(0) = 0, y(π) = 0.
// BVP Example
y'' + y = 0, y(0) = 0, y(π) = 0
y = C₁ cos x + C₂ sin x
y(0) = C₁ = 0, y(π) = C₂ sin π = 0
y = C₂ sin x (including trivial solution)
TypeConditionsUniquenessExample
IVPAt one pointTypically uniquey(0)=1, y'(0)=0
BVPAt different pointsMay be multiple or noney(0)=0, y(π)=0
📊 Key insight: IVPs model dynamic systems (e.g., motion), while BVPs model steady-state systems (e.g., beam deflection). The number of conditions equals the order of the ODE.
📘 Unit 5 summary
Ordinary differential equations model relationships between functions and their derivatives. Key methods include separation of variables, homogeneous, linear, and second-order solutions.
🔑 Key takeaways
• ODE: equation with derivatives.
• Order & degree: highest derivative and its power.
• First-order: separation, homogeneous, linear.
• Second-order: characteristic equation (real, repeated, complex roots).
• IVP: conditions at one point; BVP: conditions at different points.
