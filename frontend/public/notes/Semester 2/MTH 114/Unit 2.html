Unit 2: Infinite Sequence and Series

Introduction · convergence · comparison tests · p-series · ratio test · alternating series test

2.1 Introduction

An infinite sequence is an ordered list of numbers that continues indefinitely, denoted as {aₙ}, where aₙ is the n-th term. An infinite series is the sum of the terms of an infinite sequence, written as ∑ aₙ (from n=1 to infinity). These concepts are fundamental in understanding convergence and divergence in mathematical analysis.

📊 Sequence
An ordered list of numbers: {a₁, a₂, a₃, ...}. Example: {1/n} = 1, 1/2, 1/3, ...
📈 Series
The sum of terms of a sequence: ∑ aₙ. Example: ∑ 1/n = 1 + 1/2 + 1/3 + ...

Key Concepts

  • Convergence: A sequence converges if its terms approach a finite limit as n → ∞. A series converges if the sum of its terms approaches a finite value.
  • Divergence: A sequence or series diverges if it does not approach a finite limit.
  • Partial Sums: Sₙ = a₁ + a₂ + ... + aₙ. The series converges if limₙ→∞ Sₙ exists.
// Examples of Sequences and Series
Sequence: {1/n} → 1, 1/2, 1/3, ... (converges to 0)
Series: ∑ 1/n → 1 + 1/2 + 1/3 + ... (diverges)
Geometric Series: ∑ (1/2)ⁿ → converges to 1

2.2 Convergence Test of Infinite Series (Statement Only)

An infinite series ∑ aₙ converges if the sequence of partial sums Sₙ = a₁ + a₂ + ... + aₙ approaches a finite limit as n → ∞. Otherwise, it diverges.

N-th Term Test (Divergence Test)

  • Statement: If limₙ→∞ aₙ ≠ 0 or the limit does not exist, then ∑ aₙ diverges.
  • Note: If limₙ→∞ aₙ = 0, the series may still diverge (e.g., harmonic series).
// N-th Term Test Examples
// Diverges: lim aₙ ≠ 0
∑ n/(n+1): lim n/(n+1) = 1 ≠ 0 → diverges

// Inconclusive: lim aₙ = 0
∑ 1/n: lim 1/n = 0 → test inconclusive (harmonic series diverges)

2.3 Direct Comparison Test, Limit Comparison Test (Statement Only)

Direct Comparison Test

  • Statement: Let ∑ aₙ and ∑ bₙ be series with aₙ ≥ 0 and bₙ ≥ 0.
    • If 0 ≤ aₙ ≤ bₙ for all large n and ∑ bₙ converges, then ∑ aₙ converges.
    • If 0 ≤ bₙ ≤ aₙ for all large n and ∑ aₙ diverges, then ∑ bₙ diverges.
// Direct Comparison Test Example
// Compare ∑ 1/(n² + 1) with ∑ 1/n²
1/(n² + 1) < 1/n²
∑ 1/n² converges (p-series, p=2)
Therefore, ∑ 1/(n² + 1) converges.

Limit Comparison Test

  • Statement: Let ∑ aₙ and ∑ bₙ be series with aₙ > 0 and bₙ > 0.
    • If limₙ→∞ (aₙ/bₙ) = L, where 0 < L < ∞, then both series converge or both diverge.
    • If L = 0 and ∑ bₙ converges, then ∑ aₙ converges.
    • If L = ∞ and ∑ bₙ diverges, then ∑ aₙ diverges.
// Limit Comparison Test Example
// Compare ∑ 1/(n + n²) with ∑ 1/n²
lim [1/(n + n²)] / [1/n²] = lim n²/(n + n²) = 1
Since 0 < 1 < ∞ and ∑ 1/n² converges,
∑ 1/(n + n²) converges.

2.4 P-series Test, D'Alembert's Ratio Test, and Alternating Series Test (Statement Only)

P-series Test

  • Statement: The series ∑ 1/nᵖ converges if p > 1 and diverges if p ≤ 1.
// P-series Test Examples
∑ 1/n²: p = 2 > 1 → converges
∑ 1/n: p = 1 → diverges (harmonic series)
∑ 1/√n: p = 0.5 < 1 → diverges

D'Alembert's Ratio Test

  • Statement: For ∑ aₙ with aₙ ≠ 0, compute L = limₙ→∞ |aₙ₊₁/aₙ|.
    • If L < 1, the series converges absolutely.
    • If L > 1 or L = ∞, the series diverges.
    • If L = 1, the test is inconclusive.
// Ratio Test Examples
// ∑ n!/2ⁿ
L = lim [(n+1)!/2ⁿ⁺¹] / [n!/2ⁿ] = lim (n+1)/2 = ∞ → diverges

// ∑ 1/n!
L = lim [1/(n+1)!] / [1/n!] = lim 1/(n+1) = 0 → converges

Alternating Series Test

  • Statement: For an alternating series ∑ (-1)ⁿ aₙ or ∑ (-1)ⁿ⁺¹ aₙ with aₙ > 0, the series converges if:
    • aₙ is decreasing (or eventually decreasing).
    • limₙ→∞ aₙ = 0.
// Alternating Series Test Example
// ∑ (-1)ⁿ⁺¹ (1/n)
aₙ = 1/n
aₙ is decreasing (1 > 1/2 > 1/3 > ...)
lim 1/n = 0
Therefore, the alternating harmonic series converges.

📊 Key insight: Choosing the right convergence test depends on the form of the series. The ratio test is powerful for series with factorials or exponentials, while comparison tests work well with rational functions.
📘 Unit 2 summary
Infinite sequences and series are fundamental in calculus. Convergence tests determine whether a series converges or diverges.
🔑 Key takeaways
• Sequence: ordered list, Series: sum of sequence terms.
• N-th term test: if lim aₙ ≠ 0 → diverges.
• Comparison tests: direct and limit comparison.
• P-series: converges if p > 1.
• Ratio test: L < 1 → converges.
• Alternating series: decreasing terms → 0 → converges.
