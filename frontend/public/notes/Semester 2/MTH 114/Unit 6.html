6.1 Introduction

The study of integers and division forms the foundation of number theory, focusing on the properties and relationships of whole numbers (..., -2, -1, 0, 1, 2, ...). Division concepts underpin key ideas like divisibility, prime numbers, and modular arithmetic, which are essential in mathematics and applications like cryptography.

🔢 Integers
The set of all positive and negative whole numbers, including zero, denoted ℤ. Example: -3, 0, 7.
➗ Division
For integers a and b (b ≠ 0), a divided by b yields quotient and remainder, leading to GCD and LCM.

Applications

  • Computer Science: Algorithms, hashing, and data structures.
  • Cryptography: RSA encryption, digital signatures.
  • Pure Mathematics: Diophantine equations, number theory.

6.2 Division, Primes, The Fundamental Theorem of Arithmetic

Division

  • Definition: a is divisible by b (b ≠ 0) if there exists integer k such that a = b·k. Notation: b | a.
  • Example: 6 | 12 since 12 = 6 · 2.

Primes

  • Prime: Positive integer > 1 divisible only by 1 and itself. Example: 2, 3, 5, 7.
  • Composite: Positive integer > 1 with divisors other than 1 and itself. Example: 4, 6, 9.

Fundamental Theorem of Arithmetic

  • Statement: Every positive integer > 1 can be expressed uniquely as a product of prime numbers (up to order).
  • Example: 12 = 2² · 3, 100 = 2² · 5².
// Prime Factorization Examples
12 = 2 × 2 × 3 = 2² · 3
100 = 2 × 2 × 5 × 5 = 2² · 5²
84 = 2 × 2 × 3 × 7 = 2² · 3 · 7

6.3 The Infinitude of Primes

There are infinitely many prime numbers. This was famously proven by Euclid around 300 BCE.

Euclid's Proof

  • Assume: There are finitely many primes: p₁, p₂, ..., pₙ.
  • Construct: N = p₁ · p₂ · ... · pₙ + 1.
  • N is either prime or composite:
    • If prime: N is a new prime not in the list.
    • If composite: N must be divisible by a prime, but none of p₁, p₂, ..., pₙ divide N (remainder 1).
  • Contradiction: There must be another prime, proving infinitely many primes.
// Example with primes 2, 3, 5
N = 2 · 3 · 5 + 1 = 31 (prime)
// This process generates new primes indefinitely.

6.4 The Division Algorithm, GCD, and LCM

Division Algorithm

  • For integers a and b (b > 0), there exist unique q (quotient) and r (remainder) such that a = bq + r, with 0 ≤ r < b.
  • Example: 17 = 5 · 3 + 2 → q = 3, r = 2.

Greatest Common Divisor (GCD)

  • Largest positive integer dividing both a and b.
  • Euclidean Algorithm: If a = bq + r, then GCD(a, b) = GCD(b, r).
  • Example: GCD(48, 18):
    • 48 = 18 · 2 + 12
    • 18 = 12 · 1 + 6
    • 12 = 6 · 2 + 0
    • GCD = 6

Least Common Multiple (LCM)

  • Smallest positive integer divisible by both a and b.
  • LCM(a, b) = |a · b| / GCD(a, b).
  • Example: LCM(48, 18) = (48 · 18) / 6 = 144.
// GCD and LCM Example
a = 48, b = 18
GCD = 6
LCM = (48 × 18) / 6 = 144

6.5 Modular Arithmetic

Definition

  • a ≡ b (mod n) if n divides (a - b), i.e., a and b have the same remainder when divided by n.
  • Example: 17 ≡ 5 (mod 12) since 17 - 5 = 12.

Properties

  • Addition: If a ≡ b (mod n) and c ≡ d (mod n), then a + c ≡ b + d (mod n).
  • Multiplication: a · c ≡ b · d (mod n).
  • Exponentiation: If a ≡ b (mod n), then a^k ≡ b^k (mod n).
// Modular Arithmetic Examples
7 ≡ 2 (mod 5), 4 ≡ 9 (mod 5)
7 + 4 ≡ 2 + 9 ≡ 11 ≡ 1 (mod 5)
3 ≡ 8 (mod 5) → 3 · 4 ≡ 8 · 4 ≡ 12 ≡ 2 (mod 5)

6.6 Application of Congruences in Cryptology

Congruences in modular arithmetic are fundamental to cryptology, particularly in encryption algorithms like RSA.

RSA Encryption

  • Encryption: C ≡ M^e (mod n)
  • Decryption: M ≡ C^d (mod n)
// RSA Example
p = 3, q = 11 → n = 33
φ(n) = (2)(10) = 20
e = 7, d = 3 (since 7·3 ≡ 1 mod 20)
M = 5 → C = 5⁷ ≡ 14 (mod 33)
Decrypt: C³ = 14³ ≡ 5 (mod 33) → M = 5

Other Applications

  • Hash Functions: Secure data integrity.
  • Digital Signatures: Authentication and non-repudiation.
  • ISBN Check Digits: Error detection in book numbers.
