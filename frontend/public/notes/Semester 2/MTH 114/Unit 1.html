1.1 Definition of a Complex Number, Integral Powers of i

A complex number is a number of the form z = a + bi, where a and b are real numbers, and i is the imaginary unit with the property i² = -1. Here, a is the real part and b is the imaginary part.

📐 Definition
z = a + bi, where a, b ∈ ℝ, i² = -1. Real part = a, Imaginary part = b.
🔄 Powers of i
i¹ = i, i² = -1, i³ = -i, i⁴ = 1. The pattern repeats every 4 powers.

Integral Powers of i

  • Pattern:
    • i⁰ = 1
    • i¹ = i
    • i² = -1
    • i³ = -i
    • i⁴ = 1
    • i⁵ = i (cycle repeats)
  • Rule: For any integer n, find n mod 4 to determine the result:
    • n mod 4 = 0 → iⁿ = 1
    • n mod 4 = 1 → iⁿ = i
    • n mod 4 = 2 → iⁿ = -1
    • n mod 4 = 3 → iⁿ = -i
  • Example: i⁷ = i⁴⁺³ = i⁴ · i³ = 1 · (-i) = -i
// Powers of i
i¹ = i
i² = -1
i³ = -i
i⁴ = 1
i⁵ = i
i⁶ = -1
i⁷ = -i
i⁸ = 1
💡 Key insight: The imaginary unit i cycles through four values, making it easy to compute high powers using modular arithmetic.

1.2 Algebra of Complex Numbers

Complex numbers can be added, subtracted, multiplied, and divided using standard algebraic operations, treating i as a variable with i² = -1.

Addition and Subtraction

  • Addition: (a + bi) + (c + di) = (a + c) + (b + d)i
  • Subtraction: (a + bi) - (c + di) = (a - c) + (b - d)i
  • Example: (3 + 4i) + (2 - 5i) = 5 - i

Multiplication

  • Formula: (a + bi)(c + di) = (ac - bd) + (ad + bc)i
  • Example: (3 + 4i)(2 - 5i) = 6 - 15i + 8i - 20i² = 6 + 20 - 7i = 26 - 7i

Division

  • Method: Multiply numerator and denominator by the conjugate of the denominator.
  • Formula: (a + bi)/(c + di) = [(a + bi)(c - di)] / [(c + di)(c - di)]
  • Example: (3 + 4i)/(2 + i) = [(3 + 4i)(2 - i)] / [(2 + i)(2 - i)] = (10 + 5i)/5 = 2 + i
// Complex Number Operations
// Addition
(3 + 4i) + (2 - 5i) = 5 - i

// Multiplication
(3 + 4i)(2 - 5i) = 26 - 7i

// Division
(3 + 4i)/(2 + i) = 2 + i

1.3 Properties of Complex Numbers, Conjugate of a Complex Number

Properties of Complex Numbers

  • Commutative: z₁ + z₂ = z₂ + z₁, z₁ · z₂ = z₂ · z₁
  • Associative: (z₁ + z₂) + z₃ = z₁ + (z₂ + z₃), (z₁ · z₂) · z₃ = z₁ · (z₂ · z₃)
  • Distributive: z₁ · (z₂ + z₃) = z₁ · z₂ + z₁ · z₃
  • Additive Identity: z + 0 = z, where 0 = 0 + 0i
  • Multiplicative Identity: z · 1 = z, where 1 = 1 + 0i

Conjugate of a Complex Number

  • Definition: For z = a + bi, the conjugate is z̅ = a - bi
  • Properties:
    • z + z̅ = 2a (real)
    • z - z̅ = 2bi (purely imaginary)
    • z · z̅ = a² + b² (real, non-negative)
    • (z̅)̅ = z
  • Example: For z = 3 + 4i, z̅ = 3 - 4i
// Conjugate Examples
z = 3 + 4i
z̅ = 3 - 4i
z + z̅ = 6
z - z̅ = 8i
z · z̅ = 9 + 16 = 25

1.4 Modulus of a Complex Number and Argand's Diagram

Modulus

  • Definition: For z = a + bi, |z| = √(a² + b²)
  • Properties:
    • |z| ≥ 0, |z| = 0 iff z = 0
    • |z₁ · z₂| = |z₁| · |z₂|
    • |z₁/z₂| = |z₁|/|z₂| (if z₂ ≠ 0)
    • |z̅| = |z|
  • Example: |3 + 4i| = √(9 + 16) = 5

Argand's Diagram

  • Definition: A 2D plane where the x-axis is the real axis and the y-axis is the imaginary axis.
  • Representation: z = a + bi is plotted at point (a, b).
  • Example: 3 + 4i is plotted at (3, 4).

1.5 Polar Representation of a Complex Number

Polar Form

  • Definition: z = r(cos θ + i sin θ), where r = |z| and θ = arg(z)
  • Modulus (r): r = √(a² + b²)
  • Argument (θ): θ = tan⁻¹(b/a), adjusted for quadrant

Converting to Polar Form

  • Example: z = 3 + 4i
    • r = √(3² + 4²) = 5
    • θ = tan⁻¹(4/3) ≈ 53.13°
    • z = 5(cos 53.13° + i sin 53.13°)
// Polar Form Conversion
z = 3 + 4i
r = 5
θ = tan⁻¹(4/3) = 53.13°
z = 5(cos 53.13° + i sin 53.13°)

Advantages of Polar Form

  • Simplifies multiplication: multiply moduli, add arguments
  • Simplifies division: divide moduli, subtract arguments
  • Simplifies powers: De Moivre's theorem

1.6 Square Roots of a Complex Number (Cartesian Form)

Method

  • Let √(a + bi) = x + yi
  • Then (x + yi)² = a + bi
  • Equating real and imaginary parts:
    • x² - y² = a
    • 2xy = b
    • x² + y² = √(a² + b²)
// Find √(3 + 4i)
x² + y² = 5
2xy = 4 → y = 2/x
x² - (2/x)² = 3
x⁴ - 3x² - 4 = 0
x² = 4 → x = ±2, y = ±1
√(3 + 4i) = 2 + i or -2 - i
📐 Key insight: The square root of a complex number yields two roots that are negatives of each other.

1.7 De Moivre's Theorem and Its Application

Statement

  • For z = r(cos θ + i sin θ) and integer n: zⁿ = rⁿ(cos nθ + i sin nθ)

Applications

  • Powers: Compute high powers of complex numbers.
    // (1 + i)³
    1 + i = √2(cos 45° + i sin 45°)
    (1 + i)³ = (√2)³(cos 135° + i sin 135°)
    = 2√2(-1/√2 + i/√2) = -2 + 2i
  • Roots: Find n-th roots of complex numbers.
    // Cube roots of 1
    1 = 1(cos 0° + i sin 0°)
    Roots: cos(2kπ/3) + i sin(2kπ/3), k=0,1,2
    1, -1/2 + i√3/2, -1/2 - i√3/2
// De Moivre's Theorem General Formula
z = r(cos θ + i sin θ)
zⁿ = rⁿ(cos nθ + i sin nθ)
z^(1/n) = r^(1/n)[cos((θ + 2kπ)/n) + i sin((θ + 2kπ)/n)]
for k = 0, 1, 2, ..., n-1
📊 Key insight: De Moivre's theorem is a powerful tool for computing powers and roots of complex numbers, especially when expressed in polar form.
📘 Unit 1 summary
Complex numbers extend the real number system with the imaginary unit i. They have algebraic properties, conjugates, modulus, and polar forms.
🔑 Key takeaways
• Complex number: z = a + bi, i² = -1.
• Powers of i cycle: i, -1, -i, 1.
• Algebra: addition, subtraction, multiplication, division.
• Conjugate: z̅ = a - bi.
• Modulus: |z| = √(a² + b²).
• Polar form: z = r(cos θ + i sin θ).
• De Moivre's theorem: zⁿ = rⁿ(cos nθ + i sin nθ).
