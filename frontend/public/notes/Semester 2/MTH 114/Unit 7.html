7.1 Introduction

Fourier series and integrals are mathematical tools used to represent functions as sums or integrals of sine and cosine functions. They are fundamental in analyzing periodic phenomena and solving differential equations in physics, engineering, and signal processing.

📊 Purpose
Decompose complex functions into simpler trigonometric components. Example: Representing a sound wave as a sum of pure tones.
📐 Applications
Signal processing, heat transfer, vibration analysis, image compression (JPEG), and quantum mechanics.

Key Concepts

  • Fourier Series: Represents periodic functions as sums of sines and cosines.
  • Fourier Integral: Extends Fourier series to non-periodic functions.
  • Even/Odd Functions: Simplify Fourier series by eliminating sine or cosine terms.

7.2 Even and Odd Function

Even Function

  • Definition: f(-x) = f(x) for all x.
  • Graph: Symmetric about the y-axis.
  • Examples: cos x, x², |x|.

Odd Function

  • Definition: f(-x) = -f(x) for all x.
  • Graph: Symmetric about the origin.
  • Examples: sin x, x³, tan x.

Properties

  • ∫-aa f(x) dx = 0 for odd functions.
  • ∫-aa f(x) dx = 2∫0a f(x) dx for even functions.
// Even Function Example
f(x) = cos(x) → f(-x) = cos(-x) = cos(x)
// Odd Function Example
f(x) = sin(x) → f(-x) = sin(-x) = -sin(x)
📌 Key insight: Even functions yield only cosine terms in Fourier series; odd functions yield only sine terms. This simplifies calculations significantly.

7.3 Periodic Function

Definition

  • f(x + T) = f(x) for all x. T is the period.
  • The smallest such T is the fundamental period.

Examples

  • sin x: period 2π
  • cos(2x): period π
  • Square wave: period depends on definition.
// Periodic Function Examples
sin(x + 2π) = sin(x) → Period = 2π
cos(2x + π) = cos(2x) → Period = π

7.4 Fourier Series and Fourier Coefficients (Without Proof)

Fourier Series

  • For f(x) with period 2L:
    f(x) = a₀/2 + Σn=1∞ [aₙ cos(nπx/L) + bₙ sin(nπx/L)]

Fourier Coefficients

  • a₀: (1/L) ∫-LL f(x) dx
  • aₙ: (1/L) ∫-LL f(x) cos(nπx/L) dx
  • bₙ: (1/L) ∫-LL f(x) sin(nπx/L) dx
// Fourier Series for f(x) = x on [-π, π]
a₀ = 0 (odd function)
aₙ = 0 (odd function)
bₙ = (-2/n)(-1)ⁿ
f(x) = Σn=1∞ [(-2/n)(-1)ⁿ sin(nx)]

Convergence

  • Converges to f(x) at points of continuity.
  • Converges to the average of limits at discontinuities.

7.5 Fourier Sine and Cosine Series

Fourier Cosine Series

  • For even functions on [0, L]:
    f(x) = a₀/2 + Σn=1∞ aₙ cos(nπx/L)
  • a₀ = (2/L) ∫0L f(x) dx
  • aₙ = (2/L) ∫0L f(x) cos(nπx/L) dx

Fourier Sine Series

  • For odd functions on [0, L]:
    f(x) = Σn=1∞ bₙ sin(nπx/L)
  • bₙ = (2/L) ∫0L f(x) sin(nπx/L) dx
// Cosine Series for f(x) = x² on [0, π]
a₀ = 2π²/3
aₙ = (2/π) ∫₀^π x² cos(nx) dx
// Sine Series for f(x) = x on [0, π]
bₙ = (-2/n)(-1)ⁿ

7.6 Fourier Integral

Definition

  • For f(x) on (-∞, ∞):
    f(x) = ∫0∞ [A(ω) cos(ωx) + B(ω) sin(ωx)] dω
  • A(ω) = (1/π) ∫-∞∞ f(t) cos(ωt) dt
  • B(ω) = (1/π) ∫-∞∞ f(t) sin(ωt) dt
// Fourier Integral for f(x) = e^(-|x|)
A(ω) = (2/π)(1/(1 + ω²))
B(ω) = 0 (even function)
f(x) = (2/π) ∫₀^∞ [1/(1 + ω²)] cos(ωx) dω

Conditions

  • Piecewise continuous.
  • Finite number of discontinuities.
  • Absolutely integrable: ∫-∞∞ |f(x)| dx < ∞

7.7 Fourier Sine and Cosine Integral

Fourier Cosine Integral

  • For even extension on [0, ∞):
    f(x) = (2/π) ∫₀^∞ [∫₀^∞ f(t) cos(ωt) dt] cos(ωx) dω
// Cosine Integral for f(x) = 1 on [0, 1]
∫₀^∞ f(t) cos(ωt) dt = sin(ω)/ω
f(x) = (2/π) ∫₀^∞ [sin(ω)/ω] cos(ωx) dω

Fourier Sine Integral

  • For odd extension on [0, ∞):
    f(x) = (2/π) ∫₀^∞ [∫₀^∞ f(t) sin(ωt) dt] sin(ωx) dω

Applications

  • Heat Equation: Solving with Dirichlet or Neumann boundary conditions.
  • Signal Processing: Analyzing non-periodic signals.
  • Quantum Mechanics: Wavefunction analysis.

📘 Unit 7 summary
Fourier series represent periodic functions as sums of sines and cosines. Fourier integrals extend this to non-periodic functions. Even/odd functions simplify the series.
🔑 Key takeaways
• Fourier series: f(x) = a₀/2 + Σ(aₙ cos + bₙ sin).
• Even functions: only cosine terms; odd: only sine terms.
• Fourier coefficients: a₀, aₙ, bₙ from integrals.
• Fourier integral: non-periodic functions.
• Cosine/Sine integrals: for even/odd extensions.
