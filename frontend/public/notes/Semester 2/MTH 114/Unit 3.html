3.1 Definite Integral

The definite integral represents the accumulation of a quantity over an interval, often interpreted as the area under a curve or the total change of a function. For a function f(x) continuous on [a, b], the definite integral is defined as:

∫ab f(x) dx = F(b) - F(a), where F(x) is the antiderivative of f(x) (i.e., F'(x) = f(x)).

📐 Definition
∫ₐᵇ f(x) dx = F(b) - F(a), where F'(x) = f(x). Represents area under the curve from a to b.
📊 Purpose
Computes areas, total quantities, net change. Used in physics, economics, and engineering.
// Example: ∫₀² x² dx
F(x) = x³/3
F(2) - F(0) = 8/3 - 0 = 8/3
// Represents area under y = x² from 0 to 2

Geometric Interpretation

  • If f(x) ≥ 0, the integral gives the area under the curve.
  • If f(x) < 0, the integral gives the negative of the area above the curve (signed area).

3.3 Improper Integral

An improper integral is a definite integral where either the interval is infinite or the integrand is unbounded within the interval.

Types

  • Infinite Limits: ∫ₐ∞ f(x) dx = limt→∞ ∫ₐt f(x) dx
  • Unbounded Integrand: If f(x) is unbounded at c ∈ [a, b], split the integral at c and take limits.
// Infinite Limit Example
∫₁∞ 1/x² dx = limt→∞ [-1/x]₁t
= limt→∞ (-1/t + 1) = 1 (converges)

// Unbounded Integrand Example
∫₀¹ 1/√x dx = limt→0⁺ [2√x]ₜ¹
= limt→0⁺ (2 - 2√t) = 2 (converges)

Convergence vs Divergence

  • Converges: The limit exists and is finite.
  • Diverges: The limit does not exist or is infinite.

3.4 Quadrature [y = f(x)]

Quadrature is the process of finding the area under a curve y = f(x) over an interval [a, b] using the definite integral.

Area Under a Curve

  • If f(x) ≥ 0, area = ∫ₐᵇ f(x) dx
  • If f(x) takes negative values, the integral gives the net signed area.
// Area Under y = x² from 0 to 2
Area = ∫₀² x² dx = 8/3

// Area Between Curves y = x and y = x² from 0 to 1
Area = ∫₀¹ (x - x²) dx = 1/6

Area Between Curves

  • Area between f(x) and g(x) = ∫ₐᵇ |f(x) - g(x)| dx

3.5 Rectification [y = f(x)]

Rectification is the process of finding the arc length of a curve y = f(x) over an interval [a, b].

Arc Length Formula

  • L = ∫ₐᵇ √(1 + [f'(x)]²) dx
// Arc Length of y = x² from 0 to 1
f'(x) = 2x
L = ∫₀¹ √(1 + 4x²) dx
// ≈ 1.479 (using substitution)
📐 Key insight: Arc length integrals often require numerical methods or special substitutions as they rarely have elementary antiderivatives.

3.6 Beta and Gamma Function

Gamma Function

  • Definition: Γ(x) = ∫₀∞ t^(x-1) e^(-t) dt, for x > 0
  • Properties:
    • Γ(n) = (n-1)! for positive integers
    • Γ(x+1) = x Γ(x)
    • Γ(1) = 1, Γ(1/2) = √π
// Gamma Function Examples
Γ(3) = 2! = 2
Γ(4) = 3! = 6
∫₀∞ x² e^(-x) dx = Γ(3) = 2

Beta Function

  • Definition: B(m, n) = ∫₀¹ x^(m-1) (1-x)^(n-1) dx, for m, n > 0
  • Relation: B(m, n) = Γ(m)Γ(n) / Γ(m+n)
// Beta Function Example
B(2, 3) = Γ(2)Γ(3) / Γ(5) = 1!·2! / 4! = 2/24 = 1/12

// Direct Integration
B(2, 3) = ∫₀¹ x(1-x)² dx = 1/12

Applications

  • Gamma: Probability distributions (gamma distribution), physics integrals.
  • Beta: Probability distributions (beta distribution), statistics, engineering.
