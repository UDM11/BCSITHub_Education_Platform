3.1 System Implementation and Testing

The final phase requires teams to deliver a fully functional web-based solution. The codebase must incorporate advanced concepts from the Project I syllabus:

  • Advanced jQuery: Use sliders, date pickers, and table sort modifications.
  • AJAX & JSON: Fetch information asynchronously via the Fetch API or XMLHttpRequest.
  • Framework Overview: Practical understanding of modern libraries like React, Angular, or Vue.js.
// Fetching and Displaying JSON Data Asynchronously

        let response = await fetch('/api/projects');
        let data = await response.json();
        console.log('Loaded Data:', data);
    } catch (error) {
        console.error('Fetch error:', error);
    }
}

3.3 Prescribed Chapters in the Main Report

The project report must be compiled in standard A4 format and follow these chapters strictly:

  1. Chapter 1: Introduction: Background, problem statement, objectives, scope, and limitations.
  2. Chapter 2: Review of Literature: Fundamental theories, general terminologies, and review of similar projects.
  3. Chapter 3: System Analysis and Design: Requirements analysis (Functional & Non-Functional), Feasibility analysis, Data & Process modeling, and Interface designs.
  4. Chapter 4: Implementation and Testing:
    • Implementation: Development tools used, programming languages, libraries, and module logic.
    • Testing: Detailed matrices for Unit Testing and System Testing.
  5. Chapter 5: Conclusion & Future Recommendations: Lessons learned and project summary.
📂 Report Appendices: The document must append: 1. System screenshots, 2. Core source code listings, and 3. Supervisor Visit Log Sheets.

3.4 Final Evaluation and Viva Voce

The final defense (50% Weight) is presented before an external examiner appointed by the university.

Evaluation Criteria Breakdown:

  • Final Project Report (10%): Structural adherence, clear citations, and documentation quality.
  • Slide Presentation (5%): Quality of presentation slides and defense timing.
  • System Demonstration (15%): Smooth execution of the web application, layout responsiveness, and error handling.
  • External Q&A / Viva (15%): In-depth questions regarding frontend code logic, DOM methods, and scripting.
  • Teamwork (5%): Contribution validation based on log sheets.
