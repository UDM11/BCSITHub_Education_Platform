4.1 Introduction to CSS

Cascading Style Sheets (CSS) is a stylesheet language used to control the presentation and layout of HTML documents. It separates content from design, enabling consistent styling across multiple pages and improving maintainability.

🎨 Purpose
Enhances visual appeal, user experience, and accessibility. Allows control over colors, fonts, spacing, layout, and responsive behavior.
📋 Key Concepts
Cascading: Styles apply based on specificity, source order, and importance. CSS3 is the latest version with advanced features.

Benefits of CSS

  • Separation of Concerns: Content (HTML) and presentation (CSS) are kept separate.
  • Consistency: Apply the same styles across multiple pages with one stylesheet.
  • Maintainability: Make global design changes from a single file.
  • Performance: Reduce file size and improve load times.
  • Accessibility: Support different devices and user preferences.
💡 Key insight: CSS is essential for modern web development. Without CSS, the web would consist of unstyled, plain text documents.

4.2 CSS Syntax

CSS syntax consists of selectors and declaration blocks. A declaration block contains properties and their values, enclosed in curly braces.

Basic Syntax

selector {
    property: value;
    property: value;
}

Components

  • Selector: Targets HTML elements (e.g., h1, .class, #id).
  • Property: Defines what to style (e.g., color, font-size).
  • Value: Specifies the style (e.g., blue, 16px).
  • Declaration: Property + value pair (e.g., color: blue;).
  • Declaration Block: Group of declarations inside { }.
/* CSS Syntax Example */
h1 {
    color: #2c3e50;
    font-size: 32px;
    text-align: center;
}

.highlight {
    background-color: yellow;
    padding: 4px 8px;
    border-radius: 4px;
}

4.3 Using CSS with HTML

CSS can be applied to HTML in three ways: inline, internal, and external. Each method has its use cases and advantages.

Inline CSS

  • Method: Use the style attribute directly on HTML elements.
  • Pros: Quick and specific styling.
  • Cons: Not reusable, difficult to maintain, violates separation of concerns.
<p style="color: red; font-size: 18px;">Styled inline</p>

Internal CSS

  • Method: Defined within a <style> tag in the <head> section.
  • Pros: Good for single-page styling, all CSS in one place.
  • Cons: Not reusable across multiple pages.
<head>
    <style>
        p { color: blue; font-size: 16px; }
    </style>
</head>

External CSS

  • Method: Linked via a <link> tag to a separate .css file.
  • Pros: Reusable, maintainable, cached for better performance.
  • Cons: Requires an extra HTTP request (can be cached).
<head>
    <link rel="stylesheet" href="styles.css">
</head>

Comparison

MethodScopeReusableMaintainablePerformance
InlineSingle elementNoDifficultFast
InternalSingle pageLimitedModerateFast
ExternalWhole siteYesExcellentCached
📌 Key insight: External CSS is the recommended approach for professional websites. It provides the best maintainability and performance benefits.

4.4 CSS Selectors

Selectors target HTML elements to apply styles. They range from basic to complex for precise targeting. Understanding selectors is fundamental to writing efficient CSS.

Basic Selectors

SelectorSyntaxExampleDescription
Elementelementp { }All paragraphs
Class.class.highlight { }Elements with class="highlight"
ID#id#header { }Element with id="header"
Universal** { }All elements
Grouping,h1, h2, h3 { }Multiple selectors

Combinators

  • Descendant (space): div p { } — All paragraphs inside divs.
  • Child (>): div > p { } — Paragraphs directly inside divs.
  • Adjacent Sibling (+): h1 + p { } — Paragraph immediately after h1.
  • General Sibling (~): h1 ~ p { } — All paragraphs after h1.

Pseudo-classes

  • :hover — On mouse hover.
  • :active — When element is active (clicked).
  • :focus — When element has focus.
  • :visited — Visited links.
  • :nth-child() — Specific children.
  • :first-child, :last-child
  • :not() — Exclude elements.

Pseudo-elements

  • ::before — Insert before content.
  • ::after — Insert after content.
  • ::first-line — First line of text.
  • ::first-letter — First letter of text.
/* Advanced selectors example */
/* All links inside nav */
nav a { color: white; }

/* Direct children of nav */
nav > ul { list-style: none; }

/* Hover effect */
a:hover { color: #3498db; }

/* Every 2nd list item */
li:nth-child(2n) { background: #f0f0f0; }

/* Pseudo-element */
h1::before { content: "★ "; color: gold; }

4.5 CSS Comments

Comments in CSS are used to explain code, document sections, or temporarily disable styles. They improve code maintainability and collaboration.

Syntax

  • Single-line or Multi-line: Enclosed in /* */.
  • Cannot be nested (no /* /* */ */).
/* This is a CSS comment */

/*
This is a multi-line comment
Used for documenting sections
*/

/* ========== HEADER STYLES ========== */
header {
    background: #2c3e50;
    color: white;
    padding: 20px;
    /* margin: 10px; /* Temporarily disabled */
}
📝 Key insight: Good comments explain why, not what. Use them to document complex logic, browser hacks, or sections that need clarification.

4.6 CSS Properties

CSS properties define the visual characteristics of elements. Below are key property categories.

4.6.1 Backgrounds

  • background-color — Solid color background.
  • background-image — Image or gradient background.
  • background-size — Size of background (cover, contain).
  • background-position — Position of background.
  • background-repeat — Repeat behavior.
.hero {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    background-size: cover;
    background-position: center;
    min-height: 400px;
}

4.6.2 Border and Margin

  • border — Width, style, color (e.g., border: 2px solid #333).
  • border-radius — Rounded corners.
  • margin — Outer spacing (top, right, bottom, left).
.box {
    border: 2px solid #2c3e50;
    border-radius: 8px;
    margin: 20px auto;
    width: 300px;
}

4.6.3 Padding

  • padding — Inner spacing between content and border.
  • padding-top, padding-right, padding-bottom, padding-left.
.card {
    padding: 20px;
    /* Individual values: top right bottom left */
    padding: 10px 20px 10px 20px;
}

4.6.4 Height and Width

  • height — Element height.
  • width — Element width.
  • max-width, max-height — Maximum dimensions.
  • min-width, min-height — Minimum dimensions.
.container {
    width: 100%;
    max-width: 1200px;
    height: 100vh; /* Full viewport height */
    margin: 0 auto;
}

4.6.5 Color (Color Wheel)

  • Named Colors: red, blue, transparent.
  • Hexadecimal: #ff0000 (red), #00ff00 (green), #0000ff (blue).
  • RGB: rgb(255, 0, 0), rgba(255, 0, 0, 0.5) (with alpha).
  • HSL: hsl(240, 100%, 50%), hsla(240, 100%, 50%, 0.5).
.text-primary { color: #3498db; }
.text-success { color: rgb(46, 204, 113); }
.text-warning { color: hsl(45, 100%, 50%); }
.text-danger { color: rgba(231, 76, 60, 0.8); }

4.7 Text

Controls text appearance, including decoration, transformation, spacing, and alignment.

Text Properties

  • text-decoration — underline, overline, line-through, none.
  • text-transform — uppercase, lowercase, capitalize.
  • text-align — left, right, center, justify.
  • letter-spacing — Space between characters.
  • word-spacing — Space between words.
  • text-indent — First line indentation.
  • text-shadow — Shadow effect on text.
.article {
    text-align: justify;
    text-indent: 2em;
    letter-spacing: 0.5px;
    line-height: 1.8;
}

.title {
    text-transform: uppercase;
    text-decoration: underline;
    text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
}

4.8 Font

Defines font properties like family, size, weight, and style to control typography.

Font Properties

  • font-family — Font name (e.g., Arial, Times New Roman, system-ui).
  • font-size — Text size (px, em, rem, %).
  • font-weight — Boldness (normal, bold, 100-900).
  • font-style — normal, italic, oblique.
  • font-variant — small-caps.
  • font — Shorthand property.
.body-text {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    font-size: 16px;
    font-weight: 400;
    font-style: normal;
}

.heading {
    font: bold 2.5rem/1.2 'Georgia', serif;
    /* weight size/line-height family */
}

Web Fonts

  • Google Fonts: <link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">
  • @font-face: Custom fonts.
@import url('https://fonts.googleapis.com/css2?family=Open+Sans:wght@300;400;700&display=swap');

body {
    font-family: 'Open Sans', sans-serif;
}

4.9 Alignment

Controls the alignment of text or elements within their container.

Text Alignment

  • text-align — left, right, center, justify.
  • vertical-align — top, middle, bottom, baseline.

Element Alignment

  • Flexbox: justify-content, align-items, align-self.
  • Grid: justify-items, align-items, place-items.
  • Margin Auto: margin: 0 auto; for horizontal centering.
/* Text alignment */
.center-text { text-align: center; }
.justify-text { text-align: justify; }

/* Flex alignment */
.flex-center {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}

/* Block centering */
.container {
    width: 80%;
    max-width: 1200px;
    margin: 0 auto;
}

4.10 Line Height

line-height adjusts the vertical spacing between lines of text, improving readability and aesthetics.

Values

  • Number: Multiplier of font size (e.g., line-height: 1.5; → 1.5 × font-size).
  • Length: Fixed value (e.g., line-height: 24px;).
  • Percentage: Relative to font size (e.g., line-height: 150%;).
.text-content {
    font-size: 16px;
    line-height: 1.8; /* 28.8px */
}

.compact {
    line-height: 1.2; /* Tighter spacing */
}

.spacious {
    line-height: 2.0; /* More breathing room */
}
📖 Key insight: A line height of 1.5 to 1.8 is generally recommended for body text for optimal readability.

4.11 Box Model

The CSS box model represents the structure of every HTML element, consisting of content, padding, border, and margin.

+---------------------------+
|          Margin           |
|  +---------------------+  |
|  |       Border        |  |
|  |  +-----------------+ |  |
|  |  |     Padding     | |  |
|  |  |  +-----------+  | |  |
|  |  |  |  Content  |  | |  |
|  |  |  +-----------+  | |  |
|  |  +-----------------+ |  |
|  +---------------------+  |
+---------------------------+
  • Content: The actual content (text, images, etc.).
  • Padding: Space between content and border.
  • Border: Line surrounding padding and content.
  • Margin: Space outside the border (between elements).
.box {
    width: 200px; /* Content width */
    padding: 20px; /* Inner spacing */
    border: 2px solid #333; /* Border */
    margin: 15px; /* Outer spacing */
    box-sizing: border-box; /* Include padding and border in width */
}

box-sizing

  • content-box (default): Width/height applies to content only.
  • border-box: Width/height includes padding and border.
/* Reset all elements to border-box */
*, *::before, *::after {
    box-sizing: border-box;
}

4.12 Working with Images

CSS styles images for size, positioning, and visual effects.

Image Properties

  • width, height — Set dimensions.
  • object-fit — cover, contain, fill, none, scale-down.
  • object-position — Position within container.
  • border-radius — Round corners.
  • filter — blur, brightness, contrast, grayscale, sepia.
  • opacity — Transparency (0 to 1).
/* Image gallery styles */
.gallery-image {
    width: 100%;
    height: 250px;
    object-fit: cover;
    border-radius: 8px;
    transition: transform 0.3s ease;
}

.gallery-image:hover {
    transform: scale(1.05);
    filter: brightness(1.1);
}

/* Background image with overlay */
.hero-section {
    background-image: url('hero.jpg');
    background-size: cover;
    background-position: center;
    height: 500px;
    position: relative;
}

4.13 Layout and Positioning

CSS controls element placement using positioning, flexbox, or grid layouts.

Position Properties

  • static (default): Normal flow.
  • relative: Relative to its normal position.
  • absolute: Relative to nearest positioned ancestor.
  • fixed: Relative to viewport (scrolls with page).
  • sticky: Hybrid of relative and fixed.

Flexbox

  • One-dimensional layout (row or column).
  • display: flex; — Enables flexbox.
  • flex-direction — row, column, row-reverse, column-reverse.
  • justify-content — Horizontal alignment.
  • align-items — Vertical alignment.
  • flex-wrap — Wrap items.

Grid

  • Two-dimensional layout (rows and columns).
  • display: grid; — Enables grid.
  • grid-template-columns — Define columns.
  • grid-template-rows — Define rows.
  • gap — Spacing between items.
/* Flexbox example */
.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;
    flex-wrap: wrap;
    gap: 20px;
}

/* Grid example */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

/* Position example */
.sticky-nav {
    position: sticky;
    top: 0;
    background: white;
    z-index: 1000;
}

4.14 Media Query

Media queries apply styles based on device characteristics, enabling responsive design for different screen sizes and devices.

Syntax

@media (condition) {
    /* CSS rules */
}

Common Breakpoints

  • Mobile: max-width: 480px.
  • Tablet: 481px - 768px.
  • Desktop: 769px - 1200px.
  • Large Desktop: min-width: 1201px.
/* Mobile-first approach */
.container {
    padding: 15px;
}

/* Tablet */
@media (min-width: 768px) {
    .container {
        padding: 30px;
        max-width: 720px;
        margin: 0 auto;
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .container {
        max-width: 960px;
    }
    .grid {
        grid-template-columns: repeat(3, 1fr);
    }
}

/* Orientation */
@media (orientation: landscape) {
    .hero {
        height: 80vh;
    }
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
    body {
        background: #1a1a2e;
        color: #eee;
    }
}
📱 Key insight: Use a mobile-first approach (min-width) for better performance and progressive enhancement. Media queries are essential for creating responsive websites.

4.15 CSS Website Layout

Combines CSS techniques to create structured, responsive website layouts. A typical layout includes header, navigation, main content, sidebar, and footer.

Common Layout Patterns

  • Single Column: Simple, mobile-friendly.
  • Two Column: Content + sidebar.
  • Three Column: Content + two sidebars.
  • Full Width: No sidebars.
/* Complete website layout */
/* Reset */
* { margin: 0; padding: 0; box-sizing: border-box; }

body {
    font-family: 'Segoe UI', sans-serif;
    line-height: 1.6;
}

/* Header */
.header {
    background: #2c3e50;
    color: white;
    padding: 20px 0;
    text-align: center;
}

/* Navigation */
.nav {
    background: #34495e;
    padding: 10px 0;
}
.nav ul {
    list-style: none;
    display: flex;
    justify-content: center;
    gap: 20px;
}
.nav a { color: white; text-decoration: none; }

/* Main Layout */
.container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 20px;
    display: grid;
    grid-template-columns: 2fr 1fr;
    gap: 30px;
}

/* Main Content */
.main {
    background: white;
    padding: 20px;
    border-radius: 8px;
    box-shadow: 0 2px 5px rgba(0,0,0,0.1);
}

/* Sidebar */
.sidebar {
    background: #f8f9fa;
    padding: 20px;
    border-radius: 8px;
}

/* Footer */
.footer {
    background: #2c3e50;
    color: white;
    text-align: center;
    padding: 20px 0;
    margin-top: 30px;
}

/* Responsive */
@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr;
    }
    .nav ul {
        flex-direction: column;
        align-items: center;
    }
}
<!-- HTML Structure -->
<body>
    <header class="header">
        <h1>My Website</h1>
    </header>

    <nav class="nav">
        <ul>
            <li><a href="#">Home</a></li>
            <li><a href="#">About</a></li>
            <li><a href="#">Services</a></li>
            <li><a href="#">Contact</a></li>
        </ul>
    </nav>

    <div class="container">
        <main class="main">
            <h2>Main Content</h2>
            <p>This is the main content area.</p>
        </main>

        <aside class="sidebar">
            <h3>Sidebar</h3>
            <p>Additional content.</p>
        </aside>
    </div>

    <footer class="footer">
        <p>&copy; 2025 My Website</p>
    </footer>
</body>
🏗️ Key insight: CSS layout techniques (flexbox, grid, positioning) combined with media queries enable the creation of modern, responsive, and accessible websites.
