2.1 Introduction to HTML

HTML (Hyper Text Markup Language) is the standard markup language used to create and design web pages. It provides the structure for content on the web, allowing browsers to interpret and display text, images, and multimedia. HTML uses tags to define elements and their hierarchy within a document.

📄 Purpose
Defines the structure and content of web pages. It is the backbone of every website.
🏷️ Tags
Enclosed in angle brackets, e.g., <tag>. Most tags come in pairs: opening and closing.

Key Concepts

  • HTML Elements: The building blocks of HTML pages. Each element is defined by a start tag, content, and an end tag.
  • Attributes: Provide additional information about elements. Written as name="value" inside the opening tag.
  • HTML Versions: HTML5 is the latest standard, offering improved semantics, multimedia support, and APIs.
<!-- Basic HTML document structure -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to HTML</h1>
    <p>This is a simple HTML page.</p>
</body>
</html>
💡 Key insight: HTML is not a programming language — it's a markup language that structures content. It works together with CSS (styling) and JavaScript (interactivity) to create complete web pages.

2.2 Document Structure

An HTML document follows a specific structure to ensure proper rendering in browsers. The key components include the DOCTYPE declaration, <html>, <head>, and <body> tags.

Document Components

  • <!DOCTYPE html>: Declares the document as HTML5. Ensures the browser uses standards mode.
  • <html>: The root element of the document. All other elements are nested inside it.
  • <head>: Contains metadata (information about the page), such as the title, character set, links to CSS, and scripts.
  • <body>: Contains the visible content of the page — text, images, links, forms, and other elements.
HTML Document Structure:
┌─────────────────────────────────────────┐
│ <!DOCTYPE html>                       │
│ <html>                                │
│   ┌─────────────────────────────────┐   │
│   │ <head>                         │   │
│   │  <title>Page Title</title>    │   │
│   │  <meta> <link> <script>       │   │
│   │ </head>                        │   │
│   └─────────────────────────────────┘   │
│   ┌─────────────────────────────────┐   │
│   │ <body>                         │   │
│   │  <h1>Heading</h1>             │   │
│   │  <p>Paragraph</p>             │   │
│   │  <!-- Other content -->        │   │
│   │ </body>                        │   │
│   └─────────────────────────────────┘   │
│ </html>                               │
└─────────────────────────────────────────┘
<!-- Complete document structure -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document Structure Example</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>My Page</h1>
    <p>This is the visible content.</p>
    <script src="script.js"></script>
</body>
</html>

2.4 Links and Navigation

Links (hyperlinks) are the foundation of web navigation. They allow users to navigate between pages, download files, or jump to specific sections within a page.

The <a> Tag

  • Syntax: <a href="URL">Link Text</a>
  • href Attribute: Specifies the destination URL.
  • target Attribute: Controls where to open the link.
    • _blank — Opens in a new tab/window.
    • _self — Opens in the same frame (default).
    • _parent — Opens in the parent frame.
    • _top — Opens in the full body of the window.
  • title Attribute: Provides a tooltip when hovering over the link.
<!-- Link examples -->
<a href="https://example.com">Absolute URL</a>
<a href="/about.html">Relative URL</a>
<a href="contact.html" target="_blank">Open in new tab</a>
<a href="#section1">Jump to Section 1</a>
<a href="mailto:info@example.com">Send Email</a>
<a href="tel:+1234567890">Call Us</a>

Navigation Menus

  • Using Lists: <ul> and <li> for structured navigation.
  • Semantic <nav>: Wraps navigation links for better accessibility.
<!-- Navigation menu -->
<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="services.html">Services</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

2.5 Hyperlink

Hyperlinks connect web pages and resources, enabling seamless navigation across the internet or within a site.

Types of Hyperlinks

  • Absolute URLs: Full web addresses including the protocol.
    <a href="https://www.example.com/page.html">Absolute Link</a>
  • Relative URLs: Paths relative to the current page.
    <a href="page.html">Same Directory</a>
    <a href="./folder/page.html">Subdirectory</a>
    <a href="../page.html">Parent Directory</a>
  • Anchor Links (Internal): Link to a specific section within a page using #id.
    <!-- Link to section -->
    <a href="#section1">Go to Section 1</a>

    <!-- Target section -->
    <section id="section1">
        <h2>Section 1</h2>
    </section>
  • Email Links: Open the user's email client.
    <a href="mailto:info@example.com">Send Email</a>
    <a href="mailto:info@example.com?subject=Hello">Email with Subject</a>
  • Telephone Links: Dial a phone number on mobile devices.
    <a href="tel:+1234567890">Call (123) 456-7890</a>
  • Download Links: Link to files for download.
    <a href="file.pdf" download>Download PDF</a>
🔗 Key insight: Relative URLs are preferred for internal links as they work regardless of the domain or protocol. Absolute URLs are used for external resources.

2.6 Images and Multimedia

HTML supports embedding images, audio, and video to enhance web content and create rich user experiences.

Images (<img>)

  • Required Attributes:
    • src — Image source path.
    • alt — Alternative text for accessibility and broken images.
  • Optional Attributes:
    • width and height — Image dimensions (in pixels).
    • loading="lazy" — Lazy loading for performance.
    • title — Tooltip text.

Audio (<audio>)

  • Attributes:
    • controls — Show playback controls.
    • autoplay — Auto-play (use sparingly).
    • loop — Loop the audio.
    • muted — Start muted.
  • Formats: MP3, WAV, OGG.

Video (<video>)

  • Attributes:
    • controls — Show playback controls.
    • width and height — Video dimensions.
    • autoplay — Auto-play (use sparingly).
    • poster — Image shown before video starts.
  • Formats: MP4, WebM, OGV.
<!-- Image example -->
<img src="photo.jpg" alt="Beautiful sunset over mountains" width="600" height="400">

<!-- Audio example -->
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    Your browser does not support the audio element.
</audio>

<!-- Video example -->
<video controls width="640" height="360" poster="preview.jpg">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    Your browser does not support the video tag.
</video>
🖼️ Key insight: Always include alt text for images for accessibility and SEO. Use modern image formats like WebP for better performance.

2.7 Lists, Tables, Forms and Input

These elements organize data and collect user input effectively on web pages.

Lists

  • <ul> — Unordered list (bulleted).
  • <ol> — Ordered list (numbered).
  • <li> — List item.
  • Attributes: type (1, a, A, i, I) and start for ordered lists.
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
</ul>

<ol type="A" start="3">
    <li>Third item</li>
    <li>Fourth item</li>
</ol>

Tables

  • <table> — Container for the table.
  • <tr> — Table row.
  • <th> — Header cell (bold, centered).
  • <td> — Data cell.
  • <thead>, <tbody>, <tfoot> — Group table sections.
<table border="1">
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Alice</td>
            <td>25</td>
        </tr>
    </tbody>
</table>

Forms and Input

  • <form> — Container for user input.
  • Attributes: action (submission URL), method (GET/POST).
  • Input Types: text, email, password, number, date, checkbox, radio, file, submit, reset.
<form action="/submit" method="POST">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" required>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

    <label for="message">Message:</label>
    <textarea id="message" name="message" rows="4" cols="40"></textarea>

    <input type="submit" value="Send">
</form>

2.8 Semantic HTML

Semantic HTML uses tags that convey meaning about the content's structure and purpose. This improves accessibility, SEO, and code maintainability.

Semantic Elements

ElementPurpose
<header>Introductory content or navigation
<nav>Navigation links
<main>Primary content of the page
<article>Self-contained content (blog post, news article)
<section>Thematic grouping of content
<aside>Content tangentially related (sidebar)
<footer>Footer content (copyright, links)
<figure>Images, diagrams, code snippets with captions
<figcaption>Caption for a figure
<time>Date/time information
<mark>Highlighted text
<details>Collapsible content
<summary>Summary for details element
<!-- Semantic HTML example -->
<body>
    <header>
        <h1>My Website</h1>
        <nav>
            <ul>
                <li><a href="#home">Home</a></li>
                <li><a href="#blog">Blog</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <h2>Blog Post Title</h2>
            <time datetime="2025-01-15">January 15, 2025</time>
            <section>
                <p>This is the content of the blog post.</p>
            </section>
        </article>

        <aside>
            <h3>About the Author</h3>
            <p>John Doe, web developer.</p>
        </aside>
    </main>

    <footer>
        <p>&copy; 2025 My Website</p>
    </footer>
</body>

Benefits of Semantic HTML

  • Accessibility: Assistive technologies (screen readers) understand the page structure better.
  • SEO: Search engines prioritize content based on semantic structure.
  • Maintainability: Code is easier to read and understand.
  • Consistency: Standardized structure across web projects.
🏗️ Key insight: Semantic HTML is not just about using the right tags — it's about creating meaningful, accessible, and well-structured content that works for all users.
