6.1 Introduction to JavaScript

JavaScript is a high-level, interpreted programming language used to make web pages interactive. It runs in the browser, enabling dynamic content, user interactions, and client-side logic without requiring server communication for every action.

🎯 Purpose
Adds interactivity to websites, handles events, manipulates the DOM, communicates with servers via AJAX, and creates rich user experiences.
📋 Key Features
Lightweight, interpreted, object-oriented, functional, event-driven, and dynamic. Supports both client-side and server-side (Node.js).

JavaScript History

  • 1995: Created by Brendan Eich at Netscape in 10 days.
  • 1996: Standardized as ECMAScript (ECMA-262).
  • 2005: AJAX popularized asynchronous web apps.
  • 2009: Node.js introduced server-side JavaScript.
  • 2015: ECMAScript 6 (ES6) added major features.
  • Present: Continuously evolving with annual updates.

JavaScript in the Browser

  • JavaScript Engine: V8 (Chrome), SpiderMonkey (Firefox), JavaScriptCore (Safari).
  • Browser APIs: DOM, Fetch, Web Storage, Geolocation, Canvas, etc.
💡 Key insight: JavaScript is the only programming language natively supported by all browsers, making it the essential language for web development.

6.2 Using JS in HTML

JavaScript can be integrated into HTML using three methods: inline, internal, and external.

Inline JavaScript

  • Method: Using event attributes directly in HTML tags.
  • Pros: Quick for simple interactions.
  • Cons: Mixes HTML and JS, hard to maintain.
<button onclick="alert('Clicked!')">Click Me</button>
<div onmouseover="this.style.color='red'">Hover Me</div>

Internal JavaScript

  • Method: Using <script> tags within the HTML document.
  • Pros: Good for single-page scripts.
  • Cons: Not reusable across pages.
<script>
    console.log('Hello from internal script');
    document.querySelector('h1').style.color = 'blue';
</script>

External JavaScript

  • Method: Linking to a separate .js file.
  • Pros: Reusable, cacheable, separates concerns.
  • Cons: Additional HTTP request (can be cached).
<script src="script.js"></script>
<script src="https://cdn.jsdelivr.net/npm/jquery@3.6.0/dist/jquery.min.js"></script>

Best Practices

  • Place scripts at the bottom of the body for better performance.
  • Use defer or async attributes for non-blocking loading.
  • Use external files for larger projects.
/* Recommended placement */
<body>
    <!-- HTML content -->
    <script src="script.js" defer></script>
</body>

6.4 JavaScript Comments

Comments explain code or temporarily disable execution, improving readability and maintenance.

Comment Types

  • Single-line: // — Everything after // is ignored.
  • Multi-line: /* */ — Can span multiple lines.
// This is a single-line comment
let x = 5; // This comment is on the same line

/*

Variable Declaration

6.6 Operators and Expressions

Operators perform operations on variables and values, forming expressions.

Operator Types

  • Arithmetic: +, -, *, /, %, ** (exponentiation), ++, --
  • Comparison: ==, ===, !=, !==, >, <, >=, <=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, *=, /=, %=
  • Ternary: condition ? expr1 : expr2
  • Spread/Rest: ... (spread operator)
// Arithmetic
let sum = 10 + 5; // 15
let product = 3 * 4; // 12
let power = 2 ** 3; // 8

// Comparison (strict vs loose)
console.log(5 == '5'); // true (loose equality)
console.log(5 === '5'); // false (strict equality)
console.log(5 != '5'); // false
console.log(5 !== '5'); // true

// Logical
let isAdult = age >= 18 && age <= 65;
let isAdmin = role === 'admin' || role === 'superadmin';
let isValid = !isDeleted;

// Assignment
let x = 10;
x += 5; // x = 15
x *= 2; // x = 30

// Ternary
let status = age >= 18 ? 'Adult' : 'Minor';

// Spread operator
let arr1 = [1, 2, 3];
let arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]

6.7 Control Flow and Conditionals

Conditionals control program flow based on logical conditions, enabling decision-making in code.

if-else Statement

let score = 85;

    console.log('Grade: A');
} else if (score >= 80) {
    console.log('Grade: B');

    console.log('Grade: C');

// Nested ternary (use sparingly)

6.8 Loops

Loops execute code repeatedly based on conditions, enabling iteration over data structures and repetitive tasks.

for Loop

// for loop with index
for (let i = 0; i < 5; i++) {
    console.log(i);
}
// Output: 0 1 2 3 4

while Loop

let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}
// Output: 0 1 2 3 4

do-while Loop

let i = 0;
do {
    console.log(i);
    i++;
} while (i < 5);
// Output: 0 1 2 3 4 (executes at least once)

for...of Loop (ES6)

let arr = [10, 20, 30, 40, 50];
for (let value of arr) {
    console.log(value);
}
// Output: 10 20 30 40 50

for...in Loop

let person = { name: 'John', age: 30, city: 'NYC' };
for (let key in person) {
    console.log(`${key}: ${person[key]}`);
}
// Output: name: John, age: 30, city: NYC

6.9 Functions

Functions are reusable blocks of code that perform specific tasks. They are fundamental to JavaScript programming.

Function Types

  • Function Declaration: function name() { } — Hoisted.
  • Function Expression: const name = function() { } — Not hoisted.
  • Arrow Function (ES6): const name = () => { } — Concise syntax.
  • IIFE: Immediately Invoked Function Expression — (function() { })();
// Function Declaration
function greet(name) {
    return `Hello, ${name}!`;
}

// Function Expression
const greet2 = function(name) {
    return `Hello, ${name}!`;
};

// Arrow Function
const greet3 = (name) => `Hello, ${name}!`;

// Arrow with multiple parameters
const add = (a, b) => a + b;

// Default parameters
function multiply(a, b = 1) {
    return a * b;
}

// Rest parameters
function sum(...numbers) {
    return numbers.reduce((acc, n) => acc + n, 0);
}

console.log(greet('John')); // Hello, John!
console.log(add(5, 3)); // 8
console.log(sum(1, 2, 3, 4)); // 10

Callbacks

// Function as argument (callback)
function processUserInput(callback) {
    let name = prompt('Enter your name:');
    callback(name);
}

processUserInput(function(name) {
    console.log(`Welcome, ${name}!`);
});

6.11 Objects

Objects store key-value pairs, representing complex data structures. They are fundamental to JavaScript and used extensively in web development.

Object Creation and Access

// Object literal
let person = {
    name: 'John',
    age: 30,
    city: 'New York',
    greet() {
        return `Hi, I'm ${this.name}`;
    }
};

// Access properties
console.log(person.name); // John (dot notation)
console.log(person['age']); // 30 (bracket notation)
console.log(person.greet()); // Hi, I'm John

// Add/update properties
person.email = 'john@example.com';
person.age = 31;

// Delete property
delete person.city;

Object Methods

// Object methods
let keys = Object.keys(person); // ['name', 'age', 'email', 'greet']
let values = Object.values(person); // ['John', 31, 'john@example.com', function]
let entries = Object.entries(person); // [['name','John'], ['age',31], ...]

// Object destructuring
let { name, age } = person;
console.log(name); // John

// Spread with objects
let personCopy = { ...person, city: 'Boston' };
console.log(personCopy.city); // Boston

Classes (ES6)

// Class syntax
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        return `Hello, I'm ${this.name}`;
    }

    static createAnonymous() {
        return new Person('Anonymous', 0);
    }
}

let john = new Person('John', 30);
console.log(john.greet()); // Hello, I'm John
let anonymous = Person.createAnonymous();

6.12 DOM Manipulation

The Document Object Model (DOM) is a programming interface for HTML documents. JavaScript can manipulate the DOM to dynamically change content, style, and structure.

Selecting Elements

  • document.getElementById('id') — Select by ID.
  • document.querySelector('selector') — First matching element.
  • document.querySelectorAll('selector') — All matching elements.
  • document.getElementsByClassName('class') — By class name.
  • document.getElementsByTagName('tag') — By tag name.
// Selecting elements
let header = document.getElementById('header');
let button = document.querySelector('.btn');
let items = document.querySelectorAll('.list-item');

// Modifying content
header.textContent = 'New Header Text';
header.innerHTML = '<span>Bold Text</span>';

// Modifying attributes
button.setAttribute('disabled', 'true');
button.getAttribute('data-id');

// Modifying styles
header.style.color = 'blue';
header.style.fontSize = '24px';
header.style.backgroundColor = '#f0f0f0';

// Adding/removing classes
header.classList.add('active');
header.classList.remove('active');
header.classList.toggle('highlight');

Creating and Modifying Elements

6.13 Events and Event Handling

Events are actions or occurrences that happen in the browser, and event handling allows JavaScript to respond to them.

Event Types

  • Mouse Events: click, dblclick, mouseover, mouseout, mousedown, mouseup
  • Keyboard Events: keydown, keyup, keypress
  • Form Events: submit, change, focus, blur, input
  • Document Events: DOMContentLoaded, load, unload
  • Window Events: scroll, resize, hashchange
  • Touch Events: touchstart, touchmove, touchend
// Event listener examples
// Mouse event
element.addEventListener('click', function(e) {
    console.log('Clicked at', e.clientX, e.clientY);
});

// Keyboard event
document.addEventListener('keydown', function(e) {
    if (e.key === 'Enter') {
        console.log('Enter key pressed');
    }
    if (e.key === 'Escape') {
        console.log('Escape key pressed');
    }
});

// Form event
document.querySelector('form').addEventListener('submit', function(e) {
    e.preventDefault();
    console.log('Form submitted');
});

// Event delegation
document.querySelector('.list').addEventListener('click', function(e) {
    if (e.target.tagName === 'LI') {
        console.log('List item clicked:', e.target.textContent);
    }
});
🔄 Key insight: Event delegation (adding listeners to parent elements) improves performance and handles dynamically created elements.

6.14 ES6+ Features

ECMAScript 6 (ES6) and later versions introduced many features that modern JavaScript relies on.

Key ES6+ Features

  • let and const: Block-scoped declarations.
  • Arrow Functions: Concise syntax with lexical this.
  • Template Literals: String interpolation with backticks.
  • Destructuring: Extract values from arrays/objects.
  • Spread/Rest Operators: ... for arrays and objects.
  • Default Parameters: Default values in function parameters.
  • Classes: Syntactic sugar over prototypes.
  • Modules: import and export.
  • Promises: Asynchronous operations handling.
  • Async/Await: Simpler async code.
  • Optional Chaining: ?. (object?.property).
  • Nullish Coalescing: ?? (value ?? default).
// Template literals
let name = 'John';
console.log(`Hello, ${name}!`);

// Destructuring
let [a, b, c] = [1, 2, 3];
let { x, y } = { x: 10, y: 20 };

// Spread operator
let arr1 = [1, 2, 3];
let arr2 = [...arr1, 4, 5];

// Optional chaining
let user = { profile: { name: 'John' } };
console.log(user?.profile?.name); // John
console.log(user?.address?.city); // undefined

// Nullish coalescing
let value = null ?? 'default'; // 'default'
let value2 = 0 ?? 'default'; // 0

// Async/Await
async function fetchData() {
    try {
        let response = await fetch('/api/data');
        let data = await response.json();
        console.log(data);
    } catch (error) {
        console.error(error);
    }
}
