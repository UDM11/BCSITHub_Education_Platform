Core functions · process & memory management · file systems · security & user interface

4.1 Introduction

An Operating System (OS) is the most fundamental software that runs on a computer. It acts as an intermediary between the user and the computer hardware, managing all hardware resources and providing services for application software.

🖥️ Purpose
The OS abstracts hardware complexity, provides a consistent environment for applications, and ensures efficient and fair resource allocation.
🧩 Components
Kernel (core), device drivers, system libraries, user interface (GUI/CLI), and system utilities.
  • Abstraction: The OS hides hardware details (memory addresses, I/O ports) from users and applications.
  • Resource Manager: Allocates CPU time, memory space, storage, and I/O devices among competing processes.
  • Examples: Windows 11, Ubuntu Linux, macOS Ventura, Android 14, iOS 17.
💡 Core idea: Without an operating system, a computer is just a collection of electronic components. The OS brings it to life.

4.2 Objectives of Operating System

The operating system is designed with several key objectives that guide its design and functionality.

  • Resource Management: Efficiently manage CPU, memory, storage, and I/O devices to maximize system throughput and minimize response time.
  • User Convenience: Provide an intuitive interface that makes the computer easy to use for both novice and expert users.
  • System Efficiency: Ensure that system resources are utilized optimally without waste or contention.
  • Reliability and Stability: Maintain system stability even under heavy load or hardware failures. Prevent crashes and data loss.
  • Security and Protection: Protect user data and system resources from unauthorized access, malware, and other threats.
  • Extensibility: Allow new hardware and software to be added without disrupting existing functionality.

4.3 Types of Operating Systems

Operating systems are classified based on their architecture, processing approach, and target environment. Each type serves distinct purposes.

Batch Operating System

  • Characteristics: Processes jobs in batches without user interaction. Jobs are collected, sorted, and executed sequentially.
  • Advantages: Efficient for large volumes of similar tasks; minimal overhead.
  • Disadvantages: No user interaction; long turnaround time; CPU idle time during I/O.
  • Example: Early mainframes (IBM 7090).

Multitasking / Time-Sharing OS

  • Characteristics: Allows multiple users to interact with the system simultaneously. CPU time is shared among processes using time slices.
  • Advantages: Interactive, efficient resource utilization, fast response.
  • Disadvantages: More complex scheduling; overhead from context switching.
  • Examples: Unix, Linux, Windows, macOS.

Real-Time Operating System (RTOS)

  • Characteristics: Processes data with strict timing constraints. Guarantees that critical tasks complete within specified deadlines.
  • Advantages: Predictable, deterministic, reliable for mission-critical applications.
  • Disadvantages: Limited flexibility; difficult to design and debug.
  • Examples: VxWorks, FreeRTOS, QNX (used in automotive, medical, aerospace).

Distributed Operating System

  • Characteristics: Manages a cluster of interconnected computers that appear as a single coherent system to users.
  • Advantages: High availability, scalability, fault tolerance.
  • Disadvantages: Complex to implement; network latency and synchronization challenges.
  • Examples: Amoeba, Mach, Google's Kubernetes (container orchestration).

Mobile Operating System

  • Characteristics: Optimized for smartphones, tablets, and wearables with touch interfaces, power management, and connectivity.
  • Advantages: Power-efficient, responsive, supports a wide range of apps.
  • Disadvantages: Limited multitasking compared to desktop OS; security challenges.
  • Examples: Android, iOS, HarmonyOS, watchOS.

4.4 Functions of Operating System

The OS performs a wide range of functions to manage system resources and provide a stable environment for applications.

Process Management

  • Process Creation and Termination: Creates and terminates processes as needed.
  • Scheduling: Determines which process runs on the CPU and for how long using algorithms like Round-Robin, Priority, and Multi-level Queue.
  • Process Synchronization: Coordinates concurrent processes to avoid conflicts (mutex, semaphores).
  • Inter-Process Communication (IPC): Enables processes to exchange data via pipes, message queues, shared memory.

Memory Management

  • Allocation and Deallocation: Assigns memory to processes and frees it when no longer needed.
  • Virtual Memory: Uses disk space to simulate larger memory capacity (paging, segmentation).
  • Address Translation: Maps virtual addresses to physical addresses using MMU.
  • Protection: Prevents processes from accessing each other's memory space.

File Management

  • File Operations: Create, read, write, delete, and append files.
  • Directory Management: Organize files in hierarchical structures.
  • File Systems: Implement file systems like NTFS, FAT32, ext4, APFS.
  • Access Control: Manage permissions (read, write, execute) for users and groups.

Device Management

  • Device Drivers: Interface with hardware devices (printers, keyboards, displays).
  • I/O Scheduling: Manage requests to devices to improve throughput.
  • Buffering and Caching: Temporarily store data to handle speed mismatches between devices.

Protection and Security

  • Authentication: Verify user identity (passwords, biometrics, multi-factor).
  • Authorization: Control access to resources based on user permissions.
  • Encryption: Protect data at rest and in transit.
  • Auditing: Log system events for security monitoring.

User Interface

  • GUI: Graphical environment with windows, icons, menus (Windows, macOS).
  • CLI: Command-line interface for advanced users (Bash, PowerShell).
  • Voice/gesture: Modern interfaces like Cortana, Siri, touch gestures.

4.5 Process Management – In Depth

A process is a program in execution. Process management is one of the core responsibilities of the operating system.

Process States

  • New: Process is being created.
  • Ready: Process is waiting for CPU allocation.
  • Running: Process is currently executing on the CPU.
  • Waiting: Process is waiting for I/O or an event.
  • Terminated: Process has finished execution.

Process Scheduling Algorithms

  • FCFS (First-Come, First-Served): Simple, non-preemptive, but can cause convoy effect.
  • SJF (Shortest Job First): Minimizes average waiting time, but needs knowledge of burst times.
  • Round-Robin: Preemptive, fair, uses time quantum — good for time-sharing systems.
  • Priority Scheduling: Higher priority processes run first — can cause starvation without aging.
  • Multi-level Queue: Combines multiple scheduling algorithms for different priority levels.

4.6 Memory Management – In Depth

Memory management ensures that each process has enough memory to execute and that processes do not interfere with each other.

Memory Allocation Techniques

  • Contiguous Allocation: Each process gets a single block of contiguous memory. Simple but causes external fragmentation.
  • Paging: Divides physical memory into fixed-size frames and logical memory into pages. Eliminates fragmentation.
  • Segmentation: Divides process into variable-sized segments (code, data, stack). Provides logical separation.
  • Virtual Memory: Allows processes to use more memory than physically available by swapping data to disk (page file).

Page Replacement Algorithms

  • FIFO: Replaces the oldest page — simple but can cause poor performance.
  • LRU (Least Recently Used): Replaces the page not used for the longest time — good performance, but hardware overhead.
  • Optimal: Replaces the page that will not be needed for the longest time — theoretical optimum, not practical.

4.7 File Management – In Depth

File management handles the organization, storage, and retrieval of data on storage devices.

File Operations

  • Create: Allocate space and establish an entry in the directory.
  • Read: Copy data from file to memory.
  • Write: Copy data from memory to file.
  • Delete: Free space and remove directory entry.
  • Append: Add data to the end of an existing file.

File Systems

  • NTFS: Windows default — supports large volumes, permissions, journaling.
  • FAT32: Legacy, compatible with many OS but limited to 4GB max file size.
  • ext4: Linux standard — reliable, supports large files and volumes.
  • APFS: Apple's file system — optimized for SSDs, snapshots, encryption.

Directory Structure

  • Single-level: All files in one directory — simple but limited.
  • Two-level: User directories separate files by user.
  • Hierarchical: Tree structure with nested directories — most common (Unix, Windows).
📂 File System Features: Modern file systems include journaling (prevent data corruption), snapshots (point-in-time copies), and encryption (protect data at rest).

4.8 Device Management

Device management controls and coordinates all hardware devices connected to the computer.

Device Drivers

  • Role: Provide a uniform interface for the OS to communicate with hardware.
  • Types: Character drivers (keyboard, serial), block drivers (storage), network drivers.
  • Plug and Play: Automatically detect and configure devices.

I/O Scheduling

  • Purpose: Optimize the order of I/O requests to improve device throughput.
  • Algorithms: FCFS, SCAN (elevator), C-SCAN, SSTF (shortest seek time first).

Buffering and Caching

  • Buffering: Temporarily stores data to handle speed mismatches between device and CPU.
  • Caching: Stores frequently accessed data in fast memory for faster retrieval.

4.9 Protection and Security

Protection and security are critical OS functions to safeguard data and system resources.

Protection Mechanisms

  • Access Control Lists (ACL): Define permissions for users and groups.
  • Capability-based: Process has specific capabilities to access resources.
  • Ring protection: CPU rings (0-3) isolate kernel from user processes.

Security Features

  • Authentication: Verify user identity via passwords, biometrics, or tokens.
  • Authorization: Control what authenticated users can do.
  • Encryption: Protect data with BitLocker (Windows), FileVault (macOS), LUKS (Linux).
  • Firewall: Control network traffic to prevent unauthorized access.
  • Antivirus: Detect and remove malware.
🛡️ Security best practices: Regular updates, least privilege principle, strong passwords, and security auditing are essential for system protection.

4.10 User Interface

The user interface is the part of the OS that users interact with directly. It provides access to all system functions.

Graphical User Interface (GUI)

  • Elements: Windows, icons, menus, pointers (WIMP).
  • Examples: Windows Desktop, macOS Finder, GNOME, KDE.
  • Features: Drag-and-drop, context menus, taskbars, notifications.

Command-Line Interface (CLI)

  • Characteristics: Text-based, fast, powerful for automation.
  • Examples: PowerShell, Command Prompt, Bash, Zsh.
  • Features: Scripting, pipes, redirection, environment variables.

Touch and Voice Interfaces

  • Touch: Gestures (swipe, tap, pinch) on mobile devices and touchscreens.
  • Voice: Virtual assistants like Cortana, Siri, Google Assistant.
  • Future: AR/VR interfaces, brain-computer interfaces (BCI).
