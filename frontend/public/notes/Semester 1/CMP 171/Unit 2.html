Unit 2: Computer Hardware

Physical components · architecture · functional units · I/O & memory

2.1 Introduction

Computer hardware encompasses all the tangible, physical parts of a computer system. These components are the foundation upon which software runs and data is processed. Hardware includes everything from the central processor to peripheral devices.

🔧 Purpose
Hardware provides the physical infrastructure for computing – processing, storage, and user interaction. Without hardware, software cannot exist.
📦 Key components
CPU (brain), memory (RAM/ROM), storage (HDD/SSD), motherboard, power supply, input devices (keyboard, mouse), output devices (monitor, printer).
  • Interdependence: Hardware and software are mutually dependent. The hardware executes instructions encoded in software.
  • Evolution: Hardware has evolved from vacuum tubes to transistors to integrated circuits, leading to today's powerful, energy-efficient systems.
  • Categories: Internal components (CPU, RAM, motherboard) and external peripherals (monitor, keyboard, external drives).
💡 Core idea: Hardware is the physical canvas; software is the paint. Together they create the digital experience.

2.2.1 ALU (Arithmetic Logic Unit)

The Arithmetic Logic Unit is the computational engine of the CPU. It performs all arithmetic and logical operations on data.

  • Arithmetic operations: Addition, subtraction, multiplication, division, increment, decrement.
  • Logical operations: AND, OR, NOT, XOR, comparison (greater than, less than, equal).
  • Bitwise operations: Shift left/right, rotate, bit masking.
  • Registers: ALU works with registers (accumulator, status register) to hold operands and results.
  • Performance: Modern ALUs are pipelined and can execute multiple operations per clock cycle.

2.2.2 CU (Control Unit)

The Control Unit is the manager of the CPU. It fetches instructions from memory, decodes them, and generates control signals to direct other units.

  • Instruction fetch: Fetches the next instruction from memory (using program counter).
  • Decode: Interprets the instruction and identifies the operation to be performed.
  • Control signals: Generates timing and control signals for ALU, memory, and I/O.
  • Microprogrammed vs. hardwired: Modern CUs are often microprogrammed for flexibility.
  • Pipeline control: Manages instruction pipelining for improved throughput.
⏱️ Fetch–Decode–Execute cycle: The CU repeats this cycle billions of times per second, driving all computer operations.

2.2.3 Memory Unit

The Memory Unit stores data and instructions. It is organized as a hierarchy to balance speed, capacity, and cost.

Primary Memory (Main Memory)

  • RAM (Random Access Memory): Volatile, fast, used for active data and programs. Types: DRAM, SRAM, DDR4/DDR5.
  • ROM (Read-Only Memory): Non-volatile, stores firmware (BIOS/UEFI). Types: PROM, EPROM, EEPROM.
  • Cache memory: Small, ultra-fast memory (L1, L2, L3) that stores frequently accessed data.

Secondary Memory (Storage)

  • Hard Disk Drives (HDD): Magnetic storage, high capacity, slower access.
  • Solid State Drives (SSD): Flash memory, faster, more reliable, no moving parts.
  • Optical media: CD, DVD, Blu-ray – used for archival and distribution.

2.2.4 Input and Output Units

Input/Output (I/O) units enable interaction between the computer and the external world. They are essential for user communication and data exchange.

Input Devices

  • Keyboard: Primary text input device.
  • Mouse / Touchpad: Pointing devices for graphical interfaces.
  • Scanner: Converts physical documents to digital images.
  • Microphone: Captures audio input.
  • Camera: Captures still images and video.
  • Sensors: Temperature, motion, light – used in IoT and embedded systems.

Output Devices

  • Monitor (Display): Visual output – LCD, LED, OLED.
  • Printer: Hard copy output – inkjet, laser, 3D printers.
  • Speakers: Audio output for music, alerts, voice.
  • Projector: Displays content on a large screen.

I/O Interfaces

  • Ports: USB, HDMI, DisplayPort, Ethernet, Thunderbolt.
  • Wireless: Bluetooth, Wi-Fi, NFC for wireless I/O.
  • Controllers: I/O controllers manage data transfer between CPU and devices.
🔄 Bidirectional devices: Touchscreens, network interfaces, and modems function as both input and output.

2.3 Motherboard and System Buses

The motherboard is the main circuit board that connects all hardware components. It hosts the CPU, memory, expansion slots, and I/O ports.

  • Chipset: Controls data flow between CPU, memory, and peripherals.
  • Expansion slots: PCIe, PCI – for graphics cards, network cards, storage controllers.
  • Power connectors: Supply power from the PSU to the motherboard and components.

System Buses

  • Data bus: Carries actual data between components. Width (8, 16, 32, 64 bits) affects performance.
  • Address bus: Carries memory addresses from CPU to memory. Width determines maximum addressable memory.
  • Control bus: Carries control signals (read/write, interrupt, clock) to coordinate operations.

2.4 Central Processing Unit (CPU) – In Depth

The CPU is the brain of the computer. It interprets instructions and processes data. Modern CPUs contain multiple cores and complex pipelines.

  • Cores: Multiple processing units within a single CPU (dual‑core, quad‑core, octa‑core).
  • Threads: Simultaneous multithreading (Hyper‑Threading) allows each core to handle two threads.
  • Clock speed: Measured in GHz – number of cycles per second.
  • Instruction set: x86 (Intel/AMD), ARM (mobile/embedded), RISC‑V (open standard).
  • Pipelining: Overlaps instruction stages (fetch, decode, execute, memory, writeback) for higher throughput.
⚡ Performance factors
Clock speed, core count, cache size, instruction set efficiency, and memory bandwidth.
🔋 Power & heat
Dynamic voltage/frequency scaling (DVFS) manages power consumption. Thermal solutions (heatsinks, liquid cooling) prevent overheating.

2.5 Storage Hierarchy Overview

Computers use a hierarchy of storage technologies to balance speed, cost, and capacity. The closer to the CPU, the faster and more expensive per byte.

  1. Registers: Fastest, inside CPU, very small (few hundred bytes).
  2. Cache (L1/L2/L3): SRAM, very fast, sizes from KB to MB.
  3. Main Memory (RAM): DRAM, fast, sizes from GB to TB.
  4. Solid State Drive (SSD): Flash memory, moderate speed, TBs.
  5. Hard Disk Drive (HDD): Magnetic, slower, high capacity (multiple TBs).
  6. Cloud/Offline storage: Network‑attached, tape, optical – for archival.
📈 Latency comparison: Register (1 ns) → Cache (10 ns) → RAM (100 ns) → SSD (100 µs) → HDD (10 ms). Each level is an order of magnitude slower but much larger.

2.7 Hardware Maintenance and Upgrades

Proper maintenance extends hardware life and ensures optimal performance.

  • Cleaning: Remove dust from fans, heatsinks, and vents to prevent overheating.
  • Thermal paste: Reapply between CPU and cooler to improve heat transfer.
  • Firmware updates: Update BIOS/UEFI and device drivers for compatibility and security.
  • Upgrades: Add more RAM, replace HDD with SSD, upgrade GPU for better performance.
  • Power supply: Ensure adequate wattage and clean power (UPS for surge protection).
🔧 Preventive care: Regular maintenance reduces failure rates and extends the useful life of hardware components.
