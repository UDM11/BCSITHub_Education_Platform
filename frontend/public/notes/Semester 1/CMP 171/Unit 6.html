6.1 Introduction

The Internet is a global network of interconnected computer networks that uses standardized protocols (TCP/IP) to communicate and share information. It has revolutionized how we communicate, work, learn, and entertain ourselves. The Internet enables a vast array of Internet services that power the modern digital economy.

🌐 Purpose
To enable global communication, information sharing, and access to resources. It connects billions of devices worldwide.
🧩 Components
Networks, routers, servers, clients, protocols (TCP/IP), and the physical infrastructure (fiber, satellites, cables).
  • Key Services: Email (SMTP/POP), Web (HTTP/HTTPS), File Transfer (FTP), Remote Access (SSH/TELNET), and Streaming.
  • Impact: Transformed industries — education, healthcare, commerce, entertainment, and governance.
  • Examples: Browsing websites, sending emails, streaming videos, online shopping, and social media.
💡 Core idea: The Internet is not just a technology — it's a global infrastructure that underpins modern society and the digital economy.

6.2 History of the Internet

The Internet evolved from a U.S. military research project into a global phenomenon over several decades.

Key Milestones

  • 1960s – ARPANET: Funded by the U.S. Department of Defense's ARPA (Advanced Research Projects Agency). The first packet-switching network, connecting UCLA, Stanford, and other universities.
  • 1970s – TCP/IP: Vint Cerf and Bob Kahn developed TCP/IP protocols (1974), which became the standard for internet communication.
  • 1980s – Domain Name System (DNS): Introduced in 1983, replacing host tables with hierarchical domain names. The term "Internet" came into common use.
  • 1990 – World Wide Web: Tim Berners-Lee invented the Web at CERN, creating HTML, HTTP, and the first web browser. This made the Internet accessible to the general public.
  • 1990s – Commercialization: The Internet exploded with the launch of browsers (Netscape, Internet Explorer), search engines (Yahoo, Google), and e-commerce (Amazon, eBay).
  • 2000s – Broadband & Mobile: High-speed broadband and mobile internet (3G/4G) enabled streaming, social media, and cloud services.
  • 2010s – IoT & 5G: Internet of Things (IoT) and 5G networks connect billions of devices, enabling smart cities, autonomous vehicles, and AI applications.

6.3 Working Mechanism of the Internet

The Internet operates using a combination of packet switching, routing, and protocols to transmit data reliably between devices.

Packet Switching

  • Definition: Data is broken into small packets (each with source/destination addresses) before transmission.
  • Process: Packets travel independently through the network, taking different paths. They are reassembled at the destination.
  • Advantages: Efficient use of network resources, fault tolerance (if one path fails, packets can take another).

Routing

  • Definition: Routers direct packets through the most efficient path towards the destination.
  • Routing Protocols: BGP (Border Gateway Protocol), OSPF (Open Shortest Path First) determine optimal paths.
  • Example: When you browse a website, your packets traverse multiple routers across the Internet before reaching the server.

Protocols & Addressing

  • IP Address: Unique identifier for each device (IPv4 or IPv6).
  • TCP: Ensures reliable, ordered delivery of packets. Handles retransmission of lost packets.
  • UDP: Fast, connectionless transmission (used in streaming, gaming).

6.4 IP Address and Domain Name System (DNS)

IP Address

  • Definition: A unique numerical label assigned to each device connected to a network.
  • IPv4: 32-bit address (e.g., 192.168.1.1) — ~4.3 billion addresses. Exhausted in 2011.
  • IPv6: 128-bit address (e.g., 2001:0db8:85a3::8a2e:0370:7334) — virtually unlimited (~340 undecillion addresses).
  • Types: Public (globally unique) and Private (used within local networks, NAT translates to public).

Domain Name System (DNS)

  • Definition: A hierarchical system that translates human-readable domain names (e.g., google.com) into IP addresses.
  • How it works: DNS lookup → root servers → TLD servers (e.g., .com) → authoritative servers → returns IP address.
  • Record Types: A (IPv4), AAAA (IPv6), CNAME (canonical name), MX (mail exchange), TXT (text).
  • Examples: When you type "www.example.com," DNS resolves it to an IP like 93.184.216.34.

6.5 Client-Server Architecture

The client-server model is a distributed application structure that partitions tasks between service providers (servers) and service requesters (clients).

Key Concepts

  • Client: A device or software that initiates requests. Examples: Web browser, email client, mobile app.
  • Server: A device or software that provides resources or services. Examples: Web server, email server, database server.
  • Communication: Clients send requests to servers; servers process and return responses.
  • Scalability: Multiple clients can connect to a single server, or load balancing can distribute requests across multiple servers.

Types of Servers

  • Web Servers: Apache, Nginx, IIS — serve web pages (HTTP/HTTPS).
  • Email Servers: Sendmail, Postfix, Exchange — handle SMTP, POP3, IMAP.
  • File Servers: FTP/SFTP servers — share files.
  • Database Servers: MySQL, PostgreSQL, Oracle — store and query data.
  • Application Servers: Tomcat, JBoss — run web applications.

6.6 Internet Protocols (HTTP, SMTP, POP, FTP, TELNET)

Protocols define the rules for data exchange between devices on the Internet. Each protocol serves a specific purpose.

HTTP (HyperText Transfer Protocol)

  • Purpose: Transfer hypertext (web pages) between web servers and browsers.
  • Methods: GET (retrieve), POST (submit), PUT (update), DELETE (remove).
  • HTTPS: Secure version using TLS/SSL encryption.
  • Port: HTTP: 80, HTTPS: 443.

SMTP (Simple Mail Transfer Protocol)

  • Purpose: Send email from clients to servers and between servers.
  • Features: Reliable delivery, queuing, retries.
  • Port: 25 (unencrypted), 587 (submission, TLS), 465 (SSL).

POP3 (Post Office Protocol version 3)

  • Purpose: Retrieve emails from a server to a client (downloads and deletes from server by default).
  • Port: 110 (unencrypted), 995 (SSL).

IMAP (Internet Message Access Protocol)

  • Purpose: Access and manage emails on a server (maintains emails on server).
  • Port: 143 (unencrypted), 993 (SSL).

FTP (File Transfer Protocol)

  • Purpose: Transfer files between computers over a network.
  • Features: Upload, download, directory navigation.
  • Ports: 21 (control), 20 (data).
  • SFTP/FTPS: Secure versions using SSH or SSL.

TELNET

  • Purpose: Remote terminal access to a computer (command-line interface).
  • Port: 23.
  • Note: Unencrypted, insecure. Mostly replaced by SSH (port 22) for secure access.

6.7 Static and Dynamic Web Pages

Web pages can be classified based on how their content is generated and delivered to the user.

Static Web Pages

  • Definition: Pre-built HTML files stored on the server. Content is fixed and the same for every user.
  • Characteristics: Fast loading, simple to create, no database needed.
  • Use Cases: Informational sites, brochures, landing pages.
  • Technologies: HTML, CSS, JavaScript (client-side).
  • Examples: Company "About Us" page, product brochures, personal portfolios.

Dynamic Web Pages

  • Definition: Content is generated in real-time based on user input, database queries, or other factors.
  • Characteristics: Interactive, personalized, database-driven.
  • Use Cases: E-commerce, social media, search engines, dashboards.
  • Technologies: Server-side scripting (PHP, Python, Node.js), databases (MySQL, MongoDB).
  • Examples: Facebook feed, Amazon product listings, Google search results.

6.8 Search Engines

Search engines are information retrieval systems that index and search web content, helping users find relevant information.

How Search Engines Work

  • 1. Crawling: Automated bots (spiders/crawlers) discover and scan web pages.
  • 2. Indexing: Analyzed content is stored in a massive database (index) for fast retrieval.
  • 3. Ranking: Algorithms (like Google's PageRank) determine the relevance and authority of pages for a query.
  • 4. Retrieval: Results are displayed to the user with snippets and links.

Popular Search Engines

  • Google: The most widely used search engine, known for its sophisticated algorithms and vast index.
  • Bing: Microsoft's search engine, integrated with Windows and Cortana.
  • Yahoo: Legacy search engine, now powered by Bing.
  • DuckDuckGo: Privacy-focused search engine that doesn't track users.
  • Specialized: YouTube (video), WolframAlpha (computational), Google Scholar (academic).

SEO (Search Engine Optimization)

  • Definition: Practices to improve website visibility in search results.
  • Key Factors: Content quality, keywords, backlinks, mobile-friendliness, page speed.
🔍 Key insight: Search engines are the primary gateway to the Internet's vast information. SEO is essential for visibility in the digital age.

6.9 E-Commerce and M-Commerce

E-Commerce (Electronic Commerce)

  • Definition: Buying and selling goods or services using the Internet, and the transfer of money and data to execute these transactions.
  • Types:
    • B2C (Business-to-Consumer): Amazon, Walmart, Shopify.
    • B2B (Business-to-Business): Alibaba, wholesale suppliers.
    • C2C (Consumer-to-Consumer): eBay, Etsy, Facebook Marketplace.
    • C2B (Consumer-to-Business): Freelance platforms (Upwork).
  • Technologies: Shopping carts, payment gateways (PayPal, Stripe), inventory management.

M-Commerce (Mobile Commerce)

  • Definition: Buying and selling via mobile devices (smartphones, tablets).
  • Features: Mobile apps, mobile wallets (Apple Pay, Google Pay), location-based services.
  • Growth: M-commerce is growing rapidly, with mobile accounting for over 60% of e-commerce traffic.
  • Examples: Uber, Amazon app, mobile banking apps.

Payment Systems

  • Credit/Debit Cards: Visa, Mastercard.
  • Digital Wallets: PayPal, Stripe, Alipay, WeChat Pay.
  • Cryptocurrencies: Bitcoin, Ethereum (emerging).

6.10 E-Governance

E-Governance (Electronic Governance) refers to the use of information and communication technologies (ICT) to deliver government services, exchange information, and facilitate citizen participation.

Key Aspects

  • G2C (Government-to-Citizen): Services like online tax filing, passport applications, license renewals.
  • G2B (Government-to-Business): Business registration, procurement, compliance filings.
  • G2G (Government-to-Government): Data sharing between departments, inter-agency communication.
  • G2E (Government-to-Employee): HR services, payroll, training portals.

Benefits of E-Governance

  • Transparency: Citizens can access information easily.
  • Efficiency: Reduces paperwork, speeds up processes.
  • Accessibility: Services available 24/7 from anywhere.
  • Cost Savings: Reduces administrative costs.
  • Citizen Participation: Online feedback, consultations, voting.

Challenges

  • Digital Divide: Not all citizens have internet access or digital literacy.
  • Security: Protecting sensitive data from breaches.
  • Privacy: Balancing service delivery with individual privacy rights.
  • Interoperability: Integrating systems across different government departments.

Examples of E-Governance

  • India: Digital India, Aadhaar (digital identity), e‑Hospital.
  • USA: USA.gov, Healthcare.gov, IRS online filing.
  • Estonia: e‑Estonia — digital ID, e‑residency, online voting.
  • UK: GOV.UK portal for all government services.
🏛️ Key insight: E-Governance transforms how governments interact with citizens, making services more accessible, transparent, and efficient.

6.11 Internet Security Basics

Security is essential for protecting data and privacy on the Internet. Key security concepts include:

  • Encryption: SSL/TLS for HTTPS, email encryption (PGP).
  • Authentication: Passwords, 2FA, biometrics.
  • Firewalls: Control network traffic, block unauthorized access.
  • Antivirus: Detect and remove malware.
  • VPN (Virtual Private Network): Encrypted tunnel for secure communication.
🛡️ Reminder: Stay safe online — use strong passwords, enable 2FA, avoid suspicious links, and keep software updated.
