9.1 Computer Security

Computer security (also known as cybersecurity) is the practice of protecting computer systems, networks, and data from unauthorized access, theft, damage, or disruption. It encompasses a wide range of measures designed to ensure the confidentiality, integrity, and availability (CIA triad) of information.

🔒 Purpose
To safeguard hardware, software, and data from threats such as hacking, malware, phishing, and insider threats.
🧩 Components
Access controls, encryption, firewalls, antivirus software, intrusion detection systems, and security policies.

The CIA Triad

  • Confidentiality: Ensuring that data is accessible only to authorized individuals. Achieved through encryption, access controls, and authentication.
  • Integrity: Ensuring that data is accurate, complete, and has not been tampered with. Achieved through checksums, digital signatures, and version control.
  • Availability: Ensuring that data and systems are accessible when needed. Achieved through redundancy, backups, and disaster recovery plans.

🛡️ Core idea: Computer security is not a single technology but a layered approach combining policies, procedures, and technical controls.

9.2 Access Control

Access control is the process of restricting access to systems, resources, and data to authorized users only. It is a fundamental security mechanism that prevents unauthorized use and protects sensitive information.

Types of Access Control

  • Discretionary Access Control (DAC): The owner of the resource determines who can access it. Common in file systems (e.g., file permissions).
  • Mandatory Access Control (MAC): Access is determined by system policies based on security labels. Used in military and government systems.
  • Role-Based Access Control (RBAC): Access is based on the user's role within the organization (e.g., admin, manager, employee).
  • Attribute-Based Access Control (ABAC): Access is granted based on attributes (user, resource, environment). Dynamic and flexible.

Access Control Components

  • Authentication: Verifying the identity of a user (something you know, have, or are).
  • Authorization: Determining what an authenticated user is allowed to do.
  • Accounting (Auditing): Tracking user activities for security monitoring and compliance.

9.3 Protecting Against Unauthorized Access

Protecting against unauthorized access involves implementing multiple layers of defense to prevent intruders from gaining access to systems and data.

Key Protection Measures

  • Strong Password Policies: Require complex passwords (min length, special characters, numbers). Enforce regular password changes.
  • Multi-Factor Authentication (MFA): Requires two or more verification factors (e.g., password + OTP, biometric).
  • Account Lockout: Temporarily lock accounts after multiple failed login attempts to prevent brute-force attacks.
  • Session Management: Timeout inactive sessions, use secure session tokens.
  • Intrusion Detection and Prevention: Monitor for suspicious activities and automatically block threats.
  • Physical Security: Secure server rooms, use biometric access for data centers.

Common Attack Vectors and Mitigations

  • Brute Force: Mitigated by MFA, account lockout, and CAPTCHA.
  • Phishing: Mitigated by user education, email filtering, and anti-phishing tools.
  • Social Engineering: Mitigated by security awareness training and verification procedures.
🔑 Key insight: The strongest security is layered (defense in depth). No single measure is sufficient; multiple controls work together to provide comprehensive protection.

9.4 Software Piracy

Software piracy is the unauthorized copying, distribution, or use of software that is protected by copyright or licensing agreements. It is a significant issue that affects both developers and users.

Types of Software Piracy

  • Counterfeiting: Illegal copying and distribution of software with fake packaging.
  • OEM Piracy: Installing software on more computers than the license allows.
  • Downloading Cracked Software: Using illegal keygens, cracks, or unauthorized copies from torrent sites.
  • Corporate Piracy: Using one license for multiple users in an organization.

Consequences of Software Piracy

  • Financial Losses: Developers lose revenue, which affects innovation and job creation.
  • Security Risks: Pirated software often contains malware, spyware, or backdoors.
  • Legal Consequences: Users and organizations can face fines and legal action.
  • No Support: Pirated software does not receive updates or technical support.

Prevention and Alternatives

  • Use Open Source Software: Alternatives like LibreOffice, GIMP, and Linux.
  • Subscription Models: SaaS (Software as a Service) provides legal access at lower cost.
  • Educational Discounts: Many vendors offer affordable licenses for students and educators.
  • Digital Rights Management (DRM): Technical measures to prevent unauthorized copying.

9.5 Computer Viruses (Spyware, Malware, Ransomware)

Malicious software (malware) is any software designed to harm, exploit, or compromise computer systems. Understanding the different types helps in prevention and response.

Types of Malware

  • Virus: A program that attaches itself to legitimate files and spreads when executed. Can corrupt or delete data.
  • Worm: Self-replicating malware that spreads across networks without user intervention (e.g., Morris Worm).
  • Trojan Horse: Disguised as legitimate software but contains malicious payload (e.g., banking trojans).
  • Spyware: Secretly monitors user activities, captures keystrokes, and steals personal information (e.g., keyloggers).
  • Ransomware: Encrypts files and demands payment (ransom) for decryption (e.g., WannaCry, LockBit).
  • Adware: Displays unwanted advertisements, often bundled with legitimate software.
  • Rootkit: Provides hidden, privileged access to a computer, often used to conceal other malware.
  • Fileless Malware: Resides in memory and uses legitimate system tools, making detection difficult.

9.6 Anti-Virus

Antivirus software (also called anti-malware) is designed to detect, prevent, and remove malicious software from computer systems. It is a critical component of computer security.

How Antivirus Works

  • Signature-Based Detection: Compares files against a database of known virus signatures (hashes).
  • Heuristic Analysis: Detects suspicious behaviors and previously unknown threats based on patterns.
  • Behavioral Monitoring: Observes program behavior in real-time to identify malicious activities.
  • Cloud-Based Detection: Uses cloud resources for faster threat intelligence and updates.

Key Features

  • Real-Time Scanning: Continuously monitors files, emails, and downloads for threats.
  • Scheduled Scans: Perform full system scans at regular intervals.
  • Quarantine: Isolates suspicious files to prevent damage.
  • Automatic Updates: Regular updates to virus definitions protect against new threats.
  • Web Protection: Blocks malicious websites and phishing attempts.

Popular Antivirus Solutions

  • Free: Windows Defender (built-in), Avast Free, AVG Free, Bitdefender Free.
  • Paid: Norton, McAfee, Kaspersky, ESET, Malwarebytes.
  • Enterprise: Symantec Endpoint Protection, CrowdStrike, SentinelOne.

9.7 Ethical Issues

Computer security involves significant ethical considerations related to privacy, data usage, and the responsibilities of technology professionals.

Key Ethical Issues

  • Privacy: Balancing security needs with individual privacy rights. Excessive surveillance can infringe on civil liberties.
  • Data Collection: Ethical concerns about collecting, storing, and using personal data without consent.
  • Hacking: The ethical divide between white-hat (ethical) hackers who help secure systems and black-hat hackers who exploit them.
  • Disclosure: Responsible disclosure of vulnerabilities to vendors before public release.
  • Surveillance: Government surveillance programs and their impact on citizen privacy.

Ethical Frameworks

  • Professional Codes of Conduct: ACM, IEEE, and ISC² codes guide ethical behavior.
  • Transparency: Organizations should be transparent about data collection and usage.
  • Accountability: Individuals and organizations should be responsible for their security practices.

9.8 Cyber Law

Cyber law (also called IT law) encompasses the legal frameworks governing the use of computers, networks, and digital data. It addresses cybercrimes, data protection, and intellectual property in the digital realm.

Key Areas of Cyber Law

  • Cybercrime: Criminal activities conducted via computers (hacking, fraud, identity theft).
  • Data Protection: Laws protecting personal data from misuse (GDPR, CCPA).
  • Intellectual Property: Copyright, patents, and trademarks in the digital domain.
  • E-Commerce: Legal regulations for online transactions and digital signatures.
  • Digital Evidence: Admissibility and handling of electronic evidence in legal proceedings.

Important Cyber Laws Worldwide

  • GDPR (EU): General Data Protection Regulation — protects personal data of EU citizens.
  • CCPA (California): California Consumer Privacy Act — rights for data privacy.
  • IT Act (India): Information Technology Act — governs cybercrime and e-commerce.
  • CFAA (USA): Computer Fraud and Abuse Act — criminalizes unauthorized access.
  • DPA (UK): Data Protection Act — implements GDPR in the UK.
⚖️ Key insight: Cyber law is constantly evolving to address emerging technologies and threats. Organizations must comply with relevant regulations to avoid legal penalties.

9.9 Network Security

Network security involves protecting the integrity, confidentiality, and availability of data during transmission across networks. It encompasses both hardware and software solutions.

Network Security Threats

  • Hacking: Unauthorized access to network resources.
  • Phishing: Deceptive attacks to obtain sensitive information.
  • Denial of Service (DoS): Overwhelming systems to make them unavailable.
  • Man-in-the-Middle (MITM): Intercepting communication between parties.
  • Eavesdropping: Unauthorized interception of network traffic.

Network Security Measures

  • Firewalls: Control traffic based on rules.
  • Intrusion Detection/Prevention Systems (IDS/IPS): Monitor and block threats.
  • Virtual Private Networks (VPNs): Secure communication over public networks.
  • Network Segmentation: Divide networks to limit threat spread.
  • Secure Protocols: Use HTTPS, SSH, SFTP for encrypted communication.

9.10 Hardware and Software Firewall

A firewall is a security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. Firewalls can be hardware-based, software-based, or a combination of both.

Hardware Firewall

  • Description: Physical devices placed between a network and the internet (e.g., routers with built-in firewalls).
  • Advantages: Centralized protection, no performance impact on individual devices, protects the entire network.
  • Examples: Cisco ASA, Fortinet, Palo Alto Networks.

Software Firewall

  • Description: Programs installed on individual devices to control traffic.
  • Advantages: Granular control per device, customizable rules, protection even outside the network.
  • Examples: Windows Firewall, ZoneAlarm, Norton Firewall.

9.11 Data and Message Security

Data and message security involves protecting information during storage (data at rest) and transmission (data in motion). It ensures confidentiality, integrity, and authenticity.

Data Security (At Rest)

  • Encryption: Encrypt data stored on devices (Full Disk Encryption, File-level encryption).
  • Access Controls: Restrict who can read/write data.
  • Backups: Regular backups to prevent data loss.
  • Data Masking: Hide sensitive data elements in non-production environments.
  • Hardware Security Modules (HSM): Secure key storage and crypto operations.

Message Security (In Transit)

  • SSL/TLS: Secures HTTP traffic (HTTPS).
  • End-to-End Encryption: Only sender and receiver can read messages (WhatsApp, Signal).
  • VPN: Encrypts all traffic between device and server.
  • Secure Email: PGP, S/MIME for email encryption.

Best Practices

  • Use strong encryption algorithms (AES-256, RSA-2048).
  • Implement secure key management.
  • Regularly update and patch systems.
  • Use secure communication protocols.

9.12 Encryption and Decryption

Encryption is the process of converting plaintext (readable data) into ciphertext (unreadable data) using an algorithm and a key. Decryption is the reverse process — converting ciphertext back to plaintext using a decryption key.

Types of Encryption

  • Symmetric Encryption: Same key for encryption and decryption. Fast but requires secure key exchange.
  • Asymmetric Encryption: Two keys — public key for encryption, private key for decryption. Slower but more secure for key exchange.

Common Encryption Algorithms

  • Symmetric: AES (Advanced Encryption Standard), DES (Data Encryption Standard), Blowfish, Twofish.
  • Asymmetric: RSA (Rivest-Shamir-Adleman), ECC (Elliptic Curve Cryptography), Diffie-Hellman.
  • Hashing: SHA-256, MD5 (not recommended for security), bcrypt.

Encryption Applications

  • HTTPS: Uses SSL/TLS to secure web traffic.
  • VPNs: Encrypt all internet traffic.
  • Email Encryption: PGP, S/MIME.
  • File Encryption: BitLocker (Windows), FileVault (macOS), VeraCrypt.
  • Messaging: End-to-end encryption in Signal, WhatsApp, Telegram.

# Example: AES-256 symmetric encryption (Python)
from cryptography.fernet import Fernet

# Generate a key
key = Fernet.generate_key()
cipher = Fernet(key)

# Encrypt
plaintext = b"Hello, World!"
ciphertext = cipher.encrypt(plaintext)

# Decrypt
decrypted = cipher.decrypt(ciphertext)
print(decrypted) # b'Hello, World!'
🔐 Key insight: Encryption is the foundation of modern digital security. It protects data from unauthorized access during storage and transmission, making it essential for privacy and compliance.
