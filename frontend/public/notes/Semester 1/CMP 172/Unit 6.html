6.1 Introduction to Array

An array is a collection of elements of the same data type stored in contiguous memory locations, accessed using a common name and index. Arrays provide an efficient way to manage multiple related data items.

📊 Purpose
Simplify handling of multiple values of the same type. Avoid declaring many separate variables.
🧩 Characteristics
Fixed size, indexed from 0, contiguous memory, homogeneous data type.

Why Use Arrays?

  • Efficient Storage: Store multiple values in a single structured variable.
  • Easy Access: Access elements using index (0 to size-1).
  • Loop-Friendly: Iterate through elements using loops.
  • Memory Efficiency: Contiguous allocation means faster access.
// Without array
int marks1 = 85, marks2 = 90, marks3 = 78, marks4 = 92, marks5 = 88;

// With array
int marks[5] = {85, 90, 78, 92, 88}; // Much cleaner!

// Accessing array elements
printf("First mark: %d\n", marks[0]); // 85
printf("Third mark: %d\n", marks[2]); // 78
💡 Key insight: Arrays are fundamental data structures in C. They form the basis for strings and more complex data structures.

6.2 Declaration

Array declaration specifies the data type, array name, and size. The compiler allocates memory based on this declaration.

Syntax and Examples

  • Syntax: data_type array_name[size];
  • Examples:
    int numbers[5]; // Array of 5 integers
    float scores[10]; // Array of 10 floats
    char letters[26]; // Array of 26 characters
    double values[20]; // Array of 20 doubles
  • Rules:
    • Size must be a positive integer constant.
    • Size can be a constant expression (e.g., #define SIZE 5).
    • Variable-length arrays (VLA) are allowed in C99 (size can be a runtime value).

Array Declaration Examples

// Using const
const int SIZE = 5;
int arr[SIZE];

// Using #define
#define MAX 10
float data[MAX];

// Variable-Length Array (C99)
int n;
printf("Enter size: ");
scanf("%d", &n);
int dynamicArr[n]; // Size determined at runtime

6.3 Memory Representation of Array

Arrays are stored in contiguous memory locations. Each element occupies a fixed size based on its data type. The address of each element can be calculated using the base address and index.

Memory Layout

  • Formula: Address of element i = Base Address + (i × Size of data type)
  • Example: For int arr[5] starting at address 1000 (int size = 4 bytes):
    • arr[0] → 1000
    • arr[1] → 1004
    • arr[2] → 1008
    • arr[3] → 1012
    • arr[4] → 1016
Memory Layout for int arr[5]:
Address:  1000  1004  1008  1012  1016
         ┌─────┬─────┬─────┬─────┬─────┐
         │     │     │     │     │     │
         └─────┴─────┴─────┴─────┴─────┘
Element:   0     1     2     3     4
// Program to display array memory addresses
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %d, address = %p\n", i, arr[i], &arr[i]);
    }
    return 0;
}

// Output shows addresses increasing by 4 bytes (int size)
📌 Key insight: The contiguous memory layout of arrays enables fast access using pointer arithmetic and efficient cache utilization.

6.4 Initialization of Array

Array initialization assigns values to array elements at the time of declaration. C provides several ways to initialize arrays.

Methods of Initialization

  • Complete Initialization: Assign values to all elements.
    int arr[5] = {1, 2, 3, 4, 5};
  • Partial Initialization: Uninitialized elements are set to 0.
    int arr[5] = {1, 2}; // arr[0]=1, arr[1]=2, arr[2..4]=0
  • Size Omitted: Compiler infers the size from the initializer list.
    int arr[] = {1, 2, 3, 4, 5}; // Size = 5
  • Designated Initialization (C99): Initialize specific elements.
    int arr[5] = {[2] = 10, [4] = 20}; // arr[0]=0, arr[1]=0, arr[2]=10, arr[3]=0, arr[4]=20

Runtime Initialization

  • Using Loops: Initialize array elements at runtime.
    int arr[5];
    for (int i = 0; i < 5; i++) {
        arr[i] = i * 2;
    }
  • User Input: Read values from the user.
    int arr[5];
    for (int i = 0; i < 5; i++) {
        scanf("%d", &arr[i]);
    }
// Various initialization examples
int a[5] = {0}; // All elements zero
int b[3] = {10}; // b[0]=10, b[1]=0, b[2]=0
int c[] = {1, 2, 3}; // Size = 3
int d[3][3] = {0}; // 2D array all zeros

6.5 Types of Arrays

6.5.1 Single Dimensional and Multidimensional

Single Dimensional Array (1D Array)

  • Definition: A linear array with a single index.
  • Representation: data_type arr[size];
  • Access: arr[index] where index ranges from 0 to size-1.
// 1D Array example
int numbers[5] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++) {
    printf("%d ", numbers[i]);
}
// Output: 10 20 30 40 50

Multidimensional Array

  • Definition: Arrays with multiple indices (2D, 3D, etc.).
  • 2D Array Syntax: data_type array_name[rows][columns];
  • Memory Layout: Stored in row-major order (row by row).
// 2D Array example - Matrix
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// Accessing elements
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
// Output:
// 1 2 3
// 4 5 6

// 3D Array
int cube[2][2][2] = {
    {{1, 2}, {3, 4}},
    {{5, 6}, {7, 8}}
};
printf("cube[1][0][1] = %d\n", cube[1][0][1]); // 6

2D Array Initialization

  • Full Initialization: int arr[2][3] = {{1,2,3},{4,5,6}};
  • Partial Initialization: int arr[2][3] = {{1,2},{4}}; (remaining elements = 0)
  • Size Omitted: int arr[][3] = {{1,2,3},{4,5,6}}; (rows inferred)

6.6 Character Array and Strings

A character array is an array of characters. A string is a character array terminated by a null character (\0). Strings are a fundamental concept in C for text handling.

Character Array vs String

  • Character Array: Just an array of characters without a null terminator.
    char arr[5] = {'H', 'e', 'l', 'l', 'o'}; // Not a string
  • String: Character array with a null terminator.
    char str[6] = "Hello"; // Automatically adds \0
    char str2[] = "World"; // Size = 6 (5 chars + \0)

String Declaration Methods

  • Using Array:
    char str[20] = "Hello";
    char str2[] = "Hello"; // Size automatically 6
  • Using Pointer:
    char *str = "Hello"; // String literal (read-only)

Difference Between Methods

MethodMemory LocationModifiable
char str[20] = "Hello"StackYes
char *str = "Hello"Read-only segmentNo (modification causes undefined behavior)
// String examples
char str1[20] = "Hello";
str1[0] = 'h'; // Valid: modifies first character
printf("%s\n", str1); // hello

char *str2 = "Hello";
// str2[0] = 'h'; // NOT allowed - undefined behavior

6.7 Reading and Writing Strings

C provides several functions for reading and writing strings. Choosing the right function is important for security and functionality.

Reading Strings

  • scanf("%s", str): Reads until whitespace. Does NOT read spaces. No & needed for array name.
    char str[50];
    scanf("%s", str); // Reads "Hello" from "Hello World"
  • gets(str): Reads entire line including spaces. Deprecated and unsafe (buffer overflow risk).
  • fgets(str, size, stdin): Safe alternative. Reads up to size-1 characters or newline.
    char str[50];
    fgets(str, sizeof(str), stdin); // Safe reading with buffer limit
  • scanf("%[^\n]", str): Reads until newline (reads spaces).
    char str[50];
    scanf(" %[^\n]", str); // Reads entire line

Writing Strings

  • printf("%s", str): Prints string without newline.
  • puts(str): Prints string and adds newline automatically.
    char str[] = "Hello";
    printf("%s", str); // Hello
    puts(str); // Hello (with newline)
  • fputs(str, stdout): Prints string without newline (safer version of puts).
// Complete string I/O example
#include <stdio.h>

int main() {
    char name[100];
    char city[100];

    printf("Enter your name: ");
    fgets(name, sizeof(name), stdin); // Safe: reads full line

    printf("Enter your city: ");
    scanf(" %[^\n]", city); // Reads full line including spaces

    printf("Name: %s", name);
    printf("City: %s\n", city);
    return 0;
}
📝 Key insight: Always use fgets() for reading strings to prevent buffer overflow. Avoid gets() as it is deprecated and unsafe.

6.8 Null Character

The null character (\0) is a character with ASCII value 0 that marks the end of a string in C. It is essential for string handling functions like printf(), strlen(), and strcpy().

Characteristics

  • Representation: Written as \0 in source code.
  • ASCII Value: 0 (decimal), 0x00 (hex).
  • Purpose: Indicates string termination.
  • Size: Takes 1 byte of memory.
// Null character examples
char str1[6] = {'H', 'e', 'l', 'l', 'o', '\0'}; // Explicit null
char str2[] = "Hello"; // Implicit null (size = 6)

printf("Length of str1: %zu\n", strlen(str1)); // 5
printf("Size of str2: %zu\n", sizeof(str2)); // 6 (includes \0)

// Without null terminator
char str3[5] = {'H', 'e', 'l', 'l', 'o'}; // NOT a string
printf("%s\n", str3); // Undefined behavior - may print extra characters 
String "Hello" in memory:
Address:  1000  1001  1002  1003  1004  1005
         ┌─────┬─────┬─────┬─────┬─────┬─────┐
         │  H  │  e  │  l  │  l  │  o  │ \0  │
         └─────┴─────┴─────┴─────┴─────┴─────┘
🔑 Key insight: The null terminator is what distinguishes strings from character arrays in C. Always ensure strings are properly null-terminated.

6.9 Library Functions for String Handling

The C standard library provides <string.h> with functions for string manipulation. These functions are essential for working with strings efficiently.

Common String Functions

FunctionDescriptionExample
strlen(str)Returns length (without \0)strlen("Hello") → 5
strcpy(dest, src)Copies src to dest (including \0)strcpy(dest, "Hello")
strncpy(dest, src, n)Copies n charactersstrncpy(dest, "Hello", 3)
strcat(dest, src)Appends src to deststrcat(dest, " World")
strncat(dest, src, n)Appends n charactersstrncat(dest, " World", 3)

// String functions example
#include <stdio.h>
#include <string.h>

int main() {
    char str1[50] = "Hello";
    char str2[50] = "World";
    char buffer[100];

    printf("Length of str1: %zu\n", strlen(str1)); // 5

    strcpy(buffer, str1); // Copy str1 to buffer
    strcat(buffer, " "); // Add space
    strcat(buffer, str2); // Append str2
    printf("Concatenated: %s\n", buffer); // Hello World

    // String comparison
if (strcmp(str1, "Hello") == 0) {
        printf("Strings are equal\n");
    }

    // Searching
char *pos = strchr(buffer, 'W');
if (pos) {
        printf("Found 'W' at position: %ld\n", pos - buffer);
    }

    return 0;
}

strtok() Example - Tokenization

// strtok example
char str[] = "apple,banana,orange,grape";
char *token = strtok(str, ",");
while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, ",");
}
// Output:
// apple
// banana
// orange
// grape
