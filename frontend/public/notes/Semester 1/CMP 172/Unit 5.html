Unit 5: Control Statement

Control structures · decision making · loops · break · continue · switch

5.1 Introduction to Control Structure

Control structures in C determine the flow of program execution. They allow a program to make decisions, repeat actions, or execute statements in a specific order. Without control structures, programs would be limited to simple linear execution.

🎯 Purpose
Enable dynamic program behavior by controlling the flow of execution based on conditions or repetitions.
📋 Types
Sequential, Decision-Making (if, switch), Iteration (for, while, do-while).

Types of Control Structures

  • Sequential: Statements execute in order, one after another.
  • Selection (Decision-Making): Choose between different paths based on conditions (if, if-else, switch).
  • Iteration (Looping): Repeat a block of code multiple times (for, while, do-while).
  • Jump: Transfer control unconditionally (break, continue, goto, return).
Program Flow:
┌─────────────────────────────────────────┐
│           Sequential Flow               │
│   Statement 1 → Statement 2 → Statement 3 │
├─────────────────────────────────────────┤
│         Decision-Making Flow             │
│   Condition? → Yes → Block A            │
│             → No  → Block B            │
├─────────────────────────────────────────┤
│          Iteration Flow                  │
│   While Condition? → Execute Block → Repeat │
└─────────────────────────────────────────┘
💡 Key insight: Control structures are the building blocks of algorithmic logic. Mastering them is essential for writing complex and useful programs.

5.2 Sequential Control Statement

Sequential control is the default flow in C programs. Statements are executed in the order they appear, from top to bottom, without any branching or repetition.

Characteristics

  • No conditions or loops.
  • Each statement runs exactly once.
  • Execution order is the same as the written order.
  • Most straightforward and common flow.
// Sequential control example
#include <stdio.h>

int main() {
    int a = 5;
    int b = 10;
    int sum = a + b;
    printf("Sum: %d\n", sum);
    int product = a * b;
    printf("Product: %d\n", product);
    return 0;
}

// Output:
// Sum: 15
// Product: 50
📝 Key insight: All programs start with sequential flow. Control structures like if and loops modify this default behavior.

5.3 Decision Making Statement

Decision-making statements allow a program to execute different code blocks based on conditions. They enable the program to make choices and respond to different situations.

5.3.1 if, if-else, if-else if, nested if, and switch case

if Statement

  • Syntax: if (condition) { // code }
  • Behavior: Executes the block only if the condition is true (non-zero).
// if statement example
int x = 10;
if (x > 5) {
    printf("x is greater than 5\n");
}
// Output: x is greater than 5

if-else Statement

  • Syntax: if (condition) { // block1 } else { // block2 }
  • Behavior: Executes block1 if condition is true, otherwise executes block2.
// if-else statement example
int x = 3;
if (x > 5) {
    printf("x is greater than 5\n");
} else {
    printf("x is not greater than 5\n");
}
// Output: x is not greater than 5

if-else if Ladder

  • Syntax: if (cond1) { } else if (cond2) { } else if (cond3) { } else { }
  • Behavior: Checks multiple conditions sequentially; executes the block for the first true condition.
// if-else if example
int marks = 75;
if (marks >= 90) {
    printf("Grade A\n");
} else if (marks >= 75) {
    printf("Grade B\n");
} else if (marks >= 50) {
    printf("Grade C\n");
} else {
    printf("Grade F\n");
}
// Output: Grade B

Nested if Statement

  • Definition: An if statement inside another if statement.
  • Usage: For checking multiple conditions with hierarchical logic.
// Nested if example
int x = 10, y = 5;
if (x > 0) {
    if (y > 0) {
        printf("Both are positive\n");
    } else {
        printf("x is positive, y is not\n");
    }
}
// Output: Both are positive

switch case Statement

  • Syntax:
    switch (expression) {
        case value1: statement; break;
        case value2: statement; break;
        default: statement;
    }
  • Behavior: Selects one of many blocks based on the value of the expression.
  • Important: Use break to prevent fall-through. Use default for unmatched values.
// switch case example
int day = 3;
switch (day) {
    case 1: printf("Monday\n"); break;
    case 2: printf("Tuesday\n"); break;
    case 3: printf("Wednesday\n"); break;
    case 4: printf("Thursday\n"); break;
    case 5: printf("Friday\n"); break;
    case 6: printf("Saturday\n"); break;
    case 7: printf("Sunday\n"); break;
    default: printf("Invalid day\n");
}
// Output: Wednesday

switch vs if-else

Featureswitchif-else
ConditionSingle expression with multiple valuesAny boolean expression
ReadabilityGood for many discrete valuesBetter for complex conditions
PerformanceFaster (jump table)Slower (sequential checks)
Range CheckingNo (only discrete values)Yes (e.g., x > 5 && x < 10)
⚡ Key insight: Use if-else for complex conditions and ranges. Use switch for discrete value matching. switch can be more readable and efficient for many cases.

5.4 Iteration (Loop) Statement

Iteration statements (loops) repeat a block of code multiple times until a condition is met. They are essential for tasks that require repetition, such as processing arrays or implementing algorithms.

5.4.1 for, while, do-while, nested loops

for Loop

  • Syntax: for (initialization; condition; increment) { // body }
  • Behavior: Initializes once, checks condition before each iteration, and executes increment after each iteration.
  • Best for: Known number of iterations.
// for loop example
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// Output: 1 2 3 4 5

// Infinite for loop
for (;;) {
    printf("Infinite\n");
}

while Loop

  • Syntax: while (condition) { // body }
  • Behavior: Checks condition before each iteration. If true, executes the body; otherwise, exits.
  • Best for: Unknown number of iterations.
// while loop example
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}
// Output: 1 2 3 4 5

do-while Loop

  • Syntax: do { // body } while (condition);
  • Behavior: Executes the body first, then checks the condition. Guarantees at least one execution.
  • Best for: Menu-driven programs where the menu should display at least once.
// do-while loop example
int i = 1;
do {
    printf("%d ", i);
    i++;
} while (i <= 5);
// Output: 1 2 3 4 5

// Guaranteed execution even if condition is false
int j = 10;
do {
    printf("Executed once\n");
} while (j < 5);
// Output: Executed once

Nested Loops

  • Definition: A loop inside another loop.
  • Usage: For multi-dimensional iterations (matrices, patterns).
// Nested loops example - multiplication table
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        printf("%3d ", i * j);
    }
    printf("\n");
}
// Output:
// 1 2 3
// 2 4 6
// 3 6 9

// Nested loops - star pattern
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        printf("* ");
    }
    printf("\n");
}
// Output:
// *
// * *
// * * *
// * * * *
// * * * * *
🔄 Key insight: Choose the right loop type based on your requirements. for loops are best when you know the number of iterations. while loops work well when the condition depends on runtime values. do-while ensures at least one execution.

5.5 Break and Continue

Break and continue are jump statements that alter the normal flow of loops or switch cases. They provide additional control over loop execution.

break Statement

  • Purpose: Terminates the innermost loop or switch case immediately.
  • Usage: Exiting loops early when a condition is met.
// break statement example
for (int i = 1; i <= 10; i++) {
    if (i == 6) {
        break; // Exit loop when i reaches 6
    }
    printf("%d ", i);
}
// Output: 1 2 3 4 5

// break in switch
int day = 3;
switch (day) {
    case 1: printf("Monday"); break;
    case 2: printf("Tuesday"); break;
    case 3: printf("Wednesday"); break; // Stops execution
    default: printf("Invalid");
}

continue Statement

  • Purpose: Skips the rest of the current iteration and jumps to the next iteration.
  • Usage: Skipping specific iterations based on a condition.
// continue statement example
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue; // Skip when i equals 3
    }
    printf("%d ", i);
}
// Output: 1 2 4 5

// continue in while loop
int j = 0;
while (j < 5) {
    j++;
    if (j == 3) {
        continue; // Skip the rest when j=3
    }
    printf("%d ", j);
}
// Output: 1 2 4 5

goto Statement (Note)

  • Purpose: Transfers control to a labeled statement.
  • Warning: Using goto is generally discouraged as it makes code hard to read and maintain.
// goto example (generally avoid)
#include <stdio.h>

int main() {
    int i = 0;
    start:
    i++;
    printf("%d ", i);
    if (i < 5) {
        goto start;
    }
    return 0;
}
// Output: 1 2 3 4 5
📌 Key insight: break and continue are useful for controlling loop flow, but use them judiciously. Overuse can make code harder to understand. In most cases, structured loop conditions are preferable.
📘 Unit 5 summary
Control statements determine program flow. C provides sequential, decision-making (if, switch), and iteration (for, while, do-while) structures.
🔑 Key takeaways
• Sequential: default top-to-bottom execution.
• Decision making: if, if-else, switch for branching.
• Loops: for (fixed), while (condition-based), do-while (at least once).
• break exits, continue skips iteration.
• Choose the right control structure for the task.
