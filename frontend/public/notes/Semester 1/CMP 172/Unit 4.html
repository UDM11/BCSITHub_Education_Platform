4.1 Operator, Operand, and Expression

Operators are symbols that perform operations on data. Operands are the variables or values on which operations are performed. An expression is a combination of operators and operands that evaluates to a single value.

➕ Operator
Symbols that perform operations (e.g., +, -, *, /, %, ==, &&).
📊 Operand
Values or variables operated on (e.g., x, 5, y, 3.14).

Basic Terminology

  • Unary Operator: Operates on a single operand (e.g., -x, ++x, !y).
  • Binary Operator: Operates on two operands (e.g., a + b, x * y).
  • Ternary Operator: Operates on three operands (e.g., condition ? value1 : value2).
  • Expression: A combination of operators and operands that yields a value.
// Examples of operators, operands, and expressions
int x = 10, y = 5;

// Operator: +, Operands: x, y → Expression: x + y
int sum = x + y;

// Operator: *, Operands: x, 2 → Expression: x * 2
int product = x * 2;

// Operator: >, Operands: x, y → Expression: x > y
int isGreater = x > y;

// Ternary operator: condition ? expr1 : expr2
int max = (x > y) ? x : y;
💡 Key insight: Every C statement is built from expressions. Understanding operators and operands is fundamental to writing effective C programs.

4.2 Types of Operators

C provides a rich set of operators categorized by their functionality. Understanding each category is essential for writing efficient and readable code.

4.2.1 Arithmetic Operator

Arithmetic operators perform mathematical calculations on numeric operands (int, float, double, etc.).

  • + (Addition): Adds two operands. a + b
  • - (Subtraction): Subtracts second from first. a - b
  • * (Multiplication): Multiplies two operands. a * b
  • / (Division): Divides first by second. a / b
    • Integer division: 5 / 2 = 2 (truncates decimal)
    • Floating division: 5.0 / 2.0 = 2.5
  • % (Modulus): Returns the remainder of integer division. a % b (works only with integers)
// Arithmetic operators example
#include <stdio.h>

int main() {
    int a = 10, b = 3;
    float c = 10.0, d = 3.0;

    printf("Addition: %d\n", a + b); // 13
    printf("Subtraction: %d\n", a - b); // 7
    printf("Multiplication: %d\n", a * b); // 30
    printf("Division (int): %d\n", a / b); // 3 (truncated)
    printf("Division (float): %.1f\n", c / d); // 3.3
    printf("Modulus: %d\n", a % b); // 1
    return 0;
}

Relational operators compare two values and return 1 (true) or 0 (false). They are used in decision-making and loop conditions.

int a = 5, b = 3;

4.2.3 Logical or Boolean Operator

Logical operators combine boolean expressions to produce a single boolean result. They are used in complex conditions.

OperatorMeaningTruth Table
&&Logical ANDtrue && true = true; true && false = false
||Logical ORtrue || false = true; false || false = false
!Logical NOT!true = false; !false = true
// Logical operators example
int x = 5, y = 3, z = 7;
int result = (x > y) && (y < z); // true && true = 1
printf("Result: %d\n", result); // 1

int result2 = (x > y) || (x > z); // true || false = 1
printf("Result2: %d\n", result2); // 1

int result3 = !(x > y); // !true = 0
printf("Result3: %d\n", result3); // 0

4.2.5 Bitwise Operator

Bitwise operators perform operations on individual bits of integer operands. They are used in low-level programming, cryptography, and optimization.

// Bitwise operators example
int a = 5, b = 3; // a = 0101, b = 0011
printf("a & b: %d\n", a & b); // 1 (0001)
printf("a | b: %d\n", a | b); // 7 (0111)
printf("a ^ b: %d\n", a ^ b); // 6 (0110)
printf("~a: %d\n", ~a); // -6
printf("a << 1: %d\n", a << 1); // 10 (1010)
printf("a >> 1: %d\n", a >> 1); // 2 (0010)

4.2.6 Prefix and Postfix Increment and Decrement Operator

Increment (++) and decrement (--) operators add or subtract 1 from a variable. Their behavior differs based on whether they are used as prefix or postfix.

  • Prefix (++x, --x): Increment/decrement first, then use the value.
  • Postfix (x++, x--): Use the current value first, then increment/decrement.
// Prefix vs Postfix example
int x = 5, y;
y = ++x; // x = 6, y = 6 (prefix: increment then assign)
printf("x: %d, y: %d\n", x, y); // x: 6, y: 6

x = 5;
y = x++; // y = 5, x = 6 (postfix: assign then increment)
printf("x: %d, y: %d\n", x, y); // x: 6, y: 5

4.2.7 Ternary Operator (Conditional Operator)

The ternary operator (?:) is a concise conditional operator that evaluates an expression based on a condition. It is the only ternary operator in C.

  • Syntax: condition ? expression1 : expression2
  • Behavior: If condition is true, expression1 is evaluated; otherwise, expression2 is evaluated.
// Ternary operator example
int a = 10, b = 5;
int max = (a > b) ? a : b; // max = 10
printf("Max: %d\n", max);

// Nested ternary
int x = 5, y = 10, z = 7;
int largest = (x > y) ? ((x > z) ? x : z) : ((y > z) ? y : z);
printf("Largest: %d\n", largest); // 10

4.2.8 Special Operators (sizeof and comma)

Special operators perform unique tasks that don't fit into other categories.

sizeof Operator

  • Purpose: Returns the size (in bytes) of a variable or data type.
  • Return type: size_t (unsigned integer).
  • Usage: sizeof(type) or sizeof(variable)
// sizeof operator example
#include <stdio.h>

int main() {
    int x = 10;
    float y = 3.14;
    char z = 'A';

    printf("Size of int: %zu bytes\n", sizeof(int));
    printf("Size of float: %zu bytes\n", sizeof(float));
    printf("Size of char: %zu bytes\n", sizeof(char));
    printf("Size of x: %zu bytes\n", sizeof(x));
    printf("Size of array: %zu bytes\n", sizeof(int[5]));
    return 0;
}

Comma Operator (,)

  • Purpose: Separates expressions, evaluated left to right.
  • Value: The value of the comma expression is the value of the rightmost expression.
// Comma operator example
int a, b;
a = (b = 5, b + 2); // b = 5, then a = 7
printf("a: %d, b: %d\n", a, b); // a: 7, b: 5

// Using comma in for loop
for (int i = 0, j = 10; i < 5; i++, j--) {
    printf("i: %d, j: %d\n", i, j);
}

4.3 Evaluation of Expression

Expression evaluation is the process of determining the value of an expression based on operator precedence, associativity, and data types. Understanding evaluation is crucial for writing correct and predictable code.

Steps in Expression Evaluation

  • 1. Identify Operators: Recognize all operators and their operands.
  • 2. Apply Precedence: Higher precedence operators are evaluated first.
  • 3. Apply Associativity: If operators have equal precedence, evaluate based on associativity (left-to-right or right-to-left).
  • 4. Type Conversion: Implicit or explicit type conversions may occur.
  • 5. Compute Result: The final value is computed.

Evaluation Examples

// Example 1: Basic precedence
int x = 5 + 3 * 2; // * has higher precedence than +
// 3 * 2 = 6, then 5 + 6 = 11
printf("x: %d\n", x); // 11

// Example 2: Using parentheses
int y = (5 + 3) * 2; // Parentheses override precedence
// 5 + 3 = 8, then 8 * 2 = 16
printf("y: %d\n", y); // 16

// Example 3: Mixed operators
int z = 10 + 5 * 2 - 8 / 4; // * and / first
// 5*2=10, 8/4=2, then 10+10-2=18
printf("z: %d\n", z); // 18

Type Conversion in Expressions

  • Implicit Conversion (Type Promotion):
    • char and short → int (integer promotion).
    • int → float → double (if mixed types).
    • Result type is the type with higher rank.
  • Explicit Conversion (Type Casting):
    float x = (float)5 / 2; // 5.0 / 2.0 = 2.5
    int y = (int)3.14; // 3 (truncated)

Common Pitfalls

  • Integer Division: 5/2 = 2 (not 2.5).
  • Operator Precedence Errors: Using & instead of &&, or = instead of ==.
  • Short-Circuit Evaluation: In && and ||, the right operand may not be evaluated.
    int x = 5, y = 0;
    if (y != 0 && x / y > 0) { // Safe: y != 0 is false, so x/y is never evaluated
        printf("OK");
    }

4.4 Operator Precedence and Associativity

Operator precedence determines the order in which operators are evaluated in an expression. Associativity determines the order when operators of equal precedence appear together.

Associativity Examples

// Left-to-right associativity (most operators)
int x = 10 - 5 - 2; // (10 - 5) - 2 = 3

// Right-to-left associativity (assignment)
int a, b, c;
a = b = c = 5; // (a = (b = (c = 5)))
// All variables get value 5

Practical Tips

  • Use Parentheses: When in doubt, use parentheses to make the order of evaluation explicit.
  • Readability: Complex expressions with many operators are hard to read and maintain.
  • Break Complex Expressions: Split complex expressions into multiple simpler statements.
// Without parentheses (ambiguous)
int x = a + b * c - d / e; // Hard to read

// With parentheses (clear)
int x = (a + (b * c)) - (d / e); // Explicit order

// Better: break into multiple statements
int product = b * c;
int quotient = d / e;
int x = a + product - quotient;
📐 Key insight: Operator precedence and associativity are fundamental to understanding expression evaluation. Always use parentheses for clarity, especially in complex expressions.
