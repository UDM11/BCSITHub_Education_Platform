2.1 C Character Set

The C character set consists of all the characters that can be used to write valid C programs. These characters form the building blocks for tokens, strings, and other program elements. The compiler recognizes and processes these characters according to C language rules.

Character Categories

  • Alphabetic Characters (Letters): Both uppercase (A-Z) and lowercase (a-z) English letters. C is case-sensitive, so 'A' and 'a' are different.
  • Numeric Characters (Digits): 0 through 9. Used in numbers and identifiers.
  • Special Characters: Symbols with specific meanings in C:
    • Arithmetic Operators: + - * / %
    • Relational Operators: < > <= >= == !=
    • Logical Operators: && || !
    • Bitwise Operators: & | ^ ~ << >>
    • Punctuators/Delimiters: ; , . : ? [ ] ( ) { } " ' \
    • Other Symbols: # $ @
  • White Spaces: Space, tab, newline, carriage return, form feed, and vertical tab. Used to separate tokens and improve code readability.

💡 Key insight: C's character set is based on the ASCII character encoding standard. Understanding the character set is essential for writing correct and efficient C programs.

2.2 Tokens

Tokens are the smallest individual units in a C program that the compiler recognizes. The compiler breaks down the source code into tokens during the lexical analysis phase. There are six types of tokens in C.

Types of Tokens

  • 1. Keywords: Reserved words with predefined meanings in C. Cannot be used as identifiers.
    auto, break, case, char, const, continue, default, do, double, else,
    enum, extern, float, for, goto, if, int, long, register, return,
    short, signed, sizeof, static, struct, switch, typedef, union,
    unsigned, void, volatile, while
  • 2. Identifiers: Names given to variables, functions, arrays, structures, etc. Created by the programmer.
    int sum;
    float salary;
    char grade;
  • 3. Constants: Fixed values that do not change during program execution.
    int x = 10;
    float pi = 3.14;
    char ch = 'A';
  • 4. Operators: Symbols that perform operations on data.
    + - * / % = == != < > && ||
  • 5. Strings: Sequence of characters enclosed in double quotes.
    printf("Hello, World!");
  • 6. Punctuators: Special symbols used for syntax structure.
    ; , . : { } [ ] ( ) #

Token Example

// Example program with labeled tokens
int main ( ) {
    int x = 5 ;
    return 0 ;
}

// Keywords: int, return
// Identifiers: main, x
// Constants: 5, 0
// Operators: =
// Punctuators: (, ), {, }, ;
🔑 Key insight: Understanding tokens is fundamental to understanding how the C compiler interprets your code. Every valid C program is composed of these token types.

2.3 Escape Sequences

Escape sequences are special character combinations that start with a backslash (\) followed by a character. They represent characters that are difficult or impossible to type directly in source code, such as newline, tab, or special formatting characters.

Escape Sequence Examples

#include <stdio.h>

int main() {
    // Newline and tab
    printf("Hello\nWorld\t!");
    // Output: Hello
    // World !

    // Quoting characters
    printf("He said, \"Hello!\"");
    // Output: He said, "Hello!"

    // Backslash
    printf("C:\\Program Files");
    // Output: C:\Program Files

    // Null terminator (used in strings)
    char str[] = "Hello\0World"; // Only "Hello" is printed
    printf("%s", str);
    // Output: Hello

    return 0;
}
📝 Key insight: Escape sequences are essential for formatting output and including special characters in strings and character constants. The null character (\0) is particularly important as it marks the end of strings in C.

2.4 Variables Declaration and Initialization

Variables are named memory locations that store data. They allow programs to manipulate and process data dynamically. Declaration specifies the variable's type and name, while initialization assigns an initial value.

Variable Declaration

  • Syntax: data_type variable_name;
  • Example:
    int age;
    float salary;
    char grade;
  • Multiple Variables: Can declare multiple variables of the same type in one line.
    int a, b, c;
    float x = 3.14, y = 2.71;

Variable Initialization

  • At Declaration: Assign a value when declaring the variable.
    int age = 25;
    float salary = 50000.50;
    char grade = 'A';
  • Separate Initialization: Assign value later in the program.
    int age;
    age = 25;
    age = 26; // Value can be changed
  • Default Values: Uninitialized variables contain garbage values (undefined behavior). Always initialize variables before use.

Naming Rules for Variables

  • Must start with a letter (A-Z or a-z) or underscore (_).
  • Can contain letters, digits, and underscores.
  • Cannot contain spaces or special characters (!, @, #, $, etc.).
  • Cannot be a reserved keyword (e.g., int, return, if).
  • Case-sensitive: age, Age, and AGE are different variables.
  • Should be meaningful and descriptive (e.g., studentName instead of sn).

Scope of Variables

  • Local Variables: Declared inside a function or block. Accessible only within that block.
  • Global Variables: Declared outside all functions. Accessible throughout the program.
  • Static Variables: Retain their value between function calls.
  • Register Variables: Stored in CPU registers for faster access.
// Example showing different variable types
#include <stdio.h>

int globalVar = 100; // Global variable

int main() {
    int localVar = 10; // Local variable
    static int staticVar = 5; // Static variable
    register int regVar = 0; // Register variable

    printf("Global: %d\n", globalVar);
    printf("Local: %d\n", localVar);
    return 0;
}

2.5 Data Types

Data types define the type of data that a variable can hold, the operations that can be performed on it, and the amount of memory it occupies. C provides several built-in data types and allows programmers to create custom types.

2.5.1 Basic, Derived, and User-Defined Data Types

Basic (Primitive) Data Types

  • int: Stores integers (whole numbers). Size: 2-4 bytes (typically 4 bytes on modern systems).
    int age = 25;
    int count = -10;
  • char: Stores single characters. Size: 1 byte.
    char grade = 'A';
    char newline = '\n';
  • float: Stores single-precision floating-point numbers. Size: 4 bytes.
    float pi = 3.14f;
    float temp = -5.5f;
  • double: Stores double-precision floating-point numbers. Size: 8 bytes.
    double scientific = 3.1415926535;
    double large = 1.7e308;
  • void: Represents no value. Used for functions that return nothing or generic pointers.

Derived Data Types

  • Array: Collection of elements of the same data type stored in contiguous memory.
    int numbers[5] = {1, 2, 3, 4, 5};
    char name[50] = "John Doe";
  • Pointer: Stores the memory address of another variable.
    int *ptr;
    int x = 10;
    ptr = &x;
    printf("%d", *ptr); // Dereferencing: prints 10
  • Function: A block of code with a return type.
    int add(int a, int b) {
        return a + b;
    }

User-Defined Data Types

  • Structure (struct): Groups different data types into a single unit.
    struct Student {
        int id;
        char name[50];
        float gpa;
    };

    struct Student s1 = {101, "Alice", 3.8};
  • Union: Similar to structure but shares memory among members. Only one member can hold a value at a time.
    union Data {
        int i;
        float f;
        char str[20];
    };

    union Data data;
    data.i = 10; // f and str become invalid
  • Enumeration (enum): Defines a set of named integer constants.
    enum Color { RED, GREEN, BLUE };
    enum Color c = RED; // c = 0

    enum Status { FAIL = 0, PASS = 1, WAITING = 2 };
  • Typedef: Creates an alias for an existing data type.
    typedef int Integer;
    Integer x = 10; // Same as int x = 10;

    typedef struct Student Student;
    Student s1;

2.6 Constants/Literals

Constants (also called literals) are fixed values that cannot be changed during program execution. They represent data directly in the source code.

Types of Constants

  • Integer Literals: Whole numbers.
    int decimal = 10; // Decimal (base 10)
    int octal = 012; // Octal (base 8) - starts with 0
    int hex = 0xA; // Hexadecimal (base 16) - starts with 0x
    long big = 100L; // Long integer
    unsigned u = 100U; // Unsigned integer
  • Floating-Point Literals: Numbers with decimal points or exponent notation.
    float pi = 3.14f; // Float literal
    double e = 2.71828; // Double literal
    double scientific = 1.5e-3; // Scientific notation (0.0015)
  • Character Literals: Single characters enclosed in single quotes.
    char ch1 = 'A';
    char ch2 = '\n'; // Escape sequence
    char ch3 = 65; // ASCII value of 'A'
  • String Literals: Sequence of characters enclosed in double quotes.
    char str1[] = "Hello, World!";
    char *str2 = "Good Morning";
  • Enumeration Constants: Named integer constants defined with enum.
    enum Week { MON, TUE, WED, THU, FRI, SAT, SUN };
    enum Week today = MON;

Defining Constants

  • Using #define Preprocessor:
    #define MAX 100
    #define PI 3.14159
    #define HELLO "Hello"
  • Using const Keyword:
    const int MAX = 100;
    const float PI = 3.14159;
    const char HELLO[] = "Hello";
  • Difference: #define is handled by the preprocessor (text replacement), while const is handled by the compiler (type checking).
📌 Key insight: Use const instead of #define for type safety and better debugging. However, #define is still useful for conditional compilation.

2.7 Expressions

An expression is a combination of variables, constants, operators, and function calls that evaluates to a single value. Expressions are the building blocks of C statements.

Types of Expressions

  • Arithmetic Expressions: Perform mathematical calculations.
    int sum = a + b;
    float avg = (x + y) / 2.0;
    int product = a * b * c;
  • Relational Expressions: Compare two values and return 1 (true) or 0 (false).
    int isGreater = (a > b);
    int isEqual = (x == y);
    int notEqual = (a != b);
  • Logical Expressions: Combine relational expressions using logical operators.
    int result = (a > b) && (c < d);
    int valid = (age >= 18) || (hasPermission);
    int invalid = !(isValid);
  • Assignment Expressions: Assign values to variables.
    int x = 5;
    x += 3; // Equivalent to x = x + 3
    x *= 2; // Equivalent to x = x * 2
  • Conditional (Ternary) Expression: Shorthand for if-else.
    int max = (a > b) ? a : b;
    printf("%s", (age >= 18) ? "Adult" : "Minor");
  • Comma Expression: Evaluates multiple expressions, returning the last value.
    int x = (a = 5, b = 10, a + b); // x = 15

2.8 Statements

Statements are complete instructions in a C program that perform actions. They are the building blocks of C programs and are executed sequentially by default.

Types of Statements

  • Expression Statements: An expression followed by a semicolon.
    x = 5;
    y = a + b;
    printf("Hello");
    x++; // Increment
  • Compound Statements (Blocks): A group of statements enclosed in curly braces.
    {
        int x = 5;
        printf("%d", x);
    }
  • Control Statements: Alter the flow of execution.
    • Selection: if, if-else, switch
    • Iteration: for, while, do-while
    • Jump: break, continue, goto, return
    // Selection
    if (x > 0) {
        printf("Positive");
    }

    // Iteration
    for (int i = 0; i < 5; i++) {
        printf("%d ", i);
    }

    // Jump
    if (error) {
        return -1;
    }
  • Labeled Statements: Used with goto.
    start:
    printf("Hello");
    goto start; // Infinite loop
  • Null Statement: A single semicolon, does nothing.
    ; // Null statement
    for (i = 0; i < 10; i++); // Loop with empty body
📋 Key insight: Statements are the executable units of a C program. Understanding statement types is essential for writing structured and logical programs.

2.9 Comments

Comments are non-executable text that explain code. They are ignored by the compiler and are used to improve code readability, document functionality, and assist in debugging.

Types of Comments

  • Single-Line Comments: Start with // and continue to the end of the line.
    // This is a single-line comment
    int x = 5; // This comment is on the same line
  • Multi-Line Comments: Enclosed between /* and */.
    /* This is a multi-line comment
    that spans multiple lines
    and can contain any text */
    int y = 10;
  • Nested Comments: Not allowed in C (/* /* */ */ causes an error).

Comment Usage Examples

// File: calculator.c
// Author: John Doe
// Date: 2024-01-15
// Description: Simple calculator program

#include <stdio.h>

/* Function: add
Parameters: a, b - integers to add
Returns: sum of a and b */
int add(int a, int b) {
    return a + b; // Return the sum
}

int main() {
    int result = add(5, 3); // Call the add function
    printf("Result: %d\n", result);
    return 0; // Successful termination
}

Best Practices for Comments

  • Explain Why, Not What: Comments should explain the reasoning behind the code, not just restate what the code does.
  • Keep Comments Updated: Outdated comments are worse than no comments.
  • Use Meaningful Names: Good variable/function names reduce the need for comments.
  • Document Functions: Describe parameters, return values, and purpose.
  • Use TODOs: Mark incomplete or future work with // TODO:.
💡 Key insight: Good comments make code more maintainable and easier to understand. However, the code should be self-documenting whenever possible through clear naming and structure.
