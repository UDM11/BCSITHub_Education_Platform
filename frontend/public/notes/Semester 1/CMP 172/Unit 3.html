3.1 Unformatted and Formatted I/O

Input and Output (I/O) operations in C allow programs to interact with users and external systems by reading input and displaying output. I/O functions are categorized into unformatted and formatted types based on the level of control they provide over data representation.

📝 Unformatted I/O
Handles simple input/output without specific formatting. Works with characters and strings. Includes functions like getchar(), putchar(), gets(), puts().
🎯 Formatted I/O
Provides precise control over data format using format specifiers. Includes functions like scanf() and printf() for reading/writing various data types.

Unformatted I/O Functions

  • getchar(): Reads a single character from standard input (stdin). Returns the character read or EOF on error.
    char ch = getchar(); // Read a character from keyboard
  • putchar(): Writes a single character to standard output (stdout).
    putchar('A'); // Output: A
  • gets(): Reads a string from stdin (deprecated due to security issues). Use fgets() instead.
    char str[100];
    gets(str); // Unsafe - avoid using
  • puts(): Writes a string to stdout and appends a newline.
    puts("Hello, World!"); // Output: Hello, World! (with newline)

Formatted I/O Functions

  • printf(): Writes formatted output to stdout. Uses format specifiers.
    printf("Value: %d, PI: %.2f\n", 10, 3.14159);
  • scanf(): Reads formatted input from stdin. Uses format specifiers and addresses of variables.
    int x;
    scanf("%d", &x); // Read an integer from keyboard
  • sprintf(): Writes formatted output to a string buffer.
    char buffer[100];
    sprintf(buffer, "Value: %d", 10);
  • sscanf(): Reads formatted input from a string.
    int x;
    sscanf("10", "%d", &x);

💡 Key insight: Formatted I/O provides flexibility and control at the cost of performance. Unformatted I/O is simpler and faster but limited in functionality.

3.2 Conversion Specifiers

Conversion specifiers (also called format specifiers) are used in formatted I/O functions like printf() and scanf() to define the type and format of data being read or written. They tell the compiler how to interpret the data and how to display it.

Common Conversion Specifiers

SpecifierData TypeDescriptionExample
%dintDecimal integerprintf("%d", 10);
%iintInteger (auto-detect base)scanf("%i", &x);
%uunsigned intUnsigned decimal integerprintf("%u", 100);
%ffloatFloating-point numberprintf("%f", 3.14);
%lfdoubleDouble-precision floatprintf("%lf", 3.14159);
%ccharSingle characterprintf("%c", 'A');
%schar*Stringprintf("%s", "Hello");
%xintHexadecimal (lowercase)printf("%x", 255);
%XintHexadecimal (uppercase)printf("%X", 255);
%ointOctalprintf("%o", 8);
%pvoid*Pointer addressprintf("%p", &x);
%%-Percent signprintf("%%");

Format Modifiers

  • Width Modifier: Specifies the minimum field width.
    printf("%5d", 10); // Output: " 10" (right-aligned)
    printf("%-5d", 10); // Output: "10 " (left-aligned)
  • Precision Modifier: Specifies number of decimal places (for floats) or maximum width (for strings).
    printf("%.2f", 3.14159); // Output: 3.14
    printf("%.3s", "Hello"); // Output: Hel
  • Length Modifier: Specifies the size of the data type.
    printf("%ld", 100L); // long int
    printf("%lld", 100LL); // long long int
    printf("%hu", 100U); // unsigned short

Scanf() Specific Specifiers

  • %*: Suppresses assignment (skip input).
  • %[ ]: Scanset — matches a set of characters.
    char str[100];
    scanf("%[A-Z]", str); // Read only uppercase letters
  • %[^ ]: Matches any character except the specified ones.
    scanf("%[^\n]", str); // Read until newline
// Comprehensive printf example
#include <stdio.h>

int main() {
    int num = 42;
    float pi = 3.14159;
    char ch = 'A';
    char str[] = "Hello";

    printf("Integer: %d\n", num);
    printf("Hex: %x, Octal: %o\n", num, num);
    printf("Float: %.3f\n", pi);
    printf("Char: %c, String: %s\n", ch, str);
    printf("Right-aligned: %5d\n", num);
    printf("Left-aligned: %-5d\n", num);
    return 0;
}

3.3 Character Input and Output

Character I/O functions handle individual characters, making them useful for processing text, reading single-key inputs, and handling simple user interactions.

Character Input Functions

  • getchar(): Reads a single character from standard input (stdin). Returns the character as an integer (ASCII value) or EOF on error.
    int ch = getchar(); // Read a character
  • getc(): Reads a character from a specified stream. Equivalent to fgetc().
    FILE *fp = stdin;
    int ch = getc(fp); // Read from stdin
  • fgetc(): Reads a character from a file stream.
    FILE *fp = fopen("file.txt", "r");
    int ch = fgetc(fp); // Read from file

Character Output Functions

  • putchar(): Writes a single character to standard output (stdout).
    putchar('A'); // Output: A
  • putc(): Writes a character to a specified stream.
    putc('B', stdout); // Output: B
  • fputc(): Writes a character to a file stream.
    FILE *fp = fopen("file.txt", "w");
    fputc('C', fp); // Write to file

String I/O Functions

  • gets(): Reads a string from stdin (deprecated).
  • fgets(): Reads a string from a stream, safely limiting the number of characters.
    char str[100];
    fgets(str, sizeof(str), stdin); // Read string safely
  • puts(): Writes a string to stdout with a newline.
  • fputs(): Writes a string to a specified stream (no newline added).
    fputs("Hello", stdout); // Output: Hello

Character I/O Example

// Program to count characters, words, and lines
#include <stdio.h>

int main() {
    int ch;
    int characters = 0, words = 0, lines = 0;
    int in_word = 0;

    printf("Enter text (Ctrl+D to end):\n");

    while ((ch = getchar()) != EOF) {
        characters++;

        if (ch == '\n')
            lines++;

        if (ch == ' ' || ch == '\n' || ch == '\t') {
            in_word = 0;
        } else if (!in_word) {
            in_word = 1;
            words++;
        }
    }

    printf("\nCharacters: %d\n", characters);
    printf("Words: %d\n", words);
    printf("Lines: %d\n", lines);
    return 0;
}
📝 Key insight: Character I/O functions are the building blocks for more complex I/O operations. They are efficient and provide low-level control over input/output processing.

3.4 I/O Operations

I/O operations in C involve reading from and writing to various streams, including standard input/output (stdin/stdout) and files. Understanding these operations is essential for creating interactive programs and managing data persistence.

Standard I/O Streams

  • stdin: Standard input stream (typically the keyboard). Used by functions like getchar(), scanf(), fgets().
  • stdout: Standard output stream (typically the console). Used by functions like putchar(), printf(), fputs().
  • stderr: Standard error stream for error messages. Usually unbuffered for immediate output.

File I/O Operations

  • Opening a File: Use fopen() to open a file.
    FILE *fp = fopen("file.txt", "r"); // Read mode
    FILE *fp = fopen("file.txt", "w"); // Write mode
    FILE *fp = fopen("file.txt", "a"); // Append mode
  • File Access Modes:
    ModeDescription
    "r"Open for reading (file must exist)
    "w"Open for writing (creates new file or truncates existing)
    "a"Open for appending (creates new file if doesn't exist)
    "r+"Open for reading and writing
    "w+"Open for reading and writing (truncates)
    "a+"Open for reading and appending
    "rb", "wb", etc.Binary mode
  • Reading from Files:
    int ch = fgetc(fp); // Read a character
    char str[100];
    fgets(str, 100, fp); // Read a string
    fscanf(fp, "%d", &x); // Formatted read
    fread(buffer, size, count, fp); // Binary read
  • Writing to Files:
    fputc('A', fp); // Write a character
    fputs("Hello", fp); // Write a string
    fprintf(fp, "%d", 10); // Formatted write
    fwrite(buffer, size, count, fp); // Binary write
  • Closing a File: Always close files with fclose() to flush buffers and free resources.
    fclose(fp);

Buffer Management

  • Line Buffering: Output is stored until a newline is encountered. Used for stdout when connected to a terminal.
  • Full Buffering: Output is stored until the buffer is full. Used for file I/O.
  • No Buffering: Immediate output. Used for stderr.
  • Flushing Buffers: Use fflush() to force buffer output.
    fflush(stdout); // Flush output buffer

File I/O Example

// Program to copy a file
#include <stdio.h>

int main() {
    FILE *source, *dest;
    int ch;

    source = fopen("source.txt", "r");
    if (source == NULL) {
        fprintf(stderr, "Cannot open source file\n");
        return 1;
    }

    dest = fopen("destination.txt", "w");
    if (dest == NULL) {
        fprintf(stderr, "Cannot create destination file\n");
        fclose(source);
        return 1;
    }

    while ((ch = fgetc(source)) != EOF) {
        fputc(ch, dest);
    }

    fclose(source);
    fclose(dest);
    printf("File copied successfully!\n");
    return 0;
}

Error Handling in I/O

  • Check Return Values: Always check return values of I/O functions.
    if (fopen("file.txt", "r") == NULL) {
        perror("Error opening file");
        exit(1);
    }
  • ferror(): Checks if an error occurred on a stream.
  • feof(): Checks if the end of file has been reached.
  • perror(): Prints a descriptive error message.
// Error handling example
FILE *fp = fopen("nonexistent.txt", "r");
if (fp == NULL) {
    perror("fopen error");
    return 1;
}

int ch;
while ((ch = fgetc(fp)) != EOF) {
    putchar(ch);
}

if (ferror(fp)) {
    fprintf(stderr, "Error reading file\n");
}
fclose(fp);
📂 Key insight: Proper I/O operations are fundamental to creating functional programs. Always handle errors, close files, and manage buffers to ensure robust and reliable code.
