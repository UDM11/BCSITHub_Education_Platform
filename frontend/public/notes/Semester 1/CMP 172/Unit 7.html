7.1 Introduction to Functions

Functions are self-contained blocks of code designed to perform specific tasks. They promote modularity, reusability, and maintainability in programs. Functions allow programmers to break complex problems into smaller, manageable units.

🎯 Purpose
Break complex problems into smaller units, promote code reuse, and improve readability and maintainability.
📋 Benefits
Code reusability, easier debugging, reduced redundancy, improved organization, and modular design.

Why Use Functions?

  • Modularity: Divide large programs into smaller, manageable pieces.
  • Reusability: Write once, use multiple times.
  • Maintainability: Easier to debug and update.
  • Abstraction: Hide implementation details from the user.
// Example: Function to calculate square
#include <stdio.h>

int square(int num) {
    return num * num;
}

int main() {
    int result = square(5);
    printf("Square of 5: %d\n", result); // 25
    return 0;
}
💡 Key insight: Functions are the building blocks of structured programming. Mastering functions is essential for writing professional C programs.

7.2 Types of Functions

Functions in C are classified into two types: library functions (pre-defined in standard libraries) and user-defined functions (created by programmers).

7.2.1 Library Functions

  • Definition: Pre-defined functions provided by C standard libraries.
  • Access: Include appropriate header files (#include <header.h>).
  • Advantages: Optimized, well-tested, and readily available.
// Library functions example
#include <stdio.h> // printf, scanf
#include <math.h> // sqrt, pow, sin, cos
#include <string.h> // strlen, strcpy, strcmp

int main() {
    printf("Square root of 16: %.2f\n", sqrt(16)); // 4.00
    printf("2^3: %.0f\n", pow(2, 3)); // 8
    char str[] = "Hello";
    printf("Length: %zu\n", strlen(str)); // 5
    return 0;
}

7.2.2 User-Defined Functions

  • Definition: Functions created by programmers to meet specific requirements.
  • Advantages: Tailored to specific needs, enhances code organization and readability.
// User-defined function example
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int multiply(int a, int b) {
    return a * b;
}

int main() {
    printf("Sum: %d\n", add(5, 3)); // 8
    printf("Product: %d\n", multiply(5, 3)); // 15
    return 0;
}

7.3 Components of Functions

A function consists of three main components: prototype (declaration), call (invocation), and definition (implementation).

Function Components:

1. Prototype (Declaration)
   ┌─────────────────────────────────┐
   │ int add(int, int);             │  ← Return type, name, parameters
   └─────────────────────────────────┘

2. Function Call
   ┌─────────────────────────────────┐
   │ int result = add(5, 3);        │  ← Passing arguments
   └─────────────────────────────────┘

3. Function Definition
   ┌─────────────────────────────────┐
   │ int add(int a, int b) {        │
   │     return a + b;              │
   │ }                              │
   └─────────────────────────────────┘

7.3.1 Function Prototype

  • Definition: Declares the function's return type, name, and parameters before its use.
  • Syntax: return_type function_name(parameter_list);
  • Purpose: Informs the compiler about the function's signature (type checking).
  • Placement: Usually at the top of the file or in a header file.
// Function prototype examples
int add(int, int); // Parameter names optional
float divide(float a, float b); // With parameter names
void printMessage(void); // No parameters, no return
int square(int x); // Single parameter

7.3.2 Function Call

  • Definition: Invokes the function, passing arguments if required.
  • Syntax: function_name(arguments);
  • Execution: Control transfers to the function, and upon completion, returns to the caller.
// Function call examples
int result = add(5, 3); // Call with arguments
printMessage(); // Call with no arguments
float avg = average(10.5, 20.3, 15.7);

7.3.3 Function Definition

  • Definition: Contains the actual code to be executed.
  • Syntax:
    return_type function_name(parameter_list) {
        // Code block
        return value; // If return_type is not void
    }
// Complete function example
#include <stdio.h>

// Prototype
int calculateSum(int a, int b);

// Main function
int main() {
    int x = 10, y = 20;
    int result = calculateSum(x, y); // Function call
    printf("Sum: %d\n", result);
    return 0;
}

// Function definition
int calculateSum(int a, int b) {
    return a + b;
}

7.4 Function Arguments and Return Types

Functions can accept arguments (parameters) to receive data and return values to send results back to the caller.

Passing Arguments

  • Pass by Value: Copies of arguments are passed; changes inside function do not affect original variables.
  • Pass by Reference: Uses pointers to modify original variables.
// Pass by Value example
void changeValue(int x) {
    x = 100; // Changes only the copy
}

int main() {
    int num = 5;
    changeValue(num);
    printf("num: %d\n", num); // Still 5
    return 0;
}

// Pass by Reference (using pointers)
void changeValueRef(int *x) {
    *x = 100; // Changes original value
}

int main() {
    int num = 5;
    changeValueRef(&num);
    printf("num: %d\n", num); // Now 100
    return 0;
}

Return Types

  • void: Function does not return a value.
  • int, float, char, etc.: Function returns a value of that type.
  • Pointer Return: Function can return a pointer.
Return TypeDescriptionExample
voidNo return valuevoid printHello() { printf("Hello"); }
intReturns integerint add(int a, int b) { return a + b; }
floatReturns floatfloat divide(float a, float b) { return a / b; }
char*Returns pointer to char (string)char* getName() { return "John"; }
// Swap function using pass by reference
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 5, y = 10;
    printf("Before: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("After: x=%d, y=%d\n", x, y); // x=10, y=5
    return 0;
}
🔑 Key insight: Pass by value creates a copy; pass by reference modifies the original. Use pointers when you need to modify the original data.

7.5 Passing Arrays to Function

Arrays are passed to functions by reference (as pointers), allowing modifications to the original array. The array name decays to a pointer to the first element.

Key Points

  • Array parameter can be declared as int arr[] or int *arr.
  • The array size is typically passed as a separate parameter.
  • Modifications inside the function affect the original array.
// Passing array to function
#include <stdio.h>

// Print array elements
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

// Double array elements (modifies original)
void doubleArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] *= 2; // Modifies original array
    }
}

int main() {
    int numbers[] = {1, 2, 3, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);

    printf("Original: ");
    printArray(numbers, size);

    doubleArray(numbers, size);

    printf("Doubled: ");
    printArray(numbers, size); // 2 4 6 8 10

    return 0;
}
// Alternative: using pointer notation
int sumArray(int *arr, int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += *(arr + i); // Equivalent to arr[i]
    }
    return sum;
}
📌 Key insight: When an array is passed to a function, only the pointer to the first element is passed. The size must be passed separately to avoid array bounds issues.

7.6 Passing Strings to Function

Strings (character arrays) are passed to functions similarly to arrays — as pointers to the first character. Strings must be null-terminated (\0).

String Functions

// String function examples
#include <stdio.h>
#include <string.h>

// Print a string
void printString(char str[]) {
    printf("%s\n", str);
}

// Convert string to uppercase
void toUpper(char str[]) {
    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] >= 'a' && str[i] <= 'z') {
            str[i] = str[i] - 32; // Convert to uppercase
        }
    }
}

// Count vowels in a string
int countVowels(char *str) {
    int count = 0;
    while (*str != '\0') {
        char ch = *str;
        if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u' ||
            ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U') {
            count++;
        }
        str++;
    }
    return count;
}

int main() {
    char str[] = "Hello World";
    printString(str);
    printf("Vowels: %d\n", countVowels(str)); // 3
    toUpper(str);
    printString(str); // HELLO WORLD
    return 0;
}
📝 Key insight: Strings are passed as character pointers. Always ensure the string is null-terminated for proper functioning of string operations.

7.7 Storage Class (auto, register, static, extern)

Storage classes define the scope, lifetime, and storage location of variables in C programs.

auto Storage Class

  • Definition: Default for local variables. Allocated on the stack.
  • Scope: Block in which declared.
  • Lifetime: Exists only during block execution.
  • Keyword: auto (optional).
auto int x = 5; // Same as int x = 5;

register Storage Class

  • Definition: Suggests storing variable in CPU register (compiler may ignore).
  • Scope: Block in which declared.
  • Lifetime: Exists only during block execution.
  • Restriction: Address of register variable cannot be taken (&).
register int counter = 0; // Hints to store in register
// &counter is not allowed

static Storage Class

  • Definition: Retains value between function calls. Initialized once.
  • Scope: Block (local static) or file (global static).
  • Lifetime: Entire program execution.
// Static variable example
void countCalls() {
    static int count = 0; // Initialized only once
    count++;
    printf("Called %d times\n", count);
}

int main() {
    countCalls(); // Called 1 times
    countCalls(); // Called 2 times
    countCalls(); // Called 3 times
    return 0;
}

extern Storage Class

  • Definition: Declares a variable defined in another file or elsewhere in the same file.
  • Scope: Global.
  • Lifetime: Entire program execution.
// file1.c
int globalVar = 100; // Definition

// file2.c
extern int globalVar; // Declaration
void printGlobal() {
    printf("%d\n", globalVar);
}

7.8 Scope of Variables (Local and Global)

Scope determines where a variable is accessible in a program. C has two main scope types: local (block) and global (file).

Local Variables

  • Definition: Variables declared inside a function or block.
  • Scope: Accessible only within that block.
  • Lifetime: Exists only during block execution.
  • Storage: Allocated on the stack.
int main() {
    int x = 10; // Local variable
    {
        int y = 20; // Nested scope
        printf("%d %d\n", x, y); // x is accessible here
    }
    // printf("%d", y); // ERROR: y not accessible here
    return 0;
}

Global Variables

  • Definition: Variables declared outside all functions.
  • Scope: Accessible throughout the file (and other files with extern).
  • Lifetime: Entire program execution.
  • Storage: Allocated in the data segment.
#include <stdio.h>

int globalVar = 100; // Global variable

void func1() {
    printf("globalVar: %d\n", globalVar);
}

void func2() {
    globalVar = 200; // Modifies global variable
}

int main() {
    func1(); // 100
    func2();
    func1(); // 200
    return 0;
}

Scope Resolution (Local vs Global)

  • Local takes precedence: If a local variable has the same name as a global variable, the local variable is used within its scope.
int x = 50; // Global x

void func() {
    int x = 10; // Local x shadows global
    printf("Local x: %d\n", x); // 10
    printf("Global x: %d\n", ::x); // Not valid in C (only C++)
    printf("Global x: %d\n", x); // Need to access differently
}

Best Practices

  • Minimize global variables: They make code harder to understand and debug.
  • Use local variables: Prefer local variables for better encapsulation.
  • Pass parameters: Use function parameters to communicate between functions instead of globals.

7.9 Recursive Function

A recursive function is a function that calls itself to solve a problem by breaking it down into smaller, similar sub-problems.

Components of Recursion

  • Base Case: The condition that stops the recursion.
  • Recursive Case: The function calls itself with a modified argument.

Recursive Examples

// Factorial using recursion
int factorial(int n) {
    if (n == 0 || n == 1) { // Base case
        return 1;
    }
    return n * factorial(n - 1); // Recursive case
}

// Fibonacci using recursion
int fibonacci(int n) {
    if (n <= 1) { // Base case
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2); // Recursive case
}

// Power function using recursion
int power(int base, int exp) {
    if (exp == 0) {
        return 1;
    }
    return base * power(base, exp - 1);
}
// Complete recursive program
#include <stdio.h>

// Recursive function to calculate sum of digits
int sumOfDigits(int n) {
    if (n == 0) {
        return 0;
    }
    return (n % 10) + sumOfDigits(n / 10);
}

// Recursive function to print pattern
void printPattern(int n) {
    if (n == 0) {
        return;
    }
    printPattern(n - 1);
    for (int i = 0; i < n; i++) {
        printf("* ");
    }
    printf("\n");
}

int main() {
    printf("Factorial of 5: %d\n", factorial(5)); // 120
    printf("Fibonacci(8): %d\n", fibonacci(8)); // 21
    printf("Power 2^10: %d\n", power(2, 10)); // 1024
    printf("Sum of digits 1234: %d\n", sumOfDigits(1234)); // 10
    printPattern(5);
    return 0;
}
