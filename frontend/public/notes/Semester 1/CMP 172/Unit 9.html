Unit 9: Structure and Union

Structure declaration · initialization · arrays · pointers · nested structures · union vs structure

9.1 Introduction

Structures and unions are user-defined data types in C that allow grouping of variables of different types under a single name. They enable organized data management and are fundamental for creating complex data structures.

📦 Structure
Groups multiple variables, each retaining its own memory. All members can hold values simultaneously. Used for records like employee, student, or product information.
🔀 Union
Groups variables that share the same memory location. Only one member can hold a value at a time. Used for memory-efficient storage and variant records.

Key Differences at a Glance

  • Structure: All members have separate memory. Size is sum of all members (plus padding).
  • Union: All members share the same memory. Size is the size of the largest member.
  • Use Case: Use structures when you need to store multiple related data items simultaneously. Use unions when you need to store different types of data in the same memory location.
💡 Key insight: Structures and unions are essential for creating complex data types. They form the basis for records, linked lists, trees, and many other data structures.

9.2 Declaration and Initialization of Structure

A structure is declared using the struct keyword. It defines a blueprint for creating structure variables.

Structure Declaration

  • Syntax:
    struct structure_name {
        data_type member1;
        data_type member2;
        // ...
    };
  • Example:
    struct Student {
        int id;
        char name[50];
        float marks;
    };

Structure Initialization

  • At Declaration: Use curly braces with values in order.
    struct Student s1 = {101, "Alice", 85.5};
  • After Declaration: Assign values using the dot operator.
    struct Student s2;
    s2.id = 102;
    strcpy(s2.name, "Bob");
    s2.marks = 90.0;
  • Designated Initialization (C99): Initialize specific members.
    struct Student s3 = {.id = 103, .name = "Charlie", .marks = 88.5};
// Complete structure example
#include <stdio.h>
#include <string.h>

struct Student {
    int id;
    char name[50];
    float marks;
};

int main() {
    struct Student s1 = {101, "Alice", 85.5};
    struct Student s2;
    s2.id = 102;
    strcpy(s2.name, "Bob");
    s2.marks = 90.0;

    printf("Student 1: ID=%d, Name=%s, Marks=%.2f\n", s1.id, s1.name, s1.marks);
    printf("Student 2: ID=%d, Name=%s, Marks=%.2f\n", s2.id, s2.name, s2.marks);
    return 0;
}

9.3 Structure Variable

Structure variables are instances of a structure type. They store data for the structure's members and can be declared and used like any other variable.

Declaring Structure Variables

  • Separate Declaration:
    struct Student s1, s2, s3;
  • At Structure Definition:
    struct Student {
        int id;
        char name[50];
    } s1, s2;
  • Using typedef:
    typedef struct {
        int x;
        int y;
    } Point;

    Point p1, p2;

Accessing Structure Members

  • Dot Operator (.): Used to access members of a structure variable.
    s1.id = 101;
    strcpy(s1.name, "Alice");
  • Scope Resolution: Structure members are accessed using the dot operator.
// Structure variable example
#include <stdio.h>

struct Rectangle {
    int length;
    int breadth;
};

int main() {
    struct Rectangle rect1 = {10, 5};
    struct Rectangle rect2;

    rect2.length = 15;
    rect2.breadth = 8;

    printf("Rect1: %d x %d\n", rect1.length, rect1.breadth);
    printf("Rect2: %d x %d\n", rect2.length, rect2.breadth);
    return 0;
}

9.4 Array of Structure

An array of structures stores multiple structure instances in a single array, making it ideal for managing collections of records.

Syntax and Example

  • Syntax: struct structure_name array_name[size];
// Array of structures example
#include <stdio.h>
#include <string.h>

struct Student {
    int id;
    char name[50];
    float marks;
};

int main() {
    struct Student students[3] = {
        {1, "Alice", 85.5},
        {2, "Bob", 90.0},
        {3, "Charlie", 78.5}
    };

    for (int i = 0; i < 3; i++) {
        printf("ID: %d, Name: %s, Marks: %.2f\n",
            students[i].id, students[i].name, students[i].marks);
    }

    // Modifying array elements
    students[1].marks = 95.0;
    printf("\nAfter modification:\n");
    for (int i = 0; i < 3; i++) {
        printf("ID: %d, Name: %s, Marks: %.2f\n",
            students[i].id, students[i].name, students[i].marks);
    }

    return 0;
}

Common Operations

  • Sorting: Sort array of structures based on a member (e.g., sort by marks).
  • Searching: Search for a structure based on a member value.
  • Filtering: Extract structures meeting certain criteria.

9.5 Passing Structure to Function

Structures can be passed to functions by value or by reference. Each method has different implications for performance and modification capabilities.

Pass by Value

  • Behavior: A copy of the structure is passed.
  • Effect: Changes inside the function do not affect the original.
  • Performance: Slower for large structures (copy overhead).
// Pass by value example
void printStudent(struct Student s) {
    printf("ID: %d, Name: %s, Marks: %.2f\n", s.id, s.name, s.marks);
}

int main() {
    struct Student s = {101, "Alice", 85.5};
    printStudent(s); // Copy passed
    return 0;
}

Pass by Reference

  • Behavior: A pointer to the structure is passed.
  • Effect: Changes inside the function affect the original.
  • Performance: Faster (only pointer passed).
// Pass by reference example
void modifyStudent(struct Student *s) {
    s->marks = 95.0; // Modify original
    strcpy(s->name, "Alice Smith");
}

int main() {
    struct Student s = {101, "Alice", 85.5};
    modifyStudent(&s);
    printf("Modified: %s, %.2f\n", s.name, s.marks);
    return 0;
}

Returning Structure from Function

// Returning structure from function
struct Student createStudent(int id, char *name, float marks) {
    struct Student s;
    s.id = id;
    strcpy(s.name, name);
    s.marks = marks;
    return s;
}

int main() {
    struct Student s = createStudent(201, "David", 92.5);
    printf("Created: %s, %.2f\n", s.name, s.marks);
    return 0;
}

9.6 Passing Array of Structure to Function

An array of structures is passed to functions by reference (as a pointer), allowing efficient processing and modifications to the original data.

// Array of structures as function parameter
#include <stdio.h>
#include <string.h>

struct Student {
    int id;
    char name[50];
    float marks;
};

// Print all students
void printAllStudents(struct Student s[], int size) {
    for (int i = 0; i < size; i++) {
        printf("ID: %d, Name: %s, Marks: %.2f\n",
            s[i].id, s[i].name, s[i].marks);
    }
}

// Calculate average marks
float calculateAverage(struct Student s[], int size) {
    float sum = 0;
    for (int i = 0; i < size; i++) {
        sum += s[i].marks;
    }
    return sum / size;
}

// Find student with highest marks
struct Student findTopper(struct Student s[], int size) {
    struct Student topper = s[0];
    for (int i = 1; i < size; i++) {
        if (s[i].marks > topper.marks) {
            topper = s[i];
        }
    }
    return topper;
}

int main() {
    struct Student students[] = {
        {1, "Alice", 85.5},
        {2, "Bob", 90.0},
        {3, "Charlie", 78.5},
        {4, "David", 92.0}
    };
    int size = sizeof(students) / sizeof(students[0]);

    printf("All Students:\n");
    printAllStudents(students, size);

    printf("\nAverage Marks: %.2f\n", calculateAverage(students, size));

    struct Student topper = findTopper(students, size);
    printf("Topper: %s (%.2f)\n", topper.name, topper.marks);

    return 0;
}
📌 Key insight: When passing arrays of structures to functions, the array decays to a pointer. The size should be passed separately to avoid out-of-bounds access.

9.7 Nested Structure

A nested structure (or structure within structure) contains another structure as a member. This enables hierarchical data organization and represents complex relationships.

Nested Structure Declaration

// Nested structure example
#include <stdio.h>
#include <string.h>

struct Date {
    int day;
    int month;
    int year;
};

struct Employee {
    int id;
    char name[50];
    struct Date dob; // Nested structure
    struct Date joinDate; // Another nested structure
    float salary;
};

int main() {
    struct Employee emp = {
        101,
        "John Doe",
        {15, 5, 1990}, // dob
        {1, 6, 2015}, // joinDate
        75000.0
    };

    printf("Employee: %s\n", emp.name);
    printf("DOB: %d/%d/%d\n", emp.dob.day, emp.dob.month, emp.dob.year);
    printf("Join Date: %d/%d/%d\n", emp.joinDate.day, emp.joinDate.month, emp.joinDate.year);
    printf("Salary: %.2f\n", emp.salary);

    // Accessing nested members
    emp.dob.year = 1991; // Modify nested member

    return 0;
}

Nested Structure with Pointer

// Nested structure with pointer
struct Address {
    char street[100];
    char city[50];
    char state[30];
    int zip;
};

struct Person {
    char name[50];
    struct Address *addr; // Pointer to Address
};

int main() {
    struct Address addr1 = {"123 Main St", "New York", "NY", 10001};
    struct Person p = {"Alice", &addr1};

    printf("%s lives at %s, %s, %s - %d\n",
        p.name, p.addr->street, p.addr->city, p.addr->state, p.addr->zip);
    return 0;
}

9.8 Pointer to Structure

A pointer to structure stores the memory address of a structure variable. Pointers to structures are commonly used for efficient parameter passing and dynamic memory allocation.

Declaration and Usage

// Pointer to structure
#include <stdio.h>
#include <string.h>

struct Student {
    int id;
    char name[50];
    float marks;
};

int main() {
    struct Student s1 = {101, "Alice", 85.5};
    struct Student *ptr = &s1; // Pointer to structure

    // Access using -> operator
    printf("ID: %d\n", ptr->id);
    printf("Name: %s\n", ptr->name);
    printf("Marks: %.2f\n", ptr->marks);

    // Modify using pointer
    ptr->marks = 95.0;
    strcpy(ptr->name, "Alice Smith");

    printf("\nAfter modification:\n");
    printf("Name: %s, Marks: %.2f\n", s1.name, s1.marks);

    return 0;
}

Dynamic Allocation of Structure

// Dynamic allocation of structure
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Student {
    int id;
    char name[50];
    float marks;
};

int main() {
    struct Student *ptr = (struct Student *)malloc(sizeof(struct Student));
    if (ptr != NULL) {
        ptr->id = 201;
        strcpy(ptr->name, "David");
        ptr->marks = 92.5;

        printf("ID: %d, Name: %s, Marks: %.2f\n", ptr->id, ptr->name, ptr->marks);
        free(ptr);
    }
    return 0;
}
🔑 Key insight: The arrow operator (->) is a shorthand for (*ptr).member. It is used to access members of a structure through a pointer.

9.9 Union Declaration and Usage

A union is similar to a structure, but all members share the same memory location. Only one member can hold a value at a time. Unions are used for memory-efficient storage when only one member is needed at a time.

Union Declaration

union Data {
    int i;
    float f;
    char str[20];
};

Union Example

// Union example
#include <stdio.h>
#include <string.h>

union Data {
    int i;
    float f;
    char str[20];
};

int main() {
    union Data data;

    data.i = 10;
    printf("data.i: %d\n", data.i);

    data.f = 3.14;
    printf("data.f: %.2f\n", data.f);
    printf("data.i (after setting f): %d\n", data.i); // Overwritten!

    strcpy(data.str, "Hello");
    printf("data.str: %s\n", data.str);
    printf("data.f (after setting str): %.2f\n", data.f); // Overwritten!

    printf("Size of union: %zu bytes\n", sizeof(data)); // Size of largest member

    return 0;
}

Union with Structure

// Union inside structure
struct Item {
    int type; // 0: int, 1: float, 2: string
    union {
        int intVal;
        float floatVal;
        char strVal[50];
    } value;
};

int main() {
    struct Item item1 = {0, .value.intVal = 42};
    struct Item item2 = {1, .value.floatVal = 3.14};
    struct Item item3 = {2, .value.strVal = "Hello"};

    printf("Item1: %d\n", item1.value.intVal);
    printf("Item2: %.2f\n", item2.value.floatVal);
    printf("Item3: %s\n", item3.value.strVal);
    return 0;
}

9.10 Union vs Structure

Structures and unions both group variables of different types, but they differ fundamentally in memory allocation and usage.

Memory Comparison

Structure Memory:
┌─────────┬─────────┬─────────┬─────────┐
│ int     │ float   │ char[20]│ padding │
│ (4 bytes)│ (4 bytes)│ (20 bytes)│         │
└─────────┴─────────┴─────────┴─────────┘
Total: ~28 bytes

Union Memory:
┌─────────────────────────────────────────┐
│         Largest Member (20 bytes)       │
│         Shared by all members           │
└─────────────────────────────────────────┘
Total: 20 bytes
FeatureStructureUnion
Memory AllocationSeparate for each memberShared among all members
Total SizeSum of all members (+ padding)Size of largest member
Member ValuesAll members can hold values simultaneouslyOnly one member can hold a value at a time
AccessAll members accessible at any timeOnly last assigned member is valid
Use CaseRecords with multiple related fieldsMemory-efficient variant records
ExampleEmployee record (id, name, salary)Data type (int, float, string)

When to Use Each

  • Structure:
    • When you need to store multiple related pieces of information.
    • When all members need to be accessible simultaneously.
    • When memory usage is not a critical constraint.
  • Union:
    • When you need to store different types of data but only one at a time.
    • When memory is limited and you want to save space.
    • When implementing variant records or type-agnostic data storage.
// Structure vs Union - Practical Example
#include <stdio.h>

struct StructData {
    int i;
    float f;
    char c;
};

union UnionData {
    int i;
    float f;
    char c;
};

int main() {
    printf("Structure size: %zu bytes\n", sizeof(struct StructData));
    printf("Union size: %zu bytes\n", sizeof(union UnionData));

    struct StructData s = {10, 3.14, 'A'};
    printf("Structure: i=%d, f=%.2f, c=%c\n", s.i, s.f, s.c);

    union UnionData u;
    u.i = 10;
    printf("Union (i): %d\n", u.i);
    u.f = 3.14;
    printf("Union (f): %.2f, (i): %d\n", u.f, u.i); // i is overwritten
    return 0;
}
📊 Key insight: Choose structures when you need all members simultaneously. Choose unions when you need memory efficiency and only one member at a time. The choice depends on memory constraints and how the data will be used.
📘 Unit 9 summary
Structures group related data with separate memory for each member. Unions share memory among members, saving space but allowing only one active member at a time.
🔑 Key takeaways
• Structure: separate memory, all members active.
• Union: shared memory, only one member active.
• Nested structures for hierarchical data.
• Pointers to structures for efficient passing.
• Arrays of structures for collections.
