Unit 8: Pointers

Pointer basics · operators · arithmetic · arrays · strings · dynamic memory allocation

8.1 Introduction

Pointers are variables that store memory addresses, enabling direct memory manipulation in C. They are one of the most powerful features of C, providing flexibility, efficiency, and low-level control over memory.

🎯 Purpose
Manage memory efficiently, pass large data structures to functions, enable dynamic memory allocation, and implement data structures like linked lists and trees.
🔑 Key Concept
A pointer holds the address of another variable, not its value. This allows indirect access to data stored in memory.

Why Use Pointers?

  • Efficient Parameter Passing: Pass large structures by reference instead of copying.
  • Dynamic Memory Allocation: Allocate memory at runtime using malloc, calloc, realloc.
  • Data Structures: Implement linked lists, trees, graphs, and other dynamic structures.
  • Hardware Access: Interact with memory-mapped I/O and hardware registers.
  • Function Pointers: Pass functions as arguments to other functions.
Memory View:
Variable x:  [10]  at address 1000
Pointer p:   [1000] at address 2000

p points to x → *p = 10
💡 Key insight: Pointers provide direct access to memory, making C powerful for system programming. However, they require careful handling to avoid bugs like segmentation faults.

8.2 The & and * Operator

Pointers rely on two operators: the address-of operator (&) and the dereference operator (*).

& (Address-of Operator)

  • Purpose: Returns the memory address of a variable.
  • Syntax: &variable
  • Use: Assigning addresses to pointers.

* (Dereference Operator)

  • Purpose: Accesses the value stored at the address held by a pointer.
  • Syntax: *pointer
  • Use: Reading or modifying the value at the pointed-to location.
// & and * operators example
#include <stdio.h>

int main() {
    int x = 10;
    int *ptr = &x; // &x gets the address of x

    printf("Address of x: %p\n", &x);
    printf("Value of ptr: %p\n", ptr);
    printf("Value at ptr: %d\n", *ptr); // *ptr dereferences to get value

    *ptr = 20; // Modifies x through pointer
    printf("New value of x: %d\n", x); // 20

    return 0;
}
📌 Key insight: & gives the address, * gives the value at the address. They are inverse operations.

8.3 Declaration of Pointer

Pointer declaration specifies the data type of the variable it points to and allocates space for the pointer variable itself.

Syntax and Examples

  • Syntax: data_type *pointer_name;
  • Examples:
    int *intPtr; // Pointer to integer
    float *floatPtr; // Pointer to float
    char *charPtr; // Pointer to character
    double *doublePtr; // Pointer to double
  • Multiple Declarations:
    int *p, *q, *r; // Three pointers to int
    int *p, q, r; // p is pointer, q and r are ints

Important Notes

  • Initialization: Uninitialized pointers contain garbage values and can cause undefined behavior.
  • NULL Pointer: Initialize to NULL to indicate that the pointer doesn't point to valid memory.
    int *ptr = NULL; // Safe initialization
  • Pointer to Void: void * can point to any data type. Used in generic programming.
    void *genericPtr;
// Pointer declaration and initialization
int x = 10;
int *ptr1 = &x; // Valid: points to x
int *ptr2 = NULL; // Valid: points to nothing
// int *ptr3; // Uninitialized - dangerous!

8.4 Chain of Pointers

A chain of pointers (or multi-level pointers) involves a pointer that points to another pointer. This is useful for dynamic 2D arrays, function arguments that modify pointers, and complex data structures.

Pointer to Pointer

  • Syntax: data_type **pointer_name;
  • Levels: ** (pointer to pointer), *** (pointer to pointer to pointer), etc.
// Chain of pointers example
#include <stdio.h>

int main() {
    int x = 10;
    int *ptr1 = &x; // Pointer to x
    int **ptr2 = &ptr1; // Pointer to ptr1
    int ***ptr3 = &ptr2; // Pointer to ptr2

    printf("Value of x: %d\n", x);
    printf("Value via ptr1: %d\n", *ptr1);
    printf("Value via ptr2: %d\n", **ptr2);
    printf("Value via ptr3: %d\n", ***ptr3);

    return 0;
}
// Output: 10 10 10 10

Use Cases

  • Dynamic 2D Arrays: Allocate arrays of pointers to rows.
  • Function Arguments: Modify pointer parameters in functions.
  • Linked Lists and Trees: Nested pointers for node connections.

8.5 Pointer Arithmetic

Pointer arithmetic allows navigation through memory by incrementing, decrementing, or performing addition/subtraction on pointers.

Rules of Pointer Arithmetic

  • Increment (++): Moves pointer to the next element (adds size of data type).
  • Decrement (--): Moves pointer to the previous element.
  • Addition (+): ptr + n moves forward by n elements.
  • Subtraction (-): ptr - n moves backward by n elements.
  • Subtraction of Pointers: ptr1 - ptr2 gives the number of elements between them.
// Pointer arithmetic examples
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int *ptr = arr; // Points to arr[0]

    printf("ptr points to: %d\n", *ptr); // 10
    ptr++; // Move to next element
    printf("After ptr++: %d\n", *ptr); // 20
    ptr += 2; // Move forward by 2
    printf("After ptr+=2: %d\n", *ptr); // 40
    ptr--; // Move back by 1
    printf("After ptr--: %d\n", *ptr); // 30

    // Difference between pointers
    int *start = arr;
    int *end = &arr[4];
    printf("Number of elements: %ld\n", end - start); // 4

    return 0;
}
// Printing array using pointer arithmetic
int arr[5] = {1, 2, 3, 4, 5};
int *ptr = arr;
for (int i = 0; i < 5; i++) {
    printf("%d ", *(ptr + i)); // Same as arr[i]
}
// Output: 1 2 3 4 5

8.6 Pointers and Arrays

Arrays and pointers are closely related in C. An array name acts as a constant pointer to the first element of the array.

Array-Pointer Equivalence

  • arr[i] is equivalent to *(arr + i).
  • &arr[i] is equivalent to (arr + i).
  • The array name arr is a pointer constant (cannot be reassigned).
// Array and pointer relationship
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int *ptr = arr; // Pointer to first element

    printf("Using array indexing:\n");
    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);
    }

    printf("\nUsing pointer arithmetic:\n");
    for (int i = 0; i < 5; i++) {
        printf("*(ptr + %d) = %d\n", i, *(ptr + i));
    }

    printf("\nAddresses:\n");
    printf("arr = %p\n", arr);
    printf("&arr[0] = %p\n", &arr[0]);
    printf("ptr = %p\n", ptr);

    return 0;
}
📌 Key insight: Arrays decay to pointers when passed to functions. The size information is lost, so pass size separately.

8.7 Pointers and Character Strings

Strings in C are character arrays terminated with a null character \0. Pointers to char are used to manipulate strings efficiently.

String Pointer Declaration

char *str = "Hello"; // Points to string literal (read-only)
char str2[] = "Hello"; // Array of characters (modifiable)

String Operations with Pointers

// String pointer operations
#include <stdio.h>

int main() {
    char *str = "Hello, World!";
    char *ptr = str;

    printf("String: %s\n", str);
    printf("First character: %c\n", *str); // 'H'

    // Print using pointer
    while (*ptr != '\0') {
        printf("%c", *ptr);
        ptr++;
    }
    printf("\n");

    // Copy string using pointer
    char dest[20];
    char *src = str;
    char *destPtr = dest;
    while (*src != '\0') {
        *destPtr = *src;
        src++;
        destPtr++;
    }
    *destPtr = '\0'; // Null terminate
    printf("Copied: %s\n", dest);

    return 0;
}
⚠️ Warning: String literals (like "Hello") are read-only. Modifying them causes undefined behavior. Use character arrays for modifiable strings.

8.8 Array of Pointers

An array of pointers stores multiple pointers, each pointing to a data element or string. This is useful for managing multiple strings, implementing data structures, and handling command-line arguments.

Syntax and Examples

  • Syntax: data_type *array_name[size];
// Array of pointers to strings
#include <stdio.h>

int main() {
    char *fruits[] = {"Apple", "Banana", "Cherry", "Date", "Elderberry"};
    int size = sizeof(fruits) / sizeof(fruits[0]);

    printf("Fruits:\n");
    for (int i = 0; i < size; i++) {
        printf("%s\n", fruits[i]);
    }

    // Array of pointers to integers
    int a = 10, b = 20, c = 30;
    int *numbers[] = {&a, &b, &c};
    for (int i = 0; i < 3; i++) {
        printf("%d ", *numbers[i]);
    }
    printf("\n");

    return 0;
}

8.9 Pointers as Function Arguments

Passing pointers to functions enables pass by reference, allowing functions to modify variables in the caller's scope. This is essential for functions that need to return multiple values or modify large data structures efficiently.

// Pointer as function argument - swap function
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 5, y = 10;
    printf("Before: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("After: x=%d, y=%d\n", x, y);
    return 0;
}
// Output: Before: x=5, y=10 / After: x=10, y=5
// Function returning multiple values using pointers
void calculate(int a, int b, int *sum, int *product, int *avg) {
    *sum = a + b;
    *product = a * b;
    *avg = (a + b) / 2;
}

int main() {
    int s, p, a;
    calculate(10, 20, &s, &p, &a);
    printf("Sum: %d, Product: %d, Avg: %d\n", s, p, a);
    return 0;
}
🔑 Key insight: Pointers as function arguments are essential for pass-by-reference in C. They allow functions to modify original variables and efficiently pass large data structures.

8.10 Dynamic Memory Allocation

Dynamic memory allocation allows programs to request memory at runtime using functions from <stdlib.h>. This provides flexibility for handling variable-sized data.

8.10.1 malloc()

  • Purpose: Allocates a block of memory of the specified size.
  • Syntax: void *malloc(size_t size);
  • Return: Pointer to allocated memory, or NULL if allocation fails.
  • Content: Uninitialized (contains garbage values).
// malloc example
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 5;
    int *arr = (int *)malloc(n * sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        arr[i] = i + 1;
    }

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr); // Free allocated memory
    return 0;
}

8.10.2 calloc()

  • Purpose: Allocates memory for an array of elements and initializes all bytes to zero.
  • Syntax: void *calloc(size_t num, size_t size);
  • Return: Pointer to allocated memory, or NULL if allocation fails.
  • Content: Zero-initialized.
// calloc example
int *arr = (int *)calloc(5, sizeof(int));
// All elements are initialized to 0
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]); // All 0
}
free(arr);

8.10.3 realloc()

  • Purpose: Resizes previously allocated memory, preserving existing data if possible.
  • Syntax: void *realloc(void *ptr, size_t new_size);
  • Return: Pointer to reallocated memory (may be different), or NULL if allocation fails.
  • Note: Original pointer may become invalid.
// realloc example
int *arr = (int *)malloc(3 * sizeof(int));
arr[0] = 1; arr[1] = 2; arr[2] = 3;

arr = (int *)realloc(arr, 5 * sizeof(int));
if (arr != NULL) {
    arr[3] = 4; arr[4] = 5;
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    free(arr);
}

8.10.4 free()

  • Purpose: Deallocates previously allocated dynamic memory.
  • Syntax: void free(void *ptr);
  • Note: Always free memory to prevent memory leaks. Set pointer to NULL after freeing.
// Complete dynamic memory example
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr = NULL;
    int size, newSize;

    printf("Enter size: ");
    scanf("%d", &size);

    arr = (int *)malloc(size * sizeof(int));
    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < size; i++) {
        arr[i] = (i + 1) * 10;
    }

    printf("Original array: ");
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    printf("Enter new size: ");
    scanf("%d", &newSize);

    arr = (int *)realloc(arr, newSize * sizeof(int));
    if (arr == NULL) {
        printf("Reallocation failed\n");
        return 1;
    }

    for (int i = size; i < newSize; i++) {
        arr[i] = (i + 1) * 10;
    }

    printf("Resized array: ");
    for (int i = 0; i < newSize; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr);
    arr = NULL;
    return 0;
}

8.11 Pass by Value, Pass by Reference

C supports two ways to pass arguments to functions: pass by value and pass by reference (using pointers).

Pass by Value

  • Definition: Copies the argument's value into the function parameter.
  • Effect: Changes inside the function do not affect the original variable.
  • Memory: Separate memory allocation for the copy.
// Pass by value example
void modify(int x) {
    x = 20; // Modifies only the copy
}

int main() {
    int a = 10;
    modify(a);
    printf("a: %d\n", a); // 10 (unchanged)
    return 0;
}

Pass by Reference

  • Definition: Passes the address of the argument.
  • Effect: Changes inside the function affect the original variable.
  • Memory: No copy; works on the original memory location.
// Pass by reference example
void modify(int *x) {
    *x = 20; // Modifies the original
}

int main() {
    int a = 10;
    modify(&a);
    printf("a: %d\n", a); // 20 (modified)
    return 0;
}

🔑 Key insight: Pass by reference (using pointers) is essential for efficient parameter passing and functions that need to modify multiple variables.
