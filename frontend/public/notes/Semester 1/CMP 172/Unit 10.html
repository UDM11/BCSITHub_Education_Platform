File concepts · modes · opening/closing · I/O operations · random access · error handling

10.1 Concept of File

A file is a collection of related data stored on a secondary storage device (hard disk, SSD, USB drive, etc.). Files provide persistent storage, allowing data to be retained even after the program terminates.

📂 Purpose
Store data permanently, share data between programs, maintain logs, and handle large datasets that don't fit in memory.
📋 Types
Text Files: Human-readable (characters). Binary Files: Machine-readable (raw bytes).

Types of Files

  • Text Files:
    • Store data as a sequence of characters (ASCII/Unicode).
    • Can be read and edited using text editors (Notepad, Vim).
    • End of line is marked by newline character (\n).
    • Examples: .txt, .c, .html, .csv.
  • Binary Files:
    • Store data in the same format as it is stored in memory.
    • Not human-readable; require specific programs to interpret.
    • More efficient in terms of storage and processing speed.
    • Examples: .dat, .bin, .exe, .jpg, .mp3.

File Operations Overview

  1. Create a file.
  2. Open an existing file.
  3. Read data from a file.
  4. Write data to a file.
  5. Close the file.
  6. Delete or rename a file.
File Handling Process:
┌─────────────────────────────────────────────┐
│  Step 1: fopen() → Open/Create a file      │
│  Step 2: Read/Write data using I/O functions│
│  Step 3: fclose() → Close the file         │
└─────────────────────────────────────────────┘
💡 Key insight: Files are essential for persistent data storage. Without file handling, all program data would be lost when the program terminates.

10.2 File Operation Modes

File operation modes determine how a file can be accessed when opened. The mode is specified as the second argument to fopen().

Text File Modes

ModeDescriptionFile Must ExistEffect
"r"Read-onlyYesRead from beginning
"w"Write-onlyNoCreates new file or overwrites existing
"a"AppendNoAppends to end, creates if not exists
"r+"Read and writeYesRead and write from beginning
"w+"Read and writeNoCreates new file or overwrites existing
"a+"Read and appendNoRead anywhere, append at end

Binary File Modes

  • Same as text modes, but with 'b' suffix:
    • "rb" — Read binary
    • "wb" — Write binary
    • "ab" — Append binary
    • "rb+" — Read/Write binary
    • "wb+" — Read/Write binary (overwrite)
    • "ab+" — Read/Append binary
  • Why use binary mode? On Windows, \n in text mode is translated to \r\n. Binary mode prevents this translation.

Mode Examples

// Different file opening modes
FILE *fp1 = fopen("file.txt", "r"); // Read only
FILE *fp2 = fopen("file.txt", "w"); // Write (overwrite)
FILE *fp3 = fopen("file.txt", "a"); // Append
FILE *fp4 = fopen("file.bin", "rb"); // Read binary
FILE *fp5 = fopen("file.bin", "wb"); // Write binary

10.3 Opening and Closing of File

Files must be opened before performing any operations and closed afterward to free resources and ensure data is properly saved.

Opening a File: fopen()

  • Prototype: FILE *fopen(const char *filename, const char *mode);
  • Return: Returns a FILE* pointer on success, NULL on failure.
  • Failure Reasons: File not found (for read modes), permission denied, insufficient memory.

Closing a File: fclose()

  • Prototype: int fclose(FILE *fp);
  • Return: Returns 0 on success, EOF on error.
  • Purpose: Flushes buffer, writes remaining data, releases file handle.
// Opening and closing a file
#include <stdio.h>

int main() {
    FILE *fp = fopen("example.txt", "w");
    if (fp == NULL) {
        printf("Error opening file!\n");
        return 1;
    }

    fprintf(fp, "Hello, File!\n");
    fclose(fp); // Always close the file
    return 0;
}

Error Handling for File Operations

  • Check fopen() return: Always check if fp == NULL.
  • Use perror(): Prints the system error message.
  • Use errno: Global variable for error codes.
// Error handling example
#include <stdio.h>
#include <errno.h>
#include <string.h>

int main() {
    FILE *fp = fopen("nonexistent.txt", "r");
    if (fp == NULL) {
        perror("fopen error");
        printf("Error code: %d\n", errno);
        printf("Error message: %s\n", strerror(errno));
        return 1;
    }
    fclose(fp);
    return 0;
}
📌 Key insight: Always check if fopen() returns NULL before using the file pointer. This prevents segmentation faults and crashes.

10.4 Input Output Operations in File

File I/O operations allow reading data from and writing data to files. Different functions are available for text and binary files.

Text File Operations

Writing to Text Files

  • fputc(): Writes a single character.
    fputc('A', fp);
  • fputs(): Writes a string.
    fputs("Hello World", fp);
  • fprintf(): Writes formatted data.
    fprintf(fp, "Name: %s, Age: %d\n", "Alice", 25);

Reading from Text Files

  • fgetc(): Reads a single character. Returns EOF on end of file.
    int ch = fgetc(fp);
  • fgets(): Reads a line or up to size-1 characters.
    char buffer[100];
    fgets(buffer, 100, fp);
  • fscanf(): Reads formatted data.
    fscanf(fp, "%d %f", &num, &value);
// Text file I/O example
#include <stdio.h>

int main() {
    FILE *fp = fopen("students.txt", "w+");
    if (fp == NULL) {
        printf("Error opening file\n");
        return 1;
    }

    // Writing to file
    fprintf(fp, "Alice, 85.5\n");
    fprintf(fp, "Bob, 90.0\n");
    fprintf(fp, "Charlie, 78.5\n");

    // Rewind to beginning
    rewind(fp);

    // Reading from file
    char name[50];
    float marks;
    while (fscanf(fp, "%[^,], %f\n", name, &marks) == 2) {
        printf("Name: %s, Marks: %.2f\n", name, marks);
    }

    fclose(fp);
    return 0;
}

Binary File Operations

  • fwrite(): Writes binary data to a file.
    fwrite(ptr, size, count, fp);
  • fread(): Reads binary data from a file.
    fread(ptr, size, count, fp);
// Binary file I/O example
#include <stdio.h>

struct Student {
    int id;
    char name[50];
    float marks;
};

int main() {
    FILE *fp = fopen("students.dat", "wb+");
    if (fp == NULL) {
        printf("Error opening file\n");
        return 1;
    }

    struct Student students[] = {
        {1, "Alice", 85.5},
        {2, "Bob", 90.0},
        {3, "Charlie", 78.5}
    };

    // Write array to binary file
    fwrite(students, sizeof(struct Student), 3, fp);

    // Read back from binary file
    rewind(fp);
    struct Student readStudents[3];
    fread(readStudents, sizeof(struct Student), 3, fp);

    for (int i = 0; i < 3; i++) {
        printf("ID: %d, Name: %s, Marks: %.2f\n",
            readStudents[i].id, readStudents[i].name, readStudents[i].marks);
    }

    fclose(fp);
    return 0;
}

10.5 Random Access in File

Random access allows reading or writing at any position in a file, rather than sequentially. This is useful for large files where you need to access specific records without reading everything before them.

File Positioning Functions

  • fseek(): Moves the file pointer to a specific position.
    int fseek(FILE *fp, long offset, int whence);
    • SEEK_SET — Beginning of file
    • SEEK_CUR — Current position
    • SEEK_END — End of file
  • ftell(): Returns the current position of the file pointer.
    long pos = ftell(fp);
  • rewind(): Moves the file pointer to the beginning (equivalent to fseek(fp, 0, SEEK_SET)).
    rewind(fp);

Random Access Examples

// fseek and ftell example
#include <stdio.h>

int main() {
    FILE *fp = fopen("data.txt", "r+");
    if (fp == NULL) {
        printf("Error opening file\n");
        return 1;
    }

    // Get current position
    long pos = ftell(fp);
    printf("Initial position: %ld\n", pos);

    // Move to 5th byte from beginning
    fseek(fp, 5, SEEK_SET);
    printf("After fseek: %ld\n", ftell(fp));

    // Read from current position
    char buffer[20];
    fgets(buffer, 20, fp);
    printf("Read: %s\n", buffer);

    // Move to end and get file size
    fseek(fp, 0, SEEK_END);
    long fileSize = ftell(fp);
    printf("File size: %ld bytes\n", fileSize);

    // Return to beginning
    rewind(fp);
    printf("After rewind: %ld\n", ftell(fp));

    fclose(fp);
    return 0;
}

Random Access with Binary Files

// Random access in binary file
#include <stdio.h>

struct Record {
    int id;
    char name[50];
    float value;
};

int main() {
    FILE *fp = fopen("records.dat", "rb+");
    if (fp == NULL) {
        printf("Error opening file\n");
        return 1;
    }

    // Read 3rd record (index 2)
    struct Record rec;
    fseek(fp, 2 * sizeof(struct Record), SEEK_SET);
    fread(&rec, sizeof(struct Record), 1, fp);
    printf("3rd Record: ID=%d, Name=%s, Value=%.2f\n", rec.id, rec.name, rec.value);

    // Modify and write back
    rec.value = 999.99;
    fseek(fp, -sizeof(struct Record), SEEK_CUR); // Move back
    fwrite(&rec, sizeof(struct Record), 1, fp);

    fclose(fp);
    return 0;
}

Common Random Access Patterns

  • Sequential Access: Read/write from beginning to end.
  • Direct Access: Jump to a specific record using fseek().
  • Indexed Access: Use an index file to find record positions.
  • Database-style Access: Combine random access with fixed-size records.
// Finding a record by ID
struct Student findById(int id, FILE *fp) {
    struct Student s;
    rewind(fp);
    while (fread(&s, sizeof(struct Student), 1, fp) == 1) {
        if (s.id == id) {
            return s;
        }
    }
    struct Student empty = {-1, "", 0};
    return empty;
}
🎯 Key insight: Random access is essential for efficient file operations in large files. It allows direct access to any part of the file without reading through unnecessary data.
