6.1 Introduction

Matrices and determinants are fundamental tools in linear algebra, used to represent and solve systems of linear equations, transformations, and data in various fields.

📊 Matrices
Rectangular arrays of numbers arranged in rows and columns. Denoted as [aᵢⱼ], where aᵢⱼ is the element in the i-th row and j-th column.
🧮 Determinants
Scalar values computed from square matrices. Used to analyze invertibility, solve linear systems, and compute areas/volumes.

Basic Concepts

  • Dimensions: An m×n matrix has m rows and n columns.
  • Elements: aᵢⱼ represents the element in row i, column j.
  • Square Matrix: m = n (same number of rows and columns).
  • Applications: Computer graphics (transformations), machine learning (data representation), economics (input-output models), engineering (circuit analysis).
Matrix A (2×3):
┌         ┐
│ 1  2  3 │
│ 4  5  6 │
└         ┘
a₁₁ = 1, a₁₂ = 2, a₂₁ = 4, a₂₃ = 6
💡 Key insight: Matrices provide a structured way to organize and manipulate data, making them essential in both theoretical and applied mathematics.

6.3 Matrix Operations

Matrix operations allow manipulation of matrices to solve equations, transform data, or model relationships in various disciplines.

Basic Operations

  • Addition/Subtraction: Add corresponding elements. Matrices must have same dimensions.
  • Scalar Multiplication: Multiply each element by a constant.
  • Matrix Multiplication: Dot product of rows and columns. A (m×n) × B (n×p) → C (m×p).
// Matrix Addition
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
A + B = [[6, 8], [10, 12]]

// Scalar Multiplication
2A = [[2, 4], [6, 8]]

// Matrix Multiplication
A (2×2) × B (2×2)
AB = [[1·5+2·7, 1·6+2·8],
     [3·5+4·7, 3·6+4·8]]
  = [[19, 22], [43, 50]]

Properties

  • Commutative: A + B = B + A (addition), but AB ≠ BA (multiplication).
  • Associative: (A + B) + C = A + (B + C), (AB)C = A(BC).
  • Distributive: A(B + C) = AB + AC.

6.4 Transpose of a Matrix, Determinant of a Matrix

The transpose and determinant of a matrix provide insights into its structure and properties, essential for linear algebra applications.

Transpose

  • Definition: (Aᵀ)ᵢⱼ = aⱼᵢ. Swap rows and columns.
  • Properties:
    • (Aᵀ)ᵀ = A
    • (A + B)ᵀ = Aᵀ + Bᵀ
    • (AB)ᵀ = Bᵀ Aᵀ

Determinant

  • 2×2 Determinant: det(A) = ad - bc for [[a, b], [c, d]].
  • 3×3 Determinant: Use expansion by minors (see 6.5).
// Transpose example
A = [[1, 2, 3], [4, 5, 6]]
Aᵀ = [[1, 4], [2, 5], [3, 6]]

// 2×2 determinant
A = [[2, 3], [4, 5]]
det(A) = 2·5 - 3·4 = 10 - 12 = -2

6.5 Minors and Cofactors of the Matrix

Minors and cofactors are used to compute determinants of larger matrices and analyze their properties.

Definitions

  • Minor Mᵢⱼ: Determinant of the submatrix obtained by deleting row i and column j.
  • Cofactor Cᵢⱼ: Cᵢⱼ = (-1)ⁱ⁺ʲ · Mᵢⱼ
  • Determinant Expansion: det(A) = Σ aᵢⱼ · Cᵢⱼ along any row or column.
// Minor and Cofactor example
A = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]

M₁₁ = det([[5, 6], [8, 9]]) = 5·9 - 6·8 = 45 - 48 = -3
C₁₁ = (-1)¹⁺¹ · (-3) = -3

// Determinant via cofactor expansion (first row)
det(A) = 1·C₁₁ + 2·C₁₂ + 3·C₁₃
C₁₂ = (-1)¹⁺² · det([[4, 6], [7, 9]]) = - (36 - 42) = 6
C₁₃ = (-1)¹⁺³ · det([[4, 5], [7, 8]]) = (32 - 35) = -3
det(A) = 1·(-3) + 2·6 + 3·(-3) = -3 + 12 - 9 = 0

6.6 Properties of Determinants (Singular and Non-Singular Matrix)

Properties of determinants reveal key characteristics of matrices, distinguishing singular and non-singular matrices.

Properties of Determinants

  • Property 1: det(Aᵀ) = det(A)
  • Property 2: If two rows (or columns) are swapped, det(A) changes sign.
  • Property 3: If a row is multiplied by k, det(A) is multiplied by k.
  • Property 4: If a row is a linear combination of others, det(A) = 0.
  • Property 5: det(AB) = det(A) · det(B)
  • Property 6: det(I) = 1
  • Property 7: det(cA) = cⁿ · det(A) for n×n matrix.

Singular vs Non-Singular

Singulardet(A) = 0No[[1, 2], [2, 4]] → det = 4 - 4 = 0

A = [[1, 2], [2, 4]]
det(A) = 1·4 - 2·2 = 0 → Singular, not invertible

// Non-singular matrix example

6.7 Solution of Linear Equations (Cramer's Rule for 2-3 Variables)

Cramer's rule uses determinants to solve systems of linear equations with a unique solution, efficient for small systems.

Cramer's Rule for 2 Variables

  • For system: ax + by = e, cx + dy = f
  • D = det([[a, b], [c, d]]) = ad - bc
  • Dₓ = det([[e, b], [f, d]]) = ed - bf
  • Dᵧ = det([[a, e], [c, f]]) = af - ec
  • x = Dₓ / D, y = Dᵧ / D (if D ≠ 0)

Cramer's Rule for 3 Variables

  • For system: a₁x + b₁y + c₁z = d₁, a₂x + b₂y + c₂z = d₂, a₃x + b₃y + c₃z = d₃
  • Compute D, Dₓ, Dᵧ, D₂
  • x = Dₓ/D, y = Dᵧ/D, z = D₂/D (if D ≠ 0)
// Cramer's Rule Example (2 variables)
// 2x + y = 5
// x + 3y = 4

A = [[2, 1], [1, 3]]
D = 2·3 - 1·1 = 5
Dₓ = [[5, 1], [4, 3]] = 5·3 - 1·4 = 15 - 4 = 11
Dᵧ = [[2, 5], [1, 4]] = 2·4 - 5·1 = 8 - 5 = 3
x = 11/5, y = 3/5

// Cramer's Rule Example (3 variables)
// x + y + z = 6
// 2x - y + z = 4
// -x + 2y + z = 5

// Compute D, Dₓ, Dᵧ, D₂ using determinants

Limitations

  • Requires D ≠ 0 (non-singular matrix).
  • Computationally intensive for n > 3 (O(n!) complexity).
  • For larger systems, Gaussian elimination is preferred.
📐 Key insight: Cramer's rule provides an elegant determinant-based solution for small linear systems. It is particularly useful for 2×2 and 3×3 systems in engineering and economics applications.
