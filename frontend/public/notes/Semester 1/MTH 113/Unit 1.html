1.1 Elementary Logic

Elementary logic is the foundation of reasoning, used to construct and evaluate arguments systematically, particularly in mathematics and computer science.

📊 Propositions
Statements that are either true or false (e.g., "2 + 2 = 4" is true; "2 + 2 = 5" is false). Questions and commands are not propositions.
🧩 Logical Arguments
Consist of premises (given statements) leading to a conclusion. An argument is valid if the conclusion follows logically from the premises.

Key Concepts in Elementary Logic

  • Truth Values: Propositions are evaluated as true (T) or false (F), forming the basis for logical operations and proofs.
  • Negation: The opposite of a proposition (¬p). If p is true, ¬p is false.
  • Logical Equivalence: Two propositions are logically equivalent if they have the same truth value in all possible cases.
  • Applications: Used in programming (Boolean logic in conditionals), mathematics, and decision-making to ensure consistent reasoning.
// Example: Proposition in Code
let isLoggedIn = true; // Proposition
let isAdmin = false; // Proposition

if (isLoggedIn && isAdmin) {
    console.log("Access granted");
} else {
    console.log("Access denied");
}
💡 Key insight: Elementary logic provides the tools to analyze and construct valid arguments, essential for problem-solving in mathematics, programming, and everyday reasoning.

Quantifiers

  • Universal Quantifier (∀): "For all" — applies to every element in a set.
    ∀x ∈ ℝ (x² ≥ 0) // For all real numbers x, x² is non-negative
  • Existential Quantifier (∃): "There exists" — applies to at least one element.
    ∃x ∈ ℝ (x² = 9) // There exists a real number x such that x² = 9
  • Negation of Quantifiers:
    ¬∀x P(x) = ∃x ¬P(x) // Negating universal gives existential
    ¬∃x P(x) = ∀x ¬P(x) // Negating existential gives universal

1.4 Quantifiers

Quantifiers specify the scope of variables in logical statements, crucial for precise mathematical and computational reasoning.

Quantifiers in Detail

  • Universal Quantifier (∀): "For all" — statement is true for every element.
    ∀x ∈ ℕ (x + 1 > 0) // For all natural numbers x, x+1 is greater than 0
  • Existential Quantifier (∃): "There exists" — at least one element makes the statement true.
    ∃x ∈ ℤ (x² = 4) // There exists an integer x such that x² = 4 (x = 2 or -2)
  • Nested Quantifiers:
    ∀x ∃y (x + y = 0) // For every x, there exists a y such that x + y = 0

Quantifier Rules

  • Order Matters: ∀x ∃y P(x,y) ≠ ∃y ∀x P(x,y)
  • Negation:
    ¬∀x P(x) = ∃x ¬P(x)
    ¬∃x P(x) = ∀x ¬P(x)
📐 Key insight: Quantifiers are essential for formalizing statements in mathematics, logic, and computer science. They enable precise expression of properties over sets and domains.

1.5 Techniques of Proof

Techniques of proof are methods to establish the truth of mathematical statements, widely used in logic, mathematics, and computer science.

Proof Methods

  • Direct Proof: Assume premises are true and logically derive the conclusion.
    // Prove: If n is even, then n² is even
    // n = 2k (even definition)
    // n² = (2k)² = 4k² = 2(2k²)
    // Therefore, n² is even.
  • Proof by Contradiction: Assume the opposite of the conclusion and derive a contradiction.
    // Prove: √2 is irrational
    // Assume √2 is rational → √2 = a/b in lowest terms
    // Then 2 = a²/b² → a² = 2b²
    // This implies a is even, then b is even → contradiction
  • Mathematical Induction: Prove a base case and the inductive step.
    // Prove: sum of first n natural numbers = n(n+1)/2
    // Base case: n=1 → 1 = 1(2)/2 ✓
    // Inductive step: assume true for n, prove for n+1
  • Counterexample: Disprove a universal statement with one example.
    // Statement: "All primes are odd"
    // Counterexample: 2 is prime and even

1.7 Set Operations, Laws of the Algebra of Sets

Set operations manipulate sets to form new ones, governed by algebraic laws, essential for data analysis and logical reasoning.

Set Operations

OperationSymbolDefinitionExample
UnionA ∪ BElements in A or B{1,2} ∪ {2,3} = {1,2,3}
IntersectionA ∩ BElements in both A and B{1,2} ∩ {2,3} = {2}
DifferenceA \ BElements in A but not B{1,2} \ {2,3} = {1}
ComplementA'Elements not in AIf U={1,2,3}, {1}'={2,3}

Laws of Algebra of Sets

  • Commutative: A ∪ B = B ∪ A, A ∩ B = B ∩ A
  • Associative: (A ∪ B) ∪ C = A ∪ (B ∪ C), (A ∩ B) ∩ C = A ∩ (B ∩ C)
  • Distributive: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C), A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
  • De Morgan's: (A ∪ B)' = A' ∩ B', (A ∩ B)' = A' ∪ B'
  • Idempotent: A ∪ A = A, A ∩ A = A
  • Identity: A ∪ ∅ = A, A ∩ U = A

1.8 Real Number System, Representation on the Real Line

The real number system encompasses all numbers on the number line, used extensively in mathematics and computing for measurements and calculations.

Number System Hierarchy

  • Natural Numbers (ℕ): 1, 2, 3, ... (positive integers)
  • Whole Numbers: 0, 1, 2, 3, ...
  • Integers (ℤ): ..., -2, -1, 0, 1, 2, ...
  • Rational Numbers (ℚ): All numbers expressible as p/q (q ≠ 0)
  • Irrational Numbers: Numbers that cannot be expressed as p/q (e.g., √2, π)
  • Real Numbers (ℝ): All rational and irrational numbers

1.9 Properties of Real Numbers, Ordered Sets, Inequalities

Properties of real numbers and their ordering underpin mathematical operations and comparisons, critical for logical and computational tasks.

Properties of Real Numbers

  • Commutative: a + b = b + a, a × b = b × a
  • Associative: (a + b) + c = a + (b + c), (a × b) × c = a × (b × c)
  • Distributive: a × (b + c) = a × b + a × c
  • Identity: a + 0 = a, a × 1 = a
  • Inverse: a + (-a) = 0, a × (1/a) = 1 (a ≠ 0)

Ordered Sets

  • Total Order: For any a, b, exactly one of a < b, a = b, or a > b holds.
  • Transitivity: If a < b and b < c, then a < c.
  • Addition: If a < b, then a + c < b + c.
  • Multiplication: If a < b and c > 0, then ac < bc.

Inequalities

// |x - 3| < 5

Cartesian Product and Relation

  • Cartesian Product (A × B): Set of all ordered pairs (a, b) where a ∈ A and b ∈ B.
    A = {1, 2}, B = {a, b}
    A × B = {(1, a), (1, b), (2, a), (2, b)}
  • Relation: A subset of A × B that defines how elements relate to each other.
    R = {(1, a), (2, b)}
    1 R a (1 is related to a)
    2 R b (2 is related to b)
