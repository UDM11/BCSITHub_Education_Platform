3.1 Derivative

The derivative measures the rate at which a function changes at a specific point, forming a cornerstone of calculus with applications in optimization, physics, economics, and machine learning.

📐 Definition
For a function f(x), the derivative at x = a is f'(a) = lim(h→0) [f(a+h) - f(a)]/h, if the limit exists.
📝 Notation
f'(x), dy/dx, df/dx, d/dx[f(x)]. All represent the instantaneous rate of change of f with respect to x.
📊 Geometric Interpretation
The derivative represents the slope of the tangent line to the graph of f(x) at a given point.
💡 Applications
Physics (velocity, acceleration), Economics (marginal cost/revenue), Machine Learning (gradient descent), Optimization.

Formal Definition

// Derivative definition
f'(x) = lim(h→0) [f(x+h) - f(x)]/h

Example

// Find derivative of f(x) = x²
f'(x) = lim(h→0) [(x+h)² - x²]/h
      = lim(h→0) [x² + 2xh + h² - x²]/h
      = lim(h→0) [2xh + h²]/h
      = lim(h→0) [2x + h]
      = 2x

3.2 Average Rate of Change

The average rate of change quantifies how a function's output changes over an interval, serving as a precursor to the instantaneous rate of change (the derivative).

Definition

  • For a function f(x) over [a, b], the average rate of change is [f(b) - f(a)]/(b - a).
  • Represents the slope of the secant line between (a, f(a)) and (b, f(b)).
// Example: Average rate of change
f(x) = x², from x = 1 to x = 3
Average rate = [f(3) - f(1)]/(3 - 1)
          = (9 - 1)/2
          = 4

Applications

  • Business: Average growth rate of revenue over time.
  • Physics: Average velocity over a time interval.
  • Economics: Average cost change per unit.

Relation to Derivative

  • As the interval [a, b] shrinks (b → a), the average rate of change approaches the derivative at x = a.
  • lim(b→a) [f(b) - f(a)]/(b - a) = f'(a)

3.3 Derivative as Slope of the Tangent to Curves

The derivative represents the slope of the tangent line to a curve at a specific point, providing insight into the function's behavior.

Tangent Line

  • The line that touches the curve at a single point (x, f(x)).
  • Has the same slope as the curve at that point, given by f'(x).
  • Equation of tangent line: y - f(a) = f'(a)(x - a)
// Example: Tangent line to f(x) = x² at x = 2
f'(x) = 2x
f'(2) = 4
f(2) = 4
Tangent line: y - 4 = 4(x - 2)
          y = 4x - 4

Geometric Interpretation

  • Positive derivative: Function is increasing (upward slope).
  • Negative derivative: Function is decreasing (downward slope).
  • Zero derivative: Horizontal tangent (possible maximum, minimum, or inflection point).
Tangent Line:
         │
         │     *
         │    * *
         │   *   *  ← Tangent
         │  *     *
         │ *       *
         └───────────

3.4 Methods of Differentiation

Differentiation methods provide systematic ways to compute derivatives of various functions, essential for solving complex problems efficiently.

Power Rule

// If f(x) = xⁿ, then f'(x) = nxⁿ⁻¹
f(x) = x³ → f'(x) = 3x²
f(x) = x⁻² → f'(x) = -2x⁻³

Sum Rule

// If f(x) = g(x) + h(x), then f'(x) = g'(x) + h'(x)
f(x) = x² + 3x → f'(x) = 2x + 3

Product Rule

// If f(x) = g(x)·h(x), then f'(x) = g'(x)·h(x) + g(x)·h'(x)
f(x) = x·sin(x)
f'(x) = 1·sin(x) + x·cos(x) = sin(x) + x·cos(x)

Quotient Rule

// If f(x) = g(x)/h(x), then f'(x) = [g'(x)·h(x) - g(x)·h'(x)]/[h(x)]²
f(x) = x/(x+1)
f'(x) = [(1)(x+1) - x(1)]/(x+1)²
      = (x+1 - x)/(x+1)²
      = 1/(x+1)²

Chain Rule

// If f(x) = g(h(x)), then f'(x) = g'(h(x))·h'(x)
f(x) = (x² + 1)³
g(u) = u³, h(x) = x² + 1
f'(x) = 3(x² + 1)² · 2x = 6x(x² + 1)²

Differentiation Rules Summary

3.5 Differentiation of Implicit and Parametric Functions

Implicit and parametric functions require specialized differentiation techniques, as they are not always expressed as y = f(x).

Implicit Differentiation

  • Used when the equation is not solved for y (e.g., x² + y² = 1).
  • Differentiate both sides with respect to x, treating y as a function of x.
// Implicit differentiation example
x² + y² = 1
2x + 2y·dy/dx = 0
dy/dx = -x/y

Parametric Differentiation

  • Used when x and y are functions of a parameter t: x = f(t), y = g(t).
  • dy/dx = (dy/dt)/(dx/dt) = g'(t)/f'(t)
// Parametric differentiation example
x = t², y = t³
dx/dt = 2t, dy/dt = 3t²
dy/dx = (3t²)/(2t) = (3t)/2

Applications

  • Implicit: Economics (utility functions, constrained optimization).
  • Parametric: Physics (motion), computer graphics (animation curves).

3.6 Derivative as Rate of Change, Higher Order Derivatives

The derivative quantifies instantaneous rates of change, and higher order derivatives provide deeper insights into function behavior.

Rate of Change

  • f'(x) measures how f(x) changes per unit change in x.
  • Examples:
    • Velocity = dx/dt (rate of change of position).
    • Marginal Cost = dC/dq (rate of change of cost).
    • Marginal Revenue = dR/dq (rate of change of revenue).

Higher Order Derivatives

  • Second derivative: f''(x) = d²y/dx² — rate of change of the rate of change (acceleration).
  • Third derivative: f'''(x) = d³y/dx³ — jerk (rate of change of acceleration).
// Higher order derivatives example
f(x) = x⁴
f'(x) = 4x³
f''(x) = 12x²
f'''(x) = 24x
f''''(x) = 24

Applications of Higher Order Derivatives

  • Concavity: f''(x) > 0 → concave up, f''(x) < 0 → concave down.
  • Inflection Points: Points where concavity changes (f''(x) = 0).
  • Optimization: Second derivative test for maxima/minima.
  • Physics: Acceleration (second derivative of position).

Second Derivative Test

  • If f'(c) = 0 and f''(c) > 0 → local minimum.
  • If f'(c) = 0 and f''(c) < 0 → local maximum.
  • If f'(c) = 0 and f''(c) = 0 → test inconclusive.
// Second derivative test example
f(x) = x³ - 3x² + 2
f'(x) = 3x² - 6x = 3x(x - 2)
Critical points: x = 0, x = 2
f''(x) = 6x - 6
f''(0) = -6 < 0 → local maximum at x = 0
f''(2) = 6 > 0 → local minimum at x = 2
📈 Key insight: Higher order derivatives provide deeper insights into function behavior, including concavity, inflection points, and optimization. They are essential for modeling complex systems in physics, economics, and engineering.
