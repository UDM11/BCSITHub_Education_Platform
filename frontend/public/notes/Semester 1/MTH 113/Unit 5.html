5.1 Indefinite Integral (Algebraic, Exponential, Logarithmic, Trigonometric Functions)

The indefinite integral represents the antiderivative of a function, used to find functions whose derivatives yield the given function, with applications in various fields.

📐 Definition
∫f(x)dx = F(x) + C, where F'(x) = f(x). C is the constant of integration. Represents a family of functions.
📊 Applications
Solving differential equations, modeling accumulation, finding areas under curves, and physics applications like work and energy.

5.2 Techniques of Integration (Simplification, Substitution, By Parts)

Techniques of integration simplify the process of finding antiderivatives for complex functions, essential for solving diverse mathematical problems.

Simplification

  • Rewrite the integrand to make integration easier.
  • Example: ∫(x² + 2x)/x dx = ∫(x + 2) dx = x²/2 + 2x + C
  • Use algebraic manipulation before integrating.
// Simplification examples
∫(x³ - 1)/(x - 1) dx = ∫(x² + x + 1) dx = x³/3 + x²/2 + x + C
∫(sin²x + cos²x) dx = ∫1 dx = x + C

Substitution (u-substitution)

  • Change variables to simplify the integral.
  • Let u = g(x), du = g'(x) dx.
  • Example: ∫2x(x² + 1) dx, let u = x² + 1, du = 2x dx → ∫u du = u²/2 + C = (x² + 1)²/2 + C
// Substitution examples
∫x² cos(x³) dx, let u = x³, du = 3x² dx → (1/3)∫cos(u) du = (1/3)sin(u) + C = (1/3)sin(x³) + C

∫e^(2x) dx, let u = 2x, du = 2 dx → (1/2)∫e^u du = (1/2)e^u + C = (1/2)e^(2x) + C

Integration by Parts

  • Based on the product rule: ∫u dv = uv - ∫v du
  • Choose u to simplify when differentiated, dv to integrate easily.
  • Example: ∫x eˣ dx, let u = x, dv = eˣ dx → du = dx, v = eˣ → x eˣ - ∫eˣ dx = x eˣ - eˣ + C
// Integration by parts examples
∫x ln(x) dx, let u = ln(x), dv = x dx
du = (1/x) dx, v = x²/2
= (x²/2)ln(x) - ∫(x²/2)(1/x) dx
= (x²/2)ln(x) - (1/2)∫x dx
= (x²/2)ln(x) - x²/4 + C

∫x² sin(x) dx (requires multiple applications)

Integration Strategy

  • 1. Simplify: Algebraic manipulation first.
  • 2. Substitution: Look for composite functions.
  • 3. Integration by Parts: Products of functions.
  • 4. Trigonometric Identities: For trigonometric integrals.
  • 5. Partial Fractions: For rational functions.

5.3 Definite Integral

The definite integral quantifies the cumulative effect of a function over an interval, with wide applications in mathematics and applied sciences.

Definition

  • ∫ₐᵇ f(x) dx = F(b) - F(a), where F is an antiderivative of f.
  • Represents the signed area under the curve y = f(x) from x = a to x = b.
  • Based on Riemann sums: limit of sum of rectangle areas as width → 0.

Fundamental Theorem of Calculus

  • Part 1: If f is continuous on [a, b], then F(x) = ∫ₐˣ f(t) dt is differentiable and F'(x) = f(x).
  • Part 2: ∫ₐᵇ f(x) dx = F(b) - F(a), where F is any antiderivative.
// Definite integral examples
∫₁² x² dx = [x³/3]₁² = 8/3 - 1/3 = 7/3

∫₀^π sin(x) dx = [-cos(x)]₀^π = -cos(π) + cos(0) = 1 + 1 = 2

∫₀¹ eˣ dx = [eˣ]₀¹ = e - 1

Geometric Interpretation

  • If f(x) ≥ 0 on [a, b], the integral is the area under the curve.
  • If f(x) ≤ 0 on [a, b], the integral is negative (area below x-axis).
  • If f changes sign, the integral is the net signed area.

Properties of definite integrals simplify calculations and provide insights into their behavior, useful in theoretical and applied contexts.

Applications

  • Area Between Curves: ∫ₐᵇ [f(x) - g(x)] dx
  • Average Value: (1/(b-a)) ∫ₐᵇ f(x) dx
  • Physics: Work done, displacement, center of mass.
  • Economics: Consumer surplus, producer surplus.
📐 Key insight: Definite integrals extend the concept of summation to continuous functions. They are fundamental to calculus and have countless applications in science, engineering, and economics.
