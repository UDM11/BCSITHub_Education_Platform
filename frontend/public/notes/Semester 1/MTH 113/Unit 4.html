4.1 Increasing and Decreasing Functions

Increasing and decreasing functions describe how a function's output changes with its input, analyzed using derivatives to understand trends in various applications.

📈 Increasing Functions
A function f(x) is increasing on an interval if f'(x) > 0. As x increases, f(x) increases. Example: f(x) = x² on x > 0 has f'(x) = 2x > 0.
📉 Decreasing Functions
A function f(x) is decreasing on an interval if f'(x) < 0. As x increases, f(x) decreases. Example: f(x) = -x² on x > 0 has f'(x) = -2x < 0.

Monotonicity

  • Strictly Increasing: f'(x) > 0 for all x in the interval.
  • Strictly Decreasing: f'(x) < 0 for all x in the interval.
  • Non-strict (Monotonic): f'(x) ≥ 0 (increasing) or f'(x) ≤ 0 (decreasing), allowing f'(x) = 0 at some points.

Determining Intervals

  • Find critical points where f'(x) = 0 or undefined.
  • Test the sign of f'(x) in each interval.
  • f'(x) > 0 → increasing; f'(x) < 0 → decreasing.
// Example: f(x) = x³ - 3x
f'(x) = 3x² - 3 = 3(x² - 1)
Critical points: x = -1, x = 1
Intervals: (-∞, -1), (-1, 1), (1, ∞)
f'(-2) = 9 > 0 → increasing
f'(0) = -3 < 0 → decreasing
f'(2) = 9 > 0 → increasing
📊 Key insight: The sign of the derivative determines whether a function is increasing or decreasing. This is fundamental for understanding trends in economics, physics, and data analysis.

4.2 Critical Point, Point of Inflection

Critical points and points of inflection are key features of a function's graph, identified using derivatives to analyze behavior.

Critical Points

  • Definition: Points where f'(x) = 0 or f'(x) is undefined.
  • Potential locations of local maxima, minima, or stationary points.
  • Example: f(x) = x³ → f'(x) = 3x² = 0 at x = 0 (stationary point).

Points of Inflection

  • Definition: Points where f''(x) = 0 or undefined and concavity changes.
  • Example: f(x) = x³ → f''(x) = 6x = 0 at x = 0, concavity changes from concave down to concave up.

Testing Critical Points

  • First Derivative Test: Check sign change of f'(x) around critical points.
    • Positive to negative → local maximum.
    • Negative to positive → local minimum.
    • No sign change → stationary point (inflection).
  • Second Derivative Test: Use f''(x) at critical points.
    • f''(x) > 0 → local minimum.
    • f''(x) < 0 → local maximum.
    • f''(x) = 0 → test inconclusive.
// Example: f(x) = x⁴ - 4x³
f'(x) = 4x³ - 12x² = 4x²(x - 3)
Critical points: x = 0, x = 3
f''(x) = 12x² - 24x = 12x(x - 2)
f''(3) = 36 > 0 → local minimum at x = 3
f''(0) = 0 → inconclusive, check first derivative
f'(-1) = -16, f'(1) = -8 → both negative, no sign change → inflection at x = 0

4.3 Maximum and Minimum Value of Functions

Maximum and minimum values of functions, found using derivatives, are critical for optimization problems in mathematics and applied fields.

Local Extrema

  • Occur at critical points where f'(x) = 0 or undefined.
  • Second Derivative Test:
    • f''(x) > 0 → local minimum.
    • f''(x) < 0 → local maximum.

Global (Absolute) Extrema

  • The highest/lowest value of f(x) on a given domain.
  • Check:
    • Critical points within the domain.
    • Endpoints of the domain (for closed intervals).
// Example: f(x) = x³ - 3x² + 2, on [-1, 3]
f'(x) = 3x² - 6x = 3x(x - 2)
Critical points: x = 0, x = 2
f(-1) = -1 - 3 + 2 = -2
f(0) = 2
f(2) = 8 - 12 + 2 = -2
f(3) = 27 - 27 + 2 = 2
Global maximum: f(0) = 2, f(3) = 2
Global minimum: f(-1) = -2, f(2) = -2

First Derivative Test

  • Analyze sign changes of f'(x) around critical points.
  • Positive → Negative: local maximum.
  • Negative → Positive: local minimum.

4.4 Marginal Analysis in Business and Economics

Marginal analysis uses derivatives to evaluate incremental changes in business and economic variables, aiding decision-making.

Marginal Concepts

  • Marginal Cost (MC): C'(q) — cost of producing one additional unit.
    C(q) = 100 + 5q → MC = C'(q) = 5
  • Marginal Revenue (MR): R'(q) — revenue from one additional unit sold.
    R(q) = 50q - q² → MR = R'(q) = 50 - 2q
  • Marginal Profit (MP): P'(q) — additional profit from one more unit.
    P(q) = R(q) - C(q) → MP = P'(q) = MR - MC

Profit Maximization

  • Profit is maximized where P'(q) = 0 → MR = MC.
  • Second derivative test: P''(q) < 0 ensures maximum.
// Profit maximization example
R(q) = 100q - 2q², C(q) = 20q + 100
P(q) = (100q - 2q²) - (20q + 100) = -2q² + 80q - 100
P'(q) = -4q + 80 = 0 → q = 20
P''(q) = -4 < 0 → maximum
Maximum profit = P(20) = -800 + 1600 - 100 = 700

4.5 Concavity of Functions, Marginal Profit Analysis

Concavity describes the shape of a function's graph, and marginal profit analysis uses derivatives to optimize profitability.

Concavity

  • Concave Up: f''(x) > 0 — graph curves upward (bowl shape).
  • Concave Down: f''(x) < 0 — graph curves downward (cap shape).
  • Inflection Point: f''(x) = 0 and concavity changes.

Marginal Profit Analysis

  • Profit function: P(q) = R(q) - C(q)
  • Marginal profit: P'(q) = R'(q) - C'(q)
  • Maximum profit: P'(q) = 0, P''(q) < 0
  • P''(q) < 0 indicates decreasing marginal returns.
// Concavity and profit analysis
P(q) = -2q² + 80q - 100
P'(q) = -4q + 80
P''(q) = -4 < 0 → concave down, maximum at q = 20
Diminishing returns: P''(q) < 0 means each additional unit adds less profit.

Applications

  • Diminishing Returns: Concave down profit functions indicate diminishing marginal returns.
  • Cost Analysis: Concavity helps identify economies or diseconomies of scale.
  • Optimization: Concavity confirms whether a critical point is a maximum or minimum.

4.6 Mean Value Theorem, Optimization Problems

The Mean Value Theorem and optimization problems use derivatives to analyze function behavior and solve practical challenges.

Mean Value Theorem (MVT)

  • If f(x) is continuous on [a, b] and differentiable on (a, b), then there exists c ∈ (a, b) such that:
    f'(c) = [f(b) - f(a)]/(b - a)
  • Interpretation: There is a point where the instantaneous rate of change equals the average rate of change.
  • Applications: Proving properties of functions, error analysis, and numerical methods.
// MVT example
f(x) = x², on [1, 3]
f(3) = 9, f(1) = 1
Average rate = (9 - 1)/(3 - 1) = 4
f'(c) = 2c = 4 → c = 2 ∈ (1, 3)

Optimization Problems

  • Steps:
    1. Define the objective function (what to optimize).
    2. Express it in terms of one variable.
    3. Find critical points (f'(x) = 0).
    4. Verify using second derivative or boundaries.
// Optimization example: Maximize area with fixed perimeter
// Perimeter: 2x + 2y = 40 → y = 20 - x
// Area: A(x) = x(20 - x) = 20x - x²
A'(x) = 20 - 2x = 0 → x = 10
A''(x) = -2 < 0 → maximum
y = 20 - 10 = 10
Max area = 10 × 10 = 100 square units

Applications of Optimization

  • Business: Maximize profit, minimize cost.
  • Engineering: Minimize material usage, maximize efficiency.
  • Economics: Maximize utility, minimize production costs.
  • Machine Learning: Gradient descent for optimization.
📐 Key insight: The Mean Value Theorem provides a theoretical foundation for many results in calculus. Optimization problems are among the most practical applications of derivatives, used extensively in business, engineering, and science.
