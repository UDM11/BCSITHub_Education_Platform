7.1 Basic Principles of Counting, Factorial Notation

The basic principles of counting provide a foundation for calculating the number of possible outcomes in combinatorial problems, with factorial notation as a key tool.

📊 Fundamental Counting Principle
If one event can occur in m ways and a second in n ways, the total is m × n. Example: 3 shirts × 4 pants = 12 outfits.
➕ Addition Principle
If an event can occur in m ways or another in n ways (mutually exclusive), total is m + n. Example: 3 red + 2 blue shirts = 5 choices.

Factorial Notation

  • Definition: n! = n × (n-1) × (n-2) × ... × 2 × 1
  • Special Cases: 0! = 1, 1! = 1
  • Examples:
    • 5! = 5 × 4 × 3 × 2 × 1 = 120
    • 3! = 6, 4! = 24
    • 6! = 720

  • Fundamental Principle: Number of ways to choose a meal from 3 appetizers, 4 main courses, 2 desserts = 3 × 4 × 2 = 24.
  • Addition Principle: Number of ways to choose a book from 5 fiction or 3 non-fiction = 5 + 3 = 8.
  • Computer Science: Counting algorithm paths, password combinations.
  • Probability: Calculating sample space sizes.

7.2 Permutation, Permutation of Objects Alike

Permutations deal with the arrangement of objects where order matters, including cases where some objects are identical.

Basic Permutations

  • Permutation of n distinct objects: n! ways.
  • Permutation of r objects from n: P(n,r) = n!/(n-r)!
  • Example: P(4,2) = 4!/(4-2)! = 4×3 = 12.

Permutation of Objects Alike

  • Formula: n! / (n₁! × n₂! × ... × nₖ!)
  • Where: n₁, n₂, ... are counts of identical objects.
  • Example: "BOOK" → 4 letters, 2 O's → 4!/2! = 12 arrangements.

7.3 Permutation with Restrictions, Circular Permutation

Permutations with restrictions and circular permutations address specific constraints or arrangements, common in real-world problems.

Permutation with Restrictions

  • Objects Together: Treat as a single unit, then arrange.
  • Objects Apart: Arrange others first, then place restricted objects in gaps.
  • Example: Arranging A, B, C, D with A and B together → (AB) as one unit → 3! × 2! = 12.
  • Example: Arranging A, B, C, D with A and B apart → total 4! - arrangements with A, B together = 24 - 12 = 12.

Circular Permutation

  • Definition: Arrangements around a circle (rotations considered identical).
  • Formula: (n-1)! for n distinct objects.
  • Example: 4 people around a table: (4-1)! = 3! = 6.
// Circular permutation
// Number of ways to seat 5 people around a circular table
(5-1)! = 4! = 24

7.4 Combination, Combination with Restrictions

Combinations focus on selecting objects where order does not matter, including cases with specific constraints.

Basic Combinations

  • Formula: C(n,r) = n!/(r!(n-r)!)
  • Properties:
    • C(n,r) = C(n, n-r)
    • C(n,0) = C(n,n) = 1
    • C(n,1) = n
  • Example: Choosing 3 from 5: C(5,3) = 10.

Combination with Restrictions

  • Include Specific Items: Choose the required items, then select remaining from the rest.
  • Exclude Specific Items: Remove them from the pool before selecting.
  • At Least/At Most: Sum over valid ranges.
// Combination examples
// C(n,r) = n!/(r!(n-r)!)

// Example 1: Choose 2 from 5
C(5,2) = 5!/(2!×3!) = 120/12 = 10

// Example 2: Choose 3 from 7
C(7,3) = 7!/(3!×4!) = 5040/(6×24) = 35

// Restrictions: Choose 2 from 5, must include A
C(4,1) = 4

// Restrictions: Choose 2 from 5, exclude A
C(4,2) = 6

📐 Key insight: Permutations are for arrangements where order matters; combinations are for selections where order doesn't matter. The relationship P(n,r) = C(n,r) × r! connects the two concepts.
