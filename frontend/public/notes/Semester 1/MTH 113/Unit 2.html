2.1 Constants and Variables, Concept of Functions

Constants, variables, and functions form the foundation of mathematical modeling, essential for describing relationships in mathematics, computer science, and economics.

🔢 Constants
Fixed values that do not change, such as π or 5. Used as reference points in equations and models.
📊 Variables
Symbols representing quantities that can change, such as x or y, allowing flexibility in mathematical expressions.
📈 Functions
A rule that assigns each input to exactly one output. Denoted as f(x), e.g., f(x) = x² maps x to x².
📋 Notation
Functions are expressed as equations, tables, or graphs. f(x) indicates the output for input x.

Definition of a Function

  • A function is a relation between a set of inputs (domain) and a set of possible outputs (range) where each input is related to exactly one output.
  • Notation: f: A → B (f maps from set A to set B)
  • Example: f(x) = 2x + 3 — for every input x, there is exactly one output 2x + 3.
  • Vertical Line Test: A graph represents a function if any vertical line intersects the graph at most once.
// Function examples
f(x) = x² + 1 // Quadratic function
g(x) = 3x - 5 // Linear function
h(x) = |x| // Absolute value function
p(x) = 2^x // Exponential function
💡 Key insight: Understanding constants, variables, and functions is essential for modeling real-world relationships, from simple calculations to complex economic and scientific models.

2.2 Domain and Range of a Function

The domain and range define the scope and output of a function, critical for understanding its behavior and applicability.

Domain

  • Definition: The set of all possible input values (x) for which the function is defined.
  • Restrictions:
    • Division by zero: f(x) = 1/x → x ≠ 0
    • Even roots: f(x) = √x → x ≥ 0
    • Logarithms: f(x) = ln(x) → x > 0

Range

  • Definition: The set of all possible output values (f(x)) produced by the function.
  • Examples:
    • f(x) = x² → range: [0, ∞)
    • f(x) = sin(x) → range: [-1, 1]
    • f(x) = e^x → range: (0, ∞)

2.3 Types of Functions (Algebraic, Logarithmic, Trigonometric, Exponential)

Different types of functions serve distinct purposes in modeling phenomena, each with unique properties and applications.

Algebraic Functions

  • Polynomial: f(x) = aₙxⁿ + ... + a₁x + a₀ (e.g., f(x) = x² + 2x + 1)
  • Rational: f(x) = p(x)/q(x) (e.g., f(x) = 1/x)
  • Root: f(x) = ⁿ√x (e.g., f(x) = √x)

Logarithmic Functions

  • Form: f(x) = log_b(x) where b > 0, b ≠ 1
  • Natural Log: f(x) = ln(x) (base e)
  • Common Log: f(x) = log(x) (base 10)
  • Applications: Information theory, economics, exponential decay

Trigonometric Functions

  • Primary: sin(x), cos(x), tan(x)
  • Reciprocal: csc(x), sec(x), cot(x)
  • Applications: Signal processing, engineering, physics

Exponential Functions

  • Form: f(x) = a^x where a > 0, a ≠ 1
  • Natural Exponential: f(x) = e^x
  • Applications: Compound interest, population growth, radioactive decay

2.4 Graphic Representation

Graphic representation visualizes functions, revealing their behavior, trends, and key features through plots and graphs.

Key Features of Graphs

  • Intercepts: Points where the graph crosses axes (x-intercepts and y-intercepts).
  • Vertex: Turning point of a parabola (minimum or maximum).
  • Asymptotes: Lines that the graph approaches but never touches.
  • Periodicity: Pattern that repeats at regular intervals (trigonometric functions).
  • Symmetry: Even (y-axis) or odd (origin) symmetry.

Graphing Techniques

  • Table of Values: Plot points by evaluating f(x) for selected x values.
  • Transformations: Shift, stretch, or reflect basic graphs.
    • Vertical shift: f(x) + k
    • Horizontal shift: f(x - h)
    • Vertical stretch: a·f(x)
    • Reflection: -f(x) or f(-x)

2.5 Application of Functions to Business and Economics

Functions model relationships in business and economics, enabling analysis and prediction of financial and operational outcomes.

Business Functions

  • Cost Function: C(q) = Fixed Cost + Variable Cost × q
    C(q) = 100 + 5q // q = quantity produced
  • Revenue Function: R(q) = Price × q
    R(q) = 20q // Price = $20 per unit
  • Profit Function: P(q) = R(q) - C(q)
    P(q) = 20q - (100 + 5q) = 15q - 100
  • Demand Function: q = D(p) = 100 - 2p (quantity demanded at price p)
  • Supply Function: q = S(p) = 3p - 20 (quantity supplied at price p)

Break-Even Analysis

  • Break-Even Point: R(q) = C(q)
  • Example: 20q = 100 + 5q → 15q = 100 → q = 6.67 units
// Profit maximization
// R(q) = 50q - 2q², C(q) = 20q + 100
// P(q) = (50q - 2q²) - (20q + 100)
// P(q) = -2q² + 30q - 100
// Maximum at q = -b/(2a) = -30/(2(-2)) = 7.5

2.6 Limit of a Function, Properties of Limit

The limit of a function describes its behavior as the input approaches a specific value, foundational for calculus and analytical modeling.

Formal Definition

  • lim(x→a) f(x) = L means: for every ε > 0, there exists δ > 0 such that |f(x) - L| < ε whenever 0 < |x - a| < δ.
  • Intuitively: f(x) gets arbitrarily close to L as x approaches a.

Properties of Limits

// Let lim(x→a) f(x) = L and lim(x→a) g(x) = M

// 1. Sum: lim(f(x) + g(x)) = L + M
// 2. Difference: lim(f(x) - g(x)) = L - M
// 3. Product: lim(f(x) · g(x)) = L · M
// 4. Quotient: lim(f(x) / g(x)) = L / M, if M ≠ 0
// 5. Constant Multiple: lim(c·f(x)) = c·L
// 6. Power: lim(f(x)ⁿ) = Lⁿ

Evaluating Limits

  • Direct Substitution: If f(a) is defined, lim(x→a) f(x) = f(a)
  • Factoring: For 0/0 forms, factor and cancel.
  • Rationalization: Multiply by conjugate for radical expressions.
// Limit examples
// 1. Direct substitution
lim(x→2) (x² + 3) = 4 + 3 = 7

// 2. Factoring
lim(x→1) (x² - 1)/(x - 1) = lim(x→1) (x+1)(x-1)/(x-1) = lim(x→1) (x+1) = 2

// 3. Rationalization
lim(x→4) (√x - 2)/(x - 4) = lim(x→4) 1/(√x + 2) = 1/4

2.7 Limits of Polynomial and Rational Functions

Limits of polynomial and rational functions are computed using algebraic techniques, critical for understanding their behavior in mathematical models.

Polynomial Functions

  • For any polynomial f(x), lim(x→a) f(x) = f(a) (direct substitution works everywhere).
  • Example: lim(x→2) (3x² - 2x + 1) = 3(4) - 4 + 1 = 9

Rational Functions

  • If q(a) ≠ 0: lim(x→a) p(x)/q(x) = p(a)/q(a)
  • If q(a) = 0: Factor and cancel if possible.
// Rational function limits

// Case 1: q(a) ≠ 0
lim(x→2) (x² + 1)/(x - 1) = (4 + 1)/(1) = 5

// Case 2: q(a) = 0 (factor)
lim(x→2) (x² - 4)/(x - 2) = lim(x→2) (x+2)(x-2)/(x-2) = lim(x→2) (x+2) = 4

2.8 Limits at Infinity

Limits at infinity describe a function's behavior as the input grows arbitrarily large or small, useful for analyzing long-term trends.

Definition

  • lim(x→∞) f(x) = L: f(x) approaches L as x increases without bound.
  • lim(x→−∞) f(x) = L: f(x) approaches L as x decreases without bound.

Rules for Polynomials

  • lim(x→∞) aₙxⁿ = ∞ if aₙ > 0, −∞ if aₙ < 0 (for n even, sign matters; for n odd, sign matters).

Rules for Rational Functions

  • Let f(x) = p(x)/q(x) where deg(p) = m, deg(q) = n.
  • If m < n: lim(x→∞) f(x) = 0
  • If m = n: lim(x→∞) f(x) = leading coefficient ratio
  • If m > n: lim(x→∞) f(x) = ±∞
// Limits at infinity examples

// deg(p) < deg(q)
lim(x→∞) (2x)/(x² + 1) = 0

// deg(p) = deg(q)
lim(x→∞) (3x² + 2)/(2x² - 1) = 3/2

// deg(p) > deg(q)
lim(x→∞) (x³ + 1)/(x² + 1) = ∞

2.9 Continuity, Continuity at a Point

Continuity describes a function's smoothness, ensuring no breaks or jumps, vital for reliable mathematical and computational models.

Definition of Continuity

A function f is continuous at x = a if:

  1. f(a) is defined.
  2. lim(x→a) f(x) exists.
  3. lim(x→a) f(x) = f(a).

Types of Discontinuities

  • Removable: The discontinuity can be removed by redefining f(a).
  • Jump: Left-hand and right-hand limits exist but differ.
  • Infinite: Function approaches ±∞ as x approaches a.
// Continuity examples

// Continuous function
f(x) = x² + 1 // All real numbers

// Removable discontinuity
f(x) = (x² - 1)/(x - 1), x ≠ 1
// Define f(1) = 2 to make continuous

// Jump discontinuity
f(x) = { 1, if x ≥ 0
      { -1, if x < 0
// No limit at x = 0

Continuity on an Interval

  • A function is continuous on an interval if it is continuous at every point in the interval.
  • Polynomials, exponential, logarithmic, and trigonometric functions are continuous on their domains.
  • Rational functions are continuous where the denominator is non-zero.

2.10 Business Application of Limit

Limits have practical applications in business, enabling precise analysis of trends, costs, and performance metrics.

Applications

  • Marginal Analysis:
    Marginal Cost = lim(Δq→0) [C(q+Δq) - C(q)]/Δq
    Marginal Revenue = lim(Δq→0) [R(q+Δq) - R(q)]/Δq
  • Break-Even Points: Analyze behavior near critical points.
  • Market Saturation: lim(q→∞) D(q) = 0 for diminishing demand.
  • Forecasting Trends: Predict steady-state outcomes for investment decisions.
