2.1 Bisection Method

The Bisection Method is a bracketing method based on the Intermediate Value Theorem: if a continuous function f(x) changes sign over an interval [a, b] (meaning f(a) * f(b) < 0), then there exists at least one real root in that interval.

Derivation of Maximum Iterations Formula:

In each step, the interval width is halved. After N iterations, the width of the final interval containing the root is:


Width = (b - a) / 2^N

To achieve a tolerance 'E', we require:
(b - a) / 2^N <= E
2^N >= (b - a) / E

Taking the base-2 logarithm of both sides:
N >= log2((b - a) / E)

This formula allows us to pre-calculate the exact number of iterations required to guarantee a specified tolerance.

Bisection Method C Implementation:


#include <stdio.h>
#include <math.h>

// Define function f(x) = x^3 - x - 2
double f(double x) {
    return x*x*x - x - 2.0;
}

void bisection(double a, double b, double tol) {
    if (f(a) * f(b) >= 0) {
        printf("Error: Function does not change signs in interval [%lf, %lf]\n", a, b);
        return;
    }
    
    double c = a;
    int iter = 1;
    printf("%-10s %-12s %-12s %-12s %-12s\n", "Iter", "a", "b", "c (Mid)", "f(c)");
    
    while ((b - a) >= tol) {
        c = (a + b) / 2.0;
        printf("%-10d %-12.6f %-12.6f %-12.6f %-12.6f\n", iter++, a, b, c, f(c));
        
        if (fabs(f(c)) < 1e-9) {
            break;
        } else if (f(c) * f(a) < 0) {
            b = c;
        } else {
            a = c;
        }
    }
    printf("\nRoot found by Bisection: %lf\n", c);
}

int main() {
    bisection(1.0, 2.0, 0.0001);
    return 0;
}

2.2 False Position (Regula Falsi) Method

The False Position Method connects the points (a, f(a)) and (b, f(b)) with a straight line. The intersection of this line with the x-axis provides the next root estimate c, which is closer to the root than the simple midpoint.

Formula Derivation:

The slope of the line connecting (a, f(a)) and (b, f(b)) is:
Slope = [ f(b) - f(a) ] / (b - a)

Using point-slope form with the intersection point (c, 0):
0 - f(b) = Slope * (c - b)
-f(b) = ( (f(b) - f(a)) / (b - a) ) * (c - b)

Rearranging for c yields:
c = b - [ f(b) * (b - a) ] / [ f(b) - f(a) ]

False Position C Implementation:


#include <stdio.h>
#include <math.h>

double f(double x) {
    return x*x*x - x - 2.0;
}

void falsePosition(double a, double b, double tol) {
    if (f(a) * f(b) >= 0) {
        printf("Error: Sign change condition not met.\n");
        return;
    }
    
    double c = a;
    int iter = 1;
    printf("%-10s %-12s %-12s %-12s %-12s\n", "Iter", "a", "b", "c (Regula)", "f(c)");
    
    for (int i = 0; i < 100; i++) {
        c = (a * f(b) - b * f(a)) / (f(b) - f(a));
        printf("%-10d %-12.6f %-12.6f %-12.6f %-12.6f\n", iter++, a, b, c, f(c));
        
        if (fabs(f(c)) < tol) {
            break;
        }
        
        if (f(c) * f(a) < 0) {
            b = c;
        } else {
            a = c;
        }
    }
    printf("\nRoot found by Regula Falsi: %lf\n", c);
}

int main() {
    falsePosition(1.0, 2.0, 0.0001);
    return 0;
}

2.3 Newton-Raphson Method

An open method that uses the value of the function and its first derivative at a single point to approximate the root.

Proof of Quadratic Convergence (Order = 2):

Let r be the true root such that f(r) = 0.
Let e_i = x_i - r represent the error at iteration i.

Using Taylor series to expand f(r) around the current guess x_i:
f(r) = f(x_i - e_i) = f(x_i) - e_i * f'(x_i) + (e_i^2 / 2) * f''(c) = 0 (where c is between r and x_i)

Rearranging terms:
f(x_i) = e_i * f'(x_i) - (e_i^2 / 2) * f''(c)

Now substitute this expression into the Newton-Raphson iteration formula:
x_i+1 = x_i - f(x_i) / f'(x_i)
x_i+1 - r = x_i - r - [ e_i * f'(x_i) - (e_i^2 / 2) * f''(c) ] / f'(x_i)
e_i+1 = e_i - e_i + (e_i^2 / 2) * ( f''(c) / f'(x_i) )
e_i+1 = e_i^2 * [ f''(c) / (2 * f'(x_i)) ]

This shows that the error in the next iteration e_i+1 is proportional to the square of the current error e_i^2.
Order of Convergence = 2 (Quadratic Convergence).

Newton-Raphson C Implementation:


#include <stdio.h>
#include <math.h>

double f(double x) {
    return x*x*x - x - 2.0;
}

double df(double x) {
    return 3.0*x*x - 1.0;
}

void newtonRaphson(double x0, double tol) {
    double x1 = x0;
    int iter = 1;
    printf("%-10s %-15s %-15s %-15s\n", "Iter", "x_i", "f(x_i)", "f'(x_i)");
    
    while (1) {
        double fx = f(x0);
        double dfx = df(x0);
        
        if (fabs(dfx) < 1e-9) {
            printf("Error: Slope is zero. Method fails.\n");
            return;
        }
        
        x1 = x0 - fx / dfx;
        printf("%-10d %-15.6f %-15.6f %-15.6f\n", iter++, x0, fx, dfx);
        
        if (fabs(x1 - x0) < tol) {
            break;
        }
        x0 = x1;
    }
    printf("\nRoot found by Newton-Raphson: %lf\n", x1);
}

int main() {
    newtonRaphson(1.5, 0.0001);
    return 0;
}

2.4 Secant Method

Similar to Newton-Raphson but approximates the derivative using two previous points rather than evaluating it analytically.

Secant Method C Implementation:


#include <stdio.h>
#include <math.h>

double f(double x) {
    return x*x*x - x - 2.0;
}

void secant(double x0, double x1, double tol) {
    double x2;
    int iter = 1;
    printf("%-10s %-15s %-15s %-15s\n", "Iter", "x0", "x1", "x2");
    
    while (1) {
        double fx0 = f(x0);
        double fx1 = f(x1);
        
        if (fabs(fx1 - fx0) < 1e-9) {
            printf("Error: division by zero.\n");
            return;
        }
        
        x2 = x1 - fx1 * (x1 - x0) / (fx1 - fx0);
        printf("%-10d %-15.6f %-15.6f %-15.6f\n", iter++, x0, x1, x2);
        
        if (fabs(x2 - x1) < tol) {
            break;
        }
        x0 = x1;
        x1 = x2;
    }
    printf("\nRoot found by Secant: %lf\n", x2);
}

int main() {
    secant(1.0, 2.0, 0.0001);
    return 0;
}

2.5 Fixed Point Iteration Method

Solves f(x) = 0 by rewriting it in the form x = g(x) and iterating: x_i+1 = g(x_i).

Convergence proof & criteria:

Let r be the fixed point such that r = g(r).
The error in step i+1 is:
e_i+1 = x_i+1 - r = g(x_i) - g(r)

Applying the Mean Value Theorem to the right side:
g(x_i) - g(r) = g'(c) * (x_i - r) (where c is between x_i and r)
e_i+1 = g'(c) * e_i

Taking absolute values:
|e_i+1| = |g'(c)| * |e_i|

For the error to decrease with each iteration (converge), we require:
|g'(x)| < 1 in the interval enclosing the root.

Fixed Point Iteration C Implementation:


#include <stdio.h>
#include <math.h>

// f(x) = x^3 - x - 2 = 0
// We choose g(x) = (x + 2)^(1/3)
// Check derivative: g'(x) = (1/3)*(x + 2)^(-2/3)
// Near x=1.5, g'(1.5) = (1/3)*(3.5)^(-2/3) ≈ 0.14 < 1 (guaranteed to converge)
double g(double x) {
    return cbrt(x + 2.0);
}

void fixedPoint(double x0, double tol) {
    double x1;
    int iter = 1;
    printf("%-10s %-15s %-15s\n", "Iter", "x_i", "x_i+1");
    
    while (1) {
        x1 = g(x0);
        printf("%-10d %-15.6f %-15.6f\n", iter++, x0, x1);
        if (fabs(x1 - x0) < tol) {
            break;
        }
        x0 = x1;
    }
    printf("\nRoot found by Fixed Point: %lf\n", x1);
}

int main() {
    fixedPoint(1.5, 0.0001);
    return 0;
}
