Unit 6: Fixed Point Computer Arithmetic [5 Hours] - Detailed Study Guide

6.1 Signed Binary Representation Ranges

Computer systems represent signed numbers using a fixed number of bits (usually N bits). The range of numbers that can be represented in each form is:

  • Signed Magnitude: Range: -(2^(N-1) - 1) to +(2^(N-1) - 1).
    For 8 bits: -127 to +127.
  • 1's Complement: Range: -(2^(N-1) - 1) to +(2^(N-1) - 1).
    For 8 bits: -127 to +127.
  • 2's Complement: Range: -2^(N-1) to +(2^(N-1) - 1).
    For 8 bits: -128 to +127. This form is asymmetric but offers an extra negative value and avoids the dual representation of zero.

Arithmetic Overflow (V-Flag) Logic:

An overflow occurs when the sum of two positive numbers is negative, or the sum of two negative numbers is positive. It is detected using the carries generated in the final stage:

Overflow Boolean Formula: V = C_n-1 XOR C_n
Where C_n is the carry-out of the sign bit, and C_n-1 is the carry-in to the sign bit. If they are different, V = 1, indicating an arithmetic overflow has occurred.

6.2 Booth's Multiplication Algorithm

Booth's Algorithm is a multiplication algorithm that multiplies two signed binary numbers in 2's complement representation. It optimizes multiplication by grouping consecutive 1s or 0s, replacing multiple additions with single additions and subtractions.

Booth's Hardware Components:

  • Register BR: Holds the multiplicand.
  • Register QR: Holds the multiplier.
  • Register A: Accumulator register (initially cleared to 0).
  • Flip-Flop Qn+1: Holds the shifted-out LSB bit of QR during the previous step (initially 0).
  • Sequence Counter (SC): Set to the word size (N).

Detailed Trace Example (-5 * -4):

Let Multiplicand BR = -5 (2's complement of 5: 1011), 2's complement of BR: BR' + 1 = 0101.
Let Multiplier QR = -4 (2's complement of 4: 1100).
Sequence Counter SC = 4. Initialize registers A = 0000, Qn+1 = 0.

Step A QR Qn+1 SC Operation Checked Action Taken
Start 0000 1100 0 4 Initial State Initialization
1 0000 1100 0 4 Qn Qn+1 = 00 ASHR (Shift right A & QR)
1 Shift 0000 0110 0 3 - A=0000, QR=0110, Qn+1=0
2 0000 0110 0 3 Qn Qn+1 = 00 ASHR (Shift right A & QR)
2 Shift 0000 0011 0 2 - A=0000, QR=0011, Qn+1=0
3 0000 0011 0 2 Qn Qn+1 = 10 A = A - BR (Add 0101)
3 Add 0101 0011 0 2 - Addition completed
3 Shift 0010 1001 1 1 - ASHR: A=0010, QR=1001, Qn+1=1
4 0010 1001 1 1 Qn Qn+1 = 11 ASHR only (Shift right A & QR)
4 Shift 0001 0100 1 0 - ASHR: A=0001, QR=0100, Qn+1=1

Final Product Result: A & QR = 0001 0100 (Hex 14, Decimal +20).
Verify: -5 * -4 = +20. The algorithm yielded the correct positive product under 2's complement arithmetic!

6.3 Restoring Division Algorithm

Restoring division performs division on unsigned binary integers by shifting left and subtracting. If the remainder becomes negative, it is restored by adding the divisor back.

Step-by-Step Numerical Example (Divide 11 by 3):

Let Dividend Q = 11 (1011), Divisor B = 3 (0011), 2's complement of B: B' + 1 = 1101.
Initialize registers A = 0000, Sequence Counter SC = 4.

Cycle A Q SC Operation / Action
Start 0000 1011 4 Initial State
1 0001 011_ 4 shl AQ (Shift Left)
1 Sub 1110 011_ 4 A = A - B (0001 + 1101 = 1110, Negative)
1 Rest 0001 0110 3 Restore A (A + B), set Q0 = 0
2 0010 110_ 3 shl AQ (Shift Left)
2 Sub 1111 110_ 3 A = A - B (0010 + 1101 = 1111, Negative)
2 Rest 0010 1100 2 Restore A (A + B), set Q0 = 0
3 0101 100_ 2 shl AQ (Shift Left)
3 Sub 0010 100_ 2 A = A - B (0101 + 1101 = 0010, Positive)
3 Set 0010 1001 1 No restore, set Q0 = 1
4 0101 001_ 1 shl AQ (Shift Left)
4 Sub 0010 001_ 1 A = A - B (0101 + 1101 = 0010, Positive)
4 Set 0010 0011 0 No restore, set Q0 = 1

Final Outputs:
Quotient in Q = 0011 (Decimal 3).
Remainder in A = 0010 (Decimal 2).
Verify: 11 = (3 * 3) + 2. Correct!

6.4 Non-Restoring Division Algorithm

Non-Restoring Division avoids the intermediate restoring addition step. Instead of restoring A when a remainder becomes negative, it leaves A negative and performs addition in the subsequent shift cycle, reducing control complexity.

Non-Restoring Rules:

  • If A is Positive (MSB is 0): Shift AQ left, then subtract divisor B (A <- A - B).
  • If A is Negative (MSB is 1): Shift AQ left, then add divisor B (A <- A + B).
  • If the final remainder A is negative at the end of all steps, one restoring addition A <- A + B is performed to correct the remainder sign.
