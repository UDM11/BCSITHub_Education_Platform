Unit 1: Introduction to Microprocessor [9 Hours] - Detailed Study Guide

1.1 Introduction, Basic Terminology, and System Architecture

A microprocessor is a multipurpose, programmable, clock-driven, register-based electronic integrated circuit (IC) that acts as the CPU of a computer system. It reads binary instructions from a storage device called memory, accepts binary data as input, processes data according to those instructions, and provides results as output.

Key Operational Concepts:

  • Multipurpose: The processor is not hardwired for a single application; it can execute varied software algorithms.
  • Clock-Driven: The processor requires a clock signal to synchronize all internal operations. The clock frequency (measured in Megahertz or Gigahertz) dictates the instruction execution speed.
  • Register-Based: The CPU contains high-speed internal memory cells (registers) to temporarily hold addresses, instruction opcodes, and intermediate calculation data.

A typical computer system has three main hardware components connected by system buses:

1.2 System Bus Organization & Communication

A bus is a shared collection of physical wires used to transmit signals between the microprocessor, memory chips, and I/O interface units. The shared communication structure is called the System Bus Organization.

1. The Address Bus:

  • Direction: Unidirectional. Signals originate only from the CPU.
  • Function: Used by the microprocessor to select a specific memory location or I/O port address for data transfer.
  • Sizing: The number of address lines determines the maximum memory capacity the CPU can address directly. If there are N address lines, the CPU can address 2^N locations.
    For example, the Intel 8085 has a 16-bit address bus, enabling it to access 2^16 = 65,536 bytes = 64KB of memory. The Intel 8086 has a 20-bit address bus, accessing 2^20 = 1,048,576 bytes = 1MB.

2. The Data Bus:

  • Direction: Bidirectional. Data can flow into the CPU (read operation) or out of the CPU (write operation).
  • Function: Used to transfer the actual data values between the registers of the CPU, memory, and peripheral chips.
  • Sizing: The data bus width defines the word size of the processor. An 8-bit data bus (like 8085) transfers 1 byte per read/write cycle, while a 64-bit data bus transfers 8 bytes.

3. The Control Bus:

  • Direction: Bidirectional/Unidirectional depending on lines.
  • Function: Transmits control, status, and synchronization signals.
  • Key Signals:
    • MEMR (Memory Read): Initiates a memory read action.
    • MEMW (Memory Write): Initiates a memory write action.
    • IOR (I/O Read): Initiates a read action from an input port.
    • IOW (I/O Write): Initiates a write action to an output port.
    • RDY (Ready): Used by slow memories/I/O devices to insert Wait States.
    • ALE (Address Latch Enable): Demultiplexes combined address/data buses.

Tri-State Logic and Bus Buffering:

Because multiple devices share the same data and address buses, they must use tri-state buffers to prevent bus contention. A tri-state gate has three states: Logical 0, Logical 1, and High-Impedance (Hi-Z). In Hi-Z state, the device is electrically disconnected from the bus line, allowing another active device to communicate.

1.3 The Stored Program Concept & Control Unit Architectures

The Stored Program Concept (originally defined by Von Neumann) mandates that instruction codes and data codes reside in the same physical memory space. This allows the computer to alter its execution path dynamically and treat programs as data.

The Basic CPU Processing Cycle:

The execution of any instruction consists of three basic phases:

+-----------------------------------------------------------------+ | 1. FETCH | | Read opcode byte from memory address stored in Program Counter | | (PC) into Instruction Register (IR). Increment PC. | +-------------------------------+---------------------------------+ | v +-----------------------------------------------------------------+ | 2. DECODE | | Control Unit translates opcode bits into specific control lines| | and calculates memory addresses of operands. | +-------------------------------+---------------------------------+ | v +-----------------------------------------------------------------+ | 3. EXECUTE | | ALU performs operation, transfers data, or jumps to branches. | +-----------------------------------------------------------------+

Control Unit Implementations: Hardwired vs. Microprogrammed

The Control Unit (CU) generates control sequences. It is implemented in one of two ways:

Hardwired Control Unit:

Uses digital circuit gates, decoders, and counter circuits to generate timing control pulses. The hardware wiring directly maps the instruction code to control line outputs.

  • Speed: Fast. Minimal propagation delays.
  • Design: Complex to design and debug.
  • Flexibility: Low. Changing instruction behavior requires physical IC layout redesign.
  • Use Case: Preferred in RISC architectures to achieve single-cycle executions.

Microprogrammed Control Unit:

Uses a microprogram stored in a dedicated internal memory segment called Control Memory (ROM). Each macroinstruction (e.g., ADD) translates to an address in Control Memory, executing a microprogram consisting of several microinstructions.

  • Speed: Slow. Requires read operations from the internal Control ROM.
  • Design: Highly structured, simple design.
  • Flexibility: High. Updating or adding instructions only requires writing new microprogram bytes into Control ROM.
  • Use Case: Preferred in CISC architectures to handle variable-length, complex operations.
Key Difference Summary: Hardwired CU uses hardware logic gates to optimize speed, while Microprogrammed CU uses software-like microcode stored in ROM to optimize instruction flexibility.

1.4 SAP-1 (Simple As Possible - 1) Architecture

SAP-1 is an 8-bit computer architecture designed to introduce computer organization, registers, control systems, and instruction cycles.

SAP-1 Components:

  • Program Counter (PC): A 4-bit register that keeps track of the next instruction's address. It counts from 0000 to 1111 (0 to 15 in decimal).
  • Input and MAR (Memory Address Register): The MAR stores the address of the memory location currently being read or written.
  • RAM (Random Access Memory): A 16x8 memory organization (16 addresses, each storing 8 bits of data/instructions).
  • Instruction Register (IR): An 8-bit register. The upper 4 bits represent the Opcode, and the lower 4 bits represent the Address/Operand.
  • Controller-Sequence (Control Unit): Generates the 12 control signals (CON word) to coordinate SAP-1 components.
  • Accumulator (Register A): An 8-bit register that holds input/output data for ALU operations.
  • Adder-Subtracter (ALU): Performs 8-bit addition or subtraction using 2's complement.
  • B Register: Temporary register used to hold the second operand for ALU.
  • Output Register (Output Port): Displays the result of processed data.
  • Binary Display: Row of LEDs connected to the output register.

SAP-1 Control Word (CON Word):

The Controller-Sequence generates a 12-bit control word to enable or disable different registers and buses:


CON Word Bits:
   +----+----+----+----+----+----+----+----+----+----+----+----+
   | Cp | Ep | Lm | Er | Li | Ei | La | Ea | Su | Eu | Lb | Lo |
   +----+----+----+----+----+----+----+----+----+----+----+----+
   
Where:
   Cp : Program Counter Increment Flag (active-high)
   Ep : Program Counter Enable onto Bus (active-high)
   Lm : MAR Load Register Enable (active-low, Lm')
   Er : RAM Read Enable (active-low, Er')
   Li : IR Load Register Enable (active-low, Li')
   Ei : IR Enable onto Bus (active-low, Ei')
   La : Accumulator Load Register Enable (active-low, La')
   Ea : Accumulator Enable onto Bus (active-high)
   Su : Subtract Mode Select (0 = ADD, 1 = SUB)
   Eu : ALU Enable onto Bus (active-high)
   Lb : B Register Load Register Enable (active-low, Lb')
   Lo : Output Register Load Register Enable (active-low, Lo')

FETCH Cycle T-States (T1, T2, T3):

The fetch cycle is identical for all instructions and takes 3 clock cycles:

  • T1 (Address State): Address in PC is loaded into MAR. (PC is enabled, MAR is loaded).
    Active Signals: Ep = 1, Lm' = 0
    Control Word: 0101 1111 0011 (CON = 5F3H)
  • T2 (Increment State): PC is incremented by 1.
    Active Signals: Cp = 1
    Control Word: 1011 1111 0011 (CON = BF3H)
  • T3 (Memory State): RAM contents at MAR address are read onto W-bus and loaded into IR.
    Active Signals: Er' = 0, Li' = 0
    Control Word: 0010 0111 0011 (CON = 273H)

EXECUTION Cycles (T4, T5, T6) for SAP-1 Instructions:

1. LDA (Load Accumulator)

  • T4 (Address to MAR): Lower 4 bits of IR (address) are loaded into MAR.
    Active Signals: Ei' = 0, Lm' = 0 (CON = 1A3H)
  • T5 (RAM to Accumulator): Data from RAM at selected address is loaded into Accumulator.
    Active Signals: Er' = 0, La' = 0 (CON = 2C3H)
  • T6 (NOP): No operation.
    Active Signals: None (CON = 3E3H)

2. ADD (Add to Accumulator)

  • T4 (Address to MAR): Address from IR loaded into MAR.
    Active Signals: Ei' = 0, Lm' = 0 (CON = 1A3H)
  • T5 (RAM to B Register): Data from RAM loaded into B Register.
    Active Signals: Er' = 0, Lb' = 0 (CON = 2E1H)
  • T6 (ALU Sum to Accumulator): ALU output (addition mode) is enabled onto bus and loaded into Accumulator.
    Active Signals: Eu = 1, La' = 0, Su = 0 (CON = 3F7H)

3. SUB (Subtract from Accumulator)

  • T4 (Address to MAR): Address from IR loaded into MAR.
    Active Signals: Ei' = 0, Lm' = 0 (CON = 1A3H)
  • T5 (RAM to B Register): Data from RAM loaded into B Register.
    Active Signals: Er' = 0, Lb' = 0 (CON = 2E1H)
  • T6 (ALU Difference to Accumulator): ALU output (subtraction mode) is enabled onto bus and loaded into Accumulator.
    Active Signals: Eu = 1, La' = 0, Su = 1 (CON = 3FFH)

4. OUT (Output Accumulator)

  • T4 (Accumulator to Output Register): Accumulator contents are loaded into Output Register.
    Active Signals: Ea = 1, Lo' = 0 (CON = 3F2H)
  • T5 (NOP): No operation. (CON = 3E3H)
  • T6 (NOP): No operation. (CON = 3E3H)

5. HLT (Halt)

  • T4: Stops the clock generator. CPU enters standby. (CON = 3E3H with halt triggered)
  • T5: NOP
  • T6: NOP

1.5 SAP-2 Architecture and Advancements

SAP-2 is a significant advancement over the SAP-1 model, addressing its limitations and creating a complete 8-bit microcomputer system.

Key Advancements and Differences:

  • Address Space & RAM: SAP-2 uses a 16-bit address bus and can access up to 64KB (65,536 bytes) of memory. This allows it to support larger programs and separate data regions.
  • Bidirectional Registers: In SAP-2, registers like A, B, and C can both read from and write to the W-bus. They use bidirectional tri-state ports.
  • Additional Registers:
    • C Register: A new general-purpose register.
    • Flags Register: Contains two condition flags: Zero flag (Z) and Sign flag (S). These allow conditional branching.
    • Stack Pointer (SP): A 16-bit register allowing stack operations (PUSH/POP).
  • Instruction Set Expansion: SAP-2 supports a much larger set of instructions, including conditional jumps (JZ, JNZ, JM, JP), immediate loading (MVI), and logical operations (ANA, ORA, XRA).
  • Input/Output Ports: Includes two 8-bit input ports and two 8-bit output ports, allowing interfacing with external peripherals.
